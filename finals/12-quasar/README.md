# 퀘이사 — 별처럼 보인 블랙홀

[영상 재생·다운로드](quasar.mp4)

174.3초, 1080×1920, 30fps, H.264/AAC, −14.0 LUFS. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 썸네일입니다. 비스듬한 강착 원반(안쪽 청백, 바깥 주황), 검은 그림자, 세로 화면을 가로지르는 두 제트, 큰 제목 "퀘이사 / 별처럼 보인 블랙홀"이 이미 보이고, 약 1초에 제목이 머리글로 줄어듭니다.

흐름: "오늘은 별처럼 보이지만 별이 아닌 천체, 퀘이사에 대해 알아볼까요?"(원반에서 약 10⁸배 줌아웃해 망원경 속 흐린 점 하나로, 확대 원으로 그 점의 은하) → 1950년대 전파 망원경과 3C 목록(접시가 하늘을 훑으면 기록 곡선이 솟고 목록 칸이 생김) → 은하 대신 별 같은 점, 스펙트럼의 정체 모를 선 → 1963년 마르턴 슈미트(Maarten Schmidt), 실험실 수소선 무늬가 ×1.158로 늘어나 3C 273의 선과 맞물림 → 이름(quasi-stellar radio source → quasar, quasi는 라틴어 "마치 ~처럼", stellar는 stella "별", 준항성체) → 우주 팽창, 많이 밀릴수록 멀다 → 로그 거리 사다리(태양 8광분 → 약 24억 광년)와 12.9등급 → 역제곱으로 되짚은 밝기, 태양의 약 4조 배 = 우리 은하 아이콘 100개 → 며칠 사이 변하는 밝기 → 큰 공(1광년)은 깜빡임이 2년에 걸쳐 뭉개지고 작은 공(2광일)은 날카로움 → 은하 한가운데로 줌인, 태양의 약 3억 배 블랙홀 → 원반의 차등 회전·마찰 열·중력 우물, 떨어진 높이만큼 빛 → 질량 100칸 중 10칸 대 0.7칸 → 에딩턴 한계 그래프, 질량 손잡이를 올리면 한계선도 올라감 → J0529−4351(2024년 발표, 태양의 약 500조 배, 한계의 약 90%, 하루에 태양 하나) → 1980년 사진의 "별"이 2023년 "퀘이사"로 → 퀘이사 수 모형 곡선(약 100억 년 전 봉우리, 지금은 드묾) → 오해(블랙홀이 빛난다? → 빛은 빠지기 직전 바깥을 도는 기체에서) → 결론(망원경 속 점에서 원반으로 다시 줌인, 끝 제목 유지).

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형 하나에서 나옵니다. 적색이동 λ×(1+z), z = 0.158. 역제곱 밝기와 로그 거리 사다리. 얇은 껍질의 빛 도착 지연이 [0, 2R/c]에 고르게 퍼지는 깜빡임 모형. 원반의 공전 ∝ r^−1.5, 온도 ∝ r^−3/4, 중력 우물 ∝ −1/r. 효율 10% 대 0.7%. L_Edd = 3.3×10⁴ L☉ × M/M☉(3C 273 Γ ≈ 0.4, J0529−4351 Γ ≈ 0.9). 중력 적색이동 g = √(1 − 1/r). 하나의 로그 배율로 원반·제트·은하·망원경 시야를 잇는 줌.
- 단순화: 원반·제트·블랙홀의 크기 비율과 기체 덩어리의 크기·속도는 화면용입니다. 원반 색은 온도의 경향만 나타냅니다. 스펙트럼은 수소선 네 개만 그린 모식도이고, 거리는 광도 거리(약 24억 광년)로 통일했습니다. 큰 공·작은 공 깜빡임은 빛의 이동 시간 개념도이며 실제 변광 곡선이 아닙니다. 퀘이사 수 곡선은 설명용 모형 곡선입니다. 숙주 은하는 나선으로 그렸지만 3C 273의 실제 숙주는 타원 은하에 가깝습니다. 1980년 사진은 합성한 그림입니다. 1962년 달 엄폐 관측은 넣지 않았습니다. 상세는 [에피소드 README](../../episodes/quasar/README.md)와 [제작 메모](../../episodes/quasar/brief.md).
- 소리: 원반은 165 Hz 소용돌이 음, 전파 잡음은 빔이 받는 신호 세기, 수소선 음은 1/λ에 비례(Hβ = 260 Hz)해 "밀려"에서 정확히 1/1.158만큼 내려갑니다. 은하 음은 330/(1+z) Hz라 먼 은하일수록 낮습니다. 두 공의 깜빡임은 밝기 곡선을 음량으로 옮겼고(같은 에너지, 큰 공은 길고 약하게, 작은 공은 짧고 강하게), 추적 덩어리는 공전 속도를 음높이로(85 → 386 Hz), J0529−4351은 밝기 음과 한계 음이 거의 같아 느린 맥놀이, 빠져드는 덩어리는 330 Hz × g로 내려가며 사라집니다. 별의 반짝임 편 피드백에 따라 모든 효과음의 기본음은 700 Hz 미만입니다.
