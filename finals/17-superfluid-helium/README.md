# 벽을 타고 넘는 액체 — 초유체 헬륨

[영상 재생·다운로드](superfluid-helium.mp4)

166.2초, 1080×1920, 30fps, H.264/AAC, −14.1 LUFS. 한국어 내레이션(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 쇼츠용 썸네일입니다. 매달린 유리컵의 빛나는 테두리를 따라 청록 막이 기어올라 바깥으로 흘러내리고, 컵 바닥에서 떨어진 방울이 아래 액체로 떨어집니다. 흰 질문 "헬륨을 영하 271도로 식히면?"과 큰 청록 답 "벽을 타고 탈출". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "초유체 헬륨은"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 헬륨을 절대영도 가까이 식혔을 때 벌어지는 기묘한 현상에 대해 알아볼까요?"(컵을 기어 나오는 액체, 온도 막대 실온 293 K → 컵 속 헬륨 약 2 K) → 이름(helium ← helios 그리스어 태양) → 1868년 개기 일식, 나트륨 두 선 옆의 낯선 노란 선 D3 · 587 nm(Janssen · Lockyer), 1895년 지구에서(Ramsay) → 1908년 Leiden, Kamerlingh Onnes가 4.2 K(영하 269 °C)에서 처음 액체로 → 증기를 펌프로 빼며 식히면 2.17 K에서 거세게 끓던 액체가 갑자기 잠잠해짐, 비열 그래프가 λ 모양으로 치솟음(람다점) → 1938년 Kapitza(모스크바) · Allen · Misener(케임브리지): 헬륨 I은 아주 좁은 틈을 거의 못 지나가고 헬륨 II는 쏟아짐 → "superfluid · 초유체" → 3단 계기: 온도 손잡이, 원자마다 퍼지는 물결 λ와 원자 간격 0.36 nm, 물결의 박자 → 물결이 겹쳐 같은 박자로 맞물림 → 따로따로 흐르는 원자는 벽의 요철에서 에너지를 잃지만 한 덩어리는 그대로 흐름(설명 모형) → 컵 벽을 타는 막(약 30 nm, 머리카락 굵기의 수천분의 일) → 분수 효과 → 오해(절대영도면 무엇이든 얼까? 물·질소·수소는 얼지만 헬륨은 액체, 25기압에서 고체) → LHC · CERN 둘레 27 km, 자석 1.9 K, 열이 순식간에 퍼져 끓어오를 틈이 없음 → 하나하나에서 모두 함께로 → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형에서 나옵니다. 헬륨-4 열적 드브로이 파장 λ = h/√(2πmkT)(20 K 0.20 nm → 2.17 K 0.59 nm)를 원자 간격 0.36 nm와 비교하고, 두 유체 그림의 초유체 비율 1 − (T/Tλ)^5.6(화면에 비율 숫자 없음), λ 모양 비열 곡선(모형), 온도에 따른 끓음, 틈 흐름, 막을 타고 떨어지는 방울, 분수, 압력에 따른 고체화, LHC 자석 온도를 씁니다.
- 단순화: 원자 크기와 물결(흐린 원)은 화면용입니다. "많은 원자가 같은 가장 낮은 상태로"는 설명 모형이며, 실제 응축 비율은 약 10%입니다. 실제 응축 조건은 물결이 간격의 약 1.4배일 때라서, 화면에서는 5.9 K에서 물결이 닿기 시작하고 2.17 K에서 맞물립니다. 마찰이 사라지는 까닭은 단순화한 설명입니다. 막 두께 30 nm는 대표값이고 시간은 압축했습니다. 헬륨 대 네온의 영점 떨림 비교도 설명 모형입니다. 상세는 [에피소드 README](../../episodes/superfluid-helium/README.md)와 [제작 메모](../../episodes/superfluid-helium/brief.md).
- 소리: 360 Hz 아래의 끓는 거품 소리가 람다점에서 끊겨 고요해집니다. 조금씩 다른 낮은 음들이 물결이 겹치면서 한 음으로 맞아 들어갑니다(맥놀이가 사라짐). 막을 타고 떨어지는 방울은 낮은 똑 소리, 분수는 낮은 휙 소리를 냅니다. 고체가 되면 틱이 격자에 맞춰 정렬됩니다. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 65개).
