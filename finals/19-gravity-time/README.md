# 머리가 발보다 빨리 늙는다 — 중력과 시간

[영상 재생·다운로드](gravity-time.mp4)

157.2초, 1080×1920, 30fps, H.264/AAC, −13.9 LUFS. 한국어 내레이션(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 쇼츠용 썸네일입니다. 땅 위에 선 사람의 옆모습이 있고, 머리 옆에 금빛 시계, 발 옆에 푸른 시계를 둡니다. 머리 시계의 초침이 1.5초 앞서 있고(과장), 격자는 땅 쪽으로 촘촘해집니다. 흰 질문 "머리와 발, 어디가 더 빨리 늙을까?"와 큰 금빛 답 "머리가 더 빨리". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "중력이 강한 곳일수록"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 중력에 따라 시간이 다르게 흐르는 현상에 대해 알아볼까요?"(높은 곳·머리 시계가 빨리 감, 두 시계의 차이 계기 "과장 ×10¹⁵", 실제 1초마다 1.9×10⁻¹⁶초, 키 1.7 m로 80년 동안 0.47 μs < 100만분의 1초) → 重 무거울 중 + 力 힘 력, gravity ← 라틴어 gravitas(gravis = 무거운) → 1907 · Einstein, 떨어지는 승강기 속 저울 60 kg → 0 kg → 지구 위에 선 사람 = 위로 가속하는 로켓 안(구별할 수 없음) → 3단 계기: 로켓 바닥에서 1초마다 보낸 빛, 가속도 손잡이 0 → 1 g, 천장이 받는 간격 1.000 → 1.218초(과장 ×10¹⁵, 실제 +2.2×10⁻¹⁶초) → 신호가 올라가는 사이 천장이 더 빨라짐(보낼 때 대 받을 때 속도 막대) → 위에서 보면 아래의 1초가 김 → 로켓이 땅에 내려앉아 같은 계기 "가속 1 g = 중력 1 g" → 1959 · Harvard(Pound–Rebka) 22.5 m 탑, 위에서 받은 진동수 1 − 2.5×10⁻¹⁵배 → GPS 위성 약 20,200 km, +45 μs · −7 μs · = +38 μs/일, 상대성 보정을 끄면 하루 11.4 km 어긋남 → 높이에 따라 하루에 앞서는 시간(계산, 로그 눈금 1 mm ~ 20,200 km) → 2010 · NIST 33 cm 두 원자시계, 2022 · JILA 1 mm 원자 구름(위아래 진동수 차이 1.1×10⁻¹⁹) → 블랙홀 가까이 다가가는 시계의 빠르기 0.88 → 0.10배 → 오해(느려진 것을 느낄까? 각자의 시계는 1초에 1초, 나란히 비교할 때만 0.71배) → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형에서 나옵니다. 약한 중력의 빠르기 차이는 g·h/c²(키 1.7 m에서 1.85×10⁻¹⁶)로 계산합니다. 로켓은 등가 원리 설명 모형이고(받는 간격 ≈ 1 + a·h/c²), 탑은 1 − 2.5×10⁻¹⁵입니다. GPS는 +45.7과 −7.2 μs/일을 반올림해 +45, −7, +38로 보이고, 높이 그래프는 정확한 중력 퍼텐셜 식을 씁니다. 원자시계는 NIST 3.6×10⁻¹⁷(계산), JILA 1.1×10⁻¹⁹입니다. 블랙홀 곁의 시계 빠르기는 √(1 − r_s/r)입니다.
- 단순화: 화면의 시간 차이는 모두 과장 배율로 표시했고, 그 배율을 화면에 적었습니다. 로켓 장면의 빛은 느리게 그렸습니다("빛은 느리게 그림" 표기). 받는 간격과 보내는 간격은 천장 시계 기준으로 그렸습니다. GPS 하루 11 km는 38 μs에 빛의 속도를 곱한 거리 환산이며, 실제 수신기 오차는 더 복잡하게 쌓입니다. 블랙홀의 시계는 지평선 쪽으로 천천히 옮겨 놓는 시계로 그렸습니다(자유 낙하하는 시계는 멀리서 더 느려 보임). NIST의 실제 측정값은 (4.1 ± 1.6)×10⁻¹⁷입니다. 상세는 [에피소드 README](../../episodes/gravity-time/README.md)와 [제작 메모](../../episodes/gravity-time/brief.md).
- 소리: 높이가 다른 두 시계가 서로 다른 낮은 음높이로 틱을 냅니다. 과장 배율에서는 박자가 점점 어긋납니다. 빛 신호는 보낼 때와 받을 때 틱을 내고, 그 간격이 늘어나는 것이 들립니다. 탑·블랙홀·오해 장면에서는 받은 진동수가 음높이를 정합니다. GPS 표시가 밀려날 때 낮은 휙 소리가 나고, 블랙홀 쪽 시계의 틱은 점점 느려집니다. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 79개).
