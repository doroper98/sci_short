0초 프레임이 쇼츠용 썸네일입니다. 왼쪽 아래 레이더 접시에서 오른쪽 위 비행기로 가는 호박색 빔과 펄스 호, 비행기 둘레에서 접시 쪽으로 퍼지는 초록 메아리 호, 희미한 거리 고리. 흰 질문 "레이더를 피하려면?"과 큰 초록 답 "메아리를 줄인다". 약 1초에 제목이 머리글로 줄고, 마지막 문장 시작(158.0초)에 포스터가 돌아와 끝까지 유지됩니다(이때 비행기는 기울어져 메아리가 다른 쪽으로 감).

흐름: "오늘은 전파의 메아리로 보는 레이더와, 레이더를 피하는 방법에 대해 알아볼까요?"(펄스와 메아리, "피하는"에서 비행기가 기울어 메아리가 "딴 데로") → 1934 영국: 송신탑에서 복엽 폭격기로 "죽음의 광선?" → 윌킨스의 계산: 퍼지며 약해지는 파면 "세기 ∝ 1 ÷ 거리²", "떨어뜨리기: 불가능", 펄스가 폭격기에 닿아 약한 메아리가 수신 안테나에 "찾기: 가능" → "1935. 2. 26" 데번트리: 방송 송신탑의 긴 파장(약 50 m) 파면, 들판의 밴, 복엽 폭격기의 메아리, 수신기 화면의 초록 선이 흔들림, "약 13 km" → RADAR 글자와 RAdio · Detection · And · Ranging, "1940 · 미국 해군" → 본질: 짧은 펄스와 희미한 메아리, 받은 신호 그래프의 큰 봉우리·작은 봉우리, "왕복 시간 → 거리", "진동수 변화 → 속도" → 거리: 0~150 km 축 위 왕복, 시계 "0.0000초 → 0.0010초", "전파가 간 길 300 km", "300 km ÷ 2 = 150 km"(실제 0.001초를 4,000배 느리게) → 축이 돌아가는 빔이 되어 둥근 레이더 화면(거리 고리, 잔광, 점, 비구름), "방향"·"거리" → 도플러: 다가오는 비행기의 촘촘한 메아리 / 멀어지는 비행기의 성긴 메아리(차이 과장 선언) → 스피드건과 자동차 "시속 100 km", "24 GHz 전파 → 약 4,400 Hz 높아짐", 기상 레이더 속도 화면(다가옴 / 멀어짐) → 같은 접시의 긴 파장 넓은 빔(화면에 한 점) / 짧은 파장 좁은 빔(두 점), "빔 폭 ≈ 파장 ÷ 안테나 지름" → 비구름: 3 cm 빔은 약해지고 10 cm 빔은 먼 비구름까지, "10 cm" → 반사 단면적 σ: 비행기의 '레이더에 비친 크기' 원이 줄어듦 → 평판: 정면이면 메아리가 그대로, 30° 기울이면 반사파가 60° 위로(θ·θ) → 흡수 재료 층과 열 점 → 막대 "돌아온 메아리": 정면 · 기울임 · 흡수 재료 → 지평선: 크게 휜 지구, 지평선에 스치는 직선, 그늘의 낮은 비행기에는 전파가 닿지 않음, "안테나 높이 25 m → 지평선 약 21 km" → 오해(스텔스는 안 보일까?): 로그–로그 그래프 메아리 ∝ σ ÷ 거리⁴, 보통은 R에서, σ ÷ 10,000은 R ÷ 10에서 "잡힘" → 포스터.

- 모형: 화면·그래프·이름표·소리가 `scenes.mjs` 머리의 모형 하나에서 나옵니다. R = c·t/2, 파면 묶음의 도착 시각 = 거리 ÷ 화면 속도, 도플러 압축 (c − v)/(c + v)(화면 ×0.67/×1.5), 원형 구경 빔 [2J1(x)/x]²(D/λ = 2.2와 14, 두 점 9° 간격), 비 감쇠 e^(−αL), 평판의 반사 법칙과 가장자리의 약한 회절, 지구 접선과 그늘, P ∝ σ/R⁴. 상세는 [에피소드 README](../../episodes/radar/README.md)와 [제작 메모](../../episodes/radar/brief.md).
- 단순화: 화면의 파면 속도·시간 압축, 도플러 차이 과장, 데번트리 장면의 거리·크기(축척 아님), 레이더 화면의 점·비구름, 빔·감쇠·반사 무늬와 '메아리 크기' 막대(상대값), 지구 곡률 과장. 시간 배율·과장은 장 제목 키커에 선언.
- 소리: 펄스를 쏠 때 짧은 220 Hz 음, 메아리가 접시에 닿을 때 같은 음을 작게(반사 세기에 따라, 기운 비행기·평판은 더 작게), 레이더 화면의 점 → 작은 틱, 도플러 메아리 → 화면의 파장 비율과 같은 비율의 음높이(다가옴 248 Hz, 멀어짐 110 Hz, 보낸 전파 165 Hz), 긴 파장/짧은 파장 → 낮은 음/높은 음(빔이 표적을 비추면 커짐, 비 속에서 작아짐), 지평선 아래 비행기 → 소리 없음. 모든 기본음 700 Hz 미만, 사건 60개, 패닝 없음. 설명용 합성음(전파는 소리를 내지 않음).
