# 섭씨, 화씨, 켈빈 — 온도를 재는 세 눈금

[영상 재생·다운로드](temperature-scales.mp4)

157.6초, 1080×1920, 30fps, H.264/AAC, −14.1 LUFS. 한국어 내레이션(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 쇼츠용 썸네일입니다. 해 질 녘 도시 위의 큰 온도계 하나가 같은 높이에서 왼쪽 °C 38과 오른쪽 °F 100을 가리키고, 옆에 작은 냄비 "끓는 물 100 °C"를 대비로 둡니다. 흰 질문 "화씨 100도면 물이 끓을까?"와 큰 주황 답 "아니, 섭씨 38도". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "온도 눈금은"에서 포스터가 돌아와 끝까지 유지됩니다. 냄비 아래의 30 px 표식은 대비를 읽히게 하려고 둔 예외입니다.

흐름: "오늘은 섭씨와 화씨, 그리고 켈빈까지, 온도를 재는 세 가지 눈금에 대해 알아볼까요?"(3단 계기: 온도계, 세 자 °C · °F · K, 온도 손잡이, "미국 일기 예보 100°F" = 37.8 °C = 310.9 K) → 처음의 온도계는 오르내림만, "몇 도?" → 기준점 두 개(얼음물, 끓는 물) + 고르게 나누기 → 1724년 Fahrenheit: 얼음 + 염화암모늄 혼합물 = 처음의 0, 사람의 체온 = 96, 다듬은 눈금에서 어는 점 32 · 끓는 점 212 · 체온 98.6 → 1742년 Celsius: 끓는 점 0 · 어는 점 100(거꾸로, 데우면 숫자가 작아짐) → 뒤집힘 → 攝爾修斯의 攝 + 氏 = 攝氏(섭씨), 華倫海特의 華 + 氏 = 華氏(화씨) → 같은 구간이 섭씨 100칸 · 화씨 180칸(화씨 1칸 = 섭씨 5/9칸) → °F = 1.8 × °C + 32, 두 직선이 −40에서 만남 → 1848년 William Thomson(훗날 Lord Kelvin): 자가 0 K까지 내려감, 칸 크기는 그대로, K = °C + 273.15, °K → K(1967) → 오해(20 °C는 10 °C의 두 배? 0 K부터 다시 그리면 283 K 대 293 K, 평균 운동 에너지 차이 약 3.5%) → 과학은 비율이 맞는 켈빈, 전구 상자 6500 K(2700 K 따뜻한 빛 ~ 6500 K 낮빛) → 같은 무더위 38 · 100 · 311 → 결론.

- 모형: 온도 T 하나가 온도계 기둥, 세 자의 숫자, 환산 그래프, 소리를 함께 움직입니다. 기준점은 물체(혼합물 비커, 얼음물, 끓는 냄비, 손)에 온도계를 담가 기둥 높이로 보입니다. 색온도 막대의 색은 플랑크 흑체 복사와 CIE 색 계산에서 나옵니다. 1724년 처음 눈금은 혼합물을 4 °F에 두는 모형이고, 이 모형에서 물이 어는 점은 28.4가 됩니다(화면에 숫자 없음). 켈빈 장면의 0 K까지 내려가는 액체 온도계는 비교용 모형입니다.
- 단순화: 온도계·사람·비커 그림은 단순화입니다. 셀시우스 눈금이 뒤집힌 해와 사람은 출처마다 달라 연도 없이 "세상을 떠날 무렵"으로 썼습니다. 3.5%는 이상기체의 평균 운동 에너지 비율입니다(속력 차이는 약 1.7%). 색온도는 빛의 색을 흑체 온도로 나타낸 값이며 전구 자체의 온도가 아닙니다. 상세는 [에피소드 README](../../episodes/temperature-scales/README.md)와 [제작 메모](../../episodes/temperature-scales/brief.md).
- 소리: 기둥 높이(켈빈)가 낮은 음의 높이를 정해, 같은 온도는 세 눈금 어디서나 같은 소리입니다. 눈금 칸이 그려질 때 5칸마다 틱이 울려 화씨 180칸이 섭씨 100칸보다 1.8배 빠르게 들립니다. 섭씨와 화씨 숫자에서 나온 두 음이 −40에서 하나로 겹칩니다. 오해 장면에서는 섭씨 숫자로 낸 음이 한 옥타브 벌어지고, 켈빈 숫자로 낸 음은 거의 같습니다. 셀시우스 눈금이 뒤집힐 때 낮은 휙 소리가 납니다. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 89개).
