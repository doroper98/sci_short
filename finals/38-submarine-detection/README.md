# 잠수함은 어떻게 찾을까 — 바다는 모습을 가려도, 소리와 자기장의 흔적까지 다 가리지는 못한다

**역할**: 기획·대본·구현 계획·검수는 제작 세션(Fable), 대본 검수는 별도 Fable 작업자, 사실 확인(원문 대조)과 장면·소리 구현은 Opus 작업자 넷이 했습니다. 구현 계획서는 [PLAN.md](../../episodes/submarine-detection/PLAN.md).

**대본은 Fable 검수를 받았습니다**(2026-11-11 규칙). 초안 23문장 → 확정 21문장·800음절. 고친 핵심: "찬 쪽으로 휜다 → 그래서 층 아래에 그늘"이 귀로는 모순으로 들려 "아래로 휘어서, 층 아래 **먼 곳**에는"으로, 숫자 넷이 몰린 문장을 둘로 나누고 "가는 데는 그 절반"을 말로 넣음, 빠져 있던 '왜' 넷(왜 소리인가, 왜 원자력은 오래 숨는가, 왜 부표인가, 왜 꼬리 끝인가)을 넣음, 귀로 헷갈리는 낱말(찾는 쪽/찬 쪽, 흐트러짐/흩어짐, 공기 관, 배보다 열 배)을 바꿈, 나열뿐인 문장을 삭제. 상세와 반영하지 않은 지적은 [제작 메모](../../episodes/submarine-detection/brief.md) '대본 Fable 검수'.

**화풍 — 영상미 문법**: 무대는 바다를 옆에서 자른 단면 하나(하늘·수면·물·계기 띠)이고 장면마다 카메라만 옮깁니다. 잠수함·초계기·군함·헬리콥터·부표는 면과 명암이 있는 무광 덩어리(특정 기종이 아닌 일반화한 실루엣, 크기 과장)입니다. 빛나는 것은 신호뿐입니다. **난색(호박)은 잠수함에게서 온 것**(잠수함이 내는 소리, 맞고 돌아온 메아리, 자기장의 흔적, 계기에 찍힌 탐지), **한색(하늘색)은 찾는 쪽이 내보낸 것**(쏜 소리, 레이더 전파, 부표의 무선)입니다. 계기의 가로축은 세계의 가로 자리와 같은 자입니다. 조건 하나를 바꿀 때 옛 결과를 잔상으로 남깁니다(층 위에서 쏜 음선, 낮게 지날 때의 자기 기록선, 떠 있을 때의 레이더 점).

0초 프레임이 쇼츠용 썸네일입니다. 하늘의 초계기, 물속 잠수함과 퍼져 나가는 소리 파면, 선체 둘레에서 휘는 자기장 선, 마이크를 내린 부표, 흰 질문 "잠수함은 어떻게 찾을까?"와 큰 호박색 답 "소리와 자기장으로". 약 1초에 제목이 머리글로 줄고, 마지막 문장 끝 1.4초 전에 포스터가 돌아옵니다.

흐름: "오늘은 바닷속에 숨은 잠수함을 찾아내는 방법에 대해 알아볼까요?"(초계기의 레이더 전파가 수면에서 사라짐, 확대 원 안의 깊이 자 0~3 cm, "약 1 cm", 빈 레이더 화면) → 2차 대전: 잠수함이 충전하러 떠오르고 배터리가 참, 전파가 선체에 맞고 메아리가 돌아와 레이더 화면에 점 → 초계(哨 망볼 초, 戒 경계할 계): 되풀이해 살피는 전파 → 1955: 가라앉아 머무는 원자력 잠수함, 물속에 머문 날 1 → 90일, 전파는 수면에서 사라짐 → 본질: 프로펠러의 소리 파면과 물속 마이크의 파형, 선체 둘레에서 휘는 지구 자기장 선과 기록선의 혹, 선체가 어둠에 묻혀도 흔적은 남음 → 수동 소나(듣기만) / 능동 소나: **실제 빠르기 그대로** 쏜 뒤 1.0초에 맞고 2.0초에 메아리 도착, 초시계 "2.0초", "1,500 m" → 쏘면 쏜 배의 위치도 드러남 → 소리는 찬 쪽으로 휨(확대 원: 소리 묶음의 따뜻한 쪽 끝이 앞서가 꺾임, 빠르기 곡선) → 군함 밑에서 쏜 음선이 층에서 아래로 꺾여 층 아래 먼 곳에 그늘, 메아리 없음 → 끄는 소나를 층 아래로 내리자 음선이 잠수함에 닿고 메아리 봉우리, 헬리콥터의 담그는 소나 → 초계기는 군함보다 열 배 길게 나아가며 부표 넷을 떨어뜨림("10배") → 부표의 마이크가 층 아래로, 잠수함의 소리가 닿는 순서대로 무선이 올라가 막대가 섬(3 → 4 → 2 → 1) → 가장 큰 막대 근처로 좁힘 → 꼬리 끝 자기 탐지기: 낮게 지날 때의 혹, 두 배 먼 높이의 혹은 "1/8", 다시 낮게 바로 위를 지나 확인 → 디젤 잠수함이 내민 공기 관에 전파가 맞아 레이더 화면에 점 → 네 흔적이 한 번씩 → 명제 → 포스터.

- 모형: 화면·계기·숫자·소리가 `episodes/submarine-detection/model.mjs`의 모형 하나와 시간 계획에서 나옵니다.
  - 능동 소나: 거리 = 1,500 m/s × 왕복 시간 ÷ 2. 화면은 실제 빠르기(가는 데 1.0초, 오는 데 1.0초).
  - 소리 그늘: 소리 빠르기 분포(혼합층 0~60 m 1,520 m/s + 0.017/s, 수온약층 60~140 m 에서 1,521 → 1,497 m/s, 그 아래 + 0.017/s)에서 음선을 스넬 법칙으로 적분. 깊이 6 m 에서 2.05°로 쏜 한계 음선은 140 m 를 3.3 km 에서 지나고, (6.5 km, 220 m)의 잠수함에는 어떤 음선도 닿지 않습니다. 깊이 200 m 에서 쏜 음선은 약 4.3초에 닿습니다. 화면은 깊이 약 13배 과장, 4배 빠르게(키커에 선언).
  - 부표: 받은 세기 −20·log10(거리/600 m), 거리 5.6 / 3.1 / 0.6 / 1.9 km, 소리는 실제 빠르기.
  - 자기 이상: 쌍극자, 세기 ∝ 1/거리³. 기록선 S(x, d), S(0, 2d) = S(0, d)/8.
- 단순화: 소리 빠르기 분포는 설명용 3층 모형(실제는 계절·해역마다 다르고 염분도 영향), 표면·해저 반사 손실과 수렴대는 그리지 않음. 부표의 '크기 비교'는 설명 모형(실제로는 방향을 아는 부표, 능동 부표, 도착 시각 차이도 함께 씀). 자기 이상은 단면 안에서 세로로 자화된 쌍극자 하나(실제 신호 모양은 방향·위도·선체에 따라 다름), 휜 자기장 선의 세기는 보이도록 키움. "몇 달씩 물속에"는 원자력 잠수함 일반의 능력(식량이 한계)이며 1955년의 첫 항해가 그랬다는 뜻이 아님. "열 배쯤"은 초계기 약 600 km/h, 군함 약 55 km/h 를 둥글린 값. 물체는 일반화한 실루엣이고 크기를 과장했습니다. 시간 배율은 장 제목 키커에 선언했습니다.
- 소리: 모두 합성한 설명용 소리(녹음 아님), 기본음 700 Hz 미만, 패닝 없음. 레이더 펄스 → 낮은 틱, 수면에서 사라짐 → 내려가는 잡음, 메아리 도착 → 부드러운 음, 능동 소나 → 440 Hz 짧은 음과 **정확히 2.0초 뒤** 330 Hz 메아리, 그늘 → 침묵, 부표 막대 → 세기에 따른 음높이, 자기 혹 → 혹의 크기를 따르는 220 Hz 음(두 배 거리에서는 8분의 1). 사건 83개.
