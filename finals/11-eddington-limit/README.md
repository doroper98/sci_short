# 에딩턴 한계 — 빛이 별을 밀어낸다

[영상 재생·다운로드](eddington-limit.mp4)

171.5초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
첫 프레임 = 썸네일 규칙(2026-11-03)을 처음 적용한 편입니다. 0초에 바깥층이 날아가는 청백색 별과 큰 제목 두 줄이 이미 보이고, 약 1초에 제목이 머리글로 줄어듭니다.

흐름: "오늘은 별이 얼마나 밝아질 수 있는지를 정하는 에딩턴 한계에 대해 알아볼까요?"(질량·밝기 손잡이와 Γ 계기, 별이 커지고 밝아지다 한계를 넘자 바깥층이 날아감) → 이름(아서 에딩턴 1882~1944, 1916년부터 별 속 복사압 계산, 1919년 일식에서 휘는 별빛 측정) → 핵심(빛이 미는 힘 = 중력이 되는 밝기) → 빛의 운동량과 부딪힘 → 전자와 양성자로 갈라진 기체, 빛은 전자를 중력은 양성자를, 전기력으로 묶인 한 쌍의 줄다리기 → 둘 다 거리²에 반비례(r → 2r에 둘 다 ¼, 비율 그대로) → 태양 질량 하나마다 태양 밝기의 약 3만 3천 배, 태양은 그 3만 3천분의 1 → 무거운 별일수록 한계에 다가감(로그 밝기–질량 평면, 200배 별은 한계의 80%), 별바람 → 1843년 용골자리 에타(한계의 약 5배, 밤하늘 두 번째 밝기, 호문쿨루스 성운) → 블랙홀이 삼키는 빠르기의 한계, 빅뱅 뒤 약 6.8억 년의 16억 태양질량 블랙홀 J0313−1806(한계 속도 성장 모형보다 약 150배 큼) → 오해(넘을 수 없는 벽? → 원반이면 넘는다, M82 X-2는 10배 넘게) → 결론(같아지는 밝기에서 정지, 넘으면 껍질이 날아감, 끝 제목 유지).

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형 하나에서 나옵니다. Γ = L/L_Edd(L_Edd = 3.3×10⁴ L☉ × M/M☉), 껍질의 가속 a ∝ (Γ − 1)/r² 적분, 렌즈 광자 충돌 시각표, 블랙홀의 삼키는 빠르기 상한 Ṁ = S/(1+S⁶)^(1/6), 한계 속도 성장 M = 100 M☉·e^((t−100 Myr)/50 Myr).
- 단순화: 완전 이온화 수소와 전자 산란만 가정한 고전적 에딩턴 한계입니다. 질량–광도 곡선, 에타의 광도 곡선, 호문쿨루스 모양, 블랙홀 성장 곡선은 설명용 모형입니다. 입자 크기, 빛의 휨, 별 크기와 거리는 과장했습니다. 200배 별의 바람은 모형의 a = g(Γ − 1)가 아니라 그림으로 그렸습니다(실제 별바람은 흡수선이 미는 바람). 상세는 [에피소드 README](../../episodes/eddington-limit/README.md)와 [제작 메모](../../episodes/eddington-limit/brief.md).
- 소리: 두 힘 = 두 낮은 음(중력 110 Hz 고정, 빛은 Γ에 따라 음높이가 움직임). 한계 아래에서는 맥놀이, 정확히 1이면 한 음, 넘으면 다시 맥놀이. 한계를 넘는 순간 55 Hz 쿵, 껍질이 떠나는 순간 낮은 휙, 광자 충돌 28번 180 Hz 틱, 블랙홀 성장 곡선은 질량의 로그를 음높이로. 별의 반짝임 편 피드백에 따라 모든 효과음의 기본음은 700 Hz 미만입니다.
