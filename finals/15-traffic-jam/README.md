# 사고도 없는데 왜 막힐까 — 유령 체증

[영상 재생·다운로드](traffic-jam.mp4)

175.9초, 1080×1920, 30fps, H.264/AAC, −14.0 LUFS. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 쇼츠용 썸네일입니다. 밤 고속도로를 위에서 비스듬히 본 장면, 네 차로의 차들 사이로 앞에서 뒤로 번지는 빨간 브레이크 등 띠, 흰 질문 "사고도 없는데 왜 막힐까?"와 큰 주황빨강 답 "유령 체증". 약 1초에 제목이 머리글로 줄고, "교통체증은"(마지막 문장)에서 포스터 구도가 돌아와 마지막 프레임이 0초와 같은 상태로 끝납니다.

흐름: "오늘은 사고도 공사도 없는데 길이 막히는, 교통체증에 대해 알아볼까요?"(앞길에 사고 없음 ✕ · 공사 없음 ✕, 한 차의 멈췄다 가는 속도 그래프) → 이름(滯症 = 막힐 체 + 증세 증, 먹은 음식이 얹혀 내려가지 않는 증세 → 막힌 길에 빗댐, traffic jam) → 2008년 일본 원형 도로 실험 재현(둘레 230 m, 차 22대, 시속 30 km → 한 곳에서 멈춤, 정체가 뒤로 흐름) → 반응 사슬(1초 남짓 늦게, 늦은 만큼 더 세게 → 뒤로 갈수록 커지는 흔들림 → 여섯 번째 차 정지 = 정체의 씨앗) → 넉넉한 16대는 잦아들고 촘촘한 22대는 자라남 → 흐름 = 밀도 × 속도, Greenshields 기본도(적어서 적게 / 느려서 적게 / 꼭대기 약 2천 대 안팎 · 한 차로) → 시공간 그림: 꼬리로 들어오는 차 > 머리에서 나가는 차 → 정체가 뒤로 약 시속 20 km → 병목 네 곳(차로 감소 · 합류 · 오르막 · 터널 입구) → 2017년 미국 실험 재현: 자율주행 한 대가 물결을 잦아들게 하고 연료 소비 감소 → 오해(차로를 자주 바꾸면 빨리? → 끼어들 때마다 새 물결) → 넉넉한 간격의 "나" 한 대가 물결을 흡수 → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형에서 나옵니다. 원형 도로·병목·자율주행·고속도로는 반응 지연이 있는 차 따라가기 모형(τ 0.25 s + 상대 속도 항, 0.02 s 고정 간격 적분)입니다. 이 모형에서 정체는 뒤로 21.1 km/h로 움직이고, 식 w = Δq/Δk로는 −22 km/h입니다. "1초 남짓"의 반응 사슬·끼어들기·마무리는 τ 1.0 s의 설명 모형입니다. 기본도는 Greenshields(v₀ 100 km/h, k_j 80대/km → 용량 2,000대/시간)입니다.
- 단순화: 원형 도로는 실제 실험 궤적이 아니라 같은 조건의 모형 결과이며 "실험 재현 · 모형", "시간 압축 · 모형"으로 표기했습니다. 1초 순수 지연 모형은 실험 간격(약 6 m)에서 차끼리 부딪치므로 두 모형으로 나눴습니다. 자율주행 장면은 실제 2017년 트랙·제어기가 아니라 같은 230 m · 22대 모형에 단순한 간격 규칙을 넣은 것이고, 연료 막대는 숫자 없는 상대값(모형 0.78)입니다. 병목 네 곳은 모두 "그 구간에서 속도가 조금 준다"는 같은 모형입니다. 물결 장면 식의 흐름(원형 도로 모형 2,290대/시간)과 기본도 꼭대기(2,000대)는 서로 다른 모형의 값입니다. 상세는 [에피소드 README](../../episodes/traffic-jam/README.md)와 [제작 메모](../../episodes/traffic-jam/brief.md).
- 소리: 브레이크 등이 켜질 때마다 92~110 Hz 아주 낮은 틱(뒤로 번지는 박자), 원형 도로 평균 속도 → 웅웅의 음높이(30 km/h 128 Hz → 정체 뒤 94 Hz), 자율주행 장면은 한 차의 속도로 웅웅이 오르내리다 고르게 가라앉음, 기본도 흐름 → 음높이와 꼭대기의 낮은 화음, 정체 꼬리·머리 틱, 첫 정지의 낮은 쿵. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 63개).
