0초 프레임이 썸네일입니다: 흰 물음 두 줄 "60도로 달궈진 여름 길, / 왜 다르게 버틸까?"와 그 아래 가장 큰 주황 주제어 "아스팔트와 / 콘크리트"(물음의 약 1.9배). 그림은 원근으로 내려다본 두 차로 — 왼쪽 검은 아스팔트, 오른쪽 줄눈이 있는 회색 콘크리트, 멀리 다가오는 트럭들.

흐름: 첫 물음(60도) → 여름 한 철, 바퀴 자국은 아스팔트에만 → 이름: concretus '함께 자라난 것' → 로마 판테온의 둥근 지붕을 고리마다 부어 지음 → 메소포타미아 벽돌을 역청으로 붙임 → 길을 잘라 본 단면: 같은 돌, 다른 풀, 무게 95:5 → 식어서 굳는다 / 물과 반응해 굳는다 → 렌즈(아스팔트): 큰 분자, 150 °C 에서 묽게 흘러 돌을 감쌈, 식으면 떨림이 느려지고 엉겨 돌을 붙잡음, 다시 데우면 다시 물러짐(굳기 막대의 잔상) → 렌즈(콘크리트): 시멘트 가루와 물, 1450 °C 가마, 알갱이 표면에서 새 물질이 자라 돌을 묶음(수화 반응), 28일 강도 곡선, 물속 시료도 같은 곡선으로 굳음 → 한여름 단면: 노면 60 °C, 역청 굳기가 점점 내려감, 바퀴가 지날 때마다 아스팔트에만 홈과 둔덕, 콘크리트는 그대로 → 줄어드는 판: 줄눈이 있으면 금이 줄눈에만, 없으면 아무 데나 → 처음의 길(바퀴 자국 / 그대로) → 정리.

- 무대: 길 하나 — 원근으로 본 두 차로(전체), 그 길을 자른 두 단면(확대), 단면 속을 보는 렌즈 하나(미시). 차로 순서(왼쪽 아스팔트, 오른쪽 콘크리트)는 끝까지 같습니다.
- 색: 난색 하나 = 열(데움·달궈짐·가마·반응열), 한색 하나 = 물(시멘트와 반응하는 물, 물속).
- 시간 배율: 첫 장면의 여름 한 철을 약 2초와 약 5초로, 아스팔트 렌즈의 몇 시간을 몇 초로, 콘크리트의 28일을 약 6초로, 바퀴 수천 번을 몇 초로(머리글 키커에 선언).
- 단순화: 역청 분자는 긴 사슬 몇 개, 새 물질(C-S-H)은 섬유 모양(실제는 나노 크기의 겔에 가까움), 굳기 막대·바퀴 자국 깊이는 설명용 눈금, 강도 곡선은 S(d) = d/(d+6)·34/28(7일 약 65%, 28일 100%, 설명용), 판의 길이 변화는 과장(화면에 "길이 변화는 과장"). 트럭은 무광 상자로 그렸습니다. 판테온 단면의 비례(안쪽 높이 = 지름)만 맞추고 세부는 생략했습니다.
- 소리: 모두 합성한 설명용 소리(녹음 아님), 사건 43개, 모든 기본음과 잡음 대역은 700 Hz 아래(사용자 규칙). 트럭이 지나는 순간 = 낮은 잡음, 온도 = 음높이(데우면 오르고 식으면 내림), 수화 = 여린 틱의 이어짐, 금 = 짧은 틱. 화면과 같은 시각표(`sound.json` ↔ `events.json` 대조 통과).
