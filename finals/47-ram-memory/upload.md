# 업로드 정보 — 47. 램은 어떻게 기억할까 (166.0초)

공통 설정(카테고리, 아동용 여부, 합성 콘텐츠 표시, 수익화 전 확인)은 [업로드 공통 설정](../../docs/YOUTUBE_UPLOAD.md)에 있습니다. 설명란은 마크다운이 적용되지 않으므로 평문으로 썼습니다.

제목
```text
1초에 15번 넘게 다시 채워야 하는 램은 어떻게 기억할까? | 새어 나가는 전하를 다시 채우는 RAM #램 #반도체 #과학
```
설명
```text
컴퓨터와 휴대전화의 램(RAM)은 1초에 15번 넘게 모든 칸을 다시 채웁니다. 램의 한 칸에 담긴 전하가 가만두면 조금씩 새어 나가기 때문입니다.

- RAM은 랜덤 액세스 메모리(Random Access Memory). 테이프와 달리 어느 칸이든 곧바로 닿는다는 뜻
- 1960년대 후반 IBM의 로버트 데나드가 한 칸을 트랜지스터 하나와 축전기 하나로 만드는 방법을 내놓음
- 램의 대부분은 축전기를 쓰는 디램(DRAM). D는 다이내믹(Dynamic), 가만두면 변한다는 뜻
- 축전기에 전하가 차 있으면 1, 비어 있으면 0. 그런데 전하는 조금씩 새어 나가 가만두면 1이 0으로 바뀜
- 쓸 때: 가로줄이 트랜지스터의 문을 열고, 세로줄의 전압을 높이면 전하가 차고 낮추면 빠져나감
- 읽을 때: 가로줄 하나가 그 줄의 문을 모두 열면, 미리 중간 전압에 맞춰 둔 긴 세로줄의 전압이 아주 조금 오르거나 내림. 줄 끝의 감지 증폭기가 그 작은 차이를 키워 1과 0을 가림
- 읽는 동안 칸의 전하는 긴 줄로 흩어지므로, 증폭기가 가려낸 값을 칸에 다시 써 넣음. 필요한 칸은 가로와 세로 번호 두 개로 찾음
- 이 성질로 램은 64밀리초마다 모든 줄을 한 바퀴씩 다시 채움(리프레시). 대부분의 칸은 더 오래 버티지만, 이 간격은 가장 빨리 새는 칸에 맞춘 것
- 전원이 꺼지면 리프레시도 멈추고, 내용은 길어야 몇 분 안에 거의 다 사라짐
- SSD(플래시)는 전하를 절연막 속에 가둬 전원 없이도 지키지만 읽고 쓰기가 훨씬 느림. 그래서 지금 쓰는 것은 램에, 오래 둘 것은 SSD에 둠

"램은 새어 나가는 전하를, 사라지기 전에 다시 채워서 기억합니다"

#램 #RAM #디램 #반도체 #과학쇼츠
```

```text

그런데 이 전하는 가만두면 조금씩 새어 나가요.

그래서 램은 64밀리초마다 모든 줄을 읽어서 다시 채워요.
1초에 15번이 넘어요.
"램은 새어 나가는 전하를, 사라지기 전에 다시 채워서 기억해요"

읽기만 하면 칸은 그대로일까요?
아니에요. 읽는 동안 전하가 흩어져서, 읽은 값을 칸에 다시 써 넣어요.

전원을 끄면 다시 채우기도 멈춰서, 램은 금세 거의 다 잊어버려요.
```

- 주제어: RAM(램)
- 고정 댓글: 램(디램)의 한 칸은 전하를 담는 아주 작은 축전기이고, 그 전하는 조금씩 새어 나갑니다. 램은 줄마다 읽어서 다시 써 넣는 리프레시를 64밀리초마다 되풀이해, 전하가 사라지기 전에 다시 채웁니다. 그래서 전원이 꺼지면 내용을 잊습니다.
