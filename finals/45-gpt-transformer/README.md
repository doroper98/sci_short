흐름: "오늘은 GPT가 문맥을 어떻게 읽는지에 대해 알아볼까요?"(주의의 선이 채찍처럼 뻗고 점이 끌려감) → '항구를 떠난 배'와 '달게 익은 배', 두 `배` 가 지도의 같은 한 점 → 다음에 올 말의 확률이 탈것 말과 과일 말 사이에서 엇비슷 → 예전 방식: 기억 덩어리가 낱말을 건너뛸 때마다 첫 낱말의 몫이 0.6배로 줄어 3% → 2017 트랜스포머: 모든 앞 낱말로 한꺼번에 곧바로, T = Transformer(모양을 바꾸는 것) → 낱말은 숫자 묶음(12,288개로 굴러감) → 두 칸만 남겨 지도의 가로·세로 자리가 되고 점이 찍힘 → 탈것 쪽(기차 버스 돛)과 과일 쪽(사과 포도 감) → `배` 는 늘 같은 자리에서 출발 → 앞의 낱말들을 한꺼번에 살핌 → 주의 59 · 32 · 9%, 막대가 붙어 100% → 항구와 떠난에 쏠림 → 당기는 선이 팽팽해지고 점이 탈것 쪽으로(카메라가 따라 들어감) → 조건 하나: '달게 익은'으로 바꾸면 점이 출발점으로 돌아왔다가 과일 쪽으로(앞의 길은 잔상) → 모든 낱말이 동시에 = 한 층, 2 · 3 · 4층에서 옮기는 폭이 줄어듦 → 층 칸이 96 까지 솟구침 → 마지막 점에서 다음에 올 만한 말의 확률(탈것 말이 높아지고 과일 말이 0 가까이) → 먼 낱말도 한 획으로(주의 37%), 아래에서는 예전 방식의 덩어리가 느리게 기어감(3%) → 주의는 글을 읽으며 익힘(같은 굵기 → 지금 굵기) → 명제 → 포스터.

- 모형: 화면의 주의 값·점의 자리·다음 말 확률은 모두 `episodes/gpt-transformer/model.mjs` 의 **두 방향짜리 아주 작은 주의 계산**에서 나옵니다. GPT 가 아닙니다.
  - 낱말의 처음 자리(지도 좌표)와 관련 점수표는 이 편을 위해 손으로 정한 값입니다(실제로는 배워서 얻음). 주의(softmax) · 섞기 · 옮겨 가기 · 다음 말 확률은 그 값에서 계산합니다.
  - `항구를 떠난 배` 의 `배`: 주의 0.589 · 0.323 · 0.088(자기). 한 층마다 `자리 ← 자리 + 0.6 × (주의로 섞은 자리 − 자리)`. 네 층의 이동 거리 0.359 > 0.199 > 0.111 > 0.063.
  - 다음에 올 만한 말(γ = 5): 처음 자리에서는 여섯 후보가 13~15% 로 엇비슷, 네 층 뒤 `항구를 떠난 배` 는 한 척이 45.5 · 위에서 41.2%, `달게 익은 배` 는 맛이 44.7 · 한 개를 38.4%.
  - 긴 문장에서 `배 → 항구를` 주의 37.0%. 예전 방식(설명 모형: 기억 = 0.6 × 앞 기억 + 0.4 × 새 낱말)에서 일곱 칸 뒤 첫 낱말의 몫 2.8%.
  - GPT-3 의 수 둘(낱말 하나 12,288개, 96층)만 대본의 값이고 모형 값이 아닙니다. 화면의 모형은 네 층입니다(키커에 선언).
- 단순화: 뜻의 지도는 수천~수만 방향을 두 방향으로 줄인 그림. 출발 자리에는 실제로 낱말의 자리(몇 번째인가) 정보도 더해집니다. 한 층 안에는 살피는 장치가 여럿이고 살핀 뒤 한 번 더 계산하는 단계가 있습니다. 주의 100% 에는 `배` 자신의 몫도 들어갑니다. "다시 살피면 뜻이 더 또렷해지므로"는 설명 모형. '탈것과 과일 사이'는 이 작은 지도에서의 자리(실제 '배'에는 몸의 배, 두 배 같은 뜻도 있음). 이 편은 '낱말'로 통일했고 실제로는 낱말보다 작은 조각 단위입니다. transform 의 뜻풀이는 어원이며, 지은이들이 그 뜻으로 이름을 정했다는 기록을 확인한 것은 아닙니다.
- 소리: 모두 합성한 설명용 소리(녹음 아님), 기본음 700 Hz 미만(가장 높은 음 494 Hz), 패닝 없음. 선이 뻗음 → 부드러운 음, 주의 막대 → 길이에 따른 음높이, 끌려감 → 올라가는 음(과일 쪽은 내려가는 음), 층 → 층마다 음, 기억 덩어리 → 칸마다 낮아지는 틱. 사건 79개.
