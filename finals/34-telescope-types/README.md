# 망원경의 종류 — 빛을 모으는 방법

[영상 재생·다운로드](telescope-types.mp4)

158.6초, 1080×1920, 30fps, H.264/AAC, −14.0 LUFS. 한국어 내레이션(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
사용자 주제(2026-11-07 기록, 완성본 번호 34): "망원경의 종류". 0초 프레임이 쇼츠용 썸네일입니다. 오목거울 단면이 위에서 내려오는 별빛 광선 다발을 되비쳐 한 점에 모으고, 그 초점이 빛납니다. 흰 질문 "망원경의 핵심은 확대?"와 큰 호박색 답 "아니, 빛 모으기". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "넓은 입구로"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 렌즈와 거울, 전파 접시까지, 망원경의 종류에 대해 알아볼까요?"(렌즈 · 거울 · 전파 접시 단면 셋) → 1610 갈릴레이의 작은 굴절망원경과 접안 시야, 목성과 네 위성이 밤마다 자리를 바꿈(1월 7일 → 13일, 위치는 모형) → 어둠에 익은 눈동자 7 mm에서 켁 10 m 조각 거울(36개)로 로그 축소, 모으는 빛 × 204만("백만 배 넘게") → tele(멀리) + skopein(보다) = telescope, 望 · 遠 · 鏡(바랄 망 · 멀 원 · 거울 경) = 멀리 바라보는 거울 → 1608 리퍼세이(네덜란드 안경 장인)의 원통: 볼록렌즈 + 오목렌즈, "처음으로 특허 신청" → 본질: 포물면 거울, 입구 지름 ×1 → ×2, 모으는 빛 ×4, 초점에 맺힌 두 별(×1 한 얼룩 · ×2 두 점) → 굴절망원경 3단 계기: ① 볼록렌즈가 빛을 한 점에(추적 표식) → 색이 갈라짐 ② 초점 확대(빨강 · 초록 · 파랑 초점, "색 차이 과장"), 별 둘레의 무지갯빛 테, 가장자리만 받친 큰 렌즈가 처짐("처짐 과장") ③ 지름 막대 "가장 큰 굴절망원경 1.02 m · 1897" → 반사망원경: 1668 뉴턴식(오목거울 + 평면거울), "모든 색이 한 점에", 뒤의 받침점 → 조각 36개 → "켁 10 m · 1993" → 전파망원경: 접시에 떨어지는 평면 파면이 수신기로 모이는 원호, 사람 눈만큼 또렷하려면 필요한 지름 가시광 2 mm → 전파 21 cm 880 m("× 약 40만") → 지구본 위 전파망원경 여섯 곳(하와이 · 애리조나 · 멕시코 · 칠레 · 스페인 · 남극)과 기선, 가상의 접시(지름 ≈ 지구), 2019 블랙홀의 그림자(설명 그림) → 대기 단면: 흔들리는 별빛, 파장별로 막히는 높이(가시광선 · 전파만 땅까지), 허블 · 제임스웹이 공기 위로 → 같은 축척의 허블 2.4 m와 제임스웹 금빛 육각 18조각(날개 펼침, 6.5 m, 적외선) → 오해(배율이 높을수록 좋을까? 배율만 높이면 흐린 얼룩만 커짐, 입구를 넓히면 두 별로 갈라짐) → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 광학 모형에서 나옵니다. 얇은 렌즈의 색별 초점 거리(렌즈 제작자 공식 + 크라운 유리 코시 근사, 화면은 분산 ×8), 포물면 반사(모든 색이 한 초점), 접시의 같은 경로 파면, 모으는 빛 ∝ D², 에어리 무늬 [2J₁(v)/v]²와 레일리 기준, 같은 또렷함의 지름 1.22 λ/θ, 갈릴레이 위성 궤도, 대기의 대략적 차단 높이를 씁니다.
- 단순화: 광선 수·굵기, 색수차(×8)·렌즈 처짐은 과장이며 화면에 적었습니다. 이상적인 렌즈·거울(수차 없음), 단색·원형 입구의 회절 무늬, 모식적인 대기 높이("높이는 대략"), 블랙홀 그림자는 실제 사진이 아닌 설명 그림입니다. 상세는 [에피소드 README](../../episodes/telescope-types/README.md)와 [제작 메모](../../episodes/telescope-types/brief.md).
- 소리: 초점 밝기는 낮은 음의 크기(입구 ×2에서 커짐), 두 별이 갈라지면 한 음이 두 음으로, 색수차는 어긋난 세 음의 맥놀이 → 거울에서 한 음으로 모임, 전파는 낮은 웅웅, 긴 파장일수록 낮은 음, 로그 읽음값은 열 배마다 단3도씩 오르는 음, 제임스웹 조각 18개는 틱 18개입니다. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 56개).
