# 강착원반 — 별이 블랙홀 둘레에서 원반이 되는 이유

[영상 재생·다운로드](accretion-disk.mp4)

174.4초, 1080×1920, 30fps, H.264(CRF 18, 28.2 MB)/AAC, −14.1 LUFS. 한국어 음성(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
사용자 주제(2026-11-10, 36번): "울집 아이(초5)가 블랙홀에 별이 빨려 들어갈 때 강착원반이 생기는 이유를 알고 싶다는데, 강착원반뿐 아니라 관련된 현상들을 설명해 주는 영상을 가장 먼저 만들어 보자." 11번(에딩턴 한계)·12번(퀘이사)과 겹치지 않게 **별이 찢어져 원반이 되는 과정**과 **왜 원반인가(각운동량)**를 중심에 두었습니다. 화면과 내레이션에서 다른 편을 언급하지 않습니다.

**화풍**(2026-11-10 사용자 결정 "발광체가 조금씩은 있으면 좋겠어", 분석 문서 PR #63의 8절 기준 초안 적용): 어두운 청록 바탕, 장면마다 채워진 발광체 하나(별 → 줄기 → 고리 → 원반, 11·12번과 같은 Glow 버퍼), 그 둘레의 가는 하늘색 선 계기, 난색(호박·주황, 안쪽은 푸른 흰색)과 한색(하늘색) 한 쌍. 화면 전체 블룸·흰 번쩍임·하드컷 없음. 무대 하나(블랙홀 중심 궤도면)를 9장면이 공유하고 카메라만 움직입니다. 어두운 페이드 전환은 관측 장면 앞뒤 2회. 사용자 시안 확인 없이 만들었습니다.

0초 프레임이 쇼츠용 썸네일입니다. 비스듬히 본 주황빛 강착원반과 가운데 검은 블랙홀, 흰 질문 "블랙홀 둘레엔 왜 원반이?"와 큰 호박색 답 "곧장 못 떨어져서". 약 1초에 제목이 머리글로 바뀌고, 마지막 문장 끝(약 172.3초)에 포스터가 돌아옵니다.

흐름(9장면, 평균 19.4초): 훅(원반) → 이름의 뜻 "降着 = 내릴 강·붙을 착", 원반 가장자리에 내려앉는 기체 → 1988년 마틴 리스의 예측(포물선 길로 다가오는 별, "예측: 밝은 빛") → 기조력(가까운 쪽·먼 쪽 화살표, '기조력 ÷ 별의 중력' 막대가 '버티는 한계'를 넘으면 별이 늘어남) → 스파게티화(국수 가락처럼 길어진 줄기) → 무거운 블랙홀이라면(질량 눈금 100만 배 → 2억 배: '빛도 못 나오는 경계'가 '별이 찢어지는 거리'를 따라잡아 덮고, 별이 찢어지지 않은 채 사라짐. "경계 × 200, 찢는 거리 × 5.8") → 찢긴 뒤(절반쯤은 우주로, 절반쯤은 되돌아옴. 모형 집계 표시) → 핵심(기체 한 덩이의 '옆으로 움직이던 운동' 화살표와 가지 못하는 '곧장 떨어지는 길') → 각운동량(거리 × 옆 속도 = 그대로, 가까울수록 빨라짐) → 충돌(되돌아온 줄기가 제 꼬리와 부딪혀 고리가 됨) → 납작해지기(카메라를 눕혀 두께가 줄어드는 것을 보임) → 원반 안(안쪽 표식이 바깥쪽 표식을 앞지름 → 나선으로 내려오는 표식, "각운동량은 바깥으로" → 온도 띠: 바깥에서 안쪽으로 뜨거워져 자외선과 엑스선) → 관측 2014년(약 2억 9천만 광년 밖 은하의 빛과 몇 달에 걸친 밝기 곡선) → 관측 2019년(M87 블랙홀 사진을 본뜬 고리: 다가오는 쪽이 더 밝음, 아래에 같은 효과를 넣은 모형 원반) → 오해(멀리서는 같은 질량의 별과 같은 중력: 다른 별들은 보통 궤도를 돈다) → 포스터.

- 모형: 화면·계기·소리가 [model.mjs](../../episodes/accretion-disk/model.mjs) 하나에서 나옵니다. 시험 입자 7,000개의 조석 붕괴(Paczyński–Wiita 퍼텐셜: 최내곽 안정 원궤도 3 Rs와 근일점 이동 재현, 속박 비율은 계산 결과 약 47%), 충돌은 되돌아온 입자의 반지름·수직 속도 감쇠로 흉내(에너지를 잃고 각운동량은 보존 → 같은 각운동량의 원궤도로), 원반은 국소 원궤도 속도와 느린 안쪽 이동, 온도 T ∝ r^(−3/4), 힐스 질량 r_t = R_s → 약 1.1×10⁸ 태양질량. 상세는 [제작 메모](../../episodes/accretion-disk/brief.md).
- 관측 사실 / 설명 모형 / 비유: 관측 사실은 2014년 ASASSN-14li(발견·거리·몇 달에 걸친 감소)와 2019년 EHT 사진에서 고리 한쪽이 더 밝다는 것입니다. 별이 찢어지는 그림·줄기·충돌·원반·나선은 설명 모형입니다. 밝기 곡선은 보고된 약 60일 감소 척도를 따른 모형 곡선이고, 고리는 사진을 본뜬 그림입니다. 피겨 선수는 비유입니다.
- 단순화: 별 크기(지평선 대비 약 4배 과장)와 근접 거리(실제 조석 반지름 약 23 Rs → 8 Rs), 시간 압축(장 제목 키커에 선언), '통째로' 장면의 별 크기, 블랙홀은 검은 원만(빛의 휨 생략), 원반 안의 각운동량 수송 기구(자기회전 불안정성 난류)는 "서로 비벼집니다"로 줄임. "약 1억 배"는 태양 같은 별·자전 없는 블랙홀 기준. 최내곽 안정 원궤도·제트·효율 수치는 넣지 않았습니다.
- 소리: 설명용 합성음 24개(우주 현상은 소리를 내지 않음). 기조력 막대 값에 비례해 높아지는 음, 찢어지는 순간의 낮은 잡음, 질량 눈금의 상승음, 통째로 삼켜질 때의 낮은 음, 추적한 기체의 옆 속도에 비례하는 음높이, 충돌 잡음 3회, 나선 낙하의 상승음 등. 기본음은 모두 700 Hz 미만, 패닝 없음.
