# 업로드 정보 — 66. 꼬리날개 (169.1초)

공통 설정(카테고리, 아동용 여부, 합성 콘텐츠 표시, 수익화 전 확인)은 [업로드 공통 설정](../../docs/YOUTUBE_UPLOAD.md)에 있습니다. 설명란은 마크다운이 적용되지 않으므로 평문으로 썼습니다.

설명
```text
보통의 비행기에서 꼬리날개만 떼어 내면, 돌풍 한 번에 뒤집힙니다. 같은 돌풍을 맞아도 꼬리날개가 있는 쪽은 한 번 끄덕이고 돌아오고, 없는 쪽은 틀어질수록 더 틀어집니다. 꼬리날개가 무게중심에서 멀리 떨어진 작은 날개이기 때문입니다.

- 뒤에 깃털을 단 화살이 곧게 날아간다는 것은 오래전부터 알려져 있었음
- 꼬리날개 전체를 가리키는 영어 empennage 는 프랑스어 empenner, '화살에 깃털을 달다'에서 온 말
- 1871년 프랑스의 알퐁스 페노는 꼬리날개를 단 고무줄 비행기를 11초 동안 약 40미터 날렸음. 조종하는 사람 없이 스스로 자세를 바로잡으며 날았음
- 수평 꼬리날개는 기수(비행기의 머리)가 위아래로, 수직 꼬리날개는 좌우로 틀어지면 바로잡음
- 돌리는 효과는 힘에 축까지의 거리를 곱한 값. 시소에서 축에서 멀리 앉을수록 잘 기우는 것과 같음
- 꼬리날개가 없고 무게중심이 날개의 양력이 걸리는 자리보다 뒤에 있으면, 기수가 들릴 때 늘어난 양력이 기수를 더 들어 올림. 들릴수록 더 들림
- 꼬리날개가 있으면 기수가 들릴 때 수평 꼬리날개도 바람을 더 가파르게 맞음. 보잉 737이나 A320 같은 여객기의 수평 꼬리날개는 넓이가 주날개의 4분의 1쯤이라 힘은 작지만, 무게중심까지의 거리가 훨씬 길어서 기수를 내리는 효과가 더 큼
- 지나쳐 내려가면 힘이 반대로 바뀌어, 한두 번 흔들린 뒤 제자리에 멈춤
- 수직 꼬리날개는 같은 원리로 기수가 다시 바람을 마주 보게 함. 풍향계가 늘 바람이 불어오는 쪽을 가리키는 것과 같음
- 꼬리날개 없이 나는 방법도 있음. B-2 폭격기는 컴퓨터가 날개 끝의 판을 쉬지 않고 움직이고, 종이비행기는 앞쪽을 여러 겹 접어 무게중심을 앞에 두고 날개 뒤끝을 살짝 올림

"꼬리날개는 무게중심에서 멀리 떨어진 작은 날개여서, 작은 힘으로도 비행기를 제자리로 되돌립니다"
```
