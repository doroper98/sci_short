- 그림: 정면 단면으로 본 심장(두 심방·두 심실·섬유 고리·판막·전도 길), 아래에 비어 있는 심전도 띠.

흐름:
1. 첫 물음 → 결과 먼저(흥분이 심장 전체를 덮음, 되감기) → 실제 빠르기로 뛰는 심장과 쓸고 지나가는 띠(심전도 = 전압을 시간에 따라).
2. 실 검류계: 자석 사이의 가는 실이 심장의 전압에 따라 흔들리고, 그 그림자가 흐르는 사진 띠에 선을 남김(실제 빠르기) → 굴곡마다 P Q R S T. 빛줄기의 끝은 펜 끝과 같은 점이고 세로로만 움직입니다. 실(옆으로 흔들림)과 기록점(세로) 사이의 렌즈·틈은 설명 그림으로 줄였고, 화면에 각주 한 줄 "렌즈로 실의 그림자를 띠 위 세로 틈에 비춤 · 설명 그림"을 두었습니다(PR #171 리뷰로 고침 — 처음에는 빛이 옆으로 움직이는데 펜은 세로로 움직였음).
3. 좌심실 벽의 세포 8개: 안쪽 −90 mV → 흥분이 옆 세포로 번짐(이온이 들어옴) → 전극을 오른쪽에 두면 경계가 다가와 위로, 왼쪽에 두면 멀어져 아래로(앞 선은 잔상) → 심장 전체로 한 박동을 천천히(심방·심실 수축 막대가 전기를 뒤따름).
4. 한 박동을 끊지 않고 네 장면에 걸쳐: 동방결절의 문턱 계기 → 발화 → 심방 흥분과 P파 → 심방 수축 / 방실결절에서 머무는 시간(섬유 고리가 막음), 평평한 선, 피가 마저 넘어감 / 히스 다발·푸르키네 섬유의 신호 점 → 심실 안쪽 벽부터 흥분, QRS(Q·R·S), 심방의 회복은 점선으로 따로(묻힘) / 심실 수축 → 방실판막 닫힘(첫째 소리) → 평평한 ST 동안 대동맥으로 피 → 바깥 벽부터 회복(한색 앞면) → T → 동맥판막 닫힘(둘째 소리) → 물결 셋 = 사건 셋.
5. 실제 빠르기로 겹쳐 그린 박동: 1분에 75번 → 120번(75번은 잔상), T 뒤 쉼 0.24초 → 0.05초 → 간격 재기(PR · QRS · QT, 모형의 값).
6. 정리.

**만든 방식**
- 무대: 정면 단면 심장 하나(`model.mjs` 의 모양). 근육은 화소마다 같은 시계의 상태(흥분 시각·회복 시각 지도)를 읽어 그립니다. 흥분은 동방결절에서의 거리(심방)와 안쪽 벽·심첨에서의 거리(심실)로 정한 설명 모형입니다.
- 같은 시계: 근육의 색, 전도 길의 신호, 수축, 판막, 피 알갱이, 심전도 펜, 이름표, 소리(`make_sound.mjs`)가 모두 `model.mjs` 의 `plan(timeline)` 이 만든 '박동 실행'의 같은 시각에서 나옵니다. 사건을 고정 개수로 되풀이하는 반복문은 없습니다.
- 색: 난색 = 전기 흥분(흥분한 근육, 신호, 펜), 한색 = 회복(재분극 앞면, T 뒤 쉼). 피는 무광의 어두운 빨강이고 빛나지 않습니다.
- 시간 배율은 머리글 키커에 선언했고 값은 실행의 빠르기에서 계산합니다: 결과 먼저 약 7배, 세포 줄 약 1,520배(흥분 사이 시간 생략), 한 박동 천천히 약 10배, 심방 약 67배, 방실결절 약 310배, 심실 약 280배, 수축 약 69배, 나머지는 실제 빠르기.
- 심전도 곡선은 한 유도(팔다리 II 유도 꼴)의 교과서 모양을 가우스의 합으로 그린 것입니다. 모양과 방향은 전극의 자리에 따라 다릅니다(화면에는 적지 않음).
- 심박수에 따른 늘이고 줄임은 PR ∝ (RR/0.8초)^0.4, QT ∝ (RR/0.8초)^0.5(Bazett 꼴)로 어림한 설명 모형입니다.
- 대동맥은 좌심실 위에서 오른쪽으로 나가게 그렸습니다(실제로는 위로 솟음). 폐동맥은 그리지 않았습니다.
