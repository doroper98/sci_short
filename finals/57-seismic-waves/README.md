**재난 주제의 선.** 겁을 주는 연출·피해 장면·특정 지진은 쓰지 않았습니다. 조기경보는 "지진을 내다보는 것이 아니라, 이미 난 지진을 빨리 알리는 것"(s21)이고, 화면도 진원 가까운 곳에는 경보보다 S파가 먼저 닿는 것을 그대로 보입니다(Fable 검수 지적). 지진 규모·로그는 다루지 않습니다.

흐름: 첫 물음(결과 먼저: 두 고리가 단면을 건너 관측소를 두 번 흔듦) → 되감기 → 단층에 힘이 쌓임 → 다시 미끄러짐, 지진계 기록에 약한 흔들림 → 큰 흔들림(표면파는 다루지 않는다는 각주) → 같은 지진 다시·확대: 관측소 아래 알갱이가 제자리 둘레에서만 흔들림 → 그리스어 seismos(흔들림) → 1900 올덤: 드럼 지진계 기록지에 두 흔들림 → P(primary 첫째)·S(secondary 둘째) → 바위 한 줄 확대(용수철은 비유): 덩어리를 누르면·비틀면 되돌아옴 → 미는 흔들림이 이웃으로 넘어감 → 같은 줄을 미는 것/비트는 것만 바꿔 경주(미는 흔들림이 닿았을 때 비트는 흔들림의 자리를 잔상으로) → P: 알갱이가 나아가는 방향으로 앞뒤로 → 바위·물 줄에서 P 가 물을 지남 → 실제 빠르기 그대로 1초에 약 6 km → S: 알갱이가 직각으로 → 실제 빠르기 1초에 약 3.5 km(P 눈금은 흐리게, 같은 시계) → 바위·물 줄에서 S 가 물 앞에서 멈춤 → 작은 지진·큰 지진(크기만 바꿈): 같은 때 도착 → 50 km·100 km 관측소: 간격이 벌어짐 → 간격 1초 칸이 켜질 때마다 거리 막대가 8 km 씩 → 100 km 에서 12초 → 조기경보: 20 km 관측소가 P 를 잡음 → 분석 → 경보 → 100 km 도시에 "S파까지 N초", 가까운 곳은 S파가 경보보다 먼저, 시간표("지진이 난 뒤에") → 지구 단면: P·S 파면 → S 가 바깥 핵에서 막힘 → S파 그늘 → P 는 바깥 핵을 지나 반대쪽에 닿음, 바깥 핵 · 액체 → 정리.
