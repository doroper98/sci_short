# 별은 왜 반짝일까 — 반짝임은 공기가 만든다

[영상 재생·다운로드](twinkle.mp4)

175.7초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 설명용 소리(사용자 결정으로 700 Hz 이상의 높은 음은 모두 뺐음 — 행성 587 Hz·달 294 Hz의 고른 음, 남은 햇빛, 그림자 띠, 바람 잡음만 남음). 배경음악 없음. 화면에 각주·출처 줄 없음. 주제 후보 목록 4번.
2026-11-05 보완: 첫 프레임 = 썸네일 규칙을 적용해 다시 렌더했습니다. 검은 화면에서 밝아지던 시작을 없애고, 0초에 은하수·초승달·밝은 별의 밤하늘과 큰 제목 "별은 왜 반짝일까 / 반짝임은 공기가 만든다"가 보이며 약 1초에 머리글로 줄어듭니다. 카메라가 움직일 때 하늘 왼쪽 끝에 생기던 약 16 px의 빈 띠도 고쳤습니다. 내레이션·자막·소리 표는 바뀌지 않았습니다.

흐름: "오늘은 밤하늘의 별이 왜 반짝이는지, 그리고 달과 태양은 왜 반짝이지 않는지 알아볼까요?"(반짝이는 별, 고요한 달) → 별빛은 우주를 건너오는 내내 고르고 반짝임은 마지막 대기에서 → 이름(twinkle = 눈을 깜빡이다, scintillation = 라틴어 불꽃) → 뉴턴의 처방(높은 산꼭대기의 고요한 공기) → 핵심(온도가 다른 공기 = 움직이는 렌즈) → 공기 덩어리가 빛을 모았다 흩어 땅 위에 밝고 어두운 무늬 → 무늬보다 작은 7 mm 눈동자, 실제 속도 1초에 밝아짐 21번 → 별은 점(빛줄기 하나가 통째로 흔들림) → 행성은 작은 원반(서로 메워 거의 고름) → 달·태양은 별보다 수십만 배 넓어 평균, 가장자리만 일렁 → 지평선 가까운 별(공기 약 6배) → 낮게 뜬 시리우스의 색 반짝임 → 개기일식 직전의 그림자 띠 → 높은 산 천문대와 허블 → 레이저 인공 별과 변형 거울(적응광학) → 오해(별이 스스로 깜빡인다 → 우주에서 보면 고요) → 결론.

- 모형과 단순화: 씨앗을 고정한 FFT 난류 위상 화면 하나(바람에 실려 흐름)에서 하늘의 반짝임, 단면 광선, 땅 위 무늬, 밝기 그래프, 소리가 함께 나옵니다. 행성·달의 고른 밝기는 원반의 발자국 평균으로 계산했습니다. 하늘과 그래프는 느린 화면(라벨 표시)이며 1초 막대만 실제 속도입니다. 하늘의 달은 실제보다 크게 그렸고 비교 칸의 크기는 각도 축척이 아닙니다(각도는 숫자로 표시). 그림자 띠는 "유력한 설명"으로 표시했습니다. 상세는 [에피소드 README](../../episodes/twinkle/README.md)와 [제작 메모](../../episodes/twinkle/brief.md).
