# AI는 어떻게 배우고 답할까 — 다음에 올 말을 맞히는 연습

[영상 재생·다운로드](ai-learning.mp4)

153.5초, 1080×1920, 30fps, H.264(CRF 18, 12.0 MB, 약 0.63 Mbps)/AAC, −14.05 LUFS. 한국어 음성(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
사용자 주제(2026-11-10, 그대로): "ai는 어떻게 학습하고 추론하는가? 우리가 쓰는 chatgpt나 claude는 어떤 과정을 거쳐 우리가 쓰게 되는가". 사용자 지시 "이건 스케쥴링 된 영상 업로드 아니고 별도로 내일 아침에 업로드 요청을 할게. 디자인언어와 법칙을 잘 적용해서 만들어."

**화풍(영상미 문법)**: 무대 하나에 세로 한 줄 — **글 띠**(무광 토큰 타일) → **모델**(무광 판 위 네 층의 손잡이 = 매개변수의 비유) → **계기**(다음 토큰의 확률 막대). 빛나는 것은 신호뿐입니다. 따뜻한 물결은 모델의 계산(순전파), 차가운 물결은 정답에서 오는 고침(역전파), GPU 칩의 맥박은 계산입니다. 손잡이는 물결이 지날 때만 그 색으로 잠깐 밝아집니다. 난색 = 모델의 계산과 선택, 한색 = 정답·사람의 평가·고침·확인. 조건을 바꾸는 곳에는 연회색 점선 잔상(고치기 전 막대, 이어 쓰기만 한 답, 다른 선택 전의 '파란')을 남깁니다. 큰 숫자는 장면마다 하나이며 사건 프레임에 뜹니다(1955, 정답 확률 12 → 22 → 45 → 74%, 1,750억, 15조, 2022). 장면별 인과 사슬 표는 [제작 메모](../../episodes/ai-learning/brief.md).

0초 프레임이 쇼츠용 썸네일입니다. 질문 토큰 타일 "하늘은 / 왜 / 파랄까?", 손잡이가 박힌 모델 판, 첫 답 토큰의 확률 막대('햇빛'이 호박색), 흰 질문 "ChatGPT는 어떻게 답할까?"와 큰 호박색 답 "다음 말 맞히기". 약 1초에 제목이 머리글로 줄고, 마지막 문장 끝 1.6초 전(151.2초)에 포스터가 돌아옵니다.

흐름: "오늘은 ChatGPT나 Claude 같은 AI가 어떻게 배우고 답하는지에 대해 알아볼까요?"(따뜻한 물결 → 막대 → 고른 타일이 날아올라 붙음, 약 1.5초마다 7번 — "햇빛 속 파란 빛이 더 많이 흩어져서") → 1955 → 習(자주 날다) 카드와 조용한 학습 고리 두 번 → 본질: 추측 → 정답 칸 → 고침이 네 번, 정답 확률 12 → 74% → 학습 한 번을 느리게: 문장이 토큰으로 갈라지고 끝 토큰을 '?'로 가림 → 막대 → 정답 공개·오차 괄호 → 차가운 물결이 위로, 지나는 층의 손잡이가 돎 → 다시 계산, 옛 막대는 점선, 12 → 22% → '매개변수'·'역전파' 이름표 → 규모: 판이 줄어 같은 판들 사이의 하나가 됨(상징), 1,750억 → 토큰이 쏟아져 들어옴, 15조 → GPU 칩 8개의 계산 맥박(×2,000), 몇 달 → 다듬기: 이어 쓰기만 한 답("바다는 왜 짤까?")이 잔상으로 → 사람이 쓴 문답 예시(한색) → 두 답 중 더 나은 쪽 체크 → 2022 → 원칙 카드로 답이 고쳐짐 → 추론: 손잡이 고정, 물결 → 확률표 → 고름 → 붙음 → 다시 … → 같은 막대에서 다른 선택('파란' → '여러') → 오해: 인터넷 상자와의 연결을 끊고 판에서 한 조각씩 지음 → 그럴듯하지만 틀린 답 "바다가 비쳐서"와 '확인' 괄호 → 한 번 더 고르고 명제 "다음에 올 말을 맞히는 연습" → 포스터.

- 모형: 화면·숫자·소리가 `scenes.mjs`의 계획(plan) 하나에서 나옵니다. 순전파·역전파 물결의 시각, 손잡이 각도(역전파가 그 층을 지날 때만 바뀜), 확률 막대, 붙는 토큰의 시각.
- 단순화: 손잡이는 매개변수의 비유(제목 "손잡이 = 매개변수"), 판의 손잡이 28개와 규모 장면의 판 격자는 상징(키커 "크기는 상징"), 토큰은 낱말 단위로 단순화, 막대의 확률값은 설명용(키커 "확률은 설명용"), 순전파·역전파는 약 1초로 느리게(키커 "한 번을 느리게"), "몇 달"은 몇 초로(키커). 오해 장면의 틀린 답은 하늘이 파란 이유에 대한 흔한 오해(실제는 공기 분자의 레일리 산란)를 예로 썼습니다.
- 소리: 순전파마다 131 Hz 낮은 음, 역전파마다 90→200 Hz 휘익, 타일이 붙을 때 196 Hz, 숫자·표시 틱, 정답·문답 예시 스웰. 모든 기본음 700 Hz 미만, 사건 38개, 패닝 없음. 설명용 합성음.
