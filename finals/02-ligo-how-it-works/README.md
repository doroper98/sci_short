# LIGO는 어떻게 잴까 — 어둠 속의 작은 밝아짐

[영상 재생·다운로드](ligo-how-it-works.mp4)

175.5초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 광학 모형에서 만든 설명용 소리(광검출기 밝기 = 음량, 왕복 틱, 단계별로 걸러지는 땅 울림, 두 관측소 틱). 배경음악 없음.

흐름: 예측 질문(겹친 빛은 밝을까 어두울까 → 어두움) → 기원(干涉計 어원, 1887 마이컬슨 → 1972 바이스 설계 → 2015 첫 검출) → 본질(마루·골 중첩, 길이를 자로 재지 않고 밝기로 읽음) → 분할(레이저 → 빔 분할기 → 직각 4 km 팔, 각 팔 약 300회 왕복 = 1,200 km) → 재결합(어두운 무늬, 중력파 통과 시 ΔL ≈ 4×10⁻¹⁸ m → 밝기 변화) → 격리(지면 진동 1조 배, 40 kg 거울 4단 진자, 10 Hz에서 1억분의 1, 초고진공 관) → 일치(핸퍼드·리빙스턴 3,002 km, 10 ms 창, 6.9 ms) → 오해(시계로 재지 않음) → 결론.

- 단순화(화면에는 표시하지 않음): 밝기 변화 약 2×10⁸배 과장(ΔL 숫자는 실제), 팔 길이 ±8% 과장, 완전 어두운 무늬 운전(실제는 DC 오프셋), 300회 왕복은 공동 축적의 대리, 진자 흔들림 폭은 그림용, 핸퍼드 글리치는 설명용 가상. 상세는 [제작 메모](../../episodes/ligo-how-it-works/brief.md)와 [에피소드 README](../../episodes/ligo-how-it-works/README.md).
