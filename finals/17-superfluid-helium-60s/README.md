# 헬륨을 영하 271도로 식히면 — 60초 핵심판 (길이 실험)

[영상 재생·다운로드](superfluid-helium-60s.mp4)

59.9초, 1080×1920, 30fps, H.264/AAC 48 kHz, −14.1 LUFS(원본 −14.0). 2026-11-08 사용자 결정 "60초 핵심판 1편 시험"에 따른 **길이 실험**입니다.

- **무엇을 비교하나**: 같은 주제·같은 장면·같은 음성의 3분판([17-superfluid-helium](../17-superfluid-helium/), 166.2초, 공개 약 1.2천 회)과 60초판. 첫 문장 "오늘은 ~ 알아볼까요?"는 남겨 **길이 하나만** 바꿨습니다(첫 문장 비교는 11-07 업로드분으로 따로, 11-14 판정 예정).
- **어떻게 만들었나**: 다시 렌더하지 않고 원본 최종본을 문장 사이 쉼에서 잘라 이었습니다(`episodes/superfluid-helium/cut60.py`, 구간은 `cut.json`). 남긴 문장: s01·s02(훅) → s06(2.17 K 람다점) → s09(초유체 이름) → s10·s11(원자의 물결, 한 덩어리) → s13(벽을 타는 막) → s20(결론, 포스터 복귀). 뺀 것: 어원, 1868·1908·1938 역사, 마찰 없음 설명(s12), 분수, 고체화, 가속기 활용.
- **확인한 것**: 0초 포스터 프레임, 이음매 다섯 곳 앞뒤 프레임(자막이 해당 문장과 맞음), 마지막 포스터 복귀를 직접 봤습니다. 이음매마다 "말소리 시작 − 자막 등장" 간격이 원본과 30 ms 안에서 같습니다(동기 유지). 음량은 ebur128 로 측정.
- **미수행**: 직접 청취, 휴대전화 재생. 이음매에 30 ms 소리 페이드를 넣었지만 효과음이 문장 사이에서 잘리는 소리는 들어 보지 않았습니다.
- **판정**: 공개 후 7일 조회수, 평균 시청 비율, 시청 대 스와이프를 3분판과 비교합니다(주간 채널 보고서 `docs/CHANNEL_GROWTH.md`).
