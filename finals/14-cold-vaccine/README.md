# 감기 예방 주사가 없는 이유

[영상 재생·다운로드](cold-vaccine.mp4)

161.8초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 **F4** ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 사건마다 합성한 설명용 음향. 배경음악 없음(2026-10-31 사용자 결정).

흐름: 질문(독감 주사는 해마다 맞는데 감기 주사는 왜 없을까) → 기원(감기 感氣의 어원, 1946년 영국의 감기 연구 기관과 자원자 약 2만 명, 1956년 리노바이러스 분리, 40여 년과 논문 천 편) → 본질(백신은 얼굴 하나를 외우게 하는 훈련 · 홍역 1 · 소아마비 3) → 메커니즘(3단 계기판: 캡시드 전체 → 결합 자리 확대 → 교차 중화 행렬) → 사례(2016년 원숭이 실험의 50종 혼합, 169종의 약 3분의 1) → 대비(독감은 조성을 해마다 바꾼다) → 오해(독감 주사는 감기를 막지 못한다) → 한 줄 결론.

- **핵심 명제**: "백신은 얼굴 하나를 외우게 하는 훈련이고, 감기 바이러스는 외울 얼굴이 너무 많습니다."
- **수치**: 리노바이러스 169종(RV-A 80 · RV-B 32 · RV-C 57, VP1 염기 차이로 정의한 유전형). 캡시드 지름 약 30 nm, VP1~VP4 네 단백질이 한 벌이고 60벌이 껍질을 이룬다. 결합 자리는 HRV14 탈출 돌연변이로 정의된 네 자리(NIm-IA·IB·II·III) 계열. 감기를 일으킬 수 있는 바이러스는 200가지가 넘는다. 2016년 붉은털원숭이에서 50종 혼합 접종 시 49종에 항체 반응.
- **모형과 단순화**: "얼굴"과 "외운다"는 비유다. 교차 중화 행렬은 실제 측정 자료가 아니라 "대각선만 밝다"는 성질만 보이는 설명용 모형이며, 실제로는 일부 종류 사이에 약한 교차 반응이 보고된다. 항체는 캡시드보다 훨씬 작지만 읽히도록 크게 그렸고 결합 자리의 요철은 설명용이다. 독감 입자와 표면 돌기는 모식도다. 50종 실험은 원숭이 결과이며 사람용 백신이 만들어졌다는 뜻이 아니다(화면에 "원숭이 실험 · 2016" 명시). 전체 목록은 [제작 메모](../../episodes/cold-vaccine/brief.md).
- **범위**: 치료·복약에 관한 내용은 넣지 않았다. 면역학적으로 "왜 어려운가" 하나에 집중했다.
