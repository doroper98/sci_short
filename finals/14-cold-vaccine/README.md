# 감기 주사는 왜 없을까 — 범인이 200가지

[영상 재생·다운로드](cold-vaccine.mp4)

172.1초, 1080×1920, 30fps, H.264/AAC, −14.1 LUFS. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 쇼츠용 썸네일입니다(사용자 피드백 "쇼츠 친화적으로"를 처음부터 반영). 화면 가득 모양·색이 저마다 다른 바이러스 무리 가운데 주사기 하나, 흰 질문 "감기 주사는 왜 없을까?"와 큰 주황 답 "범인이 200가지". 약 1초에 제목이 머리글로 줄고 답은 부제가 되며, "까닭은"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 독감 예방 주사는 있는데, 감기 예방 주사는 왜 없는지 알아볼까요?"(독감 주사 ✓ / 감기 주사 ?, 한 해 2~3번의 예시 달력) → 이름(感氣는 우리나라에서 만든 한자말, 고뿔 ← 곳블 = 고(코) + 불, vaccine ← vacca 라틴어 소, 1796 · 제너 우두) → 1960~70년대 한 형(RV13 등) 백신은 맞춘 형만 막고 다른 형은 통과 → 백신 = 겉모양을 미리 보여 주기, 항체 끝이 겉면 고리에 맞물림(맞물림 0 → 100%) → 항체 없음: 세포 안으로 / 항체 있음: 들어가지 못함 → 감기 = 200가지 넘는 바이러스의 묶음 → 리노바이러스 169형 격자(A 80 · B 32 · C 57, rhino- = 코) → 한 형에 맞춘 항체를 169형에 대 보면 1 / 169 → 한 번 생긴 면역은 다른 형을 막지 못함 → 서늘한 콧속(33~35 °C)에서 더 잘 불어남(세포 실험) → 주사 항체는 주로 핏속, 점막 겉면엔 적음(설명 모형 100 : 3) → 독감은 유행 형 3가지 안팎, 해마다 맞춘 백신 → 저울: 며칠 앓는 병 vs 169가지를 다 담은 백신의 비용·위험 → 2016년 Emory 대학 50가 백신, 붉은털원숭이 두 마리 1차 41·45 → 추가 접종 49 / 50, "감기 예방 효과는 아직 미확인" → 오해(항생제? → 세균용, 바이러스에는 세포벽이 없음) → 손 씻기, 손으로 코·눈 만지지 않기 → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형 하나에서 나옵니다. 169형마다 씨앗 고정 4개 수의 겉모양(고리 모양·색), 맞물림 fit = exp(−|s_k − s_j|²/σ²)(σ = 0.16, 0.5 이상이면 막음), 항체 끝 = 자기 형 고리의 보형, 콧속 온도에 따른 증식(배가 시간 모형), 혈액 대 점막 겉면 항체 비, 원숭이 접종 결과 41/45 → 49/50, 손 씻기의 지수적 씻김.
- 단순화: 바이러스 모양·색·크기는 화면용(실제 약 30 nm, 색 없음 — 색은 '겉모양이 다르다'의 비유). 169칸 배열과 모양, 증식 속도와 점막 항체 비는 설명용 모형입니다. 콧속 온도 효과는 세포 실험 결과로 표시했습니다. 독감 해마다 갱신은 이름 없는 색 변화 고리로 그렸습니다. 원숭이·소·손은 단순 실루엣입니다. 상세는 [에피소드 README](../../episodes/cold-vaccine/README.md)와 [제작 메모](../../episodes/cold-vaccine/brief.md).
- 소리: 맞물림은 낮은 '딸깍'(247 Hz 틱 + 110/165 Hz 화음), 안 맞음은 둔한 '툭'(70 Hz). s06 맞물림 정도가 음높이 98 → 196 Hz, 격자·세기는 아주 작은 틱, 증식은 개수의 로그를 음높이로(온도마다 한 음), 원숭이 항체 수는 110·2^(n/50) Hz, 손 씻기는 700 Hz 아래 물소리 잡음. 별의 반짝임 편 피드백에 따라 모든 효과음의 기본음은 700 Hz 미만입니다.
