0초 프레임이 썸네일입니다: 흰 물음 두 줄 "1초에 점 5억 개 가까이 칠하는 / GPU는 어떻게 계산할까?"와 그 아래 가장 큰 주황 주제어 "GPU"(물음의 약 4배). 그림은 큰 화소로 된 화면 속 무광 공(왼쪽 옆의 빛을 받아 왼쪽 절반이 밝음)과 화면 아래 명령 부분 + 계산기 32개 묶음.

흐름: 첫 물음 → 광원이 돌고 매 프레임 모든 점을 다시 칠함(되감기) → 830만 점 × 60 → 화면 아래의 GPU 칩, 계산한 점이 화면으로(1999 · GeForce 256) → 점 16개 확대: 빛을 받는 각으로 밝기, 점마다 넣는 숫자(각도)만 다름, 차례로 16박자 → 순서를 섞어도 같은 그림(서로 기다리지 않음) → 명령 하나로 16개 한꺼번에 1박자(SIMD) → 광원이 옮겨 가고 다시 한꺼번에 → CPU 코어 4개가 점을 하나씩(빠른 박자) / GPU 명령 부분 + 계산기 32개(워프)가 32점씩(느린 박자), 같은 때 시작한 경주 → 칩 전체 128묶음 × 128 = 16,384 → 박자 5.7 대 2.52 GHz, 1초에 82.6조 번 → 조건에 따라 갈리면 16개는 멈춤, 2박자(갈리지 않으면 1) → 앞의 답을 기다리는 사슬, 1/32 → CPU와 GPU가 나눠 맡음 → CUDA 2006 → 행렬 A × B = C, 한 칸 = 한 줄 · 한 열을 곱해 더함(67), 명령 하나로 16칸 한꺼번에 → 2012 GPU 두 개, 틀린 비율 15.3% 대 26.2% → 여러 칩 → 처음의 화면, 정리.

- 무대: 하나의 '화면 + 칩' — 큰 화소 화면과 그 아래 계산기 묶음. 확대·비교 장면은 그 일부를 키운 것(작은 화면 잔상과 렌즈로 이음).
- 색: 난색 하나 = 데이터와 결과(빛, 점의 값, 계산 중인 계산기, 결과 칸), 한색 하나 = 명령(제어 신호). 멈춰 기다리는 계산기는 어두운 회청.
- 시간 배율: 첫 장면은 실제 속도(1초에 60장), 확대·비교 장면은 "나노초를 초로 · 아주 느리게"(머리글 키커에 선언). CPU 와 GPU 의 박자 비(5.7 : 2.52)는 지켰습니다.
- 단순화: 공의 밝기는 빛과 면이 이루는 각 하나로 계산하는 모형(실제 게임 화면은 점마다 수백 개 명령). "점 하나 = 계산 하나 = 계산기 하나"로 그림(실제로는 계산이 계산기보다 훨씬 많고 워프들이 번갈아 오름). CPU 코어는 4개로 그림(2022년 데스크톱 CPU 는 16개, CPU 코어에도 SIMD 계산 장치가 있음 — 대본은 말하지 않음). 계산기 = 엔비디아가 'CUDA 코어'라 부르는 FP32 계산 줄. 82.6조 번은 FP32 최대값(곱하고 더하기 한 번을 2번으로 셈).
- 소리: 모두 합성한 설명용 소리(녹음 아님), 사건 26개(되풀이 포함 132번), 모든 기본음과 잡음 대역은 700 Hz 아래(가장 높은 기본음 440 Hz). 명령 하나 = 낮은 음 + 짧은 틱(점 16개, 워프 32개, 행렬 16칸에서 같은 소리), 차례로 = 틱의 줄, 갈림 A·B = 두 음. 화면과 같은 시각표(`sound.json` ↔ `events.json` 대조 통과).
