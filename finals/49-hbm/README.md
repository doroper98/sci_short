# HBM — 메모리를 왜 쌓을까

[영상 재생·다운로드](hbm.mp4) · [HDR 판](hdr/hbm.hdr.mp4)(유튜브용)

- 169.3초, 1080×1920, 30fps, H.264(24.3 MB)/AAC, −14.05 LUFS(TP −1.36 dBTP).
- 한국어 음성: **Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`.
- 자막: 실제 음성의 글자 시각에 맞춤, 마지막 줄 baseline 1380.
- 배경음악 없음. 표준 화풍 + 질감 층(`film` — 숯색 바탕, 종이 같은 고정 그레인, `lit()` 둘레의 은은한 번짐). 픽셀 화풍이 아닙니다.

- 2026-11-26 밤 자동 제작. 따로 서는 독립 편이라 "N of M" 표시가 없고, 47·48 을 봤다고 가정하지 않습니다. AI 계산은 쓰이는 곳의 예로만 다룹니다(s22·s23).

0초 프레임이 썸네일입니다.
- 글: 흰 물음 두 줄 "메모리 칩을 12층으로 / 왜 쌓아 올릴까?"와 그 아래 가장 큰 주황 주제어 "HBM"(물음의 약 2.8배).
- 그림: 패키지 단면을 가까이에서 봅니다 — 계산기 칸이 꺼진 GPU, 12층으로 쌓은 메모리 기둥, 실리콘 판 속의 선 묶음.

흐름:
1. 첫 물음 → 결과 먼저(비트가 쏟아져 계산기가 켜짐, 되감기) → 이름 HBM = High Bandwidth Memory.
2. 계산기 칸 9 → 36 → 144, 메모리 선은 그대로 → 일하는 비율이 떨어짐(개념도) → 메모리 벽 1994 → 2013 표준, 2015 첫 그래픽 카드(기둥이 들어섬).
3. 선 4줄로 드문드문 오는 숫자, 대부분의 칸이 기다림 → 숫자 하나(32비트)가 오는 동안 계산 328번(RTX 4090 · GDDR6X — HBM 아님, 최대 성능끼리의 비) → 선 4줄 / 16줄(같은 빠르기) → 본질 문장.
4. 기판 위 멀리 놓인 그래픽 메모리 → 땜납 구슬 0.75 mm, 데이터 선 32개 → 비트마다 긴 선 전체가 채워졌다 비워짐(설명 모형).
5. 인터포저가 들어서고 GPU 와 기둥이 나란히 → 같은 자로 확대한 땜납 구슬과 범프(구슬 한 칸에 15개쯤) → 1,024선 → 짧은 선의 전하, 에너지 막대 3.9 대 14.0 pJ → 1.2 TB/s.
6. 위에서 본 판: 옆자리 여섯 곳이 다 참 → 같은 자리에 1 → 12층 → 칩 확대(구멍을 뚫고 구리를 채움, TSV) → 12층 · 2024 대량 생산.
7. 아래층의 열이 층을 지나 위로(설명 모형) → 들린 맨 위 칩의 구멍 줄을 맞춰 내려앉힘.
8. 위에서 본 한 인공지능용 GPU: HBM 다섯 덩이가 낱말 한 조각마다 숫자를 모두 보냄 → 3.35 TB/s.
9. 처음의 단면, 정리.

**만든 방식**
- 무대: 하나의 패키지 단면(기판 · 패키지 기판 · 인터포저 · GPU 다이 · HBM 기둥). 기판 장면은 같은 무대에서 인터포저를 걷어 낸 배치이고, 위에서 본 판은 이 단면을 눕혀 본 것입니다.
- 색: 난색 하나 = 움직이는 에너지(비트, 일하는 계산기, 선의 전하, 열), 한색 하나 = 메모리(쌓은 DRAM 칩). 기다리는 계산기는 어두운 회색입니다.
- 시간 배율: 머리글 키커에 선언했고, 값은 `scenes.mjs` 의 `SCALE` 이 모형 상수에서 계산합니다.

  | 장면 | 실제 시간 | 화면에서는 |
  |---|---|---|
  | 첫 장면 | 약 0.8 ns(비트 8개) | 2초, 24억 배 느리게 |
  | 숫자 하나 | 약 4 ps | 2.5초, 6300억 배 느리게 |
  | 긴 선의 비트 하나 | 0.05 ns | 1.4초, 294억 배 느리게 |
  | 짧은 선의 비트 하나 | 0.10 ns | 1.4초, 134억 배 느리게 |
  | 낱말 한 조각 | 수십 ms | 1.45초, 약 60배 느리게 |

  쌓는 장면은 "만드는 순서 · 시간 생략", 열은 "설명 모형 · 시간 줄임"입니다.
- 단순화:
  - 1,024선을 24줄로 그렸습니다.
  - 단면의 두께와 길이는 크게 과장했습니다.
  - 계산기 칸은 144개로 그렸습니다(실제는 1만 개가 넘습니다).
  - 비트는 점으로 그렸습니다(실제는 전압의 높낮이).
  - 선 = 축전기(에너지 ≈ CV², C ∝ 길이)는 설명 모형입니다.
  - 열이 위로만 빠지는 것도 설명 모형입니다. 실제로는 옆·아래로도 조금 빠지며, 화면에 그렇게 적었습니다.
  - '328번'은 최대 성능끼리의 비입니다.
- 소리: 모두 합성한 설명용 소리입니다(녹음 아님). 사건 35개이고, 모든 기본음과 잡음 대역은 700 Hz 아래입니다(가장 높은 값은 되감기 휙 소리의 600 Hz). 화면과 같은 시각표를 씁니다(`sfx --events-check` 통과).
