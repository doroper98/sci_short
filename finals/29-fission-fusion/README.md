0초 프레임이 쇼츠용 썸네일입니다. 막 둘로 갈라지는 우라늄 원자핵(빨강 양성자·청회색 중성자 236개)과 바깥으로 날아가는 혜성 꼴 중성자 셋, 오른쪽 위에서 맞닿은 중수소·삼중수소, 위는 태양빛 주황, 아래 40%는 원자로의 푸른 빛(물결 무늬, 솟는 빛기둥, 연료봉 끝), 흰 질문 "쪼개도 합쳐도 에너지?"와 큰 주황 답 "철을 향하기 때문". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "줄어든"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 원자핵을 쪼개는 핵분열과 합치는 핵융합, 그 차이와 쓰임에 대해 알아볼까요?"(갈라진 조각이 느리게 날아가고, 위에서 융합 섬광, 새 우라늄 원자핵과 다가오는 중수소·삼중수소) → 밤의 땅: 도시 불빛, 푸른 발전소, 송전선을 따라 흐르는 빛, "31.7%"(2024 · 전기 중 원자력) → 하늘로 고개를 들어 태양, "400만 톤 · 1초마다 질량 → 빛" → 1938: 빛줄기가 내리는 실험실, 중성자가 날아와 우라늄이 바륨·크립톤으로 → 1939: 세포 분열과 원자핵 분열이 같은 동작, "fission" → 1920 에딩턴: 태양 속 수소 넷이 헬륨으로, "−0.7%" → 화면 폭을 채운 핵자 16개가 맥동하는 강한 힘의 결합선으로 산소 16이 됨 → 카메라가 물러나 큰 저울(흩어진 16개 쪽이 내려감), "−0.85%"로 밀고 들어감 → 원자핵의 골짜기(실측 결합 에너지를 뒤집은 3D 띠, 바닥에 빛나는 철): 넓게 → 철 → 우라늄 쪽(쪼개져 조금 내려감) → 수소 쪽(합쳐져 크게 내려감) → 우라늄 235 확대: 중성자 → 삼킴 → 출렁임 → 끊어짐(느린 화면 선언) → 원자로 노심: 연료봉·제어봉, 세대마다 중성자 빛줄기, "k = 1.15 → 0.92 → 1.00" → 증기 터빈 → 물속 노심의 푸른 체렌코프 빛 → 플라스마 속 중수소·삼중수소: 차가우면 튕기고 "1억 °C"에서 부딪혀 헬륨 + 중성자 → 3D 토카막(코일, 나선 자기장, 흐르는 플라스마), "1억 °C"와 48초 시계(KSTAR · 2024 발표) → 빛나는 바닥 위 같은 무게의 연료 두 알에서 빛 기둥이 안개 낀 대기로 솟고 카메라가 4배 높은 기둥을 따라 올라감 "× 4" → 옆으로 휙 넘어가 반은 물속 사용후 연료 다발(오래, 천천히 깜빡임) · 반은 플라스마에서 떠나가는 헬륨 → 플라스마로 밀고 들어가 ITER 홀(조명, 높이 약 30 m 눈금, 작은 사람 실루엣) "2034 · 2039" → 오해(수소폭탄처럼 터질까?): 플라스마가 출렁이다 식어 꺼짐, "연료 1 g 미만" → 골짜기 → 포스터.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형에서 나옵니다. 원자핵 채움, 액체방울 분열(설명 모형), 실측 B/A 골짜기, 원자로 중성자 수 N ← N·k(설명 모형), 쿨롱 반발과 융합, 토카막 자기장선과 플라스마 입자(설명 모형). 상세는 [에피소드 README](../../episodes/fission-fusion/README.md)와 [제작 메모](../../episodes/fission-fusion/brief.md).
- 단순화: 핵자는 구슬이 아니며 크기·색·배치는 설명용입니다. 분열은 실제 10⁻¹⁴초 이하를 느린 화면으로 보였습니다. 토카막은 KSTAR·ITER의 실제 형상이 아닙니다. 체렌코프 빛은 물에 잠긴 연구용 원자로에서 실제로 보이는 현상입니다.
- 소리: 분열 → 낮은 쿵, 융합 → 따뜻한 화음 부풂, 중성자 → 지나가는 바람 소리, 원자로 → 세대마다 분열 틱(k = 1이면 일정한 박자), 골짜기 → 내려간 높이만큼 내려가는 음(융합 330 → 110 Hz, 분열 196 → 147 Hz), 온도 → 로그 음높이, 토카막 → 낮은 맥동, 식음 → 음이 내려가며 꺼짐. 카메라 전환(휙 넘어감·밀고 들어감)에는 낮은 바람 소리, 저울이 기울 때 낮은 부풂. 모든 기본음 700 Hz 미만(사건 53개).
