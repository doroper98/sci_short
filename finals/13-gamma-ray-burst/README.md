# 감마선 폭발 — 우주에서 가장 밝은 섬광

[영상 재생·다운로드](gamma-ray-burst.mp4)

175.5초, 1080×1920, 30fps, H.264/AAC, −14.0 LUFS. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
0초 프레임이 썸네일입니다. 위아래로 세로 화면을 가로지르는 청백색 제트 두 줄기가 무너지는 별의 붉은 껍질을 뚫고 나오고, 큰 제목 "감마선 폭발 / 우주에서 가장 밝은 섬광"이 이미 보이며 약 1초에 머리글로 줄어듭니다.

흐름: "오늘은 우주에서 가장 밝은 폭발, 감마선 폭발에 대해 알아볼까요?"(제트를 따라 물러나 섬광이 먼 우주의 한 점이 되고, 모형 빛 곡선) → 몇 초짜리 폭발과 태양 100억 년의 에너지 막대가 같은 높이(약 1.2×10⁴⁴ J) → 1963년 부분적 핵실험 금지 조약과 Vela 위성 → 1967년 7월 2일, 핵폭발(한 번 솟고 서서히)과 다른 봉우리 두 개의 섬광 → 위성마다 다른 도착 시각으로 계산한 방향, 지구도 태양도 아님(1973년 공개) → 감마선은 알갱이 하나의 에너지가 가시광선의 약 25만 배 → 대기에 막혀 25~50 km 높이에서 흡수, 우주 망원경으로 → 1991~2000년 BATSE 2,704개가 하늘 전체에 고르게(은하 안이었다면 띠에 85%, 관측 모형은 18%) → 1997년 GRB 970508 잔광의 적색이동 0.835, 빛이 온 거리 약 70억 광년 → 원뿔 반각 손잡이 90° → 5°, 보이는 방향 0.38%, 그 방향 밝기 ×263 → 지구를 정면으로 향한 것만 보인다 → 제트 속 빠른 덩어리가 느린 덩어리를 따라잡는 충돌마다 감마선 봉우리(설명 모형) → 주변 기체에 부딪쳐 느려지며 X선 → 가시광선 → 전파 잔광이 며칠에 걸쳐 → 2초 경계의 지속 시간 분포, 긴 폭발은 무거운 별의 붕괴와 제트 돌파 → 짧은 폭발은 중성자별 두 개의 합병 → GW170817, 중력파 뒤 1.74초에 GRB 170817A → GRB 221009A(2022년 10월 9일, 약 20억 광년, 검출기 눈금 넘침, 지구 이온층 흔들림) → 약 1만 년에 한 번 → 오해(드물다? → 보이는 것 하루 1개꼴, 실제는 수십~수백 배) → 결론(끝 제목 유지).

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형 하나에서 나옵니다. 폭발의 모형 빛 곡선과 에너지, Vela 위성의 평면 파면 도착 시각 Δt = −r·s/c(화면은 3.44배 느리게), 광자 에너지와 대기 흡수 τ = 90·e^(−h/7.5 km), 등방 무작위 하늘 지도 대 은하 원반 모형, 적색이동 × 1.835와 평탄 ΛCDM의 되돌아본 거리, 원뿔 f = 1 − cos θ, 운동량을 보존하는 다섯 덩어리의 충돌, 쓸어 담은 기체로 느려지는 머리와 잔광 곡선(t^−1.2), 두 로그정규의 지속 시간 분포, 처프 f ∝ τ^−3/8와 1.74초 지연, 무작위 제트 790개 중 지구를 향한 3개(= 1/f).
- 단순화: 제트 반각·덩어리 크기와 속도·별과 제트의 크기 비율은 화면용입니다. 하늘 지도는 BATSE 자료가 아니라 같은 수의 무작위 점입니다. 지속 시간 분포, 잔광 곡선, 1967년 섬광 곡선은 설명용 모형 곡선입니다. 내부 충돌은 설명 모형 중 하나입니다(대본도 "~라고 봅니다"). 지구 해안선은 간략화했고 이온층 높이는 과장했습니다. 상세는 [에피소드 README](../../episodes/gamma-ray-burst/README.md)와 [제작 메모](../../episodes/gamma-ray-burst/brief.md).
- 소리: 빛 곡선이 음량을, 저장된 에너지가 음높이를 정해 폭발 음과 태양 음이 같은 음에서 끝납니다. 위성 도착은 계산된 시각의 낮은 틱, 원뿔을 좁히면 10·log10(1/f)만큼 커지는 음(상한 20 dB), 덩어리 충돌마다 낮은 탁, 중성자별 처프는 합병에서 멈추고 정확히 1.74초 정적 뒤 감마선 쿵. 별의 반짝임 편 피드백에 따라 모든 효과음의 기본음은 700 Hz 미만입니다.
