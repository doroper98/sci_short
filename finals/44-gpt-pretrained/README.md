**역할**: 기획·대본·구현 계획·검수는 제작 세션(Fable), 대본 검수는 별도 Fable 작업자, 사실 확인(원문 대조)과 부품·모형·장면·소리 구현은 Opus 작업자가 했습니다. 구현 계획서는 [공통(1~3절)](../../episodes/gpt-generative/PLAN.md), [44번 모형·장면](../../episodes/gpt-pretrained/PLAN.md).

**움직임**(2026-11-12 사용자: "fable 5.2 로 만드니까 좀 다이내믹하게 gpt 영상을 만들면 좋겠어"): 빛·3D 를 늘리지 않고 움직임의 에너지를 올렸습니다. 카메라가 신호를 따라가고, 물건은 준비 → 빠르게 → 자리 잡기로 움직이며, 되풀이는 가속하고, 큰 수는 카메라가 물러나며 보이고, 숫자는 굴러 올라갑니다. 장면 전환은 끊지 않습니다. 영상미 문법(움직이는 것은 모두 사슬의 고리, 빛은 신호뿐, 난색 하나·한색 하나)은 그대로입니다. **한색(하늘색) = 주어진 글, 난색(호박) = GPT 가 내놓거나 고친 것.**

**대본은 Fable 검수를 받았습니다**(2026-11-11 규칙). 초안 23문장·690음절 → 확정 23문장·785음절. 고친 핵심: 예시 '해는 동쪽에서 [뜬다]'를 소리 내어 말함, 빠져 있던 고리 넷("조각마다 확률을 매긴다" · "글만 있으면 문제가 얼마든지 생긴다" · "크게 틀렸으면 많이, 조금 틀렸으면 적게" · "되풀이하면 정답의 확률이 올라간다")을 더함, "묻는 말에 답하지는 못합니다"(GPT-3 논문과 반대)를 "대화 본보기로 같은 공부를 더 하면 질문에 알맞게 답합니다"로, '미리'의 풀이를 출처에 맞춤("대화 같은 일을 따로 배우기에 앞서"). 상세는 [제작 메모](../../episodes/gpt-pretrained/brief.md) '대본 Fable 검수'.

0초 프레임이 쇼츠용 썸네일입니다(2026-11-13 규칙: 흰 글은 물음, 가장 큰 글은 주제어 **GPT**). 뒷부분이 가려진 글줄 "해는 동쪽에서 ▨", 아래 오르는 곡선(평균 정답 확률), 흰 물음 "글 쓰는 법을 / 어떻게 배웠을까?"와 그 아래 큰 호박색 글 "GPT #2"(주제어 GPT + 같은 줄에 약 0.6배 크기의 시리즈 번호, 그 전에는 흰 질문 "GPT는 어떻게 배웠을까?"와 큰 답 "다음 말 맞히기로"). 약 1초에 물음이 머리글 제목으로 줄고(머리글 윗줄 "오늘의 주제 · GPT #2"), 마지막 문장 끝 1.4초 전에 포스터가 돌아옵니다. 2026-11-13 사용자 지시("주제어가 딱 보여야 해")로 첫 프레임(과 끝에 돌아오는 포스터)의 글을 '위에 흰 물음, 아래에 주제어를 가장 크게'로 바꾸었고, 그림만 같은 타임라인으로 다시 렌더해 원래 소리(스트림 복사, 바이트 단위로 같음)와 합쳤습니다. 큰 글 뒤의 시리즈 번호는 같은 날 사용자 지시("GPT 는 시리즈니까 # 이후에 숫자를 붙여서 몇번째인지 알려줘.")입니다.

흐름: "오늘은 GPT가 글 쓰는 법을 어떻게 배웠는지에 대해 알아볼까요?"(가림막이 젖혀져 정답이 드러나고 다음 글이 밀려옴) → 문법·지식을 넣어 준 사람은 없음(조각이 입구에서 튕겨 나감) → P = Pre-trained, 먼저 글로 공부 → 그다음 대화 → 가리고 다음 조각 맞히기, 정답은 가린 자리에 이미 있음 → 문제가 폭포처럼 얼마든지 → 조각마다 확률(처음에는 흐른다 50 · 진다 10 · 별은 5 · 뜬다 4%) → 숫자(다이얼)를 돌리면 같은 프레임에 막대가 바뀜 → 가림막이 열리고 정답에 준 확률 4%, 틀린 정도가 길게 참 → 거꾸로 가는 펄스와 다이얼마다의 화살표 → 다이얼이 물결처럼 조금 돌고 뜬다 4% → 7% → 230번째로 건너뛰면 63% → 68%, 다이얼은 아주 조금 → 조건 하나: 30배 큰 걸음이면 이 글은 100% 가 되지만 다른 글 "해는 서쪽으로 [진다]"가 61% → 11% 로 주저앉음 → 되감기 → ×1 → ×64 타임랩스, 714걸음에 평균 정답 확률 3% → 79% → 다이얼 18개 → 이 모형의 숫자 1,900개 → 점의 벽, 1,750억 개 · 3,000억 조각 → 0~4,000년 시간 막대와 80년 눈금 → 다 배운 뒤 뜬다 90%, `동쪽에서` 를 `서쪽으로` 로 바꾸면 진다 90% → 대화 본보기로 더 공부하면 처음 보는 질문 "달은 어디로 지나?"의 `서쪽으로` 가 8% → 60% → 대화 조각이 빠르게 흐르는 동안 다이얼은 꼼짝 않음 → 명제 → 포스터.

- 모형: 화면의 확률·다이얼·곡선은 모두 `episodes/gpt-pretrained/model.mjs` 의 **실제로 학습시킨 아주 작은 모형**에서 나옵니다. GPT 가 아니며, 손으로 적은 확률은 없습니다.
  - 조각 25가지, 숫자 1,900개(`3·V·V + V`). 식: 다음 조각의 점수 = 치우침 + 바로 앞 조각 + 그 앞 조각 + 문맥 조각들의 평균, 확률 = softmax.
  - 공부할 글 아홉 문장(자리 27개), 한 번에 자리 하나씩 경사 하강(걸음 크기 0.15, 씨앗 130·순서 씨앗 7), 714걸음. 첫걸음에 `p(뜬다)` 4.0% → 7.3%.
  - 230번째 걸음: 63.3% → 68.2%. 같은 걸음을 30배로 하면 99.9% 가 되지만 "해는 서쪽으로 → 진다"가 61.4% → 11.3%(작은 걸음이면 60.6%).
  - 다 배운 뒤 `p(뜬다 | 해는 동쪽에서)` 90.1%, `p(진다 | 해는 서쪽으로)` 90.3%.
  - 대화 본보기 세 줄로 더 공부(자리 24개를 155번 돎). 본보기에 없는 질문 "달은 어디로 지나?"의 `서쪽으로`: 8.0% → 60.0%(`동쪽에서` 38.4%).
  - GPT-3 의 수 셋(1,750억 개, 3,000억 조각, 약 4,000년)만 대본의 값이고 모형 값이 아닙니다.
- 단순화: 조각은 어절 단위(실제는 더 잘게). 화면의 모형은 초깃값이 커서 엉뚱한 조각 하나가 높게 나옵니다(실제 초깃값에서는 거의 고르게 낮음). 숫자를 고치는 방식은 기본 경사 하강 기준(실제 GPT 는 걸음 크기를 숫자마다 조절하고, 여러 글을 묶어 한꺼번에 계산). 다이얼의 눈금은 ±1.6 에서 멈추게 그렸습니다. 점의 벽은 규모를 보이는 그림. "4천 년쯤"은 어림(3천억 토큰 × 낱말 0.75개, 분당 300낱말, 하루 8시간 — 속도를 240으로 잡으면 약 5,400년, 되풀이 읽은 몫을 빼면 3천 년대). "남는 것은 고쳐진 숫자뿐"은 글을 모아 둔 창고가 없다는 뜻(자주 나온 글귀를 그대로 내놓는 일은 있음). 시간 배율은 키커와 배속 표시에 선언했습니다.
- 소리: 모두 합성한 설명용 소리(녹음 아님), 기본음 700 Hz 미만, 패닝 없음. 가림막이 열림 → 틱, 틀린 정도 → 낮은 긴 음, 거꾸로 가는 펄스 → 내려가는 처프, 다이얼 → 짧은 틱(크게 → 작게), 타임랩스 → 이어지는 틱과 곡선을 따르는 음. 사건 87개.
