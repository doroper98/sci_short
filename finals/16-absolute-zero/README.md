# 얼마나 차가워질 수 있을까 — 절대영도

[영상 재생·다운로드](absolute-zero.mp4)

164.9초, 1080×1920, 30fps, H.264/AAC, −14.1 LUFS. 한국어 내레이션(**Supertonic 3 M3 남성** ×0.85 + 문장 끝 6반음 하강, MMS 정렬, `degraded: false`), 글자 시각 자막. 배경음악 없음. 화면에 각주·출처 줄 없음.
남자 목소리로 바꾼 첫 편입니다(2026-11-06 사용자 결정 "목소리는 남자 목소리로 하자", "중력파 편 음성이면 돼" → 중력파 1·2차본과 같은 M3 ×0.85·6반음).
0초 프레임이 쇼츠용 썸네일입니다. 성에 낀 창 너머 큰 유리 온도 축이 빛나는 바닥선까지 내려와 있고, 위에는 따뜻하게 날아다니는 알갱이, 바닥선에는 거의 멈춘 얼음빛 알갱이. 흰 질문 "얼마나 차가워질 수 있을까?"와 큰 얼음빛 답 "−273.15 °C". 약 1초에 제목이 머리글로 줄고, 마지막 문장 "절대영도는"에서 포스터가 돌아와 끝까지 유지됩니다.

흐름: "오늘은 더 이상 차가워질 수 없는 온도, 절대영도에 대해 알아볼까요?"(온도 축: 위로 태양 표면 약 5,500 °C·중심 약 1,500만 °C, 아래로 −273.15 °C 바닥) → 이름(絶 끊을 절 + 對 마주할 대 = 맞설 상대를 끊음, absolute ← 라틴어 absolutus "풀려난") → 1702년 무렵 Amontons의 공기 온도계: 식힐수록 압력이 고르게 줄어듦 → 직선을 늘이면 압력 0의 온도 −273.15 °C(실제 기체는 그 전에 액화, 점선 = 연장) → 3단 계기: 온도 손잡이 · 상자 속 알갱이(이상기체 모형) · 평균 속력과 압력 → 움직임이 가장 낮은 바닥 = 절대영도, 켈빈 눈금 0 K → 끝내 닿지 않는 바닥: 한 걸음마다 남은 온도의 절반(설명 모형, 확대 ×131,072까지) → 빈 우주 2.7 K(빈 공간에 놓인 물체가 빛을 주고받아 식는 설명 모형) → 부메랑 성운 약 1 K(퍼지며 식는 가스) → 레이저 냉각(여섯 방향 빛, 약 0.1 mK) → 2021년 Bremen 낙하탑 38 pK(1조분의 38 K) → 전혀 다른 얼굴: 초전도(수은 4.2 K, 1911년)와 벽을 타고 오르는 액체(헬륨 2.17 K 아래, 예고) → 오해(0 K에서는 다 멈출까? → 영점 진동) → 소수점 아래 0의 개수를 늘리는 싸움 → 결론.

- 모형: 화면·계기·소리가 `scenes.mjs` 머리의 모형에서 나옵니다. 상자의 알갱이 속력은 √T로, 압력은 T(켈빈)에 비례합니다. 계단은 걸음마다 남은 온도가 절반이 되는 설명 모형이고, 오른쪽 로그 온도 자가 계단·우주·실험실 장면 내내 표식(2.7 K, 1 K, 0.1 mK, 38 pK)을 모읍니다. 낙하탑은 실제 시간으로 떨어집니다(110 m, 4.74초). 구름 폭 계기는 38 pK에서 2초 뒤 0.25 mm, 1 μK였다면 약 4 cm로 비교합니다.
- 단순화: 알갱이 크기·색·화면 속도는 화면용입니다. 1 K까지 식힌 공기 상자는 사고 실험("이상기체 모형" 표기)입니다. 우주 배경 2.7 K와 부메랑 성운의 냉각 그림(T ∝ r^(−4/3))은 설명 모형입니다. 영점 진동의 떨림 크기는 과장입니다. 포스터와 훅의 따뜻한 알갱이 움직임은 장식이며 모형 값이 아닙니다. 상세는 [에피소드 README](../../episodes/absolute-zero/README.md)와 [제작 메모](../../episodes/absolute-zero/brief.md).
- 소리: 알갱이가 벽에 부딪칠 때의 낮은 틱(빈도·크기가 √T를 따라 줄어듦), 온도를 따라 내려가는 낮은 웅웅, 계단 걸음마다 작아지는 틱, 영점 진동의 멈추지 않는 작은 떨림 음. 모든 효과음의 기본음은 700 Hz 미만입니다(사건 53개).
