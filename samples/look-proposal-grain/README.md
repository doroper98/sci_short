# 질감 층 견본 — 숯색 바탕 · 종이 같은 고정 질감 · 빛나는 것만 은은한 번짐

> 2026-11-22 사용자(참고 릴스를 보내며): "내가 말한 영상미는 이런거야. 그레인이 조금 가미 되었으면서, 적당한 빛(절대 과하지는 않은) 혹은 광원 효과같은게 있는 느낌? 색감이나 질감을 참고 하고."
>
> 같은 날 사용자 확인: "그레인 효과라는건 약간 종이같은 그런 질감인거 맞지?"

공통 도구 `pipeline/render/look.mjs`(설정 `config/look.json`)를 66번 꼬리날개의 **실제 장면 함수**에 걸어 본 견본입니다.
참고 릴스의 화면·문구·도형은 베끼지 않았고, **색감(중성 숯색 바탕)과 질감(고정된 고운 결, 빛나는 것 둘레의 약한 번짐)만** 참고했습니다.
**아래 수치는 모두 제작 세션의 제안이며 사용자가 정한 값이 아닙니다.** 에피소드 파일(`episodes/tail-stability/`)은 고치지 않았습니다.

## 이 견본이 한 것

- **바탕** `filmBackground()`: 가운데 `#201F23` → 가장자리 `#121213` 방사형(중심 0.5, 0.42H). 화소마다 실수로 계산하고 ±0.5 삼각 디더를 넣어 8비트 띠가 없습니다. 한 번 만들어 캐시합니다.
- **팔레트**: `--look film` 은 `kit.mjs` 의 `PAL` 을 숯색 팔레트로 바꾼 뒤 장면을 읽습니다(난색 `#FF6B1A` 꼬리날개·주제어, 한색 `#5BA8F0` 돌풍·화살표, 연기 `#737B85`). PAL 을 거치지 않고 직접 적힌 청록 계열 색(엔진·조종석 창·띠 등)은 `outputs/look-proposal-grain/src/` 에 만든 **사본에서만** 중성 회색으로 바꿉니다(`render.mjs` `FILM_HARDCODED`, `--raw` 로 끔). 전체 재렌더 때 고칠 곳은 아래 '직접 적힌 색'.
- **번짐**: `lit()` 로 표시한 것(빛 지도)에만. 화면 × 빛 지도를 1/4 해상도로 흐려(6 px 알파 0.30, 28 px 알파 0.15) screen 으로 얹습니다. 빛 지도가 검은 곳(무광 비행기·글자·바탕)은 번지지 않습니다.
- **비네트**: 가장자리 10% 어둡게(0.30H → 0.82H). 바탕의 '가운데가 조금 밝은' 느낌을 장면 위에서도 이어 줍니다.
- **종이 같은 고정 질감**(그레인): 2048×2048 잡음 한 장 = 고운 결(σ 0.85 px) 85% + 조금 굵은 얼룩(σ 5 px) 15%(분산 비율). **영상 내내 같은 무늬**(`hold_frames` 0). 밝기 128 위로 갈수록 약해져 흰색에서는 0.35배 — 흰 글자·자막은 깨끗합니다. 같은 (프레임, 설정)이면 비트 단위로 같습니다.
- 번짐·비네트·질감은 화면을 한 번 읽고 한 번 쓰는 화소 연산 하나로 합니다.

## 눈으로 본 것

- 1080 원본 100%(`crop-100.jpg`, 2배 확대도 봄): 어두운 바탕에 고운 결이 보이고 무광 비행기 몸통은 '종이에 인쇄한 듯' 약하게 결이 있습니다. 흰 자막·흰 글자 가장자리는 깨끗합니다(흰색 쪽 세기 0.35배).
- 번짐: 화살표·효과 막대 둘레에만 아주 약하게 보입니다. 화면이 뜨지 않고 비행기 몸통·글자는 번지지 않습니다.
- 바탕: 띠·사각형 경계·청록 얼룩은 보이지 않았습니다. 다만 계기 바닥(`gaugeFloor`, 760~1240, `PAL.deep` 0.86)은 그라디언트 바탕 위에서 한 단 어두운 판으로 또렷이 갈립니다(지금 판도 경계선은 있음 — 설계된 판).
- 난색(꼬리날개·주제어)과 한색(돌풍·화살표)은 숯색 위에서 지금보다 또렷합니다. 연기 줄은 회색이 되어 지금보다 조금 눈에 띕니다.
- 고정 무늬 위로 비행기가 지나갈 때: 0:01.5 부근 연속 4프레임(2배 확대)에서 반점이나 '먼지' 같은 낱알은 보이지 않았습니다. 그러나 **움직이는 영상으로 보지 않았으므로**, 화면에 붙은 결로 느껴지는지는 휴대전화로 확인이 필요합니다.
- 이 견본은 HDR 화면에서 보지 못했습니다(HDR 판은 만들지 않음).
