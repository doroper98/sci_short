## 레퍼런스에서 직접 본 것

720×1280, 29.7초, 15초쯤에 컷 한 번. 과학 설명 영상이 아니라 제작사의 소개 영상입니다. 소리는 파형만 쟀고 듣지 않았습니다.

- 그림: 낮은 해상도의 픽셀 일러스트. 해질녘 항구와 등대. 하늘은 가로 색 띠로 나뉘고, 빛 번짐과 음영은 점묘(격자 무늬)로, 물결의 반짝임은 짧은 가로줄로 그렸습니다. 색 수가 적습니다(청록·주황·남색·붉은색·크림).
- 카메라: 한 장면 안에서 "PULL BACK", "DOLLY ZOOM", "CRANE UP"이라고 이름 붙인 세 가지 이동을 보여 줍니다.
- 글자: 굵은 고딕 대문자 제목과 기울인 명조 한 줄("Great drawing.", "up the tower, to the lamp"). 글자는 픽셀이 아니라 또렷합니다. 뷰파인더 모서리·"REC"·타임코드 장식이 있습니다.
- 뒤쪽은 조회수·팔로워 수와 댓글 유도 문구입니다.
- 해석(확인 아님): 층을 나눈 픽셀 그림을 가상 카메라로 찍은 것으로 보입니다. 제작 도구는 영상만으로 알 수 없습니다.

**가져온 것은 그리는 방식뿐입니다.** 등대 장면, 색, 문구, 뷰파인더 장식은 쓰지 않았습니다.

## 만든 방식

- `px.mjs`: 270×480 버퍼에 납작한 색, 가로 색 띠, 4×4 바이어 점묘(빛 번짐·띠의 이음매·반투명)를 그리고 4배로 키웁니다(한 픽셀 = 4 px). 색은 한 벌(`C`)만 씁니다.
- `run.mjs`: 키운 그림을 `pipeline/render`의 무대에 올리고, 글자는 그 위에 또렷하게 얹습니다. 제목은 GmarketSans 굵게, 곁들이는 한 줄은 같은 글꼴의 중간 굵기, 계기는 Noto Sans KR — **표준 글꼴만 씁니다.** 처음 시안은 레퍼런스처럼 기울인 명조(Noto Serif KR)를 곁들였으나 사용자가 "명조체 좀 구린데 근데...?"라고 해 뺐습니다(2026-11-15). 다섯 가지를 나란히 보여 드렸고(명조 기울임, 제목 글꼴 중간 굵기, 본문 고딕, 제목 글꼴 가는 굵기, 픽셀 글꼴), 사용자가 **픽셀 글꼴(E, Galmuri11 Bold)** 을 골랐습니다("그리고 폰트는 e가 좋은데?"). 58번 본편의 머리글 한 줄은 이 글꼴입니다(`episodes/tsunami/fetch_pixel_font.py`). 이 폴더의 시안 영상 세 편과 `run.mjs` 는 고르기 전의 글꼴(제목 글꼴 중간 굵기) 그대로입니다.
- `scene_*.mjs`: 장면마다 모형 하나(`state`·`ratio`·`progress`)에서 그림과 계기 숫자가 함께 나옵니다. 카메라는 한 무대 안에서 움직입니다.
- 렌더는 편당 수십 초입니다. 장면 하나를 그리고 다듬는 데는 편당 20~30분이 들었습니다.

```bash
node samples/look-proposal-pixel/run.mjs tsunami /tmp/poc.mp4                       # 영상
node samples/look-proposal-pixel/run.mjs tsunami /tmp/poc --still=0.5,6.5,11.4       # 정지화면 /tmp/poc_0.5.png …
```

## 시안의 수치

- 쓰나미: 빠르기 = √(9.81 × 수심), 높이 ∝ 수심^(−1/4)로 직접 계산했습니다(수심 4,000 m → 시속 713 km·1.0 m, 수심 10 m → 시속 36 km·4.5 m). 화면의 빠르기는 같은 식에 비례합니다. 세로 길이는 과장했습니다.
- 달 크레이터: "약 20배", "초속 약 20 km"는 **확인하지 않은 값**입니다.
- 3D 프린터: 층 96개, 210 °C, 3시간 10분은 보기용 값입니다.

## 58번을 만들 때 (제안, 사용자 확정 아님)

1. 대본·음성·자막·소리·검증은 표준 절차 그대로입니다(`skills/science-short/SKILL.md`). 바뀌는 것은 그림뿐입니다.
2. `px.mjs`와 `scene_tsunami.mjs`를 `episodes/tsunami/`로 복사해 `scenes.mjs`에서 부릅니다: 장면 함수가 픽셀 그림을 그려 무대에 올리고, 자막과 계기는 툴킷으로 그 위에 얹습니다.
3. 무대는 하나로 둡니다 — 바다 밑 단층에서 해안까지 이어지는 단면. 장면은 카메라의 자리로 나눕니다: 발생(바닥이 솟아 물기둥을 들어 올림) → 먼바다(배는 느끼지 못함) → 얕아짐(느려지고 높아짐) → 도달(밀려드는 물) → 경보(지진파가 먼저 옴).
4. 자막이 놓일 자리(아래쪽)는 그림을 어둡고 단순하게 둡니다. 계기는 자막과 겹치지 않게 놓습니다.
5. 수치는 묶음 10(`docs/TOPIC_BACKLOG.md`)대로 문헌에서 확인합니다.
6. 화풍만 바꾼 시험이므로 길이·첫 문장·제목 형식·공개 시각은 다른 편과 같게 둡니다. 비교 방법은 `docs/CHANNEL_GROWTH.md` H9.
