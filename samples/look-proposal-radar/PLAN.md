## 0. 이 샘플이 보여 줄 다섯 가지 (합격 기준)

1. **움직임이 곧 설명.** 화면에서 움직이는 것은 전부 인과의 한 단계다: 쏜다 → 간다 → 맞는다 → 돌아온다 → 화면에 찍힌다 → 숫자가 된다. 장식용 움직임 없음.
2. **같은 시계.** 전파의 위치, 수신기 화면의 빛점, 시간 숫자, 소리가 한 모형(`plan()`)의 같은 시각에서 나온다. 메아리가 접시에 닿는 프레임에 빛점이 솟고 숫자가 뜬다.
3. **조건 하나만 바꾼 비교.** 비행기가 절반 거리로 오면 왕복 시간이 절반이 된다. 앞 메아리의 잔상이 남은 화면에 새 메아리가 절반 자리에 찍힌다.
4. **채워진 발광체는 조금만.** 빛나는 것은 전파 묶음(난색), 메아리(한색), 수신기 화면의 선뿐이다. 접시·비행기는 면과 명암이 있는 무광 덩어리. 화면 전체 블룸·흰 번쩍·노을 하늘·광택 없음.
5. **글자는 셋.** 머리글, 거리 숫자, 수신기 화면의 눈금. (비행 중 "5분 뒤"는 1.4초만 뜨는 예외.)

수치 목표(`lookcheck.py`, 그림 영역 기준): 밝은 픽셀 4~12%, 주인공 덩어리 4~20%, 상위 1% 밝기 140~215, 색 가짓수 18~45, 하드컷 0.

## 3. 화면 배치 (1080×1920, 좌표는 화면 px)

세 단: **하늘의 숫자(300~520) / 세계(520~1060) / 수신기 화면(1098~1312)**. 자막은 툴킷 기본 위치(마지막 줄 baseline 1480).

### 3.1 카메라 (세계 층에만 적용)

`k(t) = 1 + 0.035 * smooth(t / D)`(D = 10.356), 중심 `(540, 800)`, 가로 이동 `ox = -10 * smooth(t / D)`.
`S(x, y) = [(x - 540) * k + 540 + ox, (y - 800) * k + 800]`. 세계의 모든 좌표·길이·반지름에 적용한다(선 굵기는 그대로). 별은 시차 0.3: `Sstar(x, y) = [(x - 540) * (1 + 0.3 * (k - 1)) + 540 + 0.3 * ox, …]`.
머리글·숫자 블록·수신기 화면·자막은 화면 고정.

### 3.2 세계의 고정 좌표 (카메라 적용 전)

- 접시 회전 중심(전파의 원점) `O = (176, 952)`.
- 비행기 고도선 `y = 692`. 먼 자리 `A1 = (826, 692)`(O에서 700 px), 가까운 자리 `A2 = (410.3, 692)`(O에서 350 px).
- 비행기 위치 `ax(t) = lerp(826, 410.3, easeInOut(clamp((t - fly0) / (fly1 - fly0))))`, `ay = 692`. 그 밖의 시간에는 **완전히 멈춰 있다**(실제 0.001초 동안 비행기는 25 cm밖에 못 간다. 흔들림·깜박임을 넣지 않는다).
- 올려본각 `theta(t) = atan2(952 - 692, ax(t) - 176)`(21.8° → 48.0°). 접시는 항상 이 각도를 향한다.
- 땅: 중심 `(540, 1030 + 5200)`, 반지름 5200 의 원호. `yg(x) = 1030 + 5200 - sqrt(5200² - (x - 540)²)`.

### 3.4 전파·메아리·길·섬광 (이 샘플의 주인공)

색: 난색 `WARM = [1.0, 0.70, 0.30]`(#FFB454 계열), 한색 `COOL = [0.55, 0.85, 1.0]`(#8CD9FF 계열), 흰색 `WHITE = [1.0, 0.95, 0.85]`.
Glow 버퍼 두 개(`GW` 난색, `GC` 한색). 매 프레임 `begin()` → splat → `flush(stage, {gain: 1.25, bloom: 0.38})`. 화면 전체를 덮지 않는다(버퍼는 splat 한 영역만 갱신한다).

**나가는 전파**(펄스마다, `t ≥ te`):
- 앞면 반지름 `r0 = V * (t - te)`. `r0 ≤ R + 240` 까지 그린다. 비행기를 지난 뒤에는 `fadeOut = 1 - smooth((r0 - R) / 240)` 를 곱한다(전파 대부분은 지나가 사라진다).
- 마루 3줄: 반지름 `r = r0 - 18j`(j = 0, 1, 2), 세기 `[1, 0.6, 0.32][j]`. `r < 46` 이면 건너뜀(접시 안쪽).
- 한 줄은 각도 `phi ∈ [theta − 0.30, theta + 0.30]` 를 호 길이 약 7 px 간격으로 찍는 splat 들. 각 splat: 위치 `S(O.x + r cos phi, O.y − r sin phi)`, 반지름 `7 * k`, 세기 `0.55 * amp * exp(-((phi − theta) / 0.15)²) * clamp(1.15 − 0.45 * r / 700) * fadeOut`, 색 WARM. (`theta` 는 그 펄스의 **출발 시각** 올려본각.)
- 출발 0.3초 동안 급전부(3.6절 `F`)에 splat r 50, 세기 `0.9 * (1 − a / 0.3)`, 색 WARM.

**메아리**(`t ≥ th`):
- 중심 = 그 펄스의 비행기 위치 `A`(= hit 시각의 `(ax, 692)`). 반지름 `re = V * (t − th)`. `re ≤ R`(접시 도착)까지 온전히, 그 뒤 0.4초 동안 `1 − (t − tr) / 0.4` 로 사라짐.
- 마루 2줄(간격 16, 세기 `[0.75, 0.4]`), `re − 16j > 8` 인 것만.
- 원 전체를 찍되 접시 쪽이 밝다: `w(psi) = 0.22 + 0.78 * exp(-(dpsi / 0.5)²)`, `dpsi` = A→O 방향과의 각 차이. splat 반지름 `6 * k`, 세기 `0.42 * amp * w * clamp(1.1 − 0.5 * re / 700) * (km === 75 ? 1.25 : 1)`, 색 COOL. 땅 아래(`y > yg(x)`)로 간 splat 은 버린다.

**지나간 길**(왕복이 한눈에 보이게, 6번 순서에서 캔버스 선으로):
- 가는 길: O 에서 시선 방향으로 `min(r0, R)` 까지, 시선에서 수직으로 **위쪽 6 px** 떨어진 평행선. 3 px `#FFB454` 알파 0.42 + 9 px 알파 0.10('lighter').
- 오는 길: 비행기에서 O 쪽으로 `min(re, R)` 까지, 시선 **아래쪽 6 px** 평행선. 3 px `#8CD9FF` 알파 0.50 + 9 px 알파 0.12.
- 두 길 모두 `t > tr + 0.7` 부터 0.5초 동안 사라진다. 다음 펄스가 나가면 새로 그린다.

**사건 섬광**(작고 짧게. 화면 흔들림 없음):
- 닿음(`th`): A 의 접시 쪽 모서리 `A + (-60, 18)` 에 GW splat r `(40 + 60a) * k` 세기 `0.9 * exp(-a / 0.12)`(a = t − th, 0.5초까지) + 가는 고리(캔버스 'lighter', 2 px `#FFE2B0`, 반지름 `(18 + 110 * easeOut(a / 0.5)) * k`, 알파 `0.7 * (1 − a / 0.5)`).
- 도착(`tr`): 급전부 F 에 GC splat r 44, 세기 `0.9 * exp(-a / 0.15)`(0.5초까지).

### 3.5 비행기 (채운 무광 덩어리, 옆모습, 기수가 왼쪽)
