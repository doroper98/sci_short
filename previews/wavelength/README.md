# 파장 — 전파에서 감마선까지, 다른 것은 길이 하나

[영상 재생·다운로드](https://github.com/doroper98/sci_short/raw/refs/heads/claude/serene-brahmagupta-880vh6/previews/wavelength/wavelength.mp4)

176.6초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 설명용 소리(파장 → 음높이 110~1760 Hz 대응, 마루 통과 틱, 분자 떨림 웅웅, 결합 끊김 스냅, 산란 틱). 배경음악 없음. 화면에 각주·출처 줄 없음.

흐름: "오늘은 빛의 파장에 대해 알아볼까요?" → 허셜 1800(무지개의 빨강 바깥에 온도계 → 온도가 오름, 적외선) → 리터 1801 자외선 → 어원(波長 = 물결 파 + 길 장, 마루에서 다음 마루까지; 연표 뉴턴·허셜·리터·맥스웰·헤르츠) → 본질(전파부터 감마선까지 모두 같은 파동, 다른 것은 파장 하나; c = λf, E = hc/λ) → 가시광선(약 400~700 nm, 머리카락의 100분의 1, 눈이 반응하는 창) → 적외선(분자를 흔들어 데움; 체온 36 °C 봉우리 약 9.4 μm, 리모컨 940 nm, 열화상 8~14 μm, 이산화탄소 15 μm) → 자외선(결합을 끊는 에너지; DNA, 오존층이 UVC·UVB 대부분 차단, UVA 통과, 비타민 D와 일광화상) → 산란(1/λ⁴, (700/450)⁴ ≈ 5.9배, 파란 하늘과 노을) → 동물(꿀벌 300~650 nm, 살무사 피트 기관 약 10 μm) → 오해(적외선은 빨간빛이 아니고 자외선은 보라빛이 아니다) → 결론.

- 모형: 파장 λ(t) 하나가 상태 변수이며, 위의 파동 그림·가운데 로그 눈금 스펙트럼 띠·아래 계기판(λ, f = c/λ, E = hc/λ, 구간, "무엇과 맞는가", 빈 봉우리 온도 T = 2898 μm·K/λ)·소리가 같은 값을 읽습니다. 보이지 않는 구간(전파~적외선, 자외선~감마선)은 모두 회색 빗금이고 400~700 nm만 실제 색입니다. 화면의 파동 길이는 로그 압축이며 실제 비율이 아닙니다. 원뿔세포 곡선, 물·이산화탄소 흡수, DNA "가로대 하나 끊김", 오존 기둥은 개략도입니다. 계기판의 "결합 끊김" 구간 경계 3.3 eV는 이 영상의 분류 기준이며 실제 결합 에너지는 약 3~5 eV로 결합마다 다릅니다. 상세는 [제작 메모](../../episodes/wavelength/brief.md)와 [에피소드 README](../../episodes/wavelength/README.md).
