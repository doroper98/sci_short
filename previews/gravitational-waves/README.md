178.8초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 M3 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 모형 진동수로 합성한 처프 음. 배경음악 없음(2026-10-31 사용자 결정).

흐름: 예측 질문(마지막 0.2초, 공간이 출렁일까) → 기원(重力波 어원, 1916 예측, 1974 쌍성 펄서, 2015 검출) → 본질(질량이 흔들리면 공간의 휘어짐이 빛의 속도로 퍼진다, 대칭 회전은 안 됨) → 메커니즘(3단 계기판: 궤도·파면·r/f/v/h 계기, 되먹임, 처프) → 병합·링다운 → GW150914 수치와 LIGO 작동 원리(연속 레이저 분할·두 팔 왕복·재결합 밝기, 두 관측소 7 ms 차이 → 방향) → 오해(소리를 들은 것이 아님) → 한 줄 결론.

- 물리 모형: Peters(1964) 점질량 원궤도, 처프 질량 28.3 M☉, 24→250 Hz, 마지막 0.5초를 약 70배 느리게. 격자·파면 높이와 LIGO 팔 길이 변화는 설명용 과장(화면 각주는 사용자 요청으로 제거, 이 README와 brief.md에 기록).
