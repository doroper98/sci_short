흐름: 예측 질문(마지막 0.2초, 공간이 출렁일까) → 기원(重力波 어원, 1916 예측, 1974 쌍성 펄서, 2015 검출) → 본질(질량이 흔들리면 공간의 휘어짐이 빛의 속도로 퍼진다, 대칭 회전은 안 됨) → 메커니즘(3단 계기판: 궤도·파면·r/f/v/h 계기, 되먹임, 처프) → 병합·링다운 → GW150914 수치와 라이고 → 오해(소리를 들은 것이 아님) → 한 줄 결론.

- 물리 모형: Peters(1964) 점질량 원궤도, 처프 질량 28.3 M☉, 24→250 Hz, 마지막 0.5초를 약 80배 느리게. 격자·파면 높이는 설명용 과장이며 화면에 표기.
