# 수정은 어떻게 자랄까?

[영상 재생·다운로드](https://github.com/doroper98/sci_short/raw/refs/heads/preview/quartz/previews/quartz/quartz-growth-ko.mp4)

약 1분 54초의 한국어 과학 애니메이션입니다. 한국어 Supertonic 3 M3 내레이션, 한국어 자막, 결정 성장 사건에 연결된 설명용 소리와 직접 합성한 잔잔한 음악을 포함합니다.

뜨거운 물에 녹은 성분이 안정된 결정핵에 붙어 자라는 과정, 규소·산소의 반복 구조, 평평한 결정면이 나타나는 이유를 연결합니다. 투명한 수정은 석영의 한 종류라는 점과, 불규칙한 외형도 내부는 결정질일 수 있다는 점을 설명합니다.

결합 설명을 확장해 **용존 규산 → 표면 수산기의 반응 → 물 분자 형성 → Si–O–Si 연결 → 규칙적인 삼차원 배열**을 보여줍니다. 단순히 결합이 있는 것과 장거리 질서가 있는 결정을 구분합니다.

- 1080×1920, 30fps, H.264 / yuv420p / BT.709.
- 한국어 AAC 스테레오 음성, 48kHz. 번인 자막과 별도 한국어 SRT.
- [한국어 SRT](captions.srt).
- [제작 근거·모형의 한계·재현 방법](../../samples/quartz/README.md).
- [검증 기록](validation.json).

최종 파일 전편 디코딩과 대표 장면의 인코딩 후 프레임을 확인했습니다. 자동 음성 인식은 직접 청취와 구분해 기록하며, 실제 휴대전화 재생은 미검증입니다.
