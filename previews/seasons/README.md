# 계절은 왜 생길까 — 거리가 아니라 기울기

[영상 재생·다운로드](https://github.com/doroper98/sci_short/raw/refs/heads/claude/serene-brahmagupta-880vh6/previews/seasons/seasons.mp4)

160.0초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 설명용 소리(한낮 해 높이 = 음높이, 하루 일사량 = 잡음 세기, 낮의 길이 = 지속음 길이, 달이 바뀔 때 틱). 배경음악 없음. 화면에 각주·출처 줄 없음. 커리큘럼 초안(`docs/CURRICULUM.md`) 시즌 1의 1편.

흐름: "오늘은 여름과 겨울, 계절이 왜 생기는지 알아볼까요?" → 오해(여름 = 태양에 가까워서?) → 지구는 1월 3일 가장 가깝다(1억 4710만 km, 7월 6일 1억 5209만 km) → 어원(節 = 대나무 마디, season ← 씨 뿌리기, solstice = 해가 멈춰 섬) → 앙부일구의 13개 절기선 → 본질(23.4° 기울어진 축, 6월엔 북반구가 해 쪽으로) → 해의 높이(서울 한낮 76° ↔ 29°, 같은 햇빛이 2배 넓게, 그림자 약 7배) → 낮의 길이(14.6 ↔ 9.4시간, 약 5시간 차이) → 합친 햇빛(482 ↔ 174 W/m², 약 2.8배, 거리 효과 약 7%) → 계절 지연(햇빛 최고 6월 21일, 서울 기온 최고 8월 26.1 °C) → 남반구(시드니 크리스마스 한여름, 한낮 해 80°) → 오해 판정 → 결론.

- 모형: 날짜 하나가 상태 변수이며 공전 위치, 태양 적위, 남중 고도, 그림자, 낮 길이, 대기 상단 일사량, 태양까지 거리가 모두 그 날짜에서 계산됩니다. 궤도는 실제 이심률(0.0167, 거의 원). 기온 곡선은 기상청 평년값 두 개(1월 −1.9 °C, 8월 26.1 °C)를 지나는 모형 곡선이며 다른 달 값은 표시하지 않았습니다. 앙부일구는 도식입니다. 상세는 [에피소드 README](../../episodes/seasons/README.md)와 [제작 메모](../../episodes/seasons/brief.md).
