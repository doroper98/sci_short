# 지구를 두른 바람의 띠 — 무역풍·무풍대·편서풍

179.0초, 1080×1920, 30fps, H.264/AAC. 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 설명용 소리(추적하는 공기 덩어리 위치의 모형 지표 풍속 = 바람 소리 세기, 상승음·하강음, 위도선 통과 틱, 무풍대 소나기 잡음, 띠마다 다른 바람 음색). 배경음악 없음. 화면에 각주·출처 줄 없음.

흐름: "오늘은 지구를 두른 큰 바람, 무역풍과 적도 무풍대에 대해 알아볼까요?" → 돛단배가 아는 두 바다(늘 부는 바람, 멎는 바다) → 어원(trade = 길, to blow trade = 한 방향으로 꾸준히 불다 → 18세기 무역으로 연결 → 貿易風; doldrums ← dull, 처진 상태 → 바다의 이름 → 無風帶; 연표 핼리 1686·해들리 1735·코리올리 1835·페렐 1856) → 본질("바람을 일으키는 것은 태양, 방향을 꺾는 것은 자전", 같은 폭 햇빛이 고위도에서 약 2배 넓게 퍼짐) → 적도 상승(저압대, 지표 바람 거의 없음, 소나기 구름 = 무풍대) → 해들리 순환(상층 극 쪽 흐름, 30° 하강·아열대 고압대, 사막 띠, 지표 귀환) → 자전(땅의 동쪽 속도 적도 1670·30° 1450 km/h, 적도로 오는 공기가 뒤처져 북동·남동무역풍, 전향력) → 세 띠(편서풍·극동풍, 한반도는 편서풍 띠) → 1492 콜럼버스 항로 → 오해(자전이 바람을 만든다? → 아니다) → 결론.

- 무대: 화면 중앙의 정사영 지구본(시점 +12°, 서→동 자전, Natural Earth 1:110m 대륙 윤곽). 왼쪽 가장자리의 대기 단면에 반구마다 세 순환 고리, 표면에는 띠별 바람 흐름 입자. 자전 장면은 지구본 / 0~30°N(편서풍은 30~60°N) 띠를 펼친 "공기를 따라가는 창" / 위도별 땅의 동쪽 속도 그래프의 3단 계기판이며, 공기 덩어리 하나를 추적 표식으로 따라갑니다.
- 단순화: "땅보다 느려 뒤처진다"는 해들리(1735)식 설명입니다. 정확히는 각운동량 보존이며 지표 마찰 때문에 실제 무역풍은 시속 20~30 km 안팎입니다. 그래프의 틈은 방향(뒤처짐/앞섬)만 나타내며 풍속이 아닙니다. 대기층 두께는 약 100배 과장, 춘·추분 기준(띠의 계절 이동 생략), 페렐 순환은 간접 순환이라는 점, 사막·항로 좌표의 근사는 [에피소드 README](../../episodes/global-winds/README.md)와 [제작 메모](../../episodes/global-winds/brief.md)에 있습니다.
