# 한 칸에 열 배 — 지진 규모·데시벨·pH와 로그

[영상 재생·다운로드](https://github.com/doroper98/sci_short/raw/refs/heads/claude/serene-brahmagupta-880vh6/previews/log-scale/log-scale.mp4)

165.8초, 1080×1920, 30fps, H.264/AAC. 초등학교 5학년 기준으로 천천히(문장 사이 1.2~1.8초, 한 화면에 생각 하나). 한국어 내레이션(Supertonic 3 F4 ×0.85 + 문장 끝 6반음 하강, MMS 정렬), 글자 시각 자막, 설명용 소리(더하기 자는 똑같은 틱, 곱하기 자는 ×10 한 칸마다 같은 음정(완전4도)씩 오름, 0이 떨어질 때 틱, 지진계 긁힘). 배경음악 없음. 화면에 각주·출처 줄 없음. 커리큘럼 초안 시즌 1 제안의 10편.

흐름: "오늘은 … 왜 한 칸에 열 배씩 커지는지 알아볼까요?" → 규모 6은 규모 3의 두 배? → 흔들림은 천 배(화면 10개 높이) → 더하기 자(한 칸 +1)에는 개미와 코끼리(약 20억 배)를 함께 그릴 수 없다 → 곱하기 자(한 칸 ×10)와 수모형(1·10·100·1000) → 눈금 = 0의 개수 = 몇 번 곱했나 = 로그(logos 비율 + arithmos 수) → 지진 규모(한 칸에 흔들림 10배, 에너지 약 32배, 규모 3 → 6은 1,000배) → 데시벨(데시 + 벨, 10 dB마다 세기 10배, 속삭임 30 → 대화 60은 1,000배, 귀에는 약 8배) → pH(7이 중간, 1 작아질 때마다 수소 이온 10배, 물 7 → 식초 약 3은 만 배) → 0 dB에서 120 dB(천둥)까지 1조 배가 한 그림에 → 오해(3 차이 = 3배? → 1,000배) → 결론.

- 모형과 단순화: 지진 규모는 지진계 진폭 기준의 리히터식 설명입니다. "산성을 만드는 작은 알갱이"는 수소 이온(화면에 H⁺ 표기)입니다. "귀에는 약 8배"는 10 dB마다 약 2배로 들린다는 어림 규칙입니다. 소리 효과의 크기 변화는 실제 비율이 아니라 안전하게 압축한 대응입니다. 상세는 [에피소드 README](../../episodes/log-scale/README.md)와 [제작 메모](../../episodes/log-scale/brief.md).
