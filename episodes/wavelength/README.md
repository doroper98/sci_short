## 모형 (상태 변수 하나: 파장 λ(t))

`lamKeys()`가 문장·낱말 시각에 묶인 λ 키프레임을 만들고, 키 사이는 log λ를 easeInOut으로 잇습니다. 화면의 파동·띠의 표식·계기판·소리 표가 모두 이 λ(t)에서 나옵니다.

| 양 | 식 | 예 |
|---|---|---|
| 진동수 | f = c/λ, c = 299,792,458 m/s | 550 nm → 545 THz, 1 mm → 300 GHz |
| 알갱이 에너지 | E = hc/λ, hc = 1239.84 eV·nm (2자리 유효숫자) | 700 nm 1.8 eV · 400 nm 3.1 eV · 300 nm 4.1 eV · 10 μm 0.12 eV |
| 무엇과 맞는가 | E < 1.6 분자 진동·회전(열) / 1.6–3.3 눈의 색소 전자 들뜸(보임) / 3.3–10 분자 결합 끊김 / > 10 원자 이온화 | |
| 봉우리 온도(빈) | T = 2898 μm·K / λ (10 nm–1 mm에서 표시) | 10 μm 290 K · 500 nm 5,800 K · 1 μm 2,900 K |
| 구간 | 전파 > 1 m, 마이크로파 1 mm–1 m, 적외선 700 nm–1 mm, 가시광선 400–700 nm, 자외선 10–400 nm(UVA 315–400 / UVB 280–315 / UVC 100–280), X선 0.01–10 nm, 감마선 < 0.01 nm | |
| 레일리 산란 | 세기 ∝ 1/λ⁴, (700/450)⁴ = 5.85 | |

λ(t) 일정: 훅·기원 550 nm → s05 550 nm 유지 → s06 550 nm → 1 mm(약 1 s) → "초속"부터 끝까지 1 mm → 300 nm → 가시광선: 300 → 700(“칠백”) 유지, “빨강” 뒤 700 → 400(“보라”), s08 400 → 700 → 550 → 적외선: 550 → 700 → 10 μm(s09), s10 9.4 μm(몸) → 940 nm(“리모컨과”) → 10 μm(“카메라”) → 15 μm(“이산화탄소가”) → 자외선: 15 μm → 400 nm(“사백”) → 300 nm(“커서”) → 250 nm(s12 “가장”) → 300 nm(“남은”). 흩어짐·동물·오해·정리 장면은 표식 대신 각 장면의 비교(450/700 nm, 세 구간, 0 반응, 끝에서 끝 미끄럼)를 씁니다.

### 단순화·설명 모형 (화면에는 각주 없음)

- **화면의 파장 간격은 로그로 압축**했습니다: Λ_px = 40·(λ/10 nm)^0.2 (1 mm → 400 px, 550 nm → 89 px, 300 nm → 79 px). 화면 파동은 고정 속도 360 px/s로 움직이므로 관측점을 지나는 마루 수(틱)는 "짧을수록 더 자주"의 그림이며 실제 횟수가 아닙니다. 실제 값은 계기판의 "1초에 지나가는 마루 = f"입니다.
- s05의 일곱 줄 파동(전파 560 px … 감마선 17 px)은 순서만 맞춘 상징 길이입니다.
- 가시광선 색은 Bruton의 파장→sRGB 근사(감마 0.8, 420 nm 아래·700 nm 위 어둡게)입니다. 가시광선 확대(380–780 nm)에서만 380–400·700–780을 어두운 색으로 칠했고, 그 밖의 모든 구간(전파·마이크로파·적외선·자외선·X선·감마선)은 회색 빗금, 보이지 않는 빛의 파동은 회색 점선입니다. 적외선·자외선을 빨강·보라로 칠한 곳은 없습니다.
- 훅의 프리즘: 분산을 크게 과장했고 온도계 높이는 정성적입니다(빨강 바깥이 가장 높음, 허셜 1800의 관측 순서만 따름). 염화은 종이는 보라 너머에서 서서히 검어지는 그림입니다(리터 1801).
- 기원의 E·B 그림은 평면파 하나를 비스듬히 투영한 설명 그림입니다.
- 망막 원뿔세포 감도 곡선 S 420 / M 530 / L 560 nm는 개략 가우스(실측 CIE 자료 아님), 오해 장면의 "눈의 반응"은 555 nm 봉우리의 개략 명소시 곡선입니다.
- 적외선 s09: 물 분자 흔들림 = 물의 흡수를 0.75→3 μm 사이 log λ의 부드러운 계단으로 둔 개략 모형, 온도계는 흔들림의 누적입니다. s10 이산화탄소는 15 μm·4.26 μm의 가우스 흡수띠(log λ 폭 0.035)로 흔들립니다.
- 체온 봉우리: T = 309 K(36 °C) → λ = 9.38 μm, 화면 "9.4 μm"(지시안의 9.3 μm는 2898/9.3 = 312 K ≈ 38.5 °C라 36 °C 내레이션과 맞추어 9.4로 표기). 열화상 카메라 8–14 μm, 리모컨 940 nm.
- 자외선 s11: "결합 하나가 끊어짐"은 대표 사건입니다(실제 UVB 손상의 대부분은 티민 이합체 형성). 화면 문구는 "분자 결합 에너지 약 3~5 eV"이며, 계기판의 구간 경계 3.3 eV는 이 영상의 분류 기준입니다. 실제 결합 에너지는 결합마다 다릅니다. s12의 대기 기둥은 정성적(UVC: 산소·오존이 높은 곳에서 흡수, UVB: 오존층이 대부분 흡수, UVA: 대부분 통과), 퍼센트 없음. 피부 단면의 비타민 D·일광화상 위치도 개략입니다.
- 흩어짐: 레일리 광학 두께 τ(λ) = 0.0088·λ_μm⁻⁴(해수면 연직, 450 nm 0.215 · 700 nm 0.037), 곧장 오는 빛 = exp(−τ·m), 공기량 m은 Kasten & Young(1989). 해 높이 70° → 1°로 내리면 450 nm 80 % → 0.35 %, 700 nm 96 % → 38 %. 비교 상자의 흩어짐 번쩍임은 시드 고정 난수 시각(450 nm 초당 약 7번, 700 nm는 1/5.85 비율)이며 소리 틱과 같은 목록입니다. 해 질 녘 해는 그림 테두리 안에 두어 대기 안에 그려졌습니다.
- 동물: 꿀벌 약 300–650 nm, 사람 400–700 nm, 살무사 피트 기관 약 5–30 μm(봉우리 약 10 μm). 쥐의 열 그림은 흰색=뜨거움 흑백 시각화, 꿀벌 눈의 꽃은 "자외선 사진" 흑백 모양이며 실제 벌이 보는 색이 아닙니다.

## 화면 구성

## 소리 (`sound.json`, 설명용 합성음, 음악 없음, 패닝 없음)

**모두 대응(매핑)이며 빛의 소리가 아닙니다.** 빛은 소리를 내지 않고, 음높이·틱은 화면의 같은 모형 값을 귀로 읽게 한 것입니다.

| id | 종류 | 뜻 |
|---|---|---|
| `lam_tone` | `chirp` | 파장 → 음높이 110·2^(0.8·(6 − log10 λ_nm)) Hz (1 mm 110 Hz, 550 nm 670 Hz, 10 nm 1760 Hz), essence 시작 ~ ultraviolet 끝. 진폭 = 표식이 움직이는 빠르기(log λ/s)라서 멈춰 있을 때는 들리지 않음 |
| `ess_crests` | `custom`(틱 28개) | 화면 파동의 마루가 관측점을 지나는 순간마다 한 번(같은 위상 적분에서 계산, 초당 약 1 → 5번) |
| `ess_b1`–`ess_b5`, `ess_all` | tone, swell | s05에서 띠의 구간이 켜질 때, 음높이 = 그 구간의 파장 |
| `ir_hum` | `chirp` 78 Hz + 배음 | 분자가 흔들리는 세기(물 분자 s09, 이산화탄소 s10) = 낮은 웅웅 소리 세기 |
| `ir_body/remote/co2` | tick | 적외선 사용처 카드가 켜짐, 음높이 = 그 파장 |
| `uv_snap` | tick + 짧은 고역 잡음 | DNA 가로대가 끊어지는 순간 |
| `uv_ozone` | noise | 오존층이 밝아짐(흡수) |
| `scat_blue`, `scat_red` | `custom` 틱 25개 / 5개 | 450 nm가 흩어지는 순간(3.2 s, 2400 Hz) / 700 nm(3.6 s, 900 Hz) — 화면 번쩍임과 같은 시각, 초당 밀도 비 ≈ 5.6 (모형 5.85) |
| `ani_human/bee/viper` | tone | 각 눈의 창 가운데 파장(529 nm 676 Hz · 442 nm 706 Hz · 10 μm 333 Hz) |
| `close_glide` | `chirp` | 정리 장면에서 표식이 1 km → 1 pm을 2.4 s에 지남, 띠 전체를 110 → 1760 Hz로 압축한 별도 대응 |
| 기타 | | `answer`(훅의 답), `ritter`, `crest1/2`, `maxwell`, `narrow`, `myth_x`; `silent` 사건은 화면 전용 표식 |
