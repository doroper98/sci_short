# 에피소드 폴더 `ligo-how-it-works` — LIGO는 어떻게 잴까

직접 쓰는 파일은 셋입니다: `script.json`(대본), `scenes.mjs`(화면·모형), `sound.json`(설명용 소리). 기획·출처는 `brief.md`.
사용자 기준: 모든 무대 x = 540 중심, **화면 각주·출처 줄 없음**(단순화는 이 문서에만), 배경음악 없음, 화면 표기 "LIGO".

```bash
SCISHORT_ROOT=$PWD node episodes/ligo-how-it-works/scenes.mjs --emit-sound    # 타임라인이 바뀌면 먼저: sound.json의 모형 값 갱신
SKIP_NARRATE=1 episodes/ligo-how-it-works/run.sh stills                       # outputs/ligo-how-it-works/stills/contact-sheet.jpg
SKIP_NARRATE=1 episodes/ligo-how-it-works/run.sh render sfx mix finish validate
```

## 단순화 (화면에는 쓰지 않음)

- **밝기 과장**: 실제 GW150914에서 출력 밝기 변화는 전체 무늬의 약 10⁻¹⁶ 수준입니다. 화면의 밝기·밝기 소리는 ΔL을 약 2×10⁸배 키운 "표시용 ΔL"(최대 Δφ = π/2, P = 0.5)로 계산했습니다. ΔL 숫자와 ΔL 그래프 눈금(4×10⁻¹⁸ m)은 실제 값입니다.
- **팔 늘어남 그림**: 위쪽 관측소 그림의 팔은 최대 ±8 % 늘고 줄도록 그렸습니다(실제 4×10⁻¹⁸ m).
- **어두운 무늬 운전**: 실제 LIGO는 어두운 무늬에서 아주 조금 비켜 둔 DC 판독(그래서 밝기가 h에 비례)을 씁니다. 여기서는 정확히 어두운 무늬로 두어 P ∝ (1 − cos Δφ)이므로 밝기는 h의 부호를 구분하지 않고 h의 두 배 빠르기로 오르내립니다. 두 관측소 신호는 실제로 부호가 반대였지만 이 표시에서는 같은 모양이 됩니다(대본 "똑같은 모양"과 일치).
- **300번 왕복**: 파브리–페로 공동의 빛 쌓임(피네스)을 "거울 사이를 약 300번 오간다"로 단순화. 카운터는 처음 8번만 실제처럼 하나씩(0.3 s 간격), 그 뒤는 지수적으로 빨라져 s09 "킬로미터를"에 300에 닿습니다(빨라진 것이 숫자로 드러나므로 별도 표기 없음). 공동 안 빛줄기가 굵어지는 것은 빛이 쌓이는 것을 나타낸 그림.
- **모서리 건물 축척**: 레이저·파워 재순환 거울·분할기·입력 시험질량·광검출기 사이 거리는 축척이 아닙니다(실제 수십 m). 팔 4 km만 축척.
- **신호 재순환 거울, 출력 모드 정리기, 압착광, 능동 방진대(HEPI/ISI)**는 그리지 않았습니다. 지면 대비 신호 "약 1조 배"는 LIGO 해설 자료의 어림수이며, 4단 진자의 1/10⁸(10 Hz)과 곱해서 맞추는 계산을 화면에서 하지 않습니다(나머지는 능동 방진·주파수 대역 차이).
- **진자 흔들림 그림**: 각 단의 흔들림 폭은 단마다 약 ½로 줄여 그렸습니다(실제 1/100). 숫자와 로그 막대가 실제 비율.
- **잡음 글리치**: coincide의 핸퍼드 글리치(3 ms 폭 단발)는 설명용 가상 사건입니다. 글리치를 읽을 수 있도록 그래프 시계가 2.5 s 멈춥니다("멈춰 보기" 표시), 리빙스턴 최대는 다시 움직인 뒤 `sites` 사건 시각에 "지금"을 지납니다.
- **방향 추정**: 평면파가 두 관측소를 6.9 ms 차이로 지나는 각도(cos θ = 6.9/10)로 그렸습니다. 실제로는 두 곳만으로는 하늘의 고리 하나까지만 좁혀집니다(대본 "어림").
- **어원**: 干 범할 간(끼어들다), 涉 건널 섭, 計 셀 계(헤아리다). 대본의 "잴 계"는 화면에 "셀 계 · 헤아리다"로 적었습니다. interferometer = inter + ferire + meter.
- **1887 장치**: 돌판 위 간섭계(거울 여러 개로 빛길 약 11 m)를 같은 V자 배치로 단순화해 그림(접힌 빛길 미표시).
- 미국 지도 윤곽은 손으로 찍은 개략도.

## 소리 (`sound.json`, 합성 설명음, 음악 없음)

| id | 종류 | 무엇을 소리로 | 화면의 같은 사건 |
|---|---|---|---|
| `essglow` | chirp(220 Hz 고정) | 본질 장면 두 파동의 밝기 (1 + cos δ)/2 | 마루+골 → 마루+마루 → 되돌림 |
| `splitbeam` | tone 880 Hz | 분할기가 빛을 나누는 순간 | 분할기 고리 |
| `bounce` | custom(틱 24개) | 거울에 닿을 때마다 틱; 1~8번 −28 dB, 이후 빨라지며 −46 dB까지 작아짐 | 오간 횟수 카운터가 1씩 오르는 순간 |
| `brightness` | chirp(220 Hz 고정, 644점) | 광검출기 밝기 P(t) = 소리 세기. 어두움 = 무음 | recombine의 밝기 막대·P(t) 그래프 |
| `ground`, `ground1~4` | noise 70–420 Hz | 지면 흔들림 → 진자 한 단마다 −8 dB(−22 → −54 dB) | 추적 고리가 지면 → 1단 → … → 거울로 내려감 |
| `glitch` | tick 1300 Hz | 핸퍼드에만 나타난 잡음 | 회색 처리·X 표 |
| `sites` | tick 1760 Hz × 2, 간격 0.1112 s | 리빙스턴 최대, 6.9 ms × N 뒤 핸퍼드 최대 | 지도의 두 번쩍임, 그래프 "지금" |
| `closeglow` | chirp(220 Hz) | 마지막 작은 광검출기 한 번 밝아짐 | 정리 장면 막대 |

모형에 묶인 값(brightness·essglow 표, bounce 틱 시각, ground 길이·세기, sites 간격)은 `--emit-sound`가 씁니다. 화면은 같은 식을 `ctx.events`의 시각으로 계산하므로 `sfx.py --events-check`가 화면·소리 시각을 대조합니다. 표가 낡으면 recombine 장면이 경고 한 줄을 출력합니다.
`brightness` gain +4 dB: 표의 최대 진폭이 0.5라서(P 최대 0.5) 최대 피크 ≈ 0.8. 수치 측정만 했으며 청취하지 않았습니다.
