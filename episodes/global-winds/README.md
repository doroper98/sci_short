# 에피소드 `global-winds` — 지구를 두른 바람의 띠 (무역풍·무풍대·편서풍)

"바람을 일으키는 것은 태양, 방향을 꺾는 것은 자전." 179.0초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
무대는 처음부터 끝까지 정사영 지구본 하나입니다(시점 위도 +12°, 서 → 동 자전).

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 땅의 동쪽 속도 | u(φ) = 1674·cos φ km/h → 0° 1670 · 30° 1450 · 37.5°(서울) 1330 · 60° 840 · 90° 0 (화면은 10 단위 반올림) |
| 일사량(연평균, 대기 위) | Q(φ) = 340·(1 − 0.482·P₂(sin φ)) W/m², P₂(x) = (3x² − 1)/2 → 적도 422, 극 176, 비 2.4 |
| 지표 바람 띠 | 무역풍 0–30°(북동/남동에서), 편서풍 30–60°(남서/북서에서), 극동풍 60–90°(북동/남동에서). 세기 = sin(πq)^0.7 (띠 안 위치 q), 띠 가장자리 0 → 적도 무풍대(< 4°)와 30° 부근이 잔잔함. 방향 벡터(동, 북): 무역풍 (−0.80, ∓0.56), 편서풍 (0.86, ±0.42), 극동풍 (−0.80, ∓0.48) |
| 자전 일정 λc(t) | 시점 중심 경도를 경유점(아래)을 지나는 단조 PCHIP 곡선으로 정함. 서 → 동이므로 λc는 계속 줄어듦(보이는 면에서 대륙이 왼쪽 → 오른쪽). 끊김 없음 |
| 추적 공기 덩어리 | 단면(상승·해들리)에서는 (위도, 높이) 일정표, 지구본에서는 coriolis(30 → 4°N, 150°W에서 출발)와 belts(30 → 46°N, 160°E에서 출발) 두 경로 |

자전 경유점(λc, 화면용): 0 s −8° → 훅 끝 −58°(대서양, 두 배) → s12 "사하라" +1 s 30°E(사하라·아라비아) → s15 "적도로" −2.3 s 140°W(추적 덩어리가 중앙 왼쪽) → coriolis 끝 → s18 끝(거의 정지) → s19 끝 110°E(s19 동안 한반도가 시점 중심 기준 −24° → +18°로 지나감) → s21 시작 8°E → "돌아올" 22°W → s21 끝 40°W(항로가 앞면) → 끝. 회전 속도는 약 1–15 °/s로 변합니다(가장 빠른 곳은 s20 약 147 s, 바람 띠가 경도 방향으로 고른 구간이라 그림이 바뀌지 않음).

## 단순화·설명 모형 (화면에는 각주 없음)

- **대기층 두께 과장**: 왼쪽 가장자리 단면의 두께는 0.25 R(지구 반지름 6371 km 기준 약 1600 km)로, 실제 순환 높이 약 15 km의 **약 100배**입니다. 화면 라벨은 "대기 (두께 과장)". 단면 각도는 위도 φ 원이 가장자리와 만나는 각(asin(sin φ / cos 12°))을 60°까지 쓰고 극까지는 선형으로 이었습니다(시점이 12° 기울어 극이 가장자리에서 약 2% 안쪽).
- **세 고리 모형**(해들리 0–30°, 페렐 30–60°, 극 60–90°)은 설명 모형입니다. 실제 띠는 계절·대륙에 따라 남북으로 움직이고 끊깁니다. 춘·추분 기준 그림, 계절 이동 없음.
- **단순화 1 (뒤처짐)**: "30°의 공기가 시속 1450 km를 그대로 갖고 적도로 오면 땅보다 느리다"는 해들리(1735)식 선운동량 설명입니다. 정확히는 각운동량 보존이며 마찰이 없으면 훨씬 센 동풍이 됩니다. 그래프의 공기 선(1450)과 땅 곡선 사이 음영은 **부호(뒤처짐/앞섬)만** 보여 주며 차이를 풍속으로 표시한 곳은 없습니다. 무역풍이라는 이름이 나올 때 그래프 안에 "실제 무역풍 세기 시속 20~30 km 안팎 (지표 마찰)"을 둡니다.
- **단순화 2**: 페렐 순환은 열로 직접 구동되지 않는 간접 순환이며, 편서풍의 실제 원인에는 저·고기압의 운동량 수송이 들어갑니다. 화면은 "30°에서 극 쪽으로 가는 공기가 앞선다"까지만 보여 줍니다.
- **확대 창(펼친 띠)**: 0–30°N(belts에서는 30–60°N) 띠를 평평하게 펼친 그림이고, 창 자체가 공기 덩어리와 함께 동쪽으로 시속 1450 km로 움직이는 기준틀입니다. 그래서 30°의 땅은 창 안에서 멈춰 있고, 다른 위도의 땅 눈금은 (u(φ) − 1450)×0.12(0.11) px/s로 미끄러지며 출발 경선(점선)이 휘어집니다. 평면 근사라 경도 간격은 위도마다 같게 그렸습니다.
- **지구본 위 궤적**: 위도는 9.0 s(5.4 s) 동안 30 → 4°(46°)로 이징, 경도 이동 ∝ ∫(cos30°/cos φ − 1) dt를 −22°(+16°)로 맞춘 화면용 값입니다(실제로는 며칠이 걸림). 남서로 휘는 모양만 의미가 있습니다.
- **바람 입자**: 위도·경도에 고정된 짧은 꼬리 화살표(2.6 s마다 다시 태어남, 시드 고정)로, 지구와 함께 돌고 바람장 방향으로 움직입니다. 화살표는 공기가 **가는** 쪽을 가리킵니다(북동무역풍 → 남서쪽). 속도 8 °/s는 화면용입니다. 각 띠는 그 띠를 설명하는 장면부터만 나옵니다(무역풍 s16 "동쪽에서", 편서풍 s18 "편서풍이", 극동풍 s20 "극동풍이").
- **적도 무풍대**: rise 장면의 작은 흰 흐름은 적도의 약하고 방향이 일정하지 않은 바람을 뜻하며 s10 "바람이 거의 없고"에서 0으로 줄어듭니다. 적도 구름은 위성에서 본 구름 덩어리 모양(지구 고정), 단면의 적란운과 빗줄기는 개략도입니다.
- **사막 띠**: 사하라(15–32°N, 17°W–35°E), 아라비아(14–32°N, 35–60°E), 타르, 소노라·모하비, 오스트레일리아, 칼라하리·나미브, 아타카마의 위경도 상자와 육지의 교집합(미리 계산, 가장자리 흐림)입니다. 경계는 근사입니다.
- **햇빛 다발(essence)**: 오른쪽에서 오는 수평 광선(화면의 x축은 적도면 안에 있음)이 오른쪽 가장자리의 적도(화면 각 0°)와 화면 각 60°(위도 약 58°)에 닿습니다. 다발 반폭 0.065 R일 때 닿는 호의 길이 비는 계산값 약 2.0 → "약 2배". 지구본의 명암은 읽기 쉽게 한 부드러운 조명입니다(태양 직하점은 적도, 화면 중심에서 동쪽 40°; 밤 쪽을 어둡게 하지 않음).
- **그래프 세로축**은 800 km/h에서 시작합니다(축 끊김 표시). 1670 / 1450 차이를 읽히게 하려는 선택이고, "극(90°)에서는 0"을 제목 줄에 적었습니다. 곡선은 약 61°에서 축 아래로 나갑니다.
- **기압 표시**: 적도 저압대(s09 "기압이"), 아열대 고압대 ±30°(s11 "고기압을"), 극 고압대(s20 "극에서"). 60°의 저압대(L)는 내레이션에 직접 나오지 않지만 극 순환이 켜질 때(s20) 세 고리 그림을 완성하려고 함께 보입니다.
- **오해 장면**: "자전이 없다면" 지구본은 회전하지 않고, 반구마다 적도–극을 잇는 **고리 하나**(해들리가 처음 상상한 단일 순환)와 극 → 적도로 곧장 가는 지표 바람(북반구 북풍, 남반구 남풍)을 그렸습니다. 오른쪽 "자전하면"은 세 고리와 여섯 띠(무역풍 강조). 둘 다 같은 태양 에너지로 순환이 돈다는 것이 요점입니다.
- **추적 덩어리 계기(rise·hadley)**: 높이는 "지표 / 상공 약 15 km"의 정성 표시, 상태 문구(따뜻하고 습함 → 소나기 → 식는 중 → 가라앉음·고기압 → 메마름 → 적도로)는 내레이션 요약이며 수치 아님. "지표 바람" 막대는 소리의 바람 세기와 같은 값입니다.
- **콜럼버스 항로**: 팔로스(37.2°N 6.9°W) → 카나리아(28.1°N 15.4°W) → 약 28°N을 따라 서쪽 → 산살바도르(24°N 74.5°W, 1492.10), 귀로는 히스파니올라(19.8°N 70.7°W)에서 북동쪽으로 → 약 35–38°N → 아조레스 산타마리아(37.0°N 25.1°W) → 리스본(38.7°N 9.1°W, 1493.3). 중간 경유점은 근사이며 바하마 → 히스파니올라 탐사 구간은 점선으로만 이었습니다. "볼타 두 마르"나 의도는 말하지 않습니다. 배 그림은 도식(돛은 뒤에서 오는 바람에 뱃머리 쪽으로 부풂).
- **한반도(s19)**: 37.5°N 127.5°E 표식, 구름 기호는 편서풍을 따라 서 → 동으로 움직이는 날씨의 상징(속도 임의).

## 소리 (`sound.json`, 설명용 합성음, 음악·배경음 없음, 패닝 없음)

**모두 대응(매핑)입니다.** 바람 소리는 실제 바람 녹음이 아니라 대역 잡음이고, 세기는 화면의 같은 모형 값입니다.

| id | 종류 | 뜻 |
|---|---|---|
| `wind_hook` | env_noise 300–1500 Hz | 훅: 무역풍 속 배에 일정한 바람, "멎는"에서 무풍대 배로 넘어가며 거의 0 |
| `beam_eq`, `beam_60` | tone 330 Hz | 같은 햇빛 다발: 적도 기준, 60°는 약 2배 넓게 퍼져 넓이당 절반 → 같은 음 −6 dB |
| `rise_tone` | chirp 85 → 180 Hz | 데워진 공기가 솟음: 높이 → 음높이, 오르는 동안만 들림 |
| `wind_doldrums` | env_noise | 적도의 약한 바람 → "바람이 거의 없고"에서 0 (계기의 "지표 바람" 막대와 같은 값) |
| `rain` | env_noise 2.6–7.5 kHz | 적도 소나기 구름 아래 빗소리 |
| `sink`, `sink_polar` | whoosh 높음 → 낮음 | 30°에서 / 극에서 공기가 가라앉음 |
| `wind_return` | env_noise | 지표를 따라 적도로 돌아가는 공기: 세기 = 그 위도의 모형 지표 풍속 |
| `lat_ticks` | custom 틱 7개 | 추적 덩어리가 10° 위도선을 지날 때마다, 음높이 = 위도 |
| `g1670`, `g1450` | tone 418 / 362 Hz | 땅의 동쪽 속도 → 음높이(속도 ÷ 4 Hz) |
| `wind_trade` | env_noise 300–1500 Hz | 30 → 4°N로 오는 공기: 세기 = 그 위도의 모형 무역풍 세기(무풍대에서 0) |
| `trades_on` | env_noise | 지구본 전체에 무역풍 띠가 나타남 |
| `bend` | tick ×3 | 전향력 그림의 세 화살표 |
| `wind_west` | env_noise 110–620 Hz | 30 → 46°N로 가는 공기(편서풍): 무역풍과 다른 낮은 대역 |
| `wind_polar` | env_noise 1.1–3.2 kHz | 극동풍 띠가 나타남(가늘고 높은 대역) |
| `legend` | tick ×3 | 반구마다 세 띠(극동풍 · 편서풍 · 무역풍, 높은 위도일수록 높은 음) |
