# 에피소드 `telescope-types` — 망원경의 종류 (빛을 모으는 방법)

"망원경의 핵심은 확대가 아니라, 넓은 입구로 빛을 모아 한 점에 모으는 것입니다." 158.63초, 1080×1920, 30 fps, 테마 `{base: 'slate', accent: '#F2A65A'}`(청회색 + 호박색), 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음).
**광학 모형 하나가 화면·계기·소리를 함께 움직입니다.** 렌즈의 색별 초점 거리, 포물면 거울·접시의 반사, 입구 지름에 따른 모으는 빛(∝ D²)과 회절 무늬(에어리 무늬), 같은 또렷함에 필요한 지름(1.22 λ/θ), 목성 위성 궤도, 대기의 파장별 차단 높이가 모두 `scenes.mjs` 머리의 순수 함수·상수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모, 검증 메모 |
| `script.json` | 문장 20개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 광학 모형 + 포스터·렌즈·거울·접시·지구본·에어리 무늬 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/telescope-types/scenes.mjs --emit-sound`가 씀 |
| `land.json` | Natural Earth 1:110m 육지(바람의 띠 편과 같은 파일, 사건 지평선 망원경 지구본용) |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/telescope-types/scenes.mjs --emit-sound          # 타임라인·모형이 바뀌면 먼저 (낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/telescope-types/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound` 틀은 수소폭탄 편에서 복사해 고쳤습니다(에피소드 사이 import 없음). 지구본은 공통 `pipeline/render/globe.mjs`를 씁니다. 모든 그림은 이 파일 안의 캔버스 경로이며 외부·생성 이미지는 쓰지 않았습니다(블랙홀 그림자도 설명용 고리 그림).

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 렌즈 (굴절) | 얇은 렌즈, 렌즈 제작자 공식 f(λ) ∝ 1/(n(λ) − 1). n(λ) = 1.5046 + 0.00420/λ²(μm, 크라운 유리 BK7 코시 근사). 초록(546 nm) f = 560 px일 때 실제 빨강 564.7 · 파랑 556.0 px(차이 9 px) → 화면은 분산(n − n_초록)을 8배 → 빨강 600 · 파랑 530 px("색 차이 과장"). 광선은 각 색의 초점으로 곧게(구면 수차 없음) |
| 거울·접시 (반사) | 포물면 y = vy − (x − cx)²/4f. 수직으로 들어온 광선은 색과 상관없이 초점으로. 뉴턴식: 45° 평면거울이 원뿔을 옆으로 꺾고, 옆 초점 F′는 F를 평면거울에 대해 뒤집은 점. 접시: 들어오는 평면 파면 → 반사 뒤 초점을 중심으로 줄어드는 원호(포물면의 같은 경로 성질: 초점까지 거리 = 준선까지 거리). 초점에서 본 접시까지 거리 r = 2f/(1 + cos θ) |
| 입구와 빛 | 모으는 빛 ∝ D²(손잡이 ×1 → ×2, 막대 ×4). 단면 그림의 광선은 간격 46 px로 고정 → 광선 수 ∝ D |
| 회절 무늬 | 에어리 무늬 [2J₁(v)/v]², v = π·(D/D₀)·u, u = 각도/(λ/D₀). J₁은 Numerical Recipes 근사. 두 별 간격 0.8 × 레일리 기준(1.22 λ/D₀): 지름 ×1이면 한 얼룩, ×2이면 두 점(레일리 기준의 1.6배). 화면 밝기 (D⁴/m²)^0.6(봉우리 밝기 ∝ D⁴/m²를 보기 좋게 눌러 표시), 1 − e^(−I) 톤 매핑 |
| 배율 오해 | 배율 m = 대물 초점 ÷ 접안 초점. 배율만 ×2 → 같은 무늬가 2배로 커지고 1/m²로 어두워짐("흐린 얼룩만 커짐"). 입구도 ×2 → 두 별로 갈라짐 |
| 눈동자 대 10 m | 어둠에 익은 눈동자 7 mm, 켁 10 m(조각 36개, 모서리 반지름 0.9 m 육각, 평행변 거리 1.56 m) → 넓이 (10000/7)² = 204만 배("백만 배 넘게"). 화면은 mm당 px를 43 → 43/794로 로그 축소, 읽음값은 지름 7 mm → 10 m를 로그로 |
| 같은 또렷함의 지름 | θ = 1′(2.9×10⁻⁴ rad, 사람 눈 수준) → D = 1.22 λ/θ: 가시광 0.5 μm → 2.1 mm, 전파 21 cm → 883 m(화면 880 m), 약 42만 배("× 약 40만"). 파장은 0.5 μm → 21 cm를 로그로 움직임 |
| 크기 막대 | 가장 큰 굴절망원경 1.02 m(여키스, 1897), 켁 10 m(1993), 허블 2.4 m(1990), 제임스웹 6.5 m(2021 발사, 육각 18조각, 평행변 1.32 m, 금 코팅). 허블·제임스웹은 같은 축척(1 m = 58 px) |
| 갈릴레이 위성 (s02) | 원 궤도, 목성 반지름 단위 a = 5.9 · 9.4 · 15.0 · 26.4, 주기 1.769 · 3.551 · 7.155 · 16.69일. 시작 위상은 모형(넷이 겹치지 않게 고름, 화면 "위치는 모형"). 1월 7일 → 13일 밤을 6.2초에 |
| 대기 (s16) | 멈추는 높이(대략): 감마선 35 · 엑스선 70 · 자외선 30 · 적외선 대부분 8 km(점선 = 일부 도달) · 가시광선·전파 땅까지. 별빛의 흔들림은 모식 |
| 사건 지평선 망원경 (s15) | 2017 관측(2019 발표)의 여섯 곳: 하와이 · 애리조나 · 멕시코 · 칠레 · 스페인 · 남극. 지구본 정면 경도 −78°에서 천천히 돎 |

## 소리 (`sound.json`, 사건 56개)

초점 밝기 → 110 Hz 음의 크기(입구 ×2 = 빛 ×4, 로그로 제한), 두 별이 갈라짐 → 131 Hz 한 음이 117/147 Hz 두 음으로, 색수차 → 98/104/110 Hz 세 음의 맥놀이 → 거울에서 104 Hz 한 음으로 모임, 큰 렌즈 처짐 → 내려가는 음, 전파 → 55 Hz 웅웅, 파장 0.5 μm → 21 cm → 330 → 55 Hz로 내려가는 음, 눈동자 → 10 m 넓이 → 열 배마다 단3도씩 오르는 음 6번, 사건 지평선 망원경 자리 6곳·기선 5개 → 낮은 틱, 공기에 막힌 빛 → 둔한 툭, 제임스웹 조각 18개 → 틱 18개. 모든 기본음 700 Hz 미만, 패닝 없음, 배경음악 없음. 설명용 합성음입니다(녹음 아님).

## 단순화

- 광선 수·굵기, 색수차 크기(×8), 렌즈 처짐(22 px)은 화면용 과장이며 화면에 "색 차이 과장", "처짐 과장"으로 적었습니다.
- 얇은 렌즈·포물면 거울의 이상적인 상(구면 수차·코마 없음). 뉴턴식 평면거울의 가림은 그렸지만 회절 무늬에는 넣지 않았습니다.
- 회절 무늬와 두 별의 갈라짐은 레일리 기준의 설명 모형(단색, 원형 입구).
- 전파 접시의 파장 간격과 대기 차단 높이는 모식(화면 "높이는 대략").
- 블랙홀 그림자는 실제 EHT 영상이 아니라 고리 모양 설명 그림입니다(화면 "설명 그림").
- 갈릴레이 위성의 위치는 모형(화면 "위치는 모형").
- 리퍼세이 원통의 배율 "약 3배"는 문헌의 대략값입니다.
