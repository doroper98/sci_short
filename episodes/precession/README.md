# 에피소드 `precession` — 지구 자전축의 느린 원 (세차운동과 장동)

"달과 태양이 적도의 불룩한 띠를 당기고, 돌고 있는 지구는 쓰러지는 대신 고개를 돌린다." 173.9초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
상태 변수는 **연도 y(t) 하나**입니다. 하늘의 북극 위치, 3D 지구의 자전축 방향, 방향 다이얼, 연도 표시, 장동의 물결, 달 궤도 교점, 소리가 모두 y(t)에서 계산됩니다.

| 파일 | 내용 |

| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 18개, 장면 10개 (고치지 않음) |
| `land.json` | Natural Earth 1:110m 육지 고리 (public domain, world-atlas@2.0.2 경유) — `episodes/seasons/land.json`의 사본 |
| `scenes.mjs` | 모형(순수 함수) + 하늘 원반·팽이·지구 무대 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/precession/scenes.mjs --emit-sound`가 씀 |

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 세차 | 하늘의 북극 = 황위 90° − ε, 황경 λ = 90° − 360°·(y − 2000)/25,772 (J2000 별 고정 황도 좌표, 50.29″/년 일정). ε = 23.44° 고정 |
| 같은 λ의 쓰임 | 3D 지구의 축 기운 방향 = λ − λ(2026) + 90° (2026년에 화면 오른쪽). y가 늘면 λ가 줄어 **황도 북극 위에서 보아 시계 방향** |
| 극에 가장 가까운 해(모형) | 북극성 2103년, 투반 기원전 2829년(0.2°), 베가 13790년(원에서 4.8° 떨어짐) → 화면 "약 14000년", "기원전 2700년경"(brief) |
| 장동 | 18.6년 주항만: Δε = 9.2″ cos Ω, Δψ = −17.2″ sin Ω, Ω = 125.04° − 360°·(y − 2000)/18.6 (교점 후퇴 = 위에서 시계 방향) |
| 달 궤도–적도 각 θ | cos θ = cos ε cos i − sin ε sin i cos Ω, i = 5.14° → 18.3° ~ 28.6°. "달이 비트는 힘" 막대 = sin 2θ의 상대값(숫자 없음) |
| 9.2″ 비교 | 보름달 지름 1,860″ / 9.2″ = 202 → "약 1/200". 지름 192 px 달 위에서 9.2″ = 약 1 px |
| 불룩함 | 적도 반지름 6,378 km, 극 반지름 6,357 km, 차 21 km (편평도 1/298). 화면 편평 0.12 (**약 36배 과장**) |
| 기후 세차 | 근일점 고정 그림에서 축 방향이 360°/21,000년으로 돎. 지금 12월 동지는 근일점보다 12.9° 앞 → 근일점 때 태양 적위 −22.8°(북반구 겨울), 11,000년 전 +23.4°(북반구 여름) |
| 춘분점 띠 | 150년 × 50.3″ = 2.1° (화면 "약 2°"), 1° = 120 px |

## 단순화·설명 모형 (화면에는 각주 없음; 화면의 대상 라벨은 "불룩함 크게 과장", "흔들림 크게 과장", "어긋남 크게 과장", "(모식도)"만)

- **세차 속도 일정, ε 고정.** 경사각의 4만 1천 년 변화, 행성에 의한 세차, 황도의 이동, 별의 고유운동은 무시합니다. 그래서 극에 가장 가까운 해가 실제와 수십~수백 년 다를 수 있습니다(투반 기원전 2829년 등). 화면 연도는 brief의 둥근 값.
- **하늘 원반**: 황도 북극을 가운데 둔 방위 등거리 지도(반지름 48°), **땅에서 올려다본 모습**(황경이 시계 방향으로 증가, 2026년 북극성이 위). 밝은 별 45개의 J2000 적경·적위를 코드에 직접 적고 황도 좌표로 바꿨습니다. 올려다본 하늘에서는 극이 별 사이를 **반시계**로 옮겨 가고(북극성 → 케페우스 → 백조 → 베가), 같은 운동을 황도 북극 **위(바깥)**에서 보면 축의 원뿔은 **시계** 방향입니다. 두 그림은 보는 쪽이 반대라서 화면상 방향이 반대이며 둘 다 맞습니다. 원뿔 장면에는 "황도 북극 쪽에서 볼 때"를, 하늘 원반에는 "북쪽 하늘을 올려다본 모습"을 적었습니다.
- **장동**: 18.6년 주항만 그렸습니다(1년·반년 성분 생략). 확대 띠의 세로축 = 기울기의 흔들림 Δε를 크게 과장(9.2″ → 56 px), 가로축 = 세차로 옮겨 간 거리(같은 축척이면 물결이 보이지 않음). 훅의 "끄덕임"은 북극 표식이 제자리에서 2.5초 흔들리는 상징이고, 정리 장면 원뿔 자국의 물결(한 바퀴 24번, ±0.9°)도 상징입니다(실제는 한 바퀴에 약 1,390번, ±9.2″).
- **달 궤도 그림**: 5.14°는 실제 각(같은 반지름의 점선 황도 원과 두 교점에서 만남). 달 표식은 궤도에서 가장 높은 곳에 세워 둔 것으로, 실제 한 달 공전은 그리지 않았습니다. "달이 비트는 힘" 막대는 sin 2θ의 상대값(최소 0.71 ~ 최대 1)을 0.25~1로 그린 정성 표시입니다.
- **불룩한 띠의 당김**: 가까운 쪽·먼 쪽 화살표 길이(150 / 62 px)는 비교용 과장입니다(달까지 약 60 지구반지름이라 실제 차이는 수 %). "비트는 힘"은 조석 토크의 쉬운 말, "달 2 : 태양 1"은 근사(약 2.2 : 1). 불룩함 장면의 빛은 화면 오른쪽(달·태양 쪽)에서 오는 것으로 그렸습니다.
- **팽이**: 모식 팽이(기울기 7° → 24°), 회전·세차 속도는 화면용. 팽이는 중력의 토크가 *쓰러뜨리는* 쪽이라 자전과 **같은** 방향(위에서 반시계)으로 세차하고, 지구는 토크가 *세우는* 쪽이라 자전과 **반대**(위에서 시계)로 세차합니다. 두 경우 모두 그 방향대로 그렸고, 팽이의 "비트는 힘(토크)" 화살표는 축 끝이 움직이는 방향과 평행합니다.
- **원뿔 장면**: 카메라가 공전면 옆(고도 0°)에서 24°로 올라가며 같은 지구가 이어집니다. 지구의 자전 속도(초당 9°, 서 → 동)는 화면용으로 연도와 무관합니다.
- **기후**: 궤도는 실제 이심률 0.0167(거의 원), 지구 크기는 과장. 그림은 근일점을 고정한 틀이라 축은 기후 세차 비율(2만 1천 년)로 돕니다(궤도 자체의 느린 회전 포함). 중간의 "가을"은 근일점이 북반구 가을(10월 무렵)에 오던 시기입니다. 빙하기 그래프는 21,000·41,000·100,000년 주기를 합친 **모식 곡선**(실측 자료 아님, 세로 숫자 없음)이고, 괄호 "약 2만 1천 년"은 그려진 곡선에서 실제로 약 2만 1천 년 떨어진 두 봉우리 사이에 붙였습니다.
- **천상열차분야지도**: 실제 각석을 베끼지 않은 모식 별지도입니다(무작위 별 무리 120개, 불규칙 간격의 28수 경계선, 서울 주극원 37.5°, 적도, 황도). 바깥 눈금(옛 고구려 천문도의 절기)과 안쪽 눈금(1395년 하늘)의 어긋남 14°는 모식이며 숫자로 표시하지 않았습니다. "『중성기』로 바로잡음"은 brief(한국천문연구원)를 따름. 天象列次分野之圖 풀이는 "하늘을 분야에 따라 차례로 벌여 그린 그림"으로 적었습니다.
- **章動**: 한자 표기만 쓰고 章 글자의 유래는 설명하지 않았습니다(brief: 확인하지 못함).
- **망원경·위성**: 어긋남 크게 과장. "기준 좌표 + 세차 + 장동 = 오늘 가리킬 곳"은 개념식입니다.
