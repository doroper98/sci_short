## 모형 (설명용 매개변수 모형 — 시뮬레이션 아님)

상태 변수 하나 s ∈ [−1, +1] (−1 라니냐, 0 평상, +1 엘니뇨)가 단면·지도·계기판·소리를 모두 움직입니다.

| 양 | 식 | s = −1 / 0 / +1 |
|---|---|---|
| 무역풍 세기 W (평년 = 1) | 1 − 0.7 s | 1.70 / 1.00 / 0.30 |
| Niño 3.4 수온 편차 T | 2.4 s °C | −2.4 / 0 / +2.4 |
| 서−동 해수면 차 Δη | 50 cm · (1 − 0.8 s) | 90 / 50 / 10 cm |
| 수온약층 깊이 서 D_w | 160 m · (1 − 0.45 s) | 232 / 160 / 88 m |
| 수온약층 깊이 동 D_e | 50 m · (1 + 0.8 s) | 10 / 50 / 90 m |
| 비구름 경도 λ | 140°E + 60°·max(0, s) | 140°E / 140°E / 160°W |
| 대류 세기 C (구름 크기·빗소리 밀도) | 1 + 0.6·max(0, −s) | 1.6 / 1 / 1 |
| 용승 세기 U | max(0, 1 − 1.1 s) | 1 (상한) / 1 / 0 |

- 동쪽 수온약층 계수는 지시안의 1.2 대신 **0.8**을 썼습니다. 1.2면 s = +1에서 동 110 m > 서 88 m(기울기 역전), s = −1에서 −10 m가 되어 물리적으로 맞지 않습니다. 0.8이면 엘니뇨에서 거의 평평(88 / 90 m), 라니냐에서 동쪽 10 m(거의 수면까지 올라옴)입니다.
- s(t) 일정: 평상 장면 0 → s08 시작 + 0.2 s부터 "이것이"까지 0 → +1(easeInOut) → s09 동안 +1 → s10 "무역풍이"부터 3 s 동안 +1 → −1 → 이후 −1. 원격·겨울 왼쪽은 +1, 겨울 오른쪽은 −1, 여름은 쇠퇴기 +0.3.
- 엘니뇨 전환 중 수온약층에 동쪽으로 이동하는 35 m 혹(켈빈파를 닮은 모양)을 더하고, 따뜻한 층 안에 흐름 화살표를 그립니다. 그림 장치이며 파동 역학을 계산하지 않습니다.
- 단면의 해수면 기울기(cm)와 수온약층 깊이(m)는 한 그림에 넣기 위해 크게 과장했습니다. 숫자 라벨은 모형값입니다. 단면 표층 색은 기후값 29.5 − 6u² °C(u: 서 0 → 동 1)에 편차를 더한 수온으로 칠합니다.
- 지도의 해수면 온도 편차: 엘니뇨는 235°E 중심 + 남미 연안(276°E) 가열, 라니냐는 215°E 중심의 가우스 혀, 서쪽에 반대 부호의 말굽(진폭 0.15 T). 해안선은 손으로 옮긴 개략도입니다.
- 워커 순환 고리는 상승(λ) – 상층 동진 – 하강(98°W) – 지상 무역풍. s > 0.35에서 인도네시아 위로 하강하는 반대 세포(건조)를 겹칩니다.
- **lanina 장면 s11의 Niño 3.4 다년 시계열은 NOAA ONI의 모양을 가우스 혹의 합으로 옮긴 개략도이며 공식 자료가 아닙니다**(1994–2025, 각 사건의 대략적 절정 시기와 크기). 화면에는 "모양을 옮긴 그림"이라고만 적었습니다.
- 원격 영향·겨울·여름 지도의 필리핀해 고기압/저기압, 남풍·북풍, 수증기 수송, 장마 전선은 편차장의 도식입니다(Wang et al. 2000). 동아시아 영향 라벨에는 모두 "경향"을 붙였습니다. 원격 장면의 1.2 s 지연은 상징적 지연이며 실제 전파 시간이 아닙니다.
- 오해 장면의 확률 막대(평년 1/3씩 → 엘니뇨 겨울 0.20 / 0.33 / 0.47)는 "그림 예시"로 표시한 설명용 비율이며 통계값이 아닙니다.
