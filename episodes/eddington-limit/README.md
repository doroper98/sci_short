# 에피소드 `eddington-limit` — 에딩턴 한계 (빛이 별을 밀어낸다)

"빛이 미는 힘이 중력과 같아지는 밝기, 그 너머에서는 별이 제 빛에 날아간다." 171.5초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
**모형 하나가 화면·계기·소리를 함께 움직입니다.** Γ = L/L_Edd(빛이 미는 힘 ÷ 중력)와 껍질의 가속 a = g(r)(Γ − 1)의 적분, 렌즈 속 광자 충돌 시각표, 블랙홀의 삼키는 빠르기 상한, 한계 속도 성장 곡선이 모두 `scenes.mjs` 머리의 순수 함수에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 18개, 장면 10개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·시간 계획) + 가산 부동소수 빛 버퍼(별 표면·껍질·원반·성운) + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/eddington-limit/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/eddington-limit/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/eddington-limit/run.sh stills            # outputs/eddington-limit/stills/contact-sheet.jpg
SKIP_NARRATE=1 episodes/eddington-limit/run.sh render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. `pipeline/render/index.mjs`의 그리기 도구만 씁니다(`globe.mjs`는 쓰지 않음).
빛 버퍼(`Glow`: 0.5배 해상도 가산 버퍼 + 톤 매핑 + 블룸, 더러운 사각형만 지움)는 오로라 편의 `GlowBuf`를 이 편에 맞게 다시 쓴 것입니다. 오로라·이 편에 이어 한 번 더 쓰이면 `pipeline/`으로 올릴 후보입니다.

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 에딩턴 광도 | L_Edd = 4πG M m_p c / σ_T = 1.26×10³¹ W × (M/M☉) ≈ **3.3×10⁴ L☉ × (M/M☉)** (`LEDD_PER_MSUN = 3.3e4`). 태양 Γ = 1/33,000 ≈ 3.0×10⁻⁵ |
| 두 힘 | 전자–양성자 쌍 하나에서 F_빛 = σ_T L/(4πr²c)(전자), F_중 = G M m_p / r²(양성자). 화면 단위로 `fLight(Γ, r) = Γ/r²`, `fGrav(r) = 1/r²` → 비율은 어느 r에서나 Γ |
| 산란 | 톰슨 단면적 ∝ 1/m² → 양성자는 전자의 (1/1836)² ≈ 3×10⁻⁷(화면 문구 "빛을 거의 안 받음"). 질량비 1836 |
| 껍질의 움직임 | a = K(Γ(t) − 1)/r², K = 2.6 (별 반지름/s², 화면 단위). `shellTrack()`가 1/240 s 간격으로 적분, 안쪽으로 끌리는 동안은 표면(r = 1)에 머묾. 훅의 포스터 껍질(t = −1.15 s부터 Γ = 1.6), 훅 s02의 껍질(Γ가 1을 넘는 12.54 s부터), 정리의 껍질(165.39 s부터), 그 뒤의 바람 덩어리(Γ = 1.5 고정 궤적)가 모두 이 적분. 계산 값: 훅 껍질 13.5 s에 1.15R, 15.0 s에 2.45R, 16.0 s에 3.7R("날려" 15.28 s) |
| 주계열 곡선(설명용 모형) | Γ_MS(M) = 1/(1/Γmax + 1/(Γ☉ M^2.5)) → 태양 근처 L ∝ M^3.5, Γ(10) = 0.009, Γ(60) = 0.42, Γ(100) = 0.66, **Γ(200) = 0.80**(R136a1 모형값 약 0.8, brief), 1을 넘지 않음. L(200) = 5.3×10⁶ L☉ |
| 훅 손잡이 | 포스터: M = 100, Γ = 1.6 → "정하는"−0.45 s ~ "알아볼까요"+0.35 s 동안 태양(M = 1)으로 되돌림 → "무거운"−0.1 s ~ "타오르지만"+0.5 s 동안 M 1 → 100(L은 주계열 곡선, Γ 0.66까지) → "너무"−0.1 s부터 3 s 동안 밝기만 Γ 1.5까지(1을 넘는 순간 12.54 s, "제" 12.61 s) |
| 본질 손잡이 | Γ 0.35 → 0.55("빛이") → 정확히 1("같아지는 밝기") |
| 정리 손잡이 | Γ 0.66 → 1("같아지는", 아무것도 움직이지 않음) → 1.5("너머에서는" 뒤, 껍질이 날아감) |
| 렌즈 광자 | 시드 고정 시각표(0.5~0.78 s 간격, 다섯 중 셋 이상이 표적을 향함), 렌즈 속 속도 330 px/s. 충돌 28번이 화면의 충돌 번쩍임·전자 밀림·소리 틱에 같은 시각으로 쓰임 |
| 용골자리 에타 | 모식 광도 곡선(1820~1870, 1843년 −0.8등급 최대, 시리우스 −1.46). Γ(연도): 0.9 → 대분출 1838~1858 동안 1을 넘고 1843년 5.0 → 0.9. 연도 커서: 1822 → "한계를"에서 1838 → "밝아져"에서 1843 → 머문 뒤 1870. 그래프의 에타 점(M = 100)은 L = Γ × 3.3×10⁶ |
| 호문쿨루스 | 두 덩이의 크기 ∝ (연도 − 1843) (탄도 팽창), "그때"−0.15 s의 1843 → "지금도"+0.1 s의 2026 |
| 블랙홀 먹이 | 들어오는 기체 S(t): 0.4 → 2.8(에딩턴 단위, "빨려"−0.1 s ~ "빠르기에"−0.6 s). 삼키는 빠르기 Ṁ = S/(1 + S⁶)^(1/6)(1에서 부드럽게 막힘), 밀려나는 비율 1 − Ṁ/S. 원반 밝기·빛줄기 수·막대·소리 크기가 Ṁ |
| 블랙홀 성장 | M(t) = 100 M☉ × e^((t − 100 Myr)/τ), τ = (ε/(1−ε))·σ_T c/(4πG m_p) = 50 Myr(ε = 0.1) → 680 Myr에 1.09×10⁷ M☉. J0313−1806(1.6×10⁹ M☉, z = 7.642, 빅뱅 뒤 약 6.8억 년)보다 약 150배 모자람(147배) |
| 원반(오해) | 바늘 Γ: 0.6 → 12(로그로, "빛은"−0.2 s ~ "열"+0.3 s). 화면 숫자는 "10배 넘게"만 |

## 단순화·설명 모형 (화면에는 각주 없음; 대상 표식은 "크기 과장", "휨 크게 과장", "모형 곡선", "모식", "모형: 씨앗 태양 100배 · 한계 속도로 성장"만)

- **고전적 에딩턴 한계**: 완전 이온화 수소, 전자 산란만. 실제 별 바깥층은 불투명도가 더 커서 한계가 낮아질 수 있습니다(brief). 별 내부의 기체 압력은 그리지 않았습니다(렌즈의 쌍이 한계 아래에서 떨어지지 않는 이유).
- **껍질의 가속**: K(표면 중력)는 화면용 값입니다. 시간 축척(실제로는 며칠~몇 년)은 선언하지 않은 화면 시간이며, 바깥층 전체가 하나의 얇은 껍질로 날아가는 것은 단순화입니다. 껍질 밝기는 (R/r)^1.6로 옅어지게 했습니다(질량이 일정한 껍질의 면밀도 ∝ 1/r²에 가깝게).
- **별 그림**: 쌀알 무늬·회전·빛줄기는 화면용 질감입니다. 별의 화면 반지름은 질량의 로그로 정했습니다(실제 반지름 비율 아님). 색은 질량이 클수록 푸르게(온도 표시).
- **렌즈**: 입자 크기·화살표 길이·광자 속도·충돌 빈도는 과장(실제 충돌은 훨씬 잦음). 광자가 전자에서 튀는 방향은 무작위 그림. 렌즈의 Γ는 무거운 별 하나를 가정한 0.6.
- **거리 비교**: 쌍을 r에서 2r로 옮길 때 별의 밝기·질량은 그대로입니다. 원뿔의 칸은 넓이 비율만 보이는 모식입니다.
- **주계열 곡선**: 위의 설명용 식이며 관측 자료 적합이 아닙니다. 별 점들은 곡선 둘레에 ±0.15 dex로 흩은 그림입니다.
- **별바람(s12)**: 200배 별의 거센 바람은 주로 스펙트럼선 흡수가 모는 바람이라 전자 산란만 쓰는 a = g(Γ − 1)(Γ = 0.8)로는 들어 올리지 못합니다. 그래서 이 바람만은 모형 적분이 아닌 일정한 흘러나감으로 그렸습니다.
- **용골자리 에타 광도 곡선**: 역사 기록의 모양을 따른 **모식**(1820년대 밝아짐, 1837년 말 번쩍임, 1843년 −0.8등급 최대, 1856년 뒤 먼지로 어두워짐)이며 측정값 표가 아닙니다. 그래프의 에타 점은 질량 100 M☉로 두었고(화면에 숫자 없음), Γ(연도)의 모양(최대 5, 1838~1858 동안 1 넘음)은 brief의 "약 5배, 10~20년"을 따른 모형입니다. 등급과 광도 사이의 먼지·복사 보정은 다루지 않았습니다.
- **호문쿨루스**: 두 덩이는 기울어진 타원체 껍질의 투영(주연 밝음)과 잡음 얼룩으로 만든 그림입니다. 크기와 기울기는 화면용, 팽창은 1843년부터 일정 속도로 가정했습니다. 분출 질량은 "태양 질량 10배 넘게"만 표시(brief: 약 10~45).
