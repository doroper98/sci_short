# 에피소드 `orbit-altitudes` — 제임스웹은 얼마나 높이 있을까 (산에서 우주까지)

"높을수록 위성은 느리게 돌고, 한 바퀴에 걸리는 시간은 길어집니다." 163.60초, 1080×1920, 30 fps, 테마 `{base: 'navy', accent: '#F2C14E'}`(금빛), 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음). 완성본 번호 23(`docs/TOPIC_BACKLOG.md`).
**모형이 화면·계기·소리를 함께 움직입니다.** 로그 높이 사다리, 뉴턴의 대포 궤적(실제 중력 적분), 위성의 공전 위상(하나의 모형 시계 τ), 지구 자전, 정지궤도로 오르는 위성의 높이 표가 모두 `scenes.mjs` 머리의 순수 함수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 + 검증 메모 |
| `script.json` | 문장 22개, 장면 8개 (고치지 않음) |
| `scenes.mjs` | 모형 + 사다리·지구(빛 받는 지구 `drawEarthLit`)·궤도·아이콘 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/orbit-altitudes/scenes.mjs --emit-sound`가 씀 |
| `land.json` | Natural Earth 1:110m 육지 윤곽(퍼블릭 도메인), `episodes/precession/land.json` 사본 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 |

```bash
node episodes/orbit-altitudes/scenes.mjs --emit-sound           # 타임라인·모형이 바뀌면 먼저 (낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/orbit-altitudes/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound` 틀은 중력과 시간·수소폭탄 편에서 복사해 고쳤습니다(에피소드 사이 import 없음). 지구는 `pipeline/render/globe.mjs`의 `lookCam`·`earthTextures`·`drawEarthLit`(생성한 색, 위성 사진 아님)를 씁니다.

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 원 궤도 | v = √(GM/r), T = 2π√(r³/GM), GM = 398,600.4 km³/s², R⊕ = 6,371 km. 우주정거장 400 km → 초속 7.67 km, 92분 · 허블 500 km → 7.61 km, 95분 · 극궤도 기상위성 820 km → 7.44 km, 101분 · GPS 20,200 km → 3.87 km, 11시간 58분 · 정지궤도 35,786 km(적도 반지름 6,378 km 기준 r = 42,164 km, 한 바퀴 = 1 항성일) → 3.07 km, 23시간 56분 · 달 38만 4,400 km(중심 거리를 사다리의 높이로 그림) 27.3일 · L1·L2 150만 km |
| 로그 사다리 | 화면 y ∝ log10(높이 km). 전체 63 m ~ 350만 km(훅·포스터·정리), 산 확대 56 m ~ 20 km, 도착 7,000 km ~ 320만 km. 한 칸 = ×10. 산 윤곽은 같은 눈금으로 그린 양식화한 단면(확대할 때 가로로 넓힘) |
| 공기 밀도 | 미국 표준 대기 1976을 로그 보간. 100 km 5.6×10⁻⁷ kg/m³ = 땅의 약 220만분의 1. 공기 점은 밀도^0.18에 비례하는 개수(보이게 하려는 압축) |
| 뉴턴의 대포 | 950 km로 과장한 산 꼭대기에서 수평 발사, μ/r² 중력 RK4(0.5초 간격). 초속 6.5 km → 18분 뒤 61° 떨어진 곳에 닿음, 7.0 km → 30분 뒤 110°, 7.38 km(그 높이의 원 궤도 속도) → 106분 뒤 산으로 돌아옴. 시간 1,100배 |
| 모형 시계 τ | τ(t) = ∫K dt (K = 실제 초 / 화면 초): 대포·본질·저궤도 1,100배(92분 → 약 5초), 정지궤도 장면에서 "자전과" 무렵 7,180배(하루 = 12초)로 바뀜. 모든 위성의 위상과 지구 자전(1 항성일 = 86,164초)이 같은 τ를 씀 |
| 궤도 그림 | 직교 3D, 지구 반지름 = 화면 배율, 궤도 반지름 실제 비례. 경사: 우주정거장 51.6°, 허블 28.5°, 스타링크 53°(껍질 여섯 개 × 일곱 점), 극궤도 기상위성 98.7°, 정지궤도 0° |
| 손잡이 위성 | s09: 400 → 20,200 km(로그 보간, "높을수록" ~ "느리게"), 정지궤도 장면: 820 → 35,786 km. 끝에서 동경 128.2° 위에 오도록 위상을 맞춤 |
| 천리안의 눈 (s17) | 원근 카메라를 동경 128.2° 적도 위 지구 반지름 6.62배에 두고 지구를 봄. 태양 아래 지점이 서쪽으로 움직임(화면에서는 하루 시계의 0.6배 속도로 아침 → 오후) |
| 태양 궤도 | 위: 태양 중심 그림, L 점 거리(0.01 AU)를 20배 과장, 1년 = 8초. 아래: 실제 비례 띠(달 38만 4,400 km : L1·L2 150만 km = 1 : 3.9) |
| 오해 | g(h) = 9.81·(R/(R+h))², 400 km에서 8.68 m/s² = 89%(화면 "중력 89% (약 90%)") |
| 허블 고도 | 1990년 약 615 km → 2026년 약 500 km(대표값, s14에서 연도 표시와 함께 내려옴) |

## 단순화

- 모든 궤도는 원. 극궤도 기상위성은 실제로 태양동기궤도지만 "남극과 북극 위를 지나는"으로만 말함.
- 아이콘(우주정거장·허블·제임스웹·소호·위성·여객기)은 크기를 키운 모양 그림이며 실제 비례가 아님.
- 뉴턴의 대포의 산 높이(950 km), 목성 크기(위성 궤도 대비), 태양 그림의 L 점 거리는 과장(화면에 "산 높이 과장", "L 점 거리 과장" 표시).
- 제임스웹은 실제로 L2 둘레의 헤일로 궤도를 돈다(24번 라그랑주 점 편). 이 편에서는 점으로만 그림.
- "거울은 영하 220 °C 아래"는 제임스웹 광학계가 50 K(−223 °C) 아래에서 운용된다는 NASA 설명의 반올림.
- 소리는 모두 설명용 합성음(우주의 소리 아님).
