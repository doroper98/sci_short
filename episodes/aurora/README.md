# 에피소드 `aurora` — 오로라는 왜 극지방에서만 보일까

"태양풍이 오고, 자기장이 길을 열고, 공기가 빛난다." 161.3초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
화면·계기·소리는 `scenes.mjs` 머리의 **하나의 모형**에서 나옵니다: 태양풍 세기 `flux(t)`, 폭풍 세기 `S(t)`(0 = 조용함, 1 = G5), 꼬리 입자의 속도 배수 `accel(t)`, 오로라 밝기 `pour(t)`, 고도별 방출 `EMIT(h)`, 쌍극자 관계 `L = 1/cos²λ`, 지평선 조건 `h > R(1/cos(d/R) − 1)`.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 17개, 장면 10개 (고치지 않음) |
| `land.json` | Natural Earth 1:110m 육지 고리 (public domain) — `episodes/precession/land.json`의 사본. 빛 받는 지구의 질감과 밤 쪽 해안선에 씀 |
| `scenes.mjs` | 모형(순수 함수) + 오로라 렌더러(지상 커튼, 단면, 지구본 껍질) + 자기권(자기력선·방패·입자) + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/aurora/scenes.mjs --emit-sound`가 씀 |

```bash
node episodes/aurora/scenes.mjs --emit-sound           # 타임라인이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/aurora/run.sh stills           # outputs/aurora/stills/contact-sheet.jpg
SKIP_NARRATE=1 episodes/aurora/run.sh render sfx mix finish validate
```

지구본은 `../../pipeline/render/globe.mjs`(`lookCam`, `earthTextures`, `drawEarthLit`, `makeStars`, `loadLand`)를 그대로 가져다 씁니다(파이프라인 파일은 고치지 않음).
오로라 렌더러(가산 부동소수 버퍼 + 톤 매핑 + 블룸, 고도 → 색 표 하나)는 이 편에만 있습니다. 다른 편에서 두 번 더 쓰이면 `pipeline/`으로 올릴 후보입니다.

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 방출 색 `EMIT(h)` | 산소 557.7 nm 초록: 95~108 km에서 켜져 116 km부터 척도 36 km로 감소(100~200 km가 주). 산소 630.0 nm 빨강: 170~240 km에서 켜져 255 km 위에서 척도 110 km(200 km 위가 주). 질소 N₂⁺ 427.8 nm 파랑·보라: 92~104 km. 아래 가장자리 분홍: 88~100 km. 상대값이며 지상 커튼·고도 단면·지구본 껍질·지평선 모식도가 모두 이 표 하나(`ALT_LUT`)로 색을 냄 |
| 쌍극자 | `L = 1/cos²λ` (λ = 자기력선이 땅에 닿는 자기 위도, L = 적도에서 지구 중심까지 거리, 지구 반지름 단위). 계기 값: 62° → 4.5, 65° → 5.6, 70° → 8.5 |
| 오로라 고리 | 자기 위도 띠, 조용할 때 밤 쪽 65~70°(대본), 낮 쪽 74~77°(밤 쪽으로 치우친 고리). 폭풍 S가 밤 쪽 띠를 (65 − 22S)~(70 − 15S)°로 넓힘 → G5에서 43~55° |
| 폭풍 세기 S(t) | "큰" − 0.1 s에서 0, "넓어집니다." + 0.6 s에 1(G5), 장면 끝까지 유지. G 칸 = round(5S) |
| 태양풍 세기 flux(t) | 바람 장면 1, 자기력선 장면에서 0.45로 낮췄다가 "흔들면"에 1.25, 폭풍에서 2.2. 화면의 켜진 입자 수·계기 막대·소리 크기가 같은 값 |
| 꼬리 입자 속도 accel(t) | "빨라지며" − 0.2 s부터 1.5 s 동안 1 → 5배(가속). 입자의 진행·계기 막대·음높이(196 Hz × √배수)가 같은 값 |
| 지자기극 | 북위 80.8°, 서경 72.7°(대략, 쌍극자 극). 지리극과 9.2° 어긋남. 강원 화천(북위 38.1°, 동경 127.7°)의 자기 위도는 이 모형으로 29.4° → 화면 "약 29°" |
| 저위도에서 보이는 높이 | 지평선 위로 보이려면 h > R(1/cos(d/R) − 1). 폭풍 때 오로라를 한국 북쪽 d = 1,650 km에 두면 h > 220 km만 보임 → 100~200 km 초록은 지평선 아래, 빨강만 보임 |
| 색 → 음 | 방출선 빛의 진동수를 40옥타브 낮춘 값: 초록 557.7 nm = 488.9 Hz, 빨강 630.0 nm = 432.8 Hz, 파랑 427.8 nm = 637.4 Hz, 네온 640.2 nm = 425.9 Hz (실제 소리가 아닌 대응) |

## 단순화·설명 모형 (화면에는 각주 없음; 화면의 대상 라벨은 "크기 과장", "자기극 (대략)", "모식도 · 지구 곡률 과장"만)

- **자기장 그림**: 쌍극자를 바탕으로 한 **그림용 모형**입니다. 지구를 아주 크게 그리기 위해 반지름을 r → 1 + 2.6(1 − e^−(r−1)/2.6)로 눌렀고(자기력선이 땅에 닿는 위도는 그대로), 낮 쪽은 최대 20 % 눌렀으며, 밤 쪽은 발 위도 55~72° 선을 최대 3.3배 늘이고 조금 납작하게 해 꼬리를 만들었습니다. 74~78° 위의 선은 열린 선(꼬리 엽)으로 그렸습니다. 계기의 "지구 반지름 × L"은 그림이 아니라 **순수 쌍극자 값**입니다. 실제 자기권의 꼬리 늘어남·재결합·전류는 다루지 않았습니다(brief의 "설명하지 않을 범위").
- **방패**: 자기권 경계는 Shue형 r = 3.0(2/(1 + cos θ))^0.45, 활 모양 충격파는 r = 4.0 × 1.55/(1 + 0.55 cos θ) (그림 단위). 시선에 수직인 자오면의 윤곽만 빛나는 띠로 그렸습니다. 태양풍 입자의 길은 ρ = √(b² + (1.07 ρ_경계)²)로 경계를 비껴 가게 만든 **화면용 흐름선**(유체 계산 아님)이며, 태양에서 방사상으로 퍼져 나오는 시작 부분도 화면용입니다. 태양–지구 거리·태양 크기·입자 속도는 화면용(시간 압축)이고, 실제 속도는 계기의 초속 약 400 km입니다.
- **나선**: 자이로 반지름·피치·회전 속도는 크게 과장했습니다(라벨 "크기 과장"). "가로질러서는 제자리 맴돌기"는 자기장에 수직인 속도만 가진 입자의 원운동을 옆에서 본 모습(타원)입니다. 거울점 반사·표류는 그리지 않았습니다.
- **꼬리 가속**: "흔들면"의 늘어남(+34 %)과 되돌아감(−46 %)은 상징적인 동작이며, 입자 가속의 실제 기작(재결합·평행 전기장 등)은 다루지 않았습니다. 입자 색(주황)은 꼬리의 플라스마 입자를 구분하려는 표시색입니다.
- **오로라 고리(지구본)**: 고도 88~470 km의 얇은 발광 껍질을 화면 해상도의 0.42~0.5배로 광선 추적했습니다. **높이는 1.7배 과장**(우주에서 커튼이 보이도록), 낮 쪽 고리는 햇빛에 묻혀 보이지 않으므로 85 % 어둡게 그렸습니다(실제로는 낮 쪽에도 있음). 고리 안의 밝기 무늬는 잡음으로 만든 **모식**입니다. 지구본은 한 시각에 멈춘 모습(자전 없음)이며, 자기극이 화면 위쪽(+Z)에 오도록 자전축을 9.2° 기울여 놓았습니다. 바람·자기력선·고리 장면은 자정이 서경 100°, 폭풍 장면은 동경 140°, 오해 장면은 서경 60°, 정리 장면은 동경 15°에 오게 놓은 화면용 시각입니다(계절 기울기 무시). 육지 색·구름은 `globe.mjs`의 생성 질감(위성 사진 아님), 밤 쪽 해안선은 Natural Earth.
- **지상 커튼(훅)**: 커튼 면의 흔적선이 남북으로 굽이치고(파장 900·190·90 km), 동서로 휘감기며(접힘), 커튼이 시선과 나란한 곳은 1/|cos θ|만큼 밝아지게 했습니다(얇은 발광면의 성질). 실제 커튼 두께(약 1 km)를 생각해 이 밝아짐은 3.5배에서 멈췄습니다. 광선은 자기력선 방향(고위도에서는 거의 수직)으로 세웠고, 지구 곡률에 의한 낮아짐(d²/2R)을 넣었습니다. 광선 무늬·접힘의 움직임은 화면용 속도입니다. 산·나무·호수는 생성한 풍경(특정 장소 아님)입니다.
- **화천 장면**: 사진을 베끼지 않은 모식 풍경입니다(망원 카메라, 산 능선·불빛은 생성). 붉은빛은 위 모형의 지평선 조건으로 잘린 커튼 윗부분입니다. 대기 굴절·소광은 넣지 않았습니다.

- **테렐라**: 상자·자석 공·전자총 모양은 양식화한 그림이고, 빛 고리 색(보라·분홍)은 낮은 압력 공기 방전을 떠올린 화면 색입니다. 고리 위치(자기 위도 58°)와 자기력선은 화면용입니다.
