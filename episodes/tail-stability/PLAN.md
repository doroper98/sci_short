## 0. 한눈에

- 핵심 명제(s10 = 마지막 문장): "꼬리날개는 무게중심에서 멀리 떨어진 작은 날개여서, 작은 힘으로도 비행기를 제자리로 되돌립니다."

## 3. 운동 모형 — `model.mjs`

각도 θ: 기수가 **들리면(옆모습) 양수**. 캔버스에서는 축을 중심으로 `rotate(+θ)`(기수가 왼쪽이라 시계 방향 회전이 기수 들림). 평면도에서는 같은 θ 를 '기수가 화면 위쪽으로 틀어짐'으로 쓴다.

### 3.1 돌풍(kick)

돌풍은 기수 밑에서 올라오는 짧은 바람 덩어리이고, **두 모형에 똑같이** 작용한다: 모형 시간 0 → `RISE = 0.18` 초 동안 θ 를 0 → `TH0`(= 10°)로 올린다(`smooth`). 그 뒤는 스스로 움직인다(초기 조건 θ = TH0, 각속도 0).

### 3.2 꼬리날개 있는 모형 (안정)

`θ'' = −ω²θ − 2ζω θ'`, `ω = 6.2 rad/s`, `ζ = 0.35`. 닫힌 꼴:
`θ(τ) = TH0 · e^{−ζωτ} · (cos ω_d τ + (ζω/ω_d) sin ω_d τ)`, `ω_d = ω√(1−ζ²)`, τ = 풀려난 뒤의 모형 시간.
첫 넘침(반대쪽)은 약 −3°, 약 1.5초 안에 0.3° 아래로 잦아든다.

### 3.3 꼬리날개 없는 모형 (불안정)

`θ'' = (σ²/2)·sin 2θ − c·θ'`, `σ = 3.6 /s`, `c = 0.25 /s`(2026-11-20 검수 뒤 0.8 → 0.25: 대본의 낱말이 '뒤집힌다'라서, 90° 근처에 곧 서 버리지 않고 뒤로 크게 넘어갔다 되돌아오기를 오래 되풀이하게 했다). 작은 각에서는 `θ'' = +σ²θ`(스스로 커짐), 90° 근처에서 흔들린다(바람을 가로막는 자세 — 큰 각의 움직임은 설명 모형).
RK4 로 `dt = 1/1000` 초, 0~14초를 한 번 적분해 표(Float64Array)로 두고 선형 보간해서 읽는다. 기대값(검산용, c 0.25): 풀려난 뒤 0.37초 ≈ 20°, 0.6초 ≈ 40°, 약 0.95초에 90° 통과, 최대 약 155~162°, 그 뒤 약 25°~160° 사이를 크게 오가며 천천히 잦아든다(바람을 가로막는 90° 자세 둘레). 화면의 숫자는 늘 모형에서 읽는다 — `+140°` 같은 글을 박아 쓰지 않는다.
`ω²/σ² = 3` 은 6절 저울의 값(꼬리 4 − 날개 1 = 3, 날개만 1)과 맞춘 것이다 — **바꾸려면 둘을 함께** 바꾼다.

### 3.4 다른 안정한 물체(같은 식, 값만 다름 — 설명 모형)

| 물체 | ω (rad/s) | ζ | 쓰는 곳 |
|---|---|---|---|
| 화살 | 9.0 | 0.40 | origin s04 |
| 페노의 모형 | 5.0 | 0.30 | origin s06~s07 |
| 수직 꼬리날개(평면도)·풍향계 | 6.2 | 0.35 | yaw (세로와 '같은 일'이라 같은 값) |
| 종이비행기 | 7.0 | 0.35 | tailless s22 |

### 3.5 힘(화살표 길이·저울이 읽는 값, 단위 없음)

- 날개의 늘어난 양력: `dLw(θ) = sin(2θ)/2 ÷ (sin(2·TH0)/2)` → θ = TH0 에서 1. (45°에서 가장 크고 그 뒤 줄어든다 = 실속, 설명 모형)
- 꼬리날개의 늘어난 힘(있는 모형, 작은 각에서만 씀): `dLt(θ) = 0.2 · θ/TH0` → θ = TH0 에서 1/5. θ < 0 이면 음수(아래로) — 화살표가 뒤집힌다.
- 팔 길이(모형 단위 u, 4.1절의 그림과 같은 자): 날개 `XW = 7 u`(축보다 **앞**), 꼬리날개 `LT = 140 u`(축보다 **뒤**) → 거리 비 20.
- 돌리는 효과(= 힘 × 거리, 날개의 것을 1 로): 날개 `+1 · dLw`(기수를 듦), 꼬리 `−4 · dLt/0.2`(기수를 내림). 화면에는 **1 과 4** 로 쓴다.

### 3.6 실험(run)과 모형 시계

한 번의 돌풍 실험 = run: `{id, kickEvent, models: ['tailed'|'tailless'|…], rate 구간}`.
- `rate` = 모형 시간이 벽시계의 몇 배로 흐르나(1 = 그대로, 1/8 = 8배 느리게, 0 = 멈춤, 음수 = 되감기). 구간별 상수.
- `tau(run, t)` = 돌풍 사건 시각부터 `∫ rate dt`. 이 값으로 3.1~3.3 을 읽는다.
- **바람(연기 줄)의 위상도 같은 rate 로 흐른다**: `flowPhase(t) = ∫₀ᵗ rate_now dt`(전체 영상에 하나, run 이 없을 때는 1). 느리게 볼 때 연기도 느려지고, 멈춤에서는 연기도 선다, 되감기에서는 거꾸로 간다.
- run 사이에는 모형을 0° 로 되돌린다(0.5초 `smooth`, 잔상은 0.3초에 사라짐). 되돌리는 동안은 run 이 아니다.

rate 구간은 `timeline.json` 의 문장·낱말 시각으로 정한다(`ctx.tl.at`, `ctx.tl.wordStart`). 구간 표는 5절 각 장면에 있다. `plan(tl)` 한 함수에서 전체 구간·사건 시각을 한 번 계산해 캐시한다(본보기: `samples/look-proposal-radar/scenes.mjs` 의 `plan`).

## 4. 공통 부품 — `kit.mjs`

### 4.1 옆모습 모형 `drawSide(stage, {x, y, s, theta, tail, tailAlpha, ghost, hl})`

모형 좌표(u): 원점 = 축(⊕), +x = 꼬리 쪽(오른쪽), +y = 아래. 화면 px = u × s. `(x, y)` = 축의 화면 위치. 회전은 축 중심 `rotate(theta)`.
radar 샘플의 `bodyPath`(길이 290, x −145~145)에 **x + 27** 을 해서 쓴다(기수 −118, 꼬리 끝 +172). 수직 꼬리날개를 몸통 경로에서 떼어 따로 그린다.

- 동체(몸통만): 샘플 경로에서 `lineTo(84,-17) lineTo(118,-62) lineTo(140,-62) lineTo(132,-9)` 를 `lineTo(84,-17) lineTo(132,-9)` 로 바꾼 것(+27). 채움은 위→아래 무광 그러데이션 `bodyHi → bodyMid(0.55) → bodyLo`, 윗선에 흰 0.55 가는 선, 창문 점·조종석 창(샘플 그대로).
- 주날개 단면(뿌리의 에어포일): 앞전 x = −24, 뒷전 x = +46(시위 70 u), 중심선 y = +9, 두께 9 u, 위가 볼록한 물방울 꼴. 색 `wing`, 아래쪽 어둡게. 그 아래 엔진 덮개 타원(중심 (−2, 25), 반지름 24×8, `darker`).
- 양력이 걸리는 자리 표식: (−7, +9). 축(0, 0)보다 7 u **앞**. 평소에는 그리지 않고 장면이 켠다(`hl.ac`).
- 수평 꼬리날개(옆에서 본 얇은 판): 앞전 x = 129, 뒷전 x = 173(시위 44 u), y = −5, 두께 5 u 의 얇은 렌즈 꼴. **난색 무광**(`warmHi → warmLo`).
- 수직 꼬리날개: 다각형 (111,−17) (145,−62) (167,−62) (159,−9) (샘플 값 + 27). **난색 무광**.
- `tail`: `'on'`(그림) | `'ghost'`(자리에 점선 윤곽만: `rgba(ink,0.45)`, dash [6,6], 채움 없음) | `'off'`. `tailAlpha` 로 떼고 붙이는 중간을 그린다(4.6절).
- `ghost: a` → 몸 전체를 단색 `rgba(bodyMid, a)` 실루엣으로(잔상용, 꼬리 상태는 `tail` 을 따름).
- ⊕(무게중심 = 축) `cgMark(c, x, y, r)`: 반지름 5 u(최소 14 px)의 원을 넷으로 나눠 맞은편 둘을 `ink`, 나머지를 `deep` 로 칠하고 테두리 `ink` 2 px. 모형과 함께 돈다. 모형 위에 늘 그린다.
- 접촉 그림자·광택 없음. 윤곽선만으로 그리지 않는다(면과 명암).

검산: s = 2.9 일 때 길이 약 841 px(기수 −342, 꼬리 끝 +499), 동체 높이 약 99 px, 날개 시위 203 px, 수평 꼬리날개 128×15 px, 날개 팔 20 px, 꼬리 팔 406 px.

### 4.2 평면도 모형 `drawTop(stage, {x, y, s, theta, tail, flying})`

같은 원점·같은 x 축. +y = 화면 아래(오른쪽 날개).
- 동체: x −118~172 의 길쭉한 캡슐, 반폭 17 u(기수는 둥글게, 꼬리는 가늘게).
- 주날개(뒤젖힘): 뿌리 앞전 −24·뒷전 +46, 끝(y = ±150) 앞전 +40·뒷전 +62. 좌우 대칭. 색 `wing`(뿌리 밝고 끝 조금 어둡게).
- 수평 꼬리날개: 뿌리 앞전 129·뒷전 173, 끝(y = ±55) 앞전 158·뒷전 178. 난색 무광.
  - 넓이 검산: 주날개 2 × 150 × (70 + 22)/2 = 13,800 u², 수평 꼬리날개 2 × 55 × (44 + 20)/2 = 3,520 u² → **0.255 ≈ 4분의 1**(첫 문장의 수와 같은 자).
- 수직 꼬리날개(위에서 본 얇은 판): 중심선 위 x 118~170, 두께 5 u 의 얇은 렌즈 꼴. 난색 무광(yaw 장면의 주인공). 동체 위에 그린다.
- 엔진: 날개 밑 작은 캡슐 둘(선택).
- `flying`(0~1): 전익기 윤곽으로 넘어가는 정도(5.7절).

### 4.3 연기 줄 `smokeField(stage, phase, {y0, y1, alpha, dir, wake})`

풍동의 연기 줄. **무광**(lit 아님). 모형 **뒤**에 그린다.
- 줄 간격 44 px, 줄 굵기 11 px(끝이 둥근 선), 색 `rgba(PAL.smoke, 0.72·alpha)`. 각 줄은 길이 120~260 px 의 토막과 100~240 px 의 틈이 번갈아 나온다(줄마다 `rand` 로 다른 무늬, 무늬의 주기는 2,200 px). 토막의 양 끝 40 px 은 투명해지며 사라진다(부드러운 끝).
- 위치 = 무늬 + `FLOW_V · phase`(오른쪽으로), `FLOW_V = 520 px/s`. `phase` = 3.6절의 `flowPhase(t)`.
- 왼쪽 가장자리(x 0~8)에 줄마다 작은 노즐 점(`muted`, 반지름 4) — 풍동의 연기 갈퀴.
- `dir`(rad): 바람 방향을 통째로 돌린다(yaw s19 에서만. 화면 가운데를 중심으로 회전).
- `wake: [{x, y, halfH, amp}]`: 가로막힌 뒤쪽(오른쪽)의 줄이 굽이친다. 꼬리날개 없는 모형이 크게 들렸을 때만: 축의 오른쪽에서, 모형의 세로 그림자 범위(±halfH) 안의 줄에 `amp = 16 px × |sin θ|` 의 사인 굽이(파장 180 px, 위상은 phase 를 따라 흐름)를 더한다. 0° 에서는 0.
- 기본 범위는 화면 전체(y 0~1920). 장면이 계기 자리를 비워야 하면 `y1` 로 자르고 그 아래는 4.9절의 계기 바닥을 깐다.
- 첫 순간 점검(7절)은 이 줄의 움직임과 넘어가는 모형·잔상으로 넘긴다. 줄의 굵기·밝기를 줄이면 점검값이 떨어지니, 고친 뒤 다시 잰다.

### 4.4 카드 뒤집기 `flipView(q, drawA, drawB)`

보는 방향을 바꾸는 0.8초 전환. 축의 y 를 중심으로 세로 배율을 `1 → 0.05`(앞 그림) 다음 `0.05 → 1`(뒤 그림)로. 가로는 그대로. 동체가 한 줄로 납작해졌다가 다른 면이 펼쳐진다. 연기 줄은 그대로 흐른다. 전환 중 키커에 '옆에서 본 모습' / '위에서 본 모습'을 바꿔 적는다.

### 4.5 돌풍 `gustPuff(stage, x, y, age)`

한색. **lit**(`gain 0.5`). 기수 밑 130 px 에서 기수까지 0.25초에 올라오는 짧은 줄 5개(길이 46 px, 굵기 7 px, 위로 70° 기울어짐, 간격 22 px)와 끝의 작은 화살촉 하나. 0.25~0.5초에 사라진다. 평면도에서는 기수 옆(화면 위나 아래)에서 온다. 두 모형이 함께 있는 장면에서는 **같은 프레임**에 둘 다.

### 4.6 꼬리날개 떼기·붙이기

- 떼기(`detach` 사건): 꼬리날개 조각(수직 + 수평, 난색)이 제자리에서 0.12초 뒤 풀려 바람에 실려 간다 — 오른쪽으로 `FLOW_V` 의 0.9배, 조금 위로 뜨며 천천히 돈다(초당 약 40°). 약 0.7초에 화면 밖. 떼어 낸 자리에는 점선 윤곽이 남는다.
- 붙이기(`attach` 사건): 오른쪽 밖에서 0.5초에 날아와 제자리에 붙고, 붙는 프레임에 윤곽이 0.2초 밝아진다(난색, lit 아님).
- 0초 프레임에서는 위 모형의 꼬리날개 조각이 **이미 떨어져 오른쪽 위 70×40 px 에 떠 있다**(곧 날아감).

### 4.7 각도기와 큰 숫자 `protractor(stage, x, y, R, theta, {max})`

세계 안의 눈금. 축을 중심으로 기수 쪽(왼쪽 위)의 호. 눈금은 0°·30°·60°·90°(필요하면 180°까지), 호는 `rgba(muted,0.5)` 2 px, 눈금 글자 24 px. 동체 축을 기수 너머로 이은 가는 바늘(`ink` 2 px)이 호 위를 가리킨다. 0° 기준선(바람 방향)은 점선.
큰 숫자: 호 옆에 `기수 +12°`(GmarketSans 700, 64~76 px). 꼬리날개 있는 모형은 난색, 없는 모형은 `ink`. 숫자는 그 프레임의 θ(정수 도).

### 4.8 힘 화살표 `forceArrow(stage, x, y, len, col)`

**lit**(`gain 0.6`). 굵기 9 px, 화살촉 22 px, 색 `warm`(꼬리날개의 힘) 또는 `cool`(날개의 늘어난 양력). 길이 = 힘 × 100 px(날개 1 → 100 px, 꼬리 1/5 → 20 px. 꼬리 화살표는 짧아도 그대로 둔다 — 작다는 것이 내용이다. 렌즈 안에서는 배율만큼 커 보인다). 모형과 함께 돌지 않고 **늘 화면 위/아래**(바람에 수직)로 그린다. 음수면 아래로.
화살표는 '틀어져서 달라진 힘'만 그린다(균형 상태의 양력·무게는 그리지 않음 — brief 단순화 메모).

### 4.9 계기 바닥과 저울 `leverGauge(stage, {x, y, s, theta, wing, tail, show})`

계기 자리(대략 y 760~1240)에는 `rgba(deep, 0.86)` 의 바닥을 깔고 위쪽 경계에 `border` 2 px 선. 연기 줄은 이 바닥 뒤로 지나간다.
저울 = 비행기와 **같은 가로 자**의 지렛대: 받침 삼각형이 축의 x 바로 아래, 막대는 축−60 px ~ 축+LT·s+30 px, 굵기 8 px `muted`. 막대는 모형과 같은 θ 로 기운다(받침 중심).
- 날개 자리(축 − XW·s)와 꼬리날개 자리(축 + LT·s)에서 모형의 해당 지점까지 **점선 세로 이음**(`rgba(muted,0.5)`, dash [3,7]).
- 그 자리에 4.8의 화살표(같은 값, 같은 프레임). 꼬리날개가 없는 모형이면 꼬리 자리에 **빈 점선 화살표**와 '없음'.
- 팔 길이 꺾쇠: 받침~날개 자리 '거리 1', 받침~꼬리 자리 '거리 20'(26 px).
- 돌리는 효과 막대 둘(막대 아래 60 px): `기수를 드는 효과`(cool) 와 `기수를 내리는 효과`(warm). 길이 = |효과| × 90 px(1 → 90 px, 4 → 360 px), 오른쪽 끝에 숫자(44 px). 값은 3.5절에서 그 프레임에 읽는다.
- `show` 로 단계별로 켠다(막대 → 화살표 → 꺾쇠 → 효과 막대).

### 4.10 렌즈 `lens(stage, {cx, cy, r, mag, wx, wy}, drawWorld)`

확대. 세계의 점 (wx, wy)를 중심으로 `mag` 배. 원 테두리 `muted` 4 px, 그림자 원, 세계의 그 점까지 지시선과 작은 원(전체 ↔ 확대 연결). 안에서는 `drawWorld(c)`(같은 모형·같은 연기 줄·같은 화살표)를 변환만 바꿔 다시 그린다. `lit()` 은 렌즈 안에서 **다시 자른다**(HDR 문서: 빛 지도는 바깥의 자르기를 따라가지 않는다).

### 4.11 기록선 `traceGauge(stage, {x, y, w, h, t0, span, yMin, yMax}, series)`

기수 각도–시간 그래프. 축은 `muted` 2 px, 0° 선 점선, 세로 눈금 글자 24 px(`−10°  0°  +10°  +30°`), 가로는 **모형 시간**(눈금 0.5초마다 짧은 금). `series = [{fn: τ → θ, col, dash, upTo}]` — 지금 τ 까지만 그리고 끝에 점(lit `gain 0.5`, 반지름 6). 범위를 넘으면 위쪽 테두리에서 잘리고 그 자리에 작은 ▲ 와 지금 값(`+140°`).
잔상: 앞 장면의 결과를 `dash [8,7]`, 알파 0.5 로 남긴다(조건 하나를 바꿔 비교).

배치: 모형 축 (410, 520), s = 3.0, `tail: 'ghost'`. 연기 줄은 y 260~760(풍동 창), 그 아래는 계기 바닥. 저울 y ≈ 830(막대)·효과 막대 y ≈ 930, 기록선 (80, 1010, 430×200), 렌즈 중심 (800, 1100) r 125. 각도기 R = 380. 키커 `8배 느리게 · 꼬리날개 없는 모형`.

| 구간 | 일어나는 일(사슬) | rate |
|---|---|---|
| s11 시작~'기수가' | 수평. 연기 줄이 실시간으로 흐르다가 돌풍 직전에 8배 느려진다(키커가 그때 뜸). | 1 → 1/8 |
| '기수가'(`kick_w`)~s11 끝 | 돌풍 → 기수가 10° 로(벽시계 약 1.4초). 날개 앞전에서 바람 방향의 점선(수평)과 날개 시위선 사이에 **각도 호**가 벌어지고 `받는 각 10°`. 그 프레임에 날개의 '양력이 걸리는 자리'에서 한색 화살표가 자란다. 큰 숫자 `기수 +10°`. 제목 `기수가 들리면 양력이 커진다`. | 1/8 |
| s12 (멈춤) | **멈춤**(연기도 섬, 키커 `멈춤`). 렌즈가 축 둘레를 2.5배로: 화살표의 뿌리 점(양력이 걸리는 자리, 한색)과 ⊕ 가 떨어져 있다 → 둘 사이 가로 치수선 `조금 앞`. 이어서 두 점에서 저울로 점선이 내려가고, 저울에 한색 화살표·꺾쇠 `거리 1`, 꼬리 자리에는 빈 점선 화살표 `없음`. 효과 막대: 드는 효과 `1`, 내리는 효과 `0`. 제목 `그 자리가 무게중심보다 앞`. | 0 |
| s13 | 다시 8배 느리게. θ 가 커질수록 화살표·드는 효과 막대·큰 숫자가 **같은 프레임에** 커진다(기록선이 위로 휘어 올라감). 90° 를 넘으면 렌즈가 사라지고 카메라가 축을 중심으로 s 3.0 → 2.1 로 물러난다(넘어가는 전체를 보임). 기록선은 위 테두리에서 잘리고 ▲ `+140°`. 제목 `들릴수록 더 들린다`. | 1/8 |

### 5.5 tail (s14~s17) — 옆모습, 꼬리날개 있는 모형 하나, **8배 느리게**

배치는 5.4 와 같다(같은 자, 같은 계기 자리). 장면 시작 0.6초에 꼬리날개가 날아와 붙는다(`attach1`). 기록선에는 5.4 의 결과가 점선 잔상으로 남아 있다. 키커 `8배 느리게 · 꼬리날개 있는 모형`.

| 구간 | 일어나는 일(사슬) | rate |
|---|---|---|
| s14 | '기수가'(`kick_t`)에 돌풍 → 10°. 날개의 각도 호와 **꼬리날개의 각도 호가 함께** 벌어진다. 수평 꼬리날개에 추적 원. 렌즈가 꼬리날개를 2.5배로: 얇은 난색 판이 연기 줄을 비스듬히 맞고, 위로 난색 화살표(lit). 10° 에 닿으면 멈춤. 제목 `꼬리날개도 바람을 더 가파르게` | 1/8 → 0 |
| s15 (멈춤) | 저울: 날개 자리의 한색 화살표(길이 100)와 꼬리 자리의 난색 화살표(길이 20) → `힘 1` / `힘 1/5`. 이어서 꺾쇠 `거리 1` / `거리 20`. 제목 `힘은 작지만 거리는 길다`. | 0 |
| s16 | 효과 막대가 차오른다: 드는 효과 `1`, 내리는 효과 `4`(난색 막대가 넷 배). 막대가 다 찬 프레임에 멈춤이 풀리고(`release_t`) 기수가 내려온다(8배 느리게, 0° 까지 벽시계 약 2.2초). 큰 숫자 `+10° → 0°`. 제목 `내리는 효과가 4배`. | 0 → 1/8 |
| s17 | 0° 를 지나 −3° 쯤(넘침) → 꼬리날개 화살표가 **아래로 뒤집힌다**(같은 프레임) → 다시 올라와 0 으로. 기록선이 잦아드는 물결을 그리고, 점선 잔상(없는 모형)은 위로 달아나 있다. 제목 `흔들리다 제자리에`. | 1/8 |

### 5.6 yaw (s18~s19) — 평면도

장면 시작 0.8초에 카드 뒤집기(옆 → 평면). 모형 축 (400, 600), s = 2.2(날개 끝이 y 270~930). 연기 줄은 y 260~1000, 아래 계기 바닥. 3분의 1 속도로 느리게(`rate 1/3`), 키커 `위에서 본 모습 · 3배 느리게`.

| 문장 | 화면(사슬) |
|---|---|
| s18 | '기수가'(`kick_y`)에 옆 돌풍(기수의 화면 아래쪽에서 위로) → 기수가 화면 위로 10°. 수직 꼬리날개(얇은 난색 판)가 연기 줄을 비스듬히 맞는다 → 꼬리 쪽에 난색 화살표(lit, 꼬리를 화면 위… 가 아니라 **바람에 밀리는 쪽** = 기수를 되돌리는 방향으로) → 흔들리다 0. 각도기와 큰 숫자 `기수 +10° → 0°`. 제목 `수직 꼬리날개도 같은 일`. |
| s19 | 계기 자리(y 1040~1220, x 540 가운데)에 **풍향계**(위에서 본 모습: 가는 화살 + 뒤쪽 넓은 난색 깃, 받침 원)가 뜬다. 낱말 '바람이'(`turn`)에 **바람 방향이 12° 바뀐다**(연기 줄 전체가 1초에 걸쳐 기움, `dir`). 비행기와 풍향계가 **같은 θ(τ)** 로 새 바람 쪽을 향해 돌아 멈춘다. 제목 `풍향계와 같은 원리`. |

화살표 방향 검산: 기수가 화면 위로 틀어지면 꼬리는 화면 아래로 가 있다. 바람(→)이 수직 꼬리날개의 아래 면… 이 아니라 **위에서 본 판의 바람맞이 면**을 민다 → 꼬리가 화면 위쪽으로 밀려 올라가고 기수는 내려온다. 화살표는 꼬리에서 화면 **위**를 가리킨다. (옆모습에서 기수가 들리면 꼬리날개 화살표가 위를 가리키는 것과 같은 그림이다.)

### 5.7 tailless (s20~s22)

| 문장 | 화면(사슬) |
|---|---|
| s21 앞 1.6초 | (s20 은 검수에서 s21 에 합쳐졌다.) 평면도 그대로(바람 방향은 0 으로 돌아와 있음). 장면 시작에 꼬리날개(수평·수직)가 점선으로 바뀌고(`detach2`: 조각이 바람에 실려 감), '꼬리날개 없이 나는'이 말해지는 동안 윤곽이 **전익기**로 넘어간다(`flying 0 → 1`, 1.0초): 동체가 날개 속으로 줄고, 뒤젖힌 넓은 날개 하나에 뒷전이 톱니 꼴. 색은 어두운 무광 회색. 제목 `꼬리날개 없이 나는 방법`. |
| s21 나머지 | 전익기(축 (430, 600), 날개 폭 약 700 px). 가운데에 작은 네모 `컴퓨터`(무광, 이름표 하나). 돌풍(`kick_b`)에 기수가 3° 틀어짐 → 컴퓨터에서 한쪽 날개 끝으로 **신호 점**(난색, lit `gain 0.6`, 0.15초에 도착) → 그 끝의 조종면이 위아래로 벌어진다(난색 쐐기, `flap1…flap6`) → 그 끝에 뒤로 향한 짧은 난색 화살표(공기 저항) → 기수가 돌아오다 조금 지나침 → 반대쪽 끝으로 신호 → … 약 0.45초마다 번갈아 6번. 기록선은 0 둘레의 작은 톱니(±1.5° 안). 큰 숫자 `기수 0°` 가 ±1~3 으로 떨린다. 이름표 `날개 끝의 판`(한 번). 키커 `B-2 · 위에서 본 모습`, 제목 `컴퓨터가 쉬지 않고 고친다`. |
| s22 | 카드 뒤집기(평면 → 옆). **종이비행기** 옆모습(길이 약 700 px, 기수 왼쪽): 위는 얇은 날개 판(가는 긴 삼각형의 윗변), 아래로 접힌 용골(가는 삼각형), 색 `paper`·`paperLo`. 사슬: ① 앞쪽에 접힌 겹이 세 번 포개지며 두꺼워진다(`fold1..3`, 겹 줄무늬) → 그 프레임마다 ⊕ 가 앞으로 옮겨 가 '양력이 걸리는 자리'(작은 점)보다 **앞**에 선다 ② 날개 뒤끝이 위로 15° 꺾인다(난색, `bend`) → 뒤끝에 아래로 짧은 난색 화살표 ③ 돌풍(`kick_pp`) → 10° 들렸다가 돌아온다(3.4절 값, 3배 느리게). 키커 `옆에서 본 모습 · 3배 느리게`, 제목 `종이비행기: 무게는 앞, 뒤끝은 위로`. |

## 6. 소리 — `sound.json`

모두 합성한 설명용 소리. **기본음은 700 Hz 아래**(사용자 규칙). 음악 없음(`music.enabled false`, `ambient.enabled false`).
같은 id 를 되풀이하지 않는다(번호를 붙인다 — `sfx.py --events-check` 가 id 로 대조).

| id | 시각 | 소리 | 뜻 |
|---|---|---|---|
| `wind0` … | 장면마다 하나(장면 시작) | `env_noise` low 120 high 600, 진폭은 그 장면의 rate 표를 따름(실시간 0.5, 8배 느리게 0.18, 멈춤 0.04), gain −30 dB | 바람이 분다 — 느리게 볼 때 소리도 가라앉고 멈춤에서는 거의 사라짐 |
| `kick0`,`kick1`,`kick_*` | 5절의 돌풍 시각 | `whoosh` f 180→560, 0.3초, −17 dB | 돌풍 |
| `tone_*` (run 마다) | 돌풍과 같은 시각 | `chirp`: 음높이 = 220 Hz × 2^(θ/60°) (θ 는 그 run 의 주인공 모형, 표는 벽시계 0.05초 간격, 최고 660 Hz 에서 자름), −24 dB | 돌아오는 모형은 음이 제자리로, 넘어가는 모형은 음이 올라가 버린다 |
| `rewind` | 2.20 | `whoosh` f 520→160, 0.7초 | 되감기 |
| `detach0`,`detach1`,`detach2` | 0.05초(0초 프레임의 조각이 풀려 날아감), s01 '떼면', 5.7절 | `tick` 300 Hz + 짧은 `noise` | 떼어 냄 |
| `attach0`,`attach1` | 3.0초(되감기 끝), 5.5 | `tick` 420 Hz, decay 0.12 | 붙임 |
| `pivot1`,`pivot2` | s02 | `tick` 520 Hz | 축 |
| `slide`,`balance` | s09 | `tone` 180→330 glide 2.6초 / `tone` 330 Hz 0.4초 | 추가 멀어진다 / 수평 |
| `fold1..3`,`bend` | s22 | `tick` 260·300·340 Hz / `tick` 440 | 접기 |
| `flap1..6` | s21 | `tick` 600 Hz, decay 0.04, −22 dB | 조종면 |
| `turn` | s19 | `whoosh` f 200→420, 1.0초 | 바람 방향이 바뀜 |
| `flip1..n` | 카드 뒤집기 | `whoosh` f 300→600→300, 0.5초, −24 dB | 보는 방향 바꿈 |
| `end` | s24 + 0.2 | `swell` [220, 330, 440], 2.2초, −24 dB | 맺음 |

0.3초 안에 소리가 나야 한다: `wind0` 는 0.0초에 시작하고 `kick0` 는 0.25초, 첫 문장은 0.2초에 시작한다.
`tone_*` 과 `wind*` 의 표는 `tools/export_sound.mjs` 로 `model.mjs` 에서 뽑아 `sound.json` 에 써 넣는다(대본·시각이 바뀌면 다시 뽑는다).

## 7. 점검 — 작업자가 스스로 돌려 볼 것

```bash
SKIP_NARRATE=1 episodes/tail-stability/run.sh stills        # outputs/tail-stability/stills/contact-sheet.jpg, contact-sheet-hdr.jpg
SCISHORT_ROOT=$PWD node episodes/tail-stability/render.mjs --stills --safe   # 안전 영역 겹쳐 보기
```

- 정지화면을 **직접 열어 본다**: 한글 깨짐, 겹침, 24 px 미만 글자, 자막(1260~1400)과 그림의 겹침, 빈 화면.
- 0초 프레임: 물음 + 가장 큰 '꼬리날개'. 0.0 · 0.5 · 1.0 · 1.5 · 2.0초가 서로 다른가.
- 첫 순간 수치(1초 ≥ 10%, 2초 ≥ 20%): 첫 4초만 임시로 인코딩해 `python3 -m pipeline.first_moment <mp4>` 로 잰다(소리 줄기가 없으면 첫 소리 항목만 실패한다 — 화면 값만 본다). 못 미치면 **장식을 더하지 말고** 모형 크기·잔상·연기 줄의 대비를 고친다.
- 빛 지도(`contact-sheet-hdr.jpg`): 밝은 것은 돌풍, 힘 화살표, 신호 점, 기록선의 끝점뿐. 글자·계기 숫자·연기 줄·모형은 어둡다.
- 문법: 움직이는 것마다 사슬의 어느 고리인지 말할 수 있는가. 2초 넘게 아무 고리도 움직이지 않는 구간이 있는가(멈춤 구간에서는 렌즈·저울이 움직여야 한다). 세계의 사건과 계기의 반응이 같은 프레임인가.
- 같은 사건을 되풀이하지 않는다: 넘어가는 장면은 hook(결과) → wing(느리게, 까닭) → close(되돌리는 힘이 없음) 세 번이며, 매번 보여 주는 것이 다르다.

## 8. 하지 않는 것

- 장식 입자, 뜻 없는 카메라 이동, 화면 흔들림, 화면 전체 빛 번짐·흰 번쩍, 광택, 그림 같은 하늘·구름·땅 풍경.
- 캐릭터·눈 달린 물체·의성어 글자·이모지.
- 자막·계기 숫자·이름표·연기 줄·모형을 `lit()` 에 넣기. `lit()` 안에서 `Math.random()`·횟수 세기·바깥 값 바꾸기.

### 9.1 파일과 맡은 장면

| 모듈 | 장면 | 소리 조각 |
|---|---|---|

`scenes.mjs`(모음, 제작 세션이 씀 — 고치지 않는다)가 세 모듈을 읽어 `render.mjs` 의 계약으로 내보낸다. 읽지 못한 모듈의 장면은 빈 화면으로 대신하므로, 다른 모듈이 아직 없어도 제 장면을 렌더할 수 있다.

모듈이 내보내는 것:

```js
export const scenes = {hook(stage, t, p, ctx) {…}, …};   // ctx.clock = {segs, phase(t), rate(t)} 가 더해져 들어온다
export function rateSegs(tl, ev) { return [{t0, t1, rate}, …]; }   // 제 장면 안에서 rate ≠ 1 인 벽시계 구간(느리게·멈춤·되감기). 겹치지 않게
export function titles(id, ctx) { return [[적용 시각, '키커', '제목'], …]; }   // 머리글. hook 은 키커만 쓰인다(제목 자리는 물음)
export const captionLayout = {};                                    // 선택(자막을 올릴 장면만). 1380 아래로 내리지 않는다
```

- **연기 줄은 반드시 `ctx.clock.phase(t)` 로 그린다**(영상 전체에 하나인 위상 — 장면이 바뀌어도 줄이 튀지 않는다). 제 장면의 run 은 `rateSegs` 에 낸 것과 같은 구간으로 `M.tau`·`M.runTheta` 를 쓴다(run 의 구간과 바람의 구간은 따로 둘 수 있다 — 1단계 보고: 되감기 뒤 run 에는 `{t0: 3.0, t1: Infinity, rate: 0}` 을 더해 돌풍이 다시 일어나지 않게).
- 포스터·머리글·띠·진행 막대·자막은 `scenes.mjs` 와 `render.mjs` 가 그린다. 장면은 그리지 않는다(결론 글과 끝 한 줄은 close 장면이 그린다).
- 소리: 제 조각 `sound_x.json` 에 `{"events": [...]}` 로 쓰고 `node episodes/tail-stability/tools/merge_sound.mjs` 로 `sound.json` 을 만든다(직접 고치지 않는다). id 는 영상 전체에서 하나뿐이어야 한다 — 모듈 글자를 붙인다(`b_kick1`, `c_flap3` …). 이 문서 5·6절의 id(`kick0`, `kick1`, `kick_w`, `kick_t` …)는 예시이며 같은 규칙으로 바꿔 쓴다. 장면은 `ctx.events` 에서 제 사건의 시각을 읽는다(같은 시계).

### 9.2 장면이 바뀌는 자리의 약속(넘겨주는 자세)

장면 전용 소품(시소, 끼움 그림, 저울, 렌즈, 기록선, 화살, 풍향계 …)은 **제 장면의 마지막 0.4초에 스스로 사라진다.** 다음 장면은 아래 자세에서 시작한다.

| 경계 | 앞 장면이 끝날 때 | 뒤 장면이 시작할 때 |
|---|---|---|
| hook → origin | 모형 둘, 수평. 위 `{x:400, y:470, s:2.9, tail:'ghost'}`, 아래 `{x:400, y:1110, s:2.9, tail:'on'}`. 연기 줄은 화면 전체. 각도기·숫자는 사라져 있음 | origin 이 처음 0.5초에 이 두 모형을 `drawSide` 로 그리며 지우고(알파 1 → 0) 화살을 띄운다(0 → 1) |
| origin → essence | (같은 모듈) | |
| essence → wing | 모형 하나, 수평, 꼬리날개 있음, **WT 자세** `{x:410, y:520, s:3.0}`. 연기 줄 y 260~760, 그 아래 계기 바닥(760~1240) | wing 이 같은 자세에서 시작해 처음 0.6초에 꼬리날개를 뗀다(`a_detachW`) |
| wing → tail | (같은 모듈) | |
| tail → yaw | 모형 하나, 수평, 꼬리날개 있음, WT 자세. 저울·렌즈·기록선은 사라져 있음. 계기 바닥은 남아 있음 | yaw 가 이 옆모습을 `flipView` 의 앞 그림으로 그려 평면도로 뒤집는다 |
| tailless → close | (같은 모듈) | |

essence 는 wing·tail 과 같은 틀을 쓴다: 모형은 WT 자세, 시소는 계기 바닥 위(받침이 축 x 410 바로 아래).
