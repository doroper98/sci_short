# 에피소드 `quasar` — 퀘이사 (별처럼 보인 블랙홀)

"별처럼 보이는 점 하나, 그 속에서는 거대한 블랙홀로 떨어지는 기체가 은하보다 밝게 빛난다." 174.3초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
**모형 하나가 화면·계기·소리를 함께 움직입니다.** 적색이동(λ × 1.158), 거리 사다리와 역제곱, 빛이 건너는 시간(얇은 껍질의 도착 시각 분포), 원반의 공전 ω ∝ r^−1.5·온도 T ∝ r^−3/4·중력 우물 Φ ∝ −1/r, 효율(10% 대 0.7%), 에딩턴 한계, 퀘이사 수 모형, 중력 적색이동 g, 그리고 한 개의 로그 배율로 원반·제트·은하·망원경 시야를 잇는 "줌 세계"가 모두 `scenes.mjs` 머리의 순수 함수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 10개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·시간 계획) + 가산 부동소수 빛 버퍼(원반·제트·은하) + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/quasar/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/quasar/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/quasar/run.sh stills            # outputs/quasar/stills/
SKIP_NARRATE=1 episodes/quasar/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 빛 버퍼(`Glow`), `starGlow` 계열의 원반 그리기, 머리글·포스터 제목, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`)는 에딩턴 한계 편에서 가져와 이 편에 맞게 고쳤습니다. 빛 버퍼는 오로라·에딩턴에 이어 세 번째 사용이므로 `pipeline/`으로 올릴 때가 되었습니다(이번에는 범위 밖이라 올리지 않음).

## 단순화·설명 모형 (화면에는 각주 없음; 표식은 "개념도", "모형 곡선", "비유 · 태양 1개만큼의 기체"뿐)

- **원반·제트·블랙홀 그림**: 원반의 온도·회전·도플러 비대칭은 경향만 따른 모식이고, 그림자 크기, 원반 안쪽 끝, 위로 휘어 보이는 먼 쪽 원반, 광자 고리는 화면용입니다. 원반 위 기체 덩어리의 크기·수·속도(바깥 7초에 한 바퀴)는 화면 시간입니다. 원반 무늬는 각속도 ∝ r^−1.5로 돌지만(안쪽 끝 3 rad/s, 덩어리보다 느림), 차등 회전으로 무늬가 계속 감겨 모래알처럼 되지 않도록 2.6초마다 새로 시작하는 두 겹을 엇갈려 섞습니다(첫 렌더에서 110초 무렵 무늬가 잡음처럼 변한 것을 보고 고침). 제트는 위(다가오는 쪽)를 1.6배 밝게 했고, 매듭은 로그 거리에서 바깥으로 흐르는 무늬입니다(실제 매듭 운동 아님).
- **줌 세계**: 크기 비율(원반 0.035광년, 제트 12만 광년, 은하 5만 광년)은 실제 크기 순서를 따르지만 은하는 나선 은하 그림입니다(3C 273의 숙주는 타원 은하에 가까움). 원반 주변의 따뜻한 빛(포스터의 은하 빛)과 망원경 시야의 별은 화면용이고, 줌 중 배경 별은 사라졌다가 시야에서 다시 나타납니다.
- **스펙트럼**: 수소 발머선 넷만 그린 모식도이며 선 굵기·연속 스펙트럼 밝기는 화면용. 1963년 슈미트의 실제 측정 선과 완전히 같지는 않습니다(Hα 760 nm는 눈으로 보이는 범위 끝).
- **우주 팽창 그림(개념도)**: 은하마다의 적색이동은 거리에 비례하는 장난감 법칙 z = 0.00075 × 화면 거리이며, 늘어나는 물결 묶음은 "늘어난 공간을 지나며 파장이 늘어난다"는 설명용 그림입니다. 우리 은하 광도는 3C 273 ÷ 100(4×10¹⁰ L☉)으로 두었습니다. "작은 망원경 범위"의 끝(약 13.5등급)은 숫자 없이 막대로만 표시합니다.
- **깜빡임 → 크기(개념도)**: 균일하게 빛나는 얇은 껍질이 한꺼번에 밝아진다는 가정입니다. 빛의 화면 속도는 1광년 = 140 px를 1.17초에 지나게 했고(큰 공·작은 공 같은 축척), 작은 공(반지름 2광일)은 실제 축척이라 점으로 보입니다. 작은 공의 날카로운 막대는 4일 ≈ 2.5 px지만 보이도록 6 px로 그렸고, 같은 에너지라 그래프 위로 뚫고 나갑니다. s10 밝기 곡선은 모형 번쩍임 넷(관측 자료 아님). 실제로는 빛에 가까운 속도로 다가오는 제트에서 이 한계가 느슨해질 수 있으나 다루지 않습니다.
- **엔진**: 그래프는 정규화한 모형 곡선이고 "도는 빠르기 × N", "온도 × N"은 추적 덩어리의 출발점 대비 비율입니다. 중력 우물(개념도)의 깊이는 Φ ∝ −1/r를 화면에 맞게 줄였고, "떨어진 높이만큼"은 위치 에너지를 열·빛으로 내놓는다는 설명이며 정확히는 그 일부(원반에서는 약 절반)가 빛으로 나갑니다. 효율 10%는 회전하지 않는 블랙홀(약 6%)과 빠르게 도는 블랙홀(더 큼) 사이의 대표값입니다.
- **에딩턴 그래프**: 3C 273의 밝기를 Γ = 0.4로 고정한 채 질량 손잡이를 돌렸습니다("더 밝게 빛날 수 있다"의 그림). 실제 퀘이사의 Γ는 제각각입니다.
- **J0529−4351**: 하루 태양 하나는 1년 370 M☉의 평균이며 날아드는 태양 아이콘은 "비유" 표식을 붙인 그림입니다. 1980 건판은 실제 사진이 아니라 같은 느낌의 모식 이미지입니다(별 위치 무작위).
- **우주의 시간**: 퀘이사 수 곡선은 설명용 모형(봉우리 z ≈ 2)이고 곡선 아래 점의 수는 밀도에 비례하는 그림입니다. 3C 273 표식은 빛이 출발한 때(약 20억 년 전, 광행 거리)에 두었고 숫자는 쓰지 않았습니다(대본의 "약 24억 광년"은 광도 거리라 다름).
- **오해**: 덩어리의 밝기는 국소 밝기 × g⁴로만 줄였고(도플러·빛 휨 무시), 화면의 덩어리 위치는 그림자 가장자리로 다가가 멈추도록 옮긴 "보이는 위치"입니다(사건의 지평선은 그림자보다 작음, 그리지 않음).
- **소리**: 모두 합성한 설명용 소리이며 실제 현상의 소리가 아닙니다. 음높이·크기 대응은 위 표와 같습니다.
