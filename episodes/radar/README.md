# 에피소드 `radar` — 레이더 (전파의 메아리로 보고, 메아리를 줄여 숨는다)

"레이더의 핵심은, 되돌아온 전파의 메아리에서 거리와 속도를 읽어 내는 것입니다." 164.3초, 1080×1920, 30 fps, 테마 `{base: 'noturno', accent: '#6CF2B4'}`, 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(`degraded: false`). 완성본 번호 32(`docs/TOPIC_BACKLOG.md`), 밤 자동 제작 첫 편(`config/daily.json` 첫 순서, 2026-11-08).

**화풍**: [ANIMATION_QUALITY](../../docs/ANIMATION_QUALITY.md) '2026-11-07 후속 결정: 시리즈 화풍은 지킨다'. 어두운 청록(noturno) 단색 바탕과 옅은 비네트, 떠도는 작은 점, 가는 선(1.5~3 px), 가산 합성의 작은 빛 점과 사건 섬광, 가는 호로 그린 파면, 그래프·축·이름표. 역할 색 둘: 보낸 전파 = 호박색 `#FFB85C`, 되돌아온 메아리 = 레이더 화면 초록 `#6CF2B4`(강조색, 답·큰 숫자). 레이더 접시·비행기·1930년대 복엽 폭격기·송신탑·밴·자동차·스피드건은 실제 기종·나라·표식이 없는 일반 선 아이콘(`glyphs.mjs`). 광택 3D·질감 구름·노을빛 없음. 장면 첫 0.8초는 작은 밀어 들어가기(1.07 → 1)로 잇는다. 밤 자동 제작이라 사용자 시안 확인은 하지 않았다.

## 단순화 (화면에는 각주 없음, 키커에만 두 번 선언)

- 화면의 파면 속도는 장면마다 정한 느린 속도. range 장면은 실제 1/1,000초를 4,000배 느리게(키커 선언).
- 도플러 차이는 크게 과장(키커 선언). 실제는 24 GHz·시속 100 km에서 약 4,400 Hz, 원래 진동수의 약 1천만분의 2.
- 데번트리 실험: 송신소·밴·폭격기 거리와 크기는 축척이 아님. 실제 실험은 연속 방송 전파와 수신기 화면의 변화로 보았다(화면도 연속 파면과 흔들리는 초록 선으로 그림).
- 둥근 레이더 화면의 점·잔광·비구름, 빔 모양, 비 감쇠 곡선, 평판 반사 무늬, '메아리 크기' 막대와 σ 원은 상대값 설명 그림.
- 지구 곡률 과장(키커 선언). 지평선 거리 숫자만 4/3 지구 반지름 공식.
- 실제 무기·레이더·스텔스기의 설계·성능 수치·전술은 없음.
