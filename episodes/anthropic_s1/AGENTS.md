# 이 에피소드의 범위

START_HERE.md → README.txt → CONTINUE_CODEX_KO.txt → DEPENDENCIES_AND_RIGHTS.txt 순서로 읽는다.
최신 사용자 요청은 Anthropic의 정확한 S-1을 설명하는 약10분 한국어 가로 영상이다. 루트의60~90초 과학영상 목표를 이 편에 적용하지 않는다.
원래 Supertonic3 M3 ×0.95, 현재 발음규약, 원MMS 기반 말끝보정을 유지한다. 무음 영상이나 원음캐시를 완성본으로 보고하지 않는다.
외부 osint_generator는 별도 권한 있는 의존성이다. 그 저장소의 다른 에이전트 승인절차나 지도엔진은 이 편의 의무가 아니다.
모델/폰트/BGM/음성/전체SEC원문/비밀정보를 커밋하지 않는다. 정확한 허용파일은 MANIFEST.json에 있다.
진행 후 이 폴더의 HANDOFF.txt에 실제 실행방법·검증·남은 작업을 갱신한다. 기존 저장소의 무관한 자료는 보존한다.
