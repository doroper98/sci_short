# 버섯구름은 왜 버섯 모양일까 (`mushroom-cloud`, 완성본 22)

사용자 주제(2026-11-07 기록): "핵폭탄이 터질때 버섯구름이 만들어지는 이유". 2026-11-07 지시("다이내믹함과 비주얼함을 높여야 해")에 따라 **실제로 계산한 유체 시뮬레이션**을 화면의 주인공으로 삼은 첫 편입니다.

## 구성

| 장면 | 화면 |
|---|---|
| hook | 0초 = 썸네일(해 질 녘 사막의 버섯구름 + "버섯구름은 왜 버섯 모양? / 떠오르는 뜨거운 공기") → 섬광 → 불덩이가 떠올라 버섯구름이 자람(카메라가 구름에 맞춰 물러남), 10 km 표시, "폭발 뒤 흐른 시간" 큰 숫자 |
| origin | 베수비오 화산의 화산재 기둥(같은 해법, 연속 분출원), 우산소나무 실루엣과 같은 윤곽 → 핵폭발 구름과 화산 구름을 나란히 |
| essence | 화면 가득한 뜨거운 공기 덩어리(빛나는 불덩이), 듬성한 뜨거운 공기 입자와 촘촘한 찬 공기 입자, 열기구 |
| ring | 가운데를 자른 단면(연기 + 같은 속도장으로 움직이는 빛 흐름선), 가운데·가장자리 속도 화살표(모형 값), 말려 내려가는 화살표 → 3D 소용돌이 고리(입자 5,200개, 카메라 회전) |
| stem | 밑에서 올려다본 구름, 땅의 흙먼지 입자가 원근 바닥면에서 줄기로 빨려 듦, 사방에서 몰려 드는 바람 화살표 |
| cap | 대류권의 끝(약 10 km) 빛 띠, 주변 기온과 구름 덩어리 온도선이 만나는 점, 옆으로 퍼지는 갓, 하얗게 변하는 갓(응결) |
| cases | 숲 위 산불의 불구름(같은 해법, 넓은 지면 열원) → 뒤에서 빛이 비치는 물탱크 속 잉크 방울의 거꾸로 선 버섯(단면) → 핵 구름과 잉크를 나란히 |
| myth | 느린 화면: 반구 모양 충격파가 사방으로 퍼짐(땅의 먼지가 쓸려 나감) → 그 뒤에 불덩이가 떠올라 버섯이 생김 |
| close | 0초와 같은 포스터 구도와 제목으로 돌아옴 |

## 모형 (`fluid.mjs`, `scenes.mjs` 머리)

- **축대칭 안정 유체 해법**(MAC 엇갈림 격자, 반지름 128 × 높이 256칸, 1칸 = 64 m): 반지름 방향 발산 (1/r)∂(r u)/∂r을 써서 떠오르는 열기포가 2D 소용돌이 쌍이 아니라 **진짜 소용돌이 고리**가 됩니다. 부력 B·(θ' − θ_amb(z)), θ_amb는 대류권에서 완만히, 대류권계면(150칸 ≈ 9.6 km) 위에서 가파르게 증가 → 구름이 그 높이에서 멈춰 옆으로 퍼짐(갓). 와도 보존(vorticity confinement), 작은 점성·확산, MacCormack 스칼라 이류, 적흑 SOR 압력 투영, 축 근처 상승류 감쇠(축 위 바늘 모양 제트 억제).
- 같은 해법으로 화산(분화구의 연속 분출원), 산불(중앙에 몰린 넓은 열원), 잉크(무거운 방울, 부력 대신 무게 W·s)를 계산합니다.
- 결정적(같은 시각 = 같은 그림), 25단계마다 체크포인트 → 정지화면처럼 시각이 뒤섞여도 빠르게 해당 단계로 이동.
- **그리기**: 축대칭 장을 시선 방향으로 적분(Projector) → 광학 두께, 오른쪽 낮은 해 쪽으로 빛을 따라가며 자기 그림자, 하늘 산란광(위에서), 열에 비례한 발광(시간이 지나며 식음) → 백열 색 경사, 빛 번짐. 잔 구름 결(값 잡음, 영역 비틀기)은 질감일 뿐 물리가 아님.
- 시간: 주 구름 1단계 ≈ 실제 1.5초. 꼭대기가 10 km를 지나는 165단계 ≈ 4분(대본 "몇 분 만에 10킬로미터 안팎"). 훅은 약 21배 빠르게(화면에 표시).
- 3D 소용돌이 고리 장면은 설명 그림(입자를 토러스 위에서 돌림), 충격파 반구도 해석적 그림(유체 모형 밖).

## 단순화

- 축대칭 2D 모형(실제 구름은 3D 난류). 격자보다 작은 소용돌이는 없음. 처음 불덩이는 화면에서 보이도록 실제(지름 수백 m)보다 큼.
- 대류권계면 약 10 km는 중위도 대표값. 주변 기온선(지면 30 °C, 6.5 °C/km)과 구름 덩어리 온도선은 설명용 곡선.
- 색은 설명용. 잉크는 얇은 물탱크처럼 단면으로 그림.
- 소리는 모두 설명용 합성음(`sound.json`은 `--emit-sound`로 생성).
