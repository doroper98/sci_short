# 버섯구름은 왜 버섯 모양일까 (`mushroom-cloud`, 완성본 22)

사용자 주제(2026-11-07 기록): "핵폭탄이 터질때 버섯구름이 만들어지는 이유". 2026-11-07 지시("다이내믹함과 비주얼함을 높여야 해")에 따라 **실제로 계산한 유체 시뮬레이션**을 화면의 주인공으로 삼은 첫 편입니다.

## 구성

| 장면 | 화면 |
|---|---|
| hook | 0초 = 썸네일(어두운 바탕의 대기 단면 위, 점과 등고선으로 그린 큰 버섯구름 + "버섯구름은 왜 버섯 모양? / 떠오르는 뜨거운 공기") → 섬광과 충격 고리 → 불덩이가 떠올라 버섯구름이 자람(카메라가 구름에 맞춰 물러남), 10 km 표시, "폭발 뒤 흐른 시간" 큰 숫자 |
| origin | 베수비오 화산의 화산재 기둥(같은 해법, 연속 분출원), 우산소나무 실루엣과 같은 윤곽 → 핵폭발 구름과 화산 구름을 나란히 |
| essence | 화면 가득한 뜨거운 공기 덩어리(빛나는 불덩이), 듬성한 뜨거운 공기 입자와 촘촘한 찬 공기 입자, 열기구 |
| ring | 가운데를 자른 단면(등고선 + 같은 속도장으로 움직이는 가는 흐름선), 가운데·가장자리 속도 화살표(모형 값), 말려 내려가는 화살표 → 3D 소용돌이 고리(입자 5,200개, 카메라 회전) |
| stem | 땅의 흙먼지 입자가 원근 바닥면에서 줄기로 빨려 듦, 사방에서 몰려 드는 바람 화살표 |
| cap | 대류권의 끝(약 10 km) 빛 띠, 주변 기온과 구름 덩어리 온도선이 만나는 점, 옆으로 퍼지는 갓, 하얗게 변하는 갓(응결) |
| cases | 숲 위 산불의 불구름(같은 해법, 넓은 지면 열원, 선으로 그린 나무) → 어두운 물 단면 속 잉크 방울의 거꾸로 선 버섯(단면, 카메라가 따라감) → 핵 구름과 잉크를 나란히 |
| myth | 느린 화면: 가는 반구 선의 충격파가 섬광과 함께 사방으로 퍼짐(땅의 먼지가 쓸려 나감) → 그 뒤에 불덩이가 떠올라 버섯이 생김 |
| close | 0초와 같은 포스터 구도와 제목으로 돌아옴 |

## 모형 (`fluid.mjs`, `scenes.mjs` 머리)

- **축대칭 안정 유체 해법**(MAC 엇갈림 격자; 주 구름은 반지름 192 × 높이 384칸, 1칸 ≈ 43 m, 화산·산불은 128 × 256칸, 1칸 = 64 m): 반지름 방향 발산 (1/r)∂(r u)/∂r을 써서 떠오르는 열기포가 2D 소용돌이 쌍이 아니라 **진짜 소용돌이 고리**가 됩니다. 부력 B·(θ' − θ_amb(z)), θ_amb는 대류권에서 완만히, 대류권계면(≈ 9.6 km; 주 격자 225칸, 작은 격자 150칸) 위에서 가파르게 증가 → 구름이 그 높이에서 멈춰 옆으로 퍼짐(갓). 와도 보존(vorticity confinement), 작은 점성·확산, MacCormack 스칼라 이류, 적흑 SOR 압력 투영, 축 근처 상승류 감쇠(축 위 바늘 모양 제트 억제).
- 같은 해법으로 화산(분화구의 연속 분출원), 산불(중앙에 몰린 넓은 열원), 잉크(무거운 방울, 부력 대신 무게 W·s)를 계산합니다.
- 결정적(같은 시각 = 같은 그림), 25단계마다 체크포인트 → 정지화면처럼 시각이 뒤섞여도 빠르게 해당 단계로 이동.
- **그리기(2026-11-07 리메이크, 시리즈 도식 화풍)**: 사용자 지적("너무 애니메이틱 한데… 느낌이 다르잖아")에 따라 입체 질감 구름·노을 하늘·빛 번짐 렌더를 모두 걷어 내고 시리즈(01~21번)의 도식 화풍으로 다시 그렸습니다. 해법·대본·음성·시간 계획은 그대로입니다.
  - 구름 = 모형의 추적 입자: 불덩이 물질 7,000개 + 땅의 흙먼지 3,000개가 계산된 속도장을 따라 움직이고, 축대칭 모형이라 입자마다 고정된 방위각 3곳에 작게 빛나는 점으로 찍습니다(가산 합성, 점 둘레의 작은 빛만).
  - 점의 색 = 그 자리 공기의 초과 온도(모형): 하얗게 뜨거움 → 주황 → 식은 회갈색, 응결한 갓은 옅은 흰색. 흙먼지는 모래색.
  - 윤곽 = 시선 방향 적분 밀도의 가는 등고선 2개(버섯 윤곽, 말린 고리). 고리 단면은 자른 면의 등고선과 같은 속도장의 가는 흐름선.
  - 하늘 = 대기 단면: 왼쪽 km 눈금, 땅의 가는 선과 원근 점 격자, 대류권계면 점선(약 10 km). 갓 장면은 같은 고도축 위에 기온–높이 그래프(주변 기온, 구름 덩어리).
  - 화산·산불은 같은 해법에 연속 방출 추적 입자(분화구, 숲 바닥)를 더해 재·불씨 점으로, 화산·우산소나무·나무는 가는 선 윤곽으로. 잉크는 어두운 물 단면 위 보라 점과 등고선, 카메라가 가라앉는 잉크를 따라감.
  - 사건: 섬광은 폭발 지점 둘레의 방사형 빛(짧게), 충격파는 가는 반구 선과 땅 위 타원. 화면 전체 빛 번짐은 쓰지 않음.
  - 구현: `diagram.mjs`(점 버퍼, 마칭 스퀘어 등고선), `scenes.mjs`.
- 시간: 주 구름 1단계 ≈ 실제 1.5초. 꼭대기가 10 km를 지나는 약 180단계 ≈ 4.5분(대본 "몇 분 만에 10킬로미터 안팎"). 훅은 약 22배 빠르게(화면에 표시). 포스터는 235단계.
- 3D 소용돌이 고리 장면은 설명 그림(입자를 토러스 위에서 돌림), 충격파 반구도 해석적 그림(유체 모형 밖).

## 단순화

- 축대칭 2D 모형(실제 구름은 3D 난류). 격자보다 작은 소용돌이는 없음. 처음 불덩이는 화면에서 보이도록 실제(지름 수백 m)보다 큼.
- 대류권계면 약 10 km는 중위도 대표값. 주변 기온선(지면 30 °C, 6.5 °C/km)과 구름 덩어리 온도선은 설명용 곡선.
- 색은 설명용. 점은 모형의 추적 입자이고 개수·크기는 그림을 위한 선택(실제 입자 크기 아님). 잉크는 얇은 물탱크처럼 단면으로 그림.
- 소리는 모두 설명용 합성음(`sound.json`은 `--emit-sound`로 생성).
