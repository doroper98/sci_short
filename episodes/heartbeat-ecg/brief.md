## 질문

심장은 한 번 뛰는데, 심전도에는 왜 물결이 세 번 그려질까요?
(답: 한 번의 박동 안에서 전기 상태가 세 번 크게 바뀐다 — 심방의 흥분(P), 심실의 흥분(QRS), 심실의 회복(T). 심전도는 심장 근육 세포의 전압이 뒤집히는 경계가 심장 위를 지나갈 때 피부에 생기는 작은 전압이다. 신호는 동방결절에서 저절로 시작해 심방으로 퍼지고(P), 방실결절에서 약 0.1초 늦춰지고(평평한 PR 구간 — 그동안 심방의 피가 심실로 마저 넘어감), 히스 다발·푸르키네 섬유를 타고 심실 전체로 거의 한꺼번에 번지고(QRS), 심실 근육이 다 흥분한 동안은 경계가 없어 평평하고(ST — 피를 내보내는 때), 근육이 원래 전압으로 돌아올 때 T파. 심방의 회복은 QRS 에 묻힌다. 근육은 전기를 뒤따라 조이고, 판막이 닫히는 두 때가 두 심장 소리.)

## 기원·배경

- **심전도라는 말**: 심(心, 심장) + 전(電, 전기) + 도(圖, 그림). 영어 electrocardiogram(electro + cardio + gram 기록)의 번역어. 대본에서는 s02 로 뜻을 풀어 말한다(어원 문장은 음절 예산 때문에 넣지 않음).
- **월러(1887)**: 사람의 온전한 심장에서 처음 전압을 기록(수은 모세관 전위계, 1887년 5월, 런던). 선이 거칠어 굴곡이 둘만 보였다(출처 1·2). 대본 초안에 있었으나 800음절을 넘어 뺐다.
- **에인트호번**: 실 검류계(은을 입힌 아주 가는 석영 실)를 만들어 1901년 첫 글, 1903년 자세한 기술과 기록(출처 1·3). 굴곡에 P, Q, R, S, T 라는 이름을 붙였다(그 전 보정 안 한 곡선에는 ABCD — 글자를 고른 까닭은 지금도 논쟁, 출처 2). 1924년 노벨 생리의학상, 공식 사유 "심전도의 기전을 발견한 공로"(출처 3). 대본 s03·s04 — 노벨상의 사유를 '이름을 붙인 일'로 말하지 않도록 두 사실을 나란히만 둔다.

## 본질(제1원리)

"심전도의 물결은 심장을 지나가는 전기의 그림자이고, 근육은 그 전기를 뒤따라 조입니다." (s08 · s23 같은 문장)

- 근거:
  1. 심장 근육 세포는 쉴 때 안쪽이 바깥보다 약 90 mV 낮다(심실 근육 세포의 안정 막전위 약 −85~−95 mV, 출처 6). 신호가 오면 이온 통로가 열려 안팎의 전압이 뒤집히고(탈분극), 이 뒤집힘이 이웃 세포로 번진다.
  2. 뒤집힌 곳과 쉬는 곳의 경계(파면)가 양극 전극 쪽으로 다가오면 위로, 멀어지면 아래로 그려진다(출처 7). 경계가 없으면(모두 쉬거나 모두 흥분) 선은 평평하다(ST 구간, 출처 8).
  3. 근육의 수축은 전기 흥분의 뒤에 온다(흥분–수축 연결). 그래서 심방은 P 뒤에, 심실은 QRS 뒤에 조인다(출처 9).
- '그림자'는 **비유**다(화면·자막 밖, 여기에 적음): 피부의 전압은 심장 전기 활동의 합이 몸을 통해 번진 것이다. '전기의 그림자'는 "심장의 움직임 자체가 아니라 전기 신호를 본다"는 뜻으로 쓴다.
- 상위 원리: 전하의 분리(전위차)와 그 이동 — 전지의 두 극처럼, 흥분한 부분과 쉬는 부분이 만나는 경계가 작은 전기 쌍극자를 만든다(설명 모형).

## 메커니즘 단계 (한 박동, 1분에 75번 = 0.8초, 모형의 대표값)

모형 시각(ms, 동방결절 발화 = 0). 출처 4·5·9·10 의 정상 범위 안에서 고른 대표값(직접 고름).

| 구간 | 모형 시각 | 근거(정상 범위) |
|---|---|---|
| 동방결절 발화 | 0 | — |
| P파(심방 흥분이 퍼짐) | 10~100 | P 폭 0.08~0.10 s |
| 심방 수축 | 약 90~200 | P 뒤 |
| 방실결절 지연(평평한 PR 구간) | 약 100~170 | 지연 약 0.1 s(출처 10), PR 0.12~0.20 s |
| QRS(심실 흥분) | 170~260 | QRS 0.06~0.10 s |
| 첫째 심장 소리(방실판막 닫힘) | 약 210 | QRS 시작 직후(출처 9·11) |
| ST(심실 전체 흥분, 피를 내보냄) | 260~370 | Wiggers 표: ST·T = 내보내기 |
| T파(심실 회복) | 370~570 | QT 약 0.40 s |
| 둘째 심장 소리(동맥판막 닫힘) | 약 560 | T 끝 무렵(출처 9·11) |
| 쉼·채우기(TP) | 570~800 | 심박이 빨라지면 가장 먼저 줄어듦(출처 12) |

1. **동방결절**(s09): 우심방 위쪽, 위대정맥이 들어오는 곳(출처 13). 저절로 발화(자동능).
2. **심방 → P파**(s10): 흥분이 두 심방으로 퍼짐 → 작은 P파 → 심방 수축(심실은 대부분 그 전에 수동으로 차 있고, 심방 수축은 마지막 몫을 더함).
3. **방실결절 지연**(s11·s12): 심방과 심실 사이는 섬유 조직이 막고 있어, 보통 방실결절이 유일한 전기 통로(출처 14). 결절은 느리게 전도해 약 0.1 s 늦춘다(출처 10) → 평평한 PR 구간, 그동안 심방의 피가 마저 넘어감.
4. **히스 다발·푸르키네 섬유 → QRS**(s13·s14): 빠른 전도 길(약 1~4 m/s, 일반 근육 0.3~0.4 m/s, 방실결절 약 0.05 m/s, 출처 15)로 심실 안쪽 벽에 거의 동시에 → 두꺼운 심실 근육이 0.1 s 안에 흥분 → 가장 큰 QRS. 심방의 회복 물결은 QRS 에 묻힘(s15, 출처 8).
5. **심실 수축, 두 소리, ST·T**(s16~s18): QRS 직후 심실 압력이 오르며 방실판막이 닫힘 = 첫째 소리. 심실 전체가 흥분한 동안 경계가 없어 평평(ST) — 이때 피를 내보냄. 근육이 회복하며 T파, 그 끝 무렵 동맥판막이 닫힘 = 둘째 소리.

## 장면별 인과 사슬 (모든 장면)

무대는 하나: 화면 위쪽(약 y 230~960)에 정면 단면 심장(네 방, 사이벽, 판막 둘 — 방실판막·동맥판막은 왼쪽 것만 크게), 그 안에 전도 길(동방결절 점 → 방실결절 점 → 히스 다발 → 좌우 갈래 → 푸르키네 그물). 그 아래(y 1000~1230) 심전도 띠 — 세계의 시계와 같은 시간축(1 칸 = 0.04 s, 실제 심전도 종이 25 mm/s 의 작은 칸과 같은 뜻), 펜이 지금 시각에 있다. 심장의 흥분 상태와 펜의 높이는 **같은 모형**(`model.mjs`)의 같은 시각 t 에서 나온다.

| 장면 | 사슬(고리 4~6개) | 바꿀 조건 하나와 남길 잔상 | 계기에 찍히는 것 | 소리 |
|---|---|---|---|---|
| hook(s01·s02) | 결절 불꽃 → 심방 밝아짐 → 결절에서 머묾 → 심실 밝아짐·조이기 시작 | 없음(결과 먼저 7배 느리게 → 되감기 → 실제 빠르기 느리게 한 번 더) | 띠에 P·QRS·T, 펜 높이 = 모형 전압 | 발화 틱, 두 심장 소리(낮은 둥) |
| origin(s03·s04) | 실 검류계의 가는 실이 전압에 따라 옆으로 흔들림 → 빛줄기 그림자가 움직이는 사진 띠에 선을 남김 → 그 선이 같은 P·QRS·T | 없음 | 띠 위에 P Q R S T 글자가 해당 굴곡에 하나씩(사건 순간에) | 띠가 흐르는 아주 약한 잡음, 굴곡마다 틱 |
| essence(s05~s08) | 세포 줄(근육 세포 8개 확대) 안팎 전압 표시 −90 → 흥분 파면이 세포를 차례로 뒤집음 → 경계가 전극 쪽으로 오면 띠의 선이 위로 → 경계가 없으면 평평 | 전극 위치 하나만 바꿈(경계가 다가올 때 / 멀어질 때) — 앞 선을 잔상으로 | 세포 하나의 막전압 큰 숫자(−90 → +20 mV), 띠의 위아래 | 세포가 뒤집힐 때마다 아주 짧은 틱 |
| atria(s09·s10) | 동방결절 발화 → 흥분이 두 심방 면으로 번짐 → 띠에 P → 심방 벽이 조임 → 피 점이 심실로 | 없음 | 띠의 P, 시계(ms) | 발화 틱 |
| avnode(s11·s12) | 흥분이 방실결절에 닿음 → 결절 안에서 천천히 기어감(빛점이 느림) → 띠 평평 → 심방의 피 점이 마저 넘어감 | 결절을 지나는 시간(빠른 길과 견줌: 같은 거리의 빛점 둘) | 지연 시계 0 → 100 ms | 결절 통과 동안 낮은 지속음(설명용) |
| ventricles(s13~s15) | 히스 다발·갈래·그물로 빛점이 빠르게 → 심실 안쪽 벽이 거의 동시에 밝아짐 → 띠에 QRS → 심방은 어두워지는데(회복) 띠에는 안 보임 | 없음 | 띠의 QRS, 심방 회복 표시가 QRS 아래 점선으로 묻힘 | 그물 흥분 짧은 스윕 |
| contract(s16~s19) | 심실 벽이 조임 → 방실판막 닫힘(소리 1) → 피 점이 동맥으로 → 평평한 ST → 회복(심실이 어두워짐) → T → 동맥판막 닫힘(소리 2) | 없음 | 띠의 ST·T, 두 소리 표시 | 두 심장 소리(설명용 낮은 둥, 700 Hz 아래) |
| rate(s20~s22) | 같은 박동을 실제 빠르기로 되풀이(1분에 75번) → 빨리 뛰기(1분에 120번, 설명용 값)로 바꿈 → 띠에서 T 뒤 평평한 구간이 줄어든 것이 보임 | **심박수 하나만** 바꿈, 75번의 띠를 잔상으로 | 1분에 박동 수 큰 숫자, 띠의 쉼 길이 표시 | 두 소리가 박동마다(실제 빠르기) |
| close(s23) | 한 박동을 실제 빠르기로 → 끝 한 줄 | 없음 | 띠 | 두 소리 |

- 무대와 세계 안의 눈금: 띠의 시간축 = 세계의 시계(같은 t). 띠의 세로축은 전압(1 칸 = 0.1 mV 의 뜻으로만, 눈금 글자는 쓰지 않거나 "1 mV" 하나).
- 채워진 무광 덩어리: 심장 근육 면(쉼 = 어두운 회갈색, 흥분 = 밝은 무광 살구색), 사이벽, 판막. 빛나는 것과 그 뜻: **흥분 파면의 가장자리(전기 신호)**, **전도 길을 달리는 빛점(신호)**, **동방결절의 발화 섬광**, **심전도 펜 끝과 방금 그은 선 끝(신호)**, 실 검류계의 빛줄기. 근육 면·피 점·판막·띠의 지나간 선은 `lit()` 밖.
- 난색 = 전기 흥분(탈분극, 신호와 흥분한 근육), 한색 = 회복(재분극, T파의 근육 면 변화)과 피의 흐름? → **피는 무광 짙은 적갈색 점(빛 아님)**, 한색은 회복만.
- 시간 배율: 머리글 키커는 모두 `scenes.mjs` 가 모형 상수(박동 0.8 s, 장면별 늘인 길이)에서 계산해 쓴다("실제 0.8초 · 약 N배 느리게", "실제 빠르기"). 57·49 교훈.
- 글자 셋: 머리글 / 큰 숫자 하나(시계 ms 또는 막전압 또는 1분에 박동 수) / 띠의 이름표(P · QRS · T, 사건 순간에 뜸).
- 먼저 렌더할 핵심 장면 약 10초: ventricles(히스–푸르키네 빛점, 심실이 밝아짐, 띠의 QRS).

## 현상·사례

- 쉬는 어른 1분에 60~100번(출처 16), 75번이면 0.8 s(직접 계산 60/75).
- 빨리 뛰면 주로 이완기(T 뒤 쉼·채우기)가 줄어든다 — 수축기보다 이완기가 더 가파르게 짧아짐(출처 12). 화면의 120번은 설명용 값(운동 때 흔한 범위 — 150번은 이 모형에서 T 끝과 다음 P 가 거의 붙어 '쉼'이 사라져 보여 낮춤), QT 가 조금 줄어드는 것도 모형에 넣는다(Bazett 식 꼴로 어림 — 설명 모형).

## 오해 바로잡기

- 따로 비트를 두지 않았다(음절). 다만 s16 이 "첫째 심장 소리 = 판막이 닫힐 때"로 '근육이 내는 소리'라는 생각을 바로잡고, s08 이 "물결 = 전기(움직임이 아님)"를 말한다.

## 단순화 메모

- **설명 모형**: 심장을 정면 단면의 네 방으로 그림(실제 방향·두께는 단순화, 크기 비 과장 없음을 목표). 흥분의 번짐은 전도 길에서의 거리 → 도착 시각으로 계산한 모형. 심전도 곡선은 한 유도(팔다리 II 유도 꼴 — 오른팔 −, 왼다리 +)의 교과서 모양을 가우스 합으로 그린 것(실제 기록이 아님). 화면에 "II 유도" 표시는 하지 않고 여기와 README 에만 적는다 — 물결의 모양·방향은 전극 자리에 따라 다르다.
- **비유**: '전기의 그림자'(위 본질).
- **관측 사실**: 정상 범위 수치(P·PR·QRS·QT), 심박수 범위, 두 심장 소리의 때, 에인트호번·노벨상 연도.
- 심방 수축과 심방 회복의 실제 시각은 대표값으로 고름.

## 스스로 판단이 불확실한 곳 (검수 요청)

- s01·s19 "물결 세 번 / 세 개": QRS 는 굴곡 셋(Q·R·S)의 묶음이고 U파가 보이는 사람도 있다. '큰 물결 세 개'로 묶어 말하는 것이 오해를 부르지 않는가.
- s02 "1천분의 1볼트 안팎": 굴곡 크기를 mV 단위로 어림한 것(표준 감도 1 mV 와 흔한 R 크기). 숫자를 빼고 "아주 작은 전압"으로 할지.
- s03 "이 물결을 처음 또렷하게 기록": 1887 월러의 흐릿한 기록을 빼고 '처음 또렷하게'로 줄였다. 1903 이 '처음 또렷하게'의 해로 적절한가(1901 첫 글).
- s08·s23 '전기의 그림자': 비유가 사실처럼 들리지 않는가, 핵심 명제로 충분히 분명한가.
- s11 "보통 방실결절 한 곳만": 정상 심장의 설명으로 맞는가(우회로가 있는 사람은 '보통'으로 덮음).
- s16 "심방 쪽 판막" = 방실판막(승모판·삼첨판), s18 '둘째 심장 소리' = 동맥판막(대동맥판·폐동맥판). s18 에서 '동맥 쪽 판막이 닫히며'를 음절 때문에 뺐다 — 넣는 편이 나은가.
- s17 "이때 심실은 피를 내보냅니다": ST 구간 = 내보내기의 앞부분(Wiggers 표). 내보내기는 T 동안에도 이어진다.
- s21 '운동해 빨리 뛰면 주로 … 채우는 시간이 줄어듭니다': 수축기도 조금 줄어든다. '주로'로 충분한가.
- s22 의학 문장의 선(진단을 권하거나 겁주지 않는가).
