# 에피소드 `absolute-zero` — 얼마나 차가워질 수 있을까 (절대영도)

"절대영도는 알갱이의 움직임이 가장 낮아지는 온도의 바닥이며, 다가갈수록 걸음이 짧아져 끝내 닿을 수 없는 곳이다." 174.37초, 1080×1920, 30 fps, 테마 `{base: 'navy', accent: '#7FE3FF'}`(차가운 남색 + 얼음빛 청록), 배경음악·배경음 없음.
**모형이 화면·계기·소리를 함께 움직입니다.** 이상기체 상자(공기 온도계 · 3단 계기판), 반씩 줄어드는 걸음(설명 모형), 빈 공간 물체의 복사 냉각, 부메랑 성운의 단열 팽창, 레이저 냉각(광학 당밀), 낙하탑 자유 낙하와 원자 구름 퍼짐, 영점 진동이 모두 `scenes.mjs` 머리의 순수 함수·모듈 로드 때 한 번 만든 표, 그리고 시간 계획(`plan()`)에서 나옵니다. 장면은 매 프레임 표를 읽기만 합니다(프레임마다 상태를 들고 적분하지 않음).

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·표·시간 계획) + 온도 축 포스터·기체 상자·계단·로그 눈금 자·우주·실험실·영점 진동 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/absolute-zero/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/absolute-zero/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/absolute-zero/run.sh stills            # outputs/absolute-zero/stills/
SKIP_NARRATE=1 episodes/absolute-zero/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound`, 자막 자리 어둡게 하기는 교통체증 편에서 복사해 이 편에 맞게 고쳤습니다(에피소드 사이 import 없음). 성에 무늬·온도 축·상자·탑·성운은 모두 이 파일 안의 캔버스 경로이며 외부 이미지·생성 이미지는 쓰지 않았습니다. 성에 층과 우주 배경 복사 무늬는 시드 고정으로 한 번 그려 둔 오프스크린 캔버스입니다.

## 단순화·설명 모형 (화면에는 각주 없음; 표식은 "이상기체 모형", "설명 모형", "시간 압축", "외삽", "떨림 크기 과장", "도플러 냉각 · 설명 모형"뿐)

- **이상기체 상자**: 알갱이끼리 부딪치지 않고, 크기·색·화면 속도는 그림입니다(속도는 실제 평균 속력의 0.8 px/s 배). 2차원 표본이며 실제 기체의 3차원 분포와 같지 않습니다. 계기의 평균 속력·압력은 모형 값이 아니라 공기(이상기체)의 식으로 계산한 값이고, 충돌 횟수는 화면 상자의 값입니다(√T 비례가 요점). 1 K의 공기는 실제로는 고체이며, "1 K까지 식힌 이상기체"는 사고 실험입니다(상자 위 "이상기체 모형").
- **Amontons**: 1702년 무렵 공기 온도계로 "같은 온도 변화에 같은 압력 변화"를 관찰했다는 데까지만 보입니다. 측정점은 이상기체 식에서 만든 값이며 그의 실제 측정값·눈금이 아닙니다. 그가 −273.15 °C를 계산했다고 하지 않습니다(값은 "오늘날 정밀하게 잰 값"). 물통 온도 −20 °C(얼음·소금)까지만 식혔고, 그 아래는 점선 연장(외삽)입니다.
- **켈빈 눈금**: 0 °C = 273.15 K이며 화면 눈금 글씨는 정수(273 K, 173 K …)로 줄였습니다. 눈금의 역사·환산식은 다루지 않습니다(다른 편).
- **계단**: "반씩"은 대본의 비유이며 제3법칙의 도달 불가능을 보이는 설명 모형입니다. 실제 냉각 단계마다 덜어 내는 비율은 방법에 따라 다릅니다. 1 K에서 시작한 것은 앞 장면 상자의 끝 온도와 잇기 위해서입니다.
- **빈 공간의 물체**: 복사 냉각과 T³ 열용량의 단순한 식으로 시간을 압축했습니다. 실제로 식는 데 걸리는 시간과 다릅니다. 나가는 빛의 개수는 그림을 위해 들어오는 빛의 5배에서 자릅니다. 하늘 원의 얼룩은 우주 배경 복사를 떠올리게 하는 생성 무늬이며 실제 지도가 아닙니다.
- **부메랑 성운**: 모래시계 모양은 보이는 빛 사진의 인상이고, 아주 차가운 가스는 그 바깥으로 거의 둥글게 퍼지는 흐름입니다. 온도 식 T ∝ r^(−4/3)와 가장자리 1 K, 안쪽 16.9 K는 설명용 값입니다. 화면 속도는 시간 압축입니다.
- **레이저 냉각**: 빛의 색(실제 780 nm 근적외선, 눈에 안 보임)·원자 크기·반동 크기는 화면용입니다. 감속 비율 γ, 반동 간격 30 px는 그림을 위한 값이며, 0.1 mK는 도플러 냉각이 닿는 수준의 둥근 값입니다. 앞뒤 한 쌍의 빛은 비스듬히 그렸습니다.
- **낙하탑**: 탑 모양은 그림이며, 낙하 거리 110 m · 4.74 s는 자유 낙하 식입니다(실제 실험의 모드·캡슐 구조는 생략). 38 pK는 구름이 퍼지는 운동 에너지로 잰 온도이고, 구름 폭은 그 온도의 식으로 계산했습니다(σ₀는 설명용 값). 실험은 2018년, 논문은 2021년입니다(화면은 대본대로 "2021").
- **초전도·초유체**: 이 편은 예고만 합니다. 수은 저항 곡선의 4.2 K 위 모양은 도식이고, 헬륨 막은 실루엣입니다.
- **영점 진동**: 그릇은 조화 퍼텐셜의 도식이고 떨림 크기는 과장입니다. 고전 공의 "온도 30 K → 0 K"는 흔들림이 줄어드는 것을 보이기 위한 숫자입니다.
- **포스터·훅 위쪽의 따뜻한 알갱이**: 화면 속도는 T^¼로 압축한 장식이며 모형이 아닙니다(온도 축 구슬과 바닥 알갱이는 장면의 주인공). 바닥 알갱이의 작은 떨림은 영점 진동을 미리 보이는 그림입니다.
- **소리**: 모두 합성한 설명용 소리이며 실제 현상의 소리가 아닙니다. 대응은 위 표와 같습니다.
