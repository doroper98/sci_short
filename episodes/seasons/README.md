# 에피소드 `seasons` — 계절은 왜 생길까 (거리가 아니라 기울기)

"계절은 거리가 아니라 기울기가 만든다." 160.0초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
상태 변수는 **날짜 d(t) 하나**입니다. 공전 위치, 태양 적위, 서울의 한낮 해 높이·그림자·햇빛 발자국·낮 길이, 일사량, 거리, 기온 모형, 소리가 모두 d(t)에서 계산됩니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 10개 (고치지 않음) |
| `land.json` | Natural Earth 1:110m 육지 고리 (public domain, world-atlas@2.0.2 경유) — `episodes/global-winds/land.json`의 사본 |
| `scenes.mjs` | 모형(순수 함수) + 지구본·공전 궤도 엔진 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/seasons/scenes.mjs --emit-sound`가 씀 |

```bash
node episodes/seasons/scenes.mjs --emit-sound           # 타임라인이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/seasons/run.sh stills           # outputs/seasons/stills/contact-sheet.jpg
SKIP_NARRATE=1 episodes/seasons/run.sh render sfx mix finish validate
```

지구본 엔진(정사영, 가장자리에서 육지 자르기, 경위선)은 `episodes/global-winds/scenes.mjs`에서 **복사**했고 화면 안 회전(roll)만 더했습니다. 이 엔진을 쓴 두 번째 에피소드라서 `pipeline/`으로 올리지 않았습니다(세 번째 재사용 때 승격 검토).

## 단순화·설명 모형 (화면에는 각주 없음)

- **궤도 모양**은 실제 이심률 그대로입니다(거의 원, 태양은 중심에서 약 5 px 비켜 있음). 지구·태양 크기와 둘 사이 거리는 과장. 훅에는 "궤도: 실제 모양 그대로 — 거의 원"이라고만 적었습니다.
- **원일점 날짜**: 2체 케플러 모형의 원일점은 근일점 반 주기 뒤(7월 5일경)이고, 실제 2026 원일점(7월 6일)은 달의 영향 등으로 하루쯤 늦습니다. 화면의 "7월 6일"은 천문력 날짜이며, 움직이는 지구가 원일점에 있을 때는 날짜를 표시하지 않습니다(거리 1억 5209만 km만 표시).
- **날짜 기준**: 모형의 하루 셈은 대략 한국 시간에 맞습니다(하지 6월 21일, 동지 12월 22일). 춘분은 모형값(3월 21일 0시 무렵) 대신 0.1일 앞당겨 "3월 20일"로 보입니다(2026 춘분: 3월 20일 23:46 KST). 근일점·원일점 날짜는 brief의 날짜(EarthSky 등)를 그대로 씁니다.
- **일사량**은 대기 위 값(구름·대기 흡수 제외), **낮의 길이**는 해 중심·굴절 무시(일출·일몰 정의로는 14시간 46분 / 9시간 34분).
- **기온 곡선**은 1월·8월 평년값 두 개만 지나는 매끈한 모형입니다. 평년값은 월평균이므로 실제 일평균 최고·최저와 같지 않습니다. 열 막대는 이 곡선의 기울기에서 거꾸로 만든 정성 표시입니다(숫자 없음).
- **앙부일구**는 도식입니다. 구의 중심 = 영침 끝. 절기선 13줄은 태양 황경 −90°…+90°(15° 간격)의 적위선, 시각선은 6–18시 한 시간 간격(실제 기물의 시각선·각 눈금과 다름). 영침은 극축 방향으로 북쪽 테두리 기둥에서 중심까지. 다리는 개략. 그림자 끝은 늘 한낮(정오)의 위치이고 날짜만 움직입니다. 위도는 서울 37.5°.
- **본질 장면의 23.4°**는 공전면의 수직선과 자전축 사이의 실제 각입니다. 비스듬한 시점이라 화면상 각도는 약 25°로 보입니다.
- **해의 높이 계기 ① 지구 단면**은 태양을 포함하는 자오면 단면입니다. 그 평면 안에서 자전축이 해 쪽으로 기우는 각 = 적위 δ(하지 +23.4°, 춘·추분 0°, 동지 −23.4°). 오른쪽 작은 공전도는 위에서 본 그림(축의 수평 성분이 늘 같은 쪽).
- **해의 높이 계기 ② 남북 단면**: 해는 막대 끝을 중심으로 한 원호 위에 놓아 해–막대 끝–그림자 끝이 한 직선이 되게 했습니다(각도 = 한낮 해 높이). 햇빛 다발은 같은 폭(66 px)의 평행광, 발자국 = 폭/sin h. 다발 속 점선의 흐름은 장식(빛의 속도와 무관).
- **낮의 길이 지구본**: 카메라는 태양–지구 선에 수직(황도면 위 14°)이라 낮·밤 경계가 화면의 세로 직선이 됩니다. 서울 위도선 중 뒤쪽 반은 점선(지구 뒤로 비친 선)입니다. 지구가 한 바퀴 도는 3초는 화면 시간입니다.
- **남반구 장면**: 카메라를 태양 쪽으로 18° 돌려 북극의 극야와 남극 쪽 낮이 함께 보이게 했습니다. 시드니 카드의 해는 북쪽 하늘(남반구), 서울 카드의 해는 남쪽 하늘입니다.
- **오해 장면**의 "거리가 원인이라면 → 지구 전체가 같은 계절이어야"는 내레이션의 가정을 화면에 옮긴 것이고, "두 반구는 늘 반대 계절" 근거에서 줄이 그어집니다.

## 소리 (`sound.json`, 설명용 합성음, 음악·배경음 없음, 패닝 없음)

**모두 대응(매핑)입니다.** 한 양에는 끝까지 한 대응만 씁니다: 한낮 해 높이 → 음높이(29° = 220 Hz, 76° = 440 Hz, 한 옥타브), 일사량 → 같은 대역 잡음의 크기, 낮의 길이 → 같은 음의 길이, 기온 → 음높이(−1.9 °C = 196 Hz, 26.1 °C = 392 Hz; lag 장면에서만).

| id | 종류 | 뜻 |
|---|---|---|
| `month_ticks` | custom 틱 81개 | 날짜가 움직이는 동안 달이 바뀔 때마다 틱, 음높이 = 그날의 한낮 해 높이(×2 음역) |
| `markers` | tick ×2 | 근일점·원일점 표시 |
