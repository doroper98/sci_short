# 에피소드 `gravity-time` — 머리가 발보다 빨리 늙는다 (중력과 시간)

"중력이 강한 곳일수록 시간은 느리게 흐르고, 이 차이는 우리 머리와 발 사이에도 있다." 165.22초, 1080×1920, 30 fps, 테마 `{base: 'noturno', accent: '#FFC85A'}`(금빛 강조색), 배경음악·배경음 없음.
**모형이 화면·계기·소리를 함께 움직입니다.** 약한 중력의 시계 빠르기 차이 g·h/c², 정확한 중력 퍼텐셜 식, 로켓 사고 실험(천장 시계의 시간으로 그린 빛 신호 표), 탑의 감마선 물결, GPS의 +45/−7 μs, 블랙홀 시계의 √(1 − r_s/r)가 모두 `scenes.mjs` 머리의 순수 함수와 모듈 로드 때 한 번 적분한 표, 그리고 시간 계획(`plan()`)에서 나옵니다. 장면은 매 프레임 표를 읽기만 합니다.

음성: Supertonic 3 **M3(남성)** ×0.85, `니다` 문장 끝 6반음 하강(2026-11-06 사용자가 남성 목소리로 전환; 값은 `config/voice-overrides.json`). 모든 장면 시각은 `timeline.json`의 문장·낱말 시각에서 계산하므로 목소리가 바뀌어도 `--emit-sound`와 렌더만 다시 하면 됩니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 10개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·적분 표·시간 계획) + 사람 실루엣·시계 문자판·로켓·탑·궤도·지도·그래프 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/gravity-time/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/gravity-time/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/gravity-time/run.sh stills            # outputs/gravity-time/stills/
SKIP_NARRATE=1 episodes/gravity-time/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound`는 교통체증 편에서 복사해 이 편에 맞게 고쳤습니다(에피소드 사이 import 없음). 사람·시계·로켓·탑·지구·위성·지도는 모두 이 파일 안의 캔버스 경로이며 외부 이미지·생성 이미지는 쓰지 않았습니다. 지수는 대체 글꼴의 위첨자 숫자가 고르지 않아 `tx()`가 작은 글자(최소 24 px)를 올려 그립니다(`10^{−16}` 표기).

## 단순화·설명 모형 (화면에는 각주 없음; 표식은 "과장 ×10¹⁵", "과장 ×10¹⁴", "색 차이는 과장 ×10¹⁸", "빛은 느리게 그림", "시간 압축", "모형 · 멀리서 본 모습", "계산", "각자의 시간으로 본 화면"뿐)

- **과장**: 시계 빠르기 차이는 실제로 10⁻¹⁶ 수준이라 모두 과장 배율을 화면에 적었습니다. 실제 값은 "실제" 표기와 함께 따로 보였습니다(1초마다 1.9×10⁻¹⁶초, 평생 0.47 μs, 실제 +2.2×10⁻¹⁶초 등).
- **로켓 사고 실험**: 등가 원리의 설명 모형입니다. 화면은 천장 시계의 시간으로 그렸고, 그래서 바닥 시계와 그 신호가 1.218초마다 넘어갑니다(바닥 시계로는 1초). 빛은 객실을 약 2.6초에 건너도록 아주 느리게 그렸으며, 이것은 과장 배율과 따로인 그림 장치입니다. 신호 간격이 위로 갈수록 벌어지는 것은 천장 시간 좌표에서 빛의 좌표 속도가 높이에 따라 다르기 때문이고(린들러 좌표, 국소 측정으로는 늘 c), 늘어난 간격은 천장에서 잰 파장이 1 + δ배라는 뜻입니다. s08의 속도 막대는 바깥 관성계에서 본 설명(보낼 때 바닥 속도 < 받을 때 천장 속도)으로, 숫자는 쓰지 않았습니다. 손잡이를 돌리는 동안(1.3초) 받은 간격은 1.0125 · 1.0760 · 1.1609 · 1.2155초를 거쳐 1.2183초에 정착합니다(시간에 따라 바뀌는 가속에서의 정확한 일반 상대론 계산이 아니라 같은 모형을 그대로 적분한 값).
- **탑**: 실제 실험은 철-57의 메스바우어 흡수(선원을 움직여 도플러로 진동수를 맞추는 방식)로 쟀으며, 위아래를 바꿔 두 방향을 모두 쟀습니다. 화면은 "아래 선원 → 위 검출기" 한 방향과 물결 간격만 보였습니다.
- **GPS**: +45/−7 μs는 대표값입니다(궤도 이심률, 지상 수신기의 위치·자전에 따라 조금 다름). "하루 약 11 km"는 38 μs × c의 거리 환산으로, 실제 수신기의 위치 오차가 쌓이는 방식은 위성 여러 개의 시계 오차가 함께 작용해 더 복잡합니다. 지도·장소는 가상의 그림입니다.
- **원자시계**: NIST는 알루미늄 이온 광시계 두 대(높이 차 33 cm), JILA는 스트론튬 원자 약 10만 개의 구름 하나 안의 위아래(약 1 mm)를 비교했습니다. 상자·격자·구름 모양은 그림이고, 화면의 3.6×10⁻¹⁷과 1.1×10⁻¹⁹는 g·h/c² 계산값입니다(NIST의 측정은 (4.1 ± 1.6)×10⁻¹⁷).
- **블랙홀**: √(1 − r_s/r)는 그 자리에 멈춰 있는 시계의 빠르기입니다. 화면의 시계는 천천히 내려가는 것처럼(r − r_s가 지수적으로 줄어듦) 그렸고, 자유 낙하하는 시계라면 멀리서 볼 때 도플러 효과로 더 느려 보이지만 지평선에서 멈춘 듯 보이는 결과는 같습니다. 빛 고리·색은 설명 그림(빛이 휘는 모습은 단순화)이며 시계가 붉어지는 것은 중력 적색이동을 나타낸 표현입니다.
- **오해 장면**: 위·아래 칸은 각자의 시간으로 그렸습니다. 아래 사람이 r = 2 r_s의 블랙홀 가까이에 머무를 수 있다고 가정했습니다(조석력·실제 가능성은 다루지 않음).
- **사람·문자판**: 시계 문자판은 10시 10분 무렵의 바늘을 함께 그렸으나 초침만 의미가 있습니다. 1.7 m 괄호는 머리 시계(머리 높이)와 발 시계 사이입니다.
- **소리**: 모두 합성한 설명용 소리이며 실제 현상의 소리가 아닙니다. 대응은 위 표와 같습니다.
