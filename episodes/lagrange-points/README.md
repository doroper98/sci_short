# 에피소드 `lagrange-points` — 라그랑주 점, 우주의 주차 자리 (24번)

"라그랑주 점은 두 천체의 중력을 합친 힘이, 함께 도는 데 필요한 힘과 꼭 맞는 자리입니다." 158.46초, 1080×1920, 30 fps, 테마 `{base: 'noturno', accent: '#FFC24A'}`(금빛), 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음).
**모형 하나가 화면·계기·소리를 함께 움직입니다.** 제한 삼체 문제(회전 좌표계 유효 퍼텐셜, 라그랑주 점 위치, RK4 궤도 적분), 케플러 빠르기, 태양–지구 선 위의 힘(합친 힘·필요한 힘)이 모두 `scenes.mjs` 머리의 순수 함수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모, 검증 메모 |
| `script.json` | 문장 20개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 모형 + 등고선·음영(미리 계산) + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/lagrange-points/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 |

```bash
node episodes/lagrange-points/scenes.mjs --emit-sound          # 타임라인·모형이 바뀌면 먼저 (낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/lagrange-points/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound`는 수소폭탄 편에서 복사해 고쳤습니다(에피소드 사이 import 없음).

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 단위 | G(M₁+M₂) = 1, 태양–지구 거리 a = 1, ω = 1 (1년 = 2π). 회전 좌표계, 질량 중심이 원점, 태양 (−μ, 0), 지구 (1 − μ, 0) |
| 유효 퍼텐셜 | Ω = ½(x² + y²) + (1 − μ)/r₁ + μ/r₂, 그림의 음영·등고선은 Φ = −Ω (300×300 격자, 마칭 스퀘어, 11개 높이: L1·L2·L3를 지나는 선 포함) |
| 라그랑주 점 | 직선 위 세 점은 ∂Ω/∂x = 0(5차식)을 힐 반지름 (μ/3)^(1/3)에서 시작한 뉴턴 반복으로, L4·L5 = (½ − μ, ±√3/2). 화면용 μ = 0.01 → L1 0.848, L2 1.147, L3 −1.004. 실제 μ = 3.003×10⁻⁶ → 지구에서 L1 149.1만 km, L2 150.1만 km(달 38만 4,400 km의 3.9배) |
| 화면용 질량비 | 지구를 실제 몫(μ = 3.0×10⁻⁶)보다 약 3,300배 무겁게(μ = 0.01) 그려 L1·L2가 지구에서 떨어져 보이게 함. 머리글 키커 "지구 질량 과장", 훅 "크기와 거리 과장"으로 선언. 실제 거리 장면(s11)만 실제 축척 |
| 운동 방정식 | 회전 좌표계: ẍ − 2ẏ = ∂Ω/∂x, ÿ + 2ẋ = ∂Ω/∂y (코리올리 포함), RK4, dt 0.002 |
| 고갯마루(s13) | L1·L2에서 1.2×10⁻³만큼 비켜놓고 정지 상태에서 적분 → 0.45 넘게 멀어지는 데 화면 약 3초(1년 = 6초와 같은 빠르기). 단면 그래프의 공은 L2 입자의 x 좌표를 따라 Φ(x, 0) 위를 움직임 |
| 올챙이 궤도(s15) | L4를 10° 앞으로 돌려놓고 정지 상태에서 적분. 맴돌기 주기 24.0 단위(약 3.8년), 각도 49°~72°. 화면은 1년 ≈ 1.46초(키커 "1년을 1.5초로") |
| 케플러(s05~s07) | 태양만 있을 때 원 궤도 각속도 ω = r^(−3/2): 안쪽 0.848 → 0.78년, 바깥쪽 1.147 → 1.23년. "빨리"(37.2초)에 세 천체가 한 줄, 이후 안쪽이 앞지르고 바깥쪽이 뒤처짐. "더하면"에 두 위성이 L1·L2 자리에 지구와 나란히 놓이고 모두 1년 주기 |
| 힘(선 위, 단위 질량) | 태양 쪽으로: F(x) = (1 − μ)/(x + μ)² + μ(x − 1 + μ)/|x − 1 + μ|³, 필요한 힘 N(x) = x. L1: 태양 1.345, 지구 −0.496(바깥쪽), 합 0.849 = 필요 0.848. L2: 태양 0.740, 지구 +0.406, 합 1.146 = 필요 1.147. 화살표 200 px/단위 |
| 빠르기 화살표(s09~s10) | 실제(1년 주기) v = x, 태양만 있을 때 v = √((1 − μ)/(x + μ)): L1 0.848 대 1.074(더 천천히), L2 1.147 대 0.925(더 빨리) |
| 제임스웹 헤일로(s14) | 모식 타원, 한 바퀴(반년)를 4초로. 분사는 1/4바퀴마다(약 6주, NASA 계획 21일 간격·운영 약 42일 → "몇 주마다") 7번. 사이의 어긋남 0.05·(e^(1.6 s) − 1), 분사 뒤 0.3초에 걸쳐 되돌림(설명 모형, 크기 과장) |
| 트로이 소행성(s16~s17) | 실제 μ_J = 9.54×10⁻⁴, 목성 공전 11.86년(1년 = 6초 → 71초에 한 바퀴). 점 1,567개(점 하나 = 약 10개), L4 974 : L5 593 = 9,738 : 5,931(2026년 2월). 분포는 ±60° 둘레의 모식(경도 폭 4°~30°) |
| 시간 | 관성 좌표 장면(훅·본질·다섯 점 앞부분·트로이·오해): 1년 = 6초. 다섯 점 장면에서 보는 눈이 2초 남짓에 걸쳐 지구와 함께 돌기 시작(배경 별이 반대로 돎) |

## 단순화

- 원 궤도, 제한 삼체 문제(작은 물체의 질량 무시). 지구 궤도 이심률·달·다른 행성 무시.
- 화면용 질량비 μ = 0.01(실제 3.0×10⁻⁶), 실제 축척 장면만 예외. 크기(태양·지구·위성 점)는 모두 과장.
- 헤일로 궤도는 3차원 궤도의 모식 2D 타원, 어긋남 크기 과장.
- "주차 자리"는 비유이며 화면에서는 함께 도는 자리로 보여 줌.
- 트로이 소행성의 점 분포는 모식(개수 비율만 실제).
- L4·L5는 퍼텐셜의 꼭대기이며 안정은 코리올리 효과 때문(화면 한 줄 라벨). 대본은 "맴돌며 오래 머뭅니다"까지.
- 소리는 설명용 합성음.
