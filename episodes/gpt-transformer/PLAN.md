# 45번 구현 계획서 — GPT는 문맥을 어떻게 읽을까 (T)

공통 규칙·부품·파일 구조는 `episodes/gpt-generative/PLAN.md` 1~3절입니다(먼저 읽기). 부품은 `../gpt-generative/kit.mjs` 를 import 합니다. 이 문서는 45번의 모형·무대·장면입니다.
이 편은 화면과 내레이션에서 '낱말'로 통일합니다(실제로는 낱말보다 작은 조각 — README).

## 1. 모형 — `episodes/gpt-transformer/model.mjs`

두 방향짜리 아주 작은 주의(어텐션) 계산입니다(GPT 가 아님 — README 에 밝힘). 순수 계산만 하고, `node model.mjs` 로 확인 값을 찍습니다.

- 지도 좌표 `[u, v]`, 둘 다 −1~1(v 는 위가 +). 영역: `탈것` 중심 (0.58, 0.38), `과일` 중심 (−0.58, −0.32).
- 낱말의 처음 자리 `E`:
  - `배` (0.00, 0.02) — 두 영역 사이
  - 탈것 쪽: `항구를` (0.65, 0.50) · `떠난` (0.40, 0.10) · `폭풍을` (0.30, 0.62) · 배경 `기차` (0.82, 0.22) · `버스` (0.74, 0.66) · `돛` (0.44, 0.78)
  - 과일 쪽: `익은` (−0.62, −0.20) · `달게` (−0.40, −0.55) · 배경 `사과` (−0.82, −0.36) · `포도` (−0.72, −0.66) · `감` (−0.44, −0.02)
  - 뜻이 옅은 말: `지` (0.05, −0.70) · `사흘` (0.20, −0.55) · `만에` (−0.10, −0.80) · `만난` (0.12, 0.30)
- 관련 점수표 `R[보는 낱말][살피는 낱말]`(실제 GPT 에서는 배워서 얻는 값, 이 모형에서는 설명용으로 정한 값 — README): `R[배] = {항구를: 1.9, 떠난: 1.3, 익은: 1.9, 달게: 1.3, 폭풍을: 1.0}`, `R[떠난] = {항구를: 1.0}`, `R[익은] = {달게: 1.0}`, `R[만난] = {폭풍을: 1.0}`, 나머지는 0(자기 자신 포함).
- 주의: 자리 t 의 낱말이 **자기와 그 앞의 낱말들**(j ≤ t)에 대해 `w = softmax(R[·])`. 합은 1. `항구를 떠난 배` 의 `배` → 약 `[0.59, 0.32, 0.09]`(항구를 · 떠난 · 자기).
- 한 층: 모든 낱말이 동시에 `x_i ← x_i + λ(Σ_j w_ij x_j − x_i)`, λ = 0.6. `run(words, {layers = 4}) → {W: [층][i][j], X: [층 0..L][i] = [u, v]}`.
- 다음에 올 만한 말: 후보의 방향 `O` — 탈것 쪽 `위에서` (0.75, 0.45) · `한 척이` (0.60, 0.70) · `안에는` (0.50, 0.20), 과일 쪽 `한 개를` (−0.75, −0.40) · `맛이` (−0.55, −0.65) · `껍질을` (−0.50, −0.15). `nextProbs(x) = softmax([γ·(x · O_c) …, 0])`(마지막 0 은 `그 밖`), γ 는 4층 뒤 맨 윗말이 40~60% 가 되게 고릅니다. 처음 자리에서는 여섯이 엇비슷해야 합니다(확인).
- 예전 방식(설명 모형): 기억 `m_t = α·m_{t−1} + (1 − α)·E_t`, α = 0.6. `oldShare(n)` = n 칸 뒤 기억 속 첫 낱말의 몫 = α^n.
- 문장: `SHIP = ['항구를', '떠난', '배']`, `PEAR = ['달게', '익은', '배']`, `LONG = ['항구를', '떠난', '지', '사흘', '만에', '폭풍을', '만난', '배']`.
- 익히기(s20 용): `R` 을 0 → 지금 값으로 `k ∈ [0, 1]` 배 했을 때의 주의 `attnAt(words, k)`.
- 확인 출력: SHIP·PEAR 의 층별 `배` 자리와 주의, 4층 뒤 다음 말 확률(위 3 + 그 밖)과 처음 자리에서의 확률, LONG 에서 `배 → 항구를` 주의와 `oldShare(7)`, 층마다 `배` 가 옮겨 간 거리(줄어들어야 함).

## 2. 무대

- 낱말 줄(세계): y 300. 세 낱말 예시는 크기 52, 가로 가운데 정렬(폭을 재서 x0 를 정함). 긴 문장 `LONG` 은 크기 36, 한 줄. 주어진 낱말 = `given`(한색), 뜻이 바뀌는 `배` = `made`(난색).
- 주의의 선: `배` 조각 위 가운데에서 앞 낱말 조각 위 가운데로 휘어 감(`link`, `bend`), 굵기 = 주의. **낱말 밑**(y 약 385~440)에 그 낱말이 받은 주의 막대와 %(계기가 세계와 같은 가로 자리).
- 뜻의 지도: 일할 때 `{x: 90, y: 520, w: 900, h: 580}`. 0초 포스터 프레임에서는 `{x: 90, y: 960, w: 900, h: 380}`(제목 아래)이고 제목이 줄어드는 동안 일하는 자리로 커집니다. 영역 `탈것` `과일`(중립색 타원, 점선). 낱말의 점은 `dot` — 주어진 낱말 `given`, `배` 는 `made`, 출발점·옛 도착점은 `ghost`, 지나온 길은 `trail`.
- 계기 띠(`panel`, y 1128~1338): `probBars` y0 = 1135, 4줄(다음에 올 만한 말 위 3 + 그 밖).
- 색: 한색 = 주어진 낱말. 난색 = 주의와 옮겨 가는 `배`. 빛(Glow)은 **주의의 선**에만.
- 큰 숫자(한 번에 하나): `100%`, `12,288개`, `1층`…`96층`, 주의 %.
- `POSTER = {q: ['GPT는 문맥을', '어떻게 읽을까?'], a: '앞말을 살펴서', …}`.

## 4. 검수에서 볼 것 (작업자가 먼저 스스로 확인)

- 0초 프레임: 제목이 낱말 줄·주의 선·지도의 점을 가리지 않는가.
- 주의 %의 합이 100 으로 보이는가(반올림 뒤 99·101 이 되면 가장 큰 값에서 맞춤).
- 선의 굵기 순서 = 막대 길이 순서 = 모형 값 순서인가. `배` 의 점이 옮겨 가는 프레임과 선이 당기는 프레임이 같은가.
- 지도의 낱말 이름이 서로, 또는 점과 겹치지 않는가. 영역 이름이 읽히는가.
- 낱말·% 글자 크기(낱말 34 이상, % 30 이상), 자막 자리(y ≥ 1376) 침범 없음.
- 빛은 주의의 선뿐인가.
