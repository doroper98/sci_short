# 에피소드 `reusable-rocket` — 로켓은 어떻게 돌아올까 (저궤도와 재사용 로켓)

"궤도에 오른다는 것은 높이 오르는 일이 아니라, 옆으로 빠르게 달리는 일입니다." 156.52초, 1080×1920, 30 fps, 테마 `{base: 'graphite', accent: '#FF7A1A'}`(불꽃 주황), 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음).
**모형이 화면·계기·소리를 함께 움직입니다.** 원 궤도 속도·에너지, 뉴턴의 대포 궤도(RK4), 로켓 방정식, 상승·1단 귀환 궤적(2D 둥근 지구 적분), 착륙 연소 점화 높이가 모두 `scenes.mjs` 머리의 순수 함수·표와 시간 계획(`plan()`)에서 나옵니다. 장면은 매 프레임 표를 읽기만 합니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 |
| `script.json` | 문장 20개, 장면 8개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·적분·시간 계획) + 착륙장·로켓·지구·궤적 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/reusable-rocket/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/reusable-rocket/scenes.mjs --emit-sound           # 타임라인·모형이 바뀌면 먼저 (낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/reusable-rocket/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목(흰 질문 + 큰 강조색 답), 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound`는 수소폭탄 편에서 복사해 고쳤습니다(에피소드 사이 import 없음). 로켓·착륙장·발사탑·지구는 모두 이 파일 안의 캔버스 경로이며 외부·생성 이미지는 쓰지 않았습니다. 로켓 외형은 일반적인 2단 액체 로켓(흰 몸체, 회색 단간부, 격자 날개, 다리 넷)이며 특정 회사의 도장·로고를 따라 그리지 않았습니다. 제품 이름(Falcon 9, Super Heavy, B1067)은 작은 이름표에만 있습니다.

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 궤도 속도 | v = √(GM/r), GM = 398,600 km³/s², R = 6,371 km. 200 km 7.78, 400 km 7.67 km/s. 대본·화면의 "초속 7.8 km"는 낮은 궤도의 대표값 |
| 에너지 (1 kg당) | 400 km까지 오르기 GM(1/R − 1/(R+h)) = 3.70 MJ, 초속 7.8 km 내기 ½v² = 30.4 MJ → 8.2배("여덟 배쯤"). 화면은 짧은 막대 여덟 개가 긴 막대를 채움 |
| 서울–부산 | 직선 325 km ÷ 7.8 km/s = 42초("1분이 안 걸리는") |
| 뉴턴의 대포 | 400 km에서 수평으로 4.0 · 6.0 · 7.2 · 7.8 km/s, 이체 문제 RK4(4 s 간격). 앞의 셋은 13° · 26° · 58° 앞에 떨어짐, 7.8은 400 × 869 km 타원으로 한 바퀴(5,836 s). 화면은 높이 4배 과장, 약 2,000배 빠르게 |
| 로켓 방정식 | Δv = vₑ·ln(m₀/m₁), vₑ = 3.1 km/s(등유 엔진 대표값). 궤도에 필요한 9.4 km/s(궤도 7.8 + 중력·공기·방향 손실) → 연료 몫 1 − e^(−9.4/3.1) = 95.2 %("95퍼센트 가까이") |
| 상승 (설명 모형) | 2D 둥근 지구, 지수 대기(척도 높이 8.5 km). 1단 추력 7.5 MN, 549 t, 2.6 t/s, 8초 수직 뒤 0.033 rad 기울임, 이후 속도 방향으로 추력(중력 선회). T+150 s("2분 반쯤")에 고도 70.1 km, 84.7 km 앞, 초속 2.4 km. 2단(vₑ 3.35 km/s, 120 → 21 t, 360 s, 각도 0.55 → 0.025 rad 선형)은 200 km, 초속 7.73 km, 1,519 km 앞에서 끝. 이상 Δv 3.57 + 5.84 = 9.41 km/s 중 82 %가 궤도(옆) 속도 |
| 1단 귀환 (설명 모형) | 같은 적분기. 뒤집기 10 s → 역추진 45 m/s² × D(발사장에 내리도록 이분법으로 풀어 64.1 s) → 관성 비행(정점 132 km) → 60 km에서 재진입 연소 40 m/s² × 18 s → 공기 저항(CdA/m 4.5×10⁻⁴ m²/kg) → 착륙 연소 20 m/s², 점화 높이를 풀어 높이와 속도가 함께 0이 되게(2.46 km, 초속 306 m) → T+488 s 접지 |
| 착륙 비교 (설명 모형) | 점화를 1.35배 높게 → 491 m 위에서 멈췄다가 다시 솟음, 0.62배 → 초속 118 m로 부딪힘 |
| 착륙 힘 (대표값) | 빈 1단 약 30 t → 무게 약 290 kN, 엔진 하나를 가장 약하게(약 40 %) 약 340 kN → 무게의 약 1.16배 |
| 시간 배율 | 상승 약 27×, 귀환 약 18×(구간마다 다름), 착륙 마지막 26초 약 1.7×, 대포 약 2,000×, 위성 점들 120× |

## 단순화

- 궤적은 2D 설명 모형입니다(궤도 경사·지구 자전 무시, 엔진 추력·질량 흐름은 대표값). 실제 임무마다 분리 높이(65~80 km)·속도가 다릅니다.
- 바다의 배로 내려앉는 임무는 역추진이 짧거나 없습니다. 이 편은 2015년 첫 착륙과 같은 발사장 귀환으로 그렸습니다.
- 착륙 연소는 일정 가속도 근사입니다. 모형은 계산 간격 때문에 몇 m 위에서 멈추므로, 착륙 화면에서는 그 몇 m를 연소 동안 고르게 빼서 0에 닿게 했습니다.
- 로켓 크기는 궤적 그림에서 과장했습니다(화면에 "로켓 크기 과장"). 지구 전체 그림의 높이는 4배(대포)·3배(오해) 과장입니다(머리글 키커에 표기).
- "해마다 수천 개"는 연도별 수치 막대를 쓰지 않고 위성 점이 늘어나는 그림으로만 보였습니다.
- 소리는 모두 설명용 합성음입니다(녹음 아님).
