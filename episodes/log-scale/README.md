# 에피소드 `log-scale` — 한 칸에 열 배 (지진 규모 · 데시벨 · pH와 로그)

"로그는 몇 번 곱했는지를 세는 자다. 한 칸에 열 배." 163.6초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
대상은 초등학교 5학년입니다. 한 화면에 생각 하나, 큰 숫자, 적은 글자, 느린 전환을 원칙으로 했고, "×10 한 칸"은 학교에서 쓰는 **수모형**(낱개 1 · 십모형 10 · 백모형 100 · 천모형 1000)으로 되풀이해 보여 줍니다.
모든 화면 요소·계기·소리는 `scenes.mjs` 위쪽의 순수 함수(모형)와 낱말 기준 시간표 `plan(tl)` 하나를 함께 읽습니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·수치·단순화 메모 (고치지 않음) |
| `script.json` | 문장 17개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수) + 시간표 `plan(tl)` + 수모형·아이콘 그리기 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/log-scale/scenes.mjs --emit-sound`가 씀 (낡으면 렌더가 경고) |

```bash
node episodes/log-scale/scenes.mjs --emit-sound           # 타임라인이 바뀌면 먼저 (sound.json 다시 씀)
SKIP_NARRATE=1 episodes/log-scale/run.sh stills           # outputs/log-scale/stills/contact-sheet.jpg
SKIP_NARRATE=1 episodes/log-scale/run.sh render sfx mix finish validate
```

`--emit-sound`는 수치 점검도 한 줄로 찍습니다(개미/코끼리 2×10⁹, 에너지 31.6, 30→60 dB ×1000, 느낌 ×8, pH 7→3 ×10⁴, 0→120 dB ×10¹², 1 mm × 10¹² = 10⁶ km = 달까지의 2.60배).

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 | 화면 |
|---|---|---|
| 곱하기 자 | 한 칸 = ×10 (`STEP`) | 모든 자의 칸 사이 "×10" 화살 |
| 개미 · 코끼리 | 약 3 mg · 약 6 t → 6×10⁹ / 3 = 2×10⁹ | "코끼리는 개미의 약 20억 배" |
| 지진계 진폭 | 규모 +1 → ×10 (`ampRatio`) | 규모 3·4·5·6 기록과 "×1 · ×10 · ×100 · ×1,000" |
| 지진 에너지 | 규모 +1 → ×10^1.5 = 31.6 (`energyRatio`) | "에너지는 한 칸에 약 32배" (그림 없음, 말과 글 한 줄) |
| 소리 세기 | +10 dB → ×10 (`intensityRatio`) | 30 → 60 dB = ×1,000, 0 → 120 dB = ×10¹² ("1조 배") |
| 들리는 크기 | +10 dB → 약 ×2 (`loudRatio`, 어림 규칙) | 막대 ×1 · ×2 · ×4 · ×8 |
| 수소 이온 | pH −1 → H⁺ ×10 (`hRatio`) | 상자 속 알갱이 1 · 10 · 100(정확한 개수), 물 7 → 식초 3 = 10⁴ = "만 배" |
| 더하기 자 대비 | 0 dB를 1 mm로 그리면 120 dB = 10¹² mm = 10⁶ km, 달까지 384,400 km → 2.6배 | "천둥은 약 100만 km → 달까지 거리의 약 2.6배" |
| 훅의 지진계 | 규모 3 기록의 최대 높이 19.2 px → 규모 6 = ×1000 = 19,200 px = 화면(1920 px) 10개 | "진짜 크기로 그리면 화면 10개 높이" |

### 시간표 `plan(tl)` (모두 낱말 기준, 장면 안에서 끊김 없음)

| 장면 | 일정 |
|---|---|
| hook | "지진"·"데시벨"·"피에이치가"에 주제 카드 셋, "한 칸에"부터 0.45 s 간격으로 미리 보는 곱하기 자 1·10·100·1000. s02: "규모 삼"에 규모 3 기록, "두 배"에 "2배?" 추측 기록, "아닙니다"에 줄, "지진계에"부터 규모 6 칸에 같은 크기로 다시 그림, "천 배나"부터 1.5 s 동안 ×10·×10·×10(10의 지수를 부드럽게 이징) → 칸을 넘음 |
| ruler | "한 칸"부터 0.27 s 간격 +1 뜀 10번(큰 숫자 계기), "이 자에" 한 칸 = 1 mg, "개미의"·"코끼리의"에 막대, "함께" 직전부터 1.9 s 동안 한 칸 = 1 mg → 1 t(10배씩 아홉 번), "개미는"에 "0에 붙어서 보이지 않음", "보이지"에 "약 20억 배". s05: "열 배씩"~"곱하기 자를"+0.2 s 같은 11개 눈금이 1 mg … 10 t의 곱하기 자로 바뀜(숫자가 먼저 사라지고 단위가 나중에 나타남), 두 막대가 한 자에 들어옴 → 위로 올라가고, "일,"·"십,"·"백,"·"천이"에 수모형 자, "같은 간격"에 간격 표시 |
| essence | "영의 개수"에 0들이 빛남, 10·100·1000의 0이 쟁반으로 떨어짐("영의 개수"+0.3 / "영이 두" / "천은"), 칸 번호 0·1·2·3("두 번째"·"세 번째"), "같습니다"에 "0의 개수 = 칸 번호". s07: 1000 = 10 × 10 × 10("몇 번"부터 0.35 s 간격), "세는"에 "10을 3번 곱함 → 세 번째 칸", "로그라고"에 작은 log₁₀ 1000 = 3, "비율의"에 이름 카드 |
| quake | 규모 3 기록("지진계에"), 규모 4("일 커지면") → 칸을 넘음 → "열 배가"에 세로를 1/10로 줄임; 규모 5("세 칸이라" 직전) → 줄임; 규모 6("십을") → 줄임. 세로 줄임은 10의 지수를 0.8 s씩 이징해 규모 3 기록이 1/10, 1/100, 1/1000로 부드럽게 작아짐. "천 배입니다"에 결과, "에너지는"에 32배 줄 |
| sound | s10 데시 + 벨 카드("벨은"·"전화를"·"데시는"·"십분의"·"왔습니다"). s11 0~60 dB 곱하기 자, "십데시벨"에 +10 dB 한 칸, "열 배가"에 "세기 ×10", "속삭임이"·"대화가"에 아이콘, "대화는"부터 0.4 s 간격 수모형 ×10 ×100 ×1000, "천 배입니다"에 결과. s12 "여덟" 무렵 0.3 s 간격 느낌 막대, "크게"에 요약, "곱하기 자처럼"에 ×2 표시 |
| ph | "산성의"에 산성 ← / → 염기성, "칠이"에 7 = 중간, "작아질" 앞뒤로 pH 7·6·5 상자(알갱이 1·10·100), "작은 알갱이가"에 범례, "열 배"에 ×10 화살. s14 "물은"·"식초는"에 물컵·식초병, "삼이니"부터 0.3 s 간격 네 칸, "식초에는"에 천모형 10개 vs 낱개 1개, "만 배"에 결론 |
| wide | "덕분에"부터 0.3 s 간격 0~120 dB 눈금 13개, "들릴락"·"천둥소리는"에 아이콘, "일조"에 "세기 1조 배 = 10을 12번 곱함", 0.7 s 뒤 더하기 자 대비 패널(화살이 화면 밖으로), "데시벨로는"에 "0 → 120, 열두 칸" |
| myth | "숫자가"에 3·4·5·6 자, "아니라"에 "3 차이 = 3배?"에 줄, "십을"·"세 번"·"곱한"에 ×10과 수모형, "천 배입니다"에 결과 |
| close | 정리 카드 "한 칸에 열 배", "곱하기 자"에 "곱하기 자 = 로그", "지진도"·"소리도"·"산성도"에 세 자(칸 간격 같음), "한눈에"에 같은 칸을 잇는 세로선과 "어느 자든 한 칸 = ×10" |

## 소리 (설명용 합성음, 녹음 아님)

배경음악·배경음 없음. 모든 사건에 `means`가 있습니다. 패닝 없음(모노 안전). 효과음 설정값은 −23 ~ −36 dB. 실측(sfx.wav, 50 ms 창 최대 RMS)으로 대부분 말소리 RMS(−19.9 dBFS)보다 약 15–21 dB 아래이고, 말하는 동안 mix가 6 dB 더 낮춤.

| 대응 (끝까지 유지) | 값 |
|---|---|
| 곱하기 자의 한 칸(×10) | **완전4도(×4/3) 위**. 0칸 = 130.8 Hz(C3), 4칸 413 Hz, 12칸 4,130 Hz(다섯 옥타브). 훅의 미리 보기, 1 mg → 1 t 줄여 보기(9칸), 수모형 자, 0의 개수, 지진 규모, pH 상자·네 칸, 0~120 dB 13개, 오해 장면이 모두 같은 대응 |
| 더하기 자의 한 칸(+1) | 똑같은 높이(1,100 Hz)·크기의 틱 10번 |
| 지진계 펜 긁힘 | 띠 잡음(1.4–5.2 kHz), 세기 곡선 = 그림 속 기록의 포락선. **크기 압축**: 진폭 ×10(규모 +1)마다 +2 dB(규모 3 −29 dB → 규모 6 −23 dB). 실제 ×10 진폭 차이(+20 dB)를 그대로 재생하지 않음 |
| 데시벨 음 | 392 Hz 같은 높이. **크기 압축**: 실제 +10 dB를 +2 dB로(30 dB −33 dB … 60 dB −27 dB). 실제 세기 차이를 재생하지 않음 |
| 그 밖 | 카드·표시 등장 틱, 줄 긋기(낮은 틱 두 번), 세로 줄여 보기(내려가는 바람 소리), 화면 밖으로 뻗는 막대·화살(올라가는 바람 소리), 천둥 아이콘(낮은 합성 잡음, −31 dB), "만 배"·마지막 정리(4도 간격 화음) |

## 단순화·설명 모형 (화면에는 각주 없음)

- **지진 규모**는 지진계 진폭으로 정의한 리히터식 설명입니다(모멘트 규모는 다루지 않음). 지진계 기록의 모양은 만든 모양(같은 모양을 높이만 바꿈)이고, 칸 안의 시간축은 실제 시간이 아닙니다. 훅의 "화면 10개 높이"는 규모 3 기록을 19.2 px로 그렸을 때의 비례입니다.
- **에너지 약 32배**는 10^1.5 = 31.6의 반올림. 그림으로는 보여 주지 않았습니다.
- **들리는 크기 약 8배**(10 dB마다 약 2배)는 어림 규칙입니다.
- **pH 상자**의 알갱이 개수(1 · 10 · 100)는 "몇 배인지"만 나타낸 그림입니다. 실제 물 한 방울 속 수소 이온 수가 아닙니다. 이온 농도·몰 단위는 다루지 않습니다. 화면 표기 "수소 이온 H⁺ — 산성을 만드는 알갱이". 식초는 약 3(실제 2.4~3.4).
- **pH 띠 색**은 만능 지시약 색을 흉내 낸 설명용 색입니다.
- **개미 약 3 mg, 코끼리 약 6 t**는 대표값입니다.
- **더하기 자 대비**: 들릴락 말락 한 소리(0 dB)의 세기를 1 mm로 그린 경우. 달까지 평균 거리 384,400 km로 계산(2.6배).
- **수모형**은 정확한 개수로 그렸습니다(십모형 = 낱개 10개 막대, 백모형 = 10×10 판, 천모형 = 10×10×10). 경사 투영(깊이 0.36배). 장면마다 낱개 크기가 다릅니다(자 12 px, 소리 9 px, 오해 11 px, 식초 비교 5.6 px).
- **로그 표기**는 본질 장면에 한 번만 작게 "log₁₀ 1000 = 3"으로 나옵니다. 이름의 뿌리(logos 비율 + arithmos 수, 1614 존 네이피어)는 카드로만 보여 줍니다.
- **데시벨 카드**: 1 벨 = 10 데시벨은 정의입니다. "벨"이 알렉산더 그레이엄 벨의 이름에서 왔다는 것은 brief의 기원 메모를 따랐습니다.
- **소리 크기**는 위 표처럼 압축했습니다. 화면의 ×10·×1000은 물리량의 비이고, 귀로 듣는 효과음의 크기 차는 그보다 훨씬 작습니다.

## 화면 구성

모든 요소는 x = 540 중심(머리글 가운데 정렬), 중요한 글자는 x 140–940, 핵심 내용 y ≤ 1340, 자막 기본 위치, 각주·출처 줄 없음.
전 구간 0.2–0.35 s 간격 자동 점검(스크래치 스크립트, `stage.text` 호출 기록): 24 px 미만 글자 0건, x 58–942 밖 글자 0건, y 1340 아래 글자 0건(자막 제외), 글자끼리 겹침 0건(머리글은 옛 줄이 먼저 사라진 뒤 새 줄이 나타나고, 장면 끝에서 내용과 함께 흐려짐).
화면 밖으로 뻗는 것은 의도한 두 가지(코끼리 막대, 더하기 자 화살)뿐입니다.
