# 에피소드 `fission-fusion` — 핵분열과 핵융합 (쪼개도 합쳐도 에너지가 나오는 까닭)

"쪼개든 합치든, 원자핵이 더 단단히 묶이는 쪽으로 가면 줄어든 질량만큼 에너지가 나옵니다." 165.45초, 1080×1920, 30 fps, 테마 `{base: 'graphite', accent: '#FFB547'}`, 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음). 완성본 번호 29(`docs/TOPIC_BACKLOG.md`).

**2026-11-07 재제작: 시리즈 화풍.** 첫 완성본(3D 명암 구, 화면 공간 블룸, 텍스처 배경, 분홍·보라 플라스마)을 본 사용자 피드백 "너무 애니메이틱 한데??? 느낌이 다르잖아 여태 만들것들에서"에 따라, 모형·대본·내레이션·시간 계획은 그대로 두고 그림만 시리즈 도식 화풍([ANIMATION_QUALITY](../../docs/ANIMATION_QUALITY.md) '2026-11-07 후속 결정: 시리즈 화풍은 지킨다')으로 다시 그렸습니다. 원자폭탄 편과 같은 흑연색 배경(옅은 색 빛 + 비네트), 테두리 없는 무광 핵자 구(양성자 주황·중성자 회색, 깊이는 밝기로만), 가는 선(1.5~3 px), 작은 빛 점과 짧은 꼬리의 중성자, 축·눈금이 있는 그래프, 따뜻한 강조색 하나(#FFB547, 융합)와 차가운 보조색 하나(#86D0FF, 분열). 블룸·그레인·광택 반사·텍스처 없음. 다이내믹함은 화면을 채우는 도식, 카메라 이동, 2~4초마다의 사건(흰 섬광 + 퍼지는 가는 충격 고리), 큰 숫자로 냅니다. 사용자는 정지화면 시안(0·69.8·77·116초)을 보고 승인했습니다("훨씬 좋구만").

## 소리 (`--emit-sound`)

분열 → 낮은 쿵(55~62 Hz), 융합 → 따뜻한 화음 부풂, 중성자 → 지나가는 바람 소리, 원자로 → 세대마다 분열 틱(k = 1이면 일정한 박자) + 낮은 웅웅, 골짜기 → 내려간 높이만큼 내려가는 음(융합 330 → 110 Hz, 분열 196 → 147 Hz), 온도 → 로그 음높이, 토카막 → 낮은 맥동, 식음 → 음이 내려가며 꺼짐. 모든 기본음 700 Hz 미만, 패닝 없음. 설명용 합성음(녹음 아님).

## 단순화

핵자는 구슬이 아니며 크기·색·배치는 설명용입니다. 액체방울 분열, 원자로 개체 수, 토카막 자기장·입자는 설명 모형입니다. 골짜기는 실측 B/A(그래프의 점)를 부드럽게 이은 곡선을 위아래로 뒤집어 그린 것입니다. 쿨롱 언덕 그래프는 모양만 보인 설명 모형입니다. 체렌코프 빛은 물에 잠긴 연구용 원자로와 사용후연료 저장조에서 실제로 보이는 현상입니다. 화면에 각주는 없습니다.
