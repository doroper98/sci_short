"쪼개든 합치든, 원자핵이 더 단단히 묶이는 쪽으로 가면 줄어든 질량만큼 에너지가 나옵니다." 165.45초, 1080×1920, 30 fps, 테마 `{base: 'graphite', accent: '#FFB04A'}`, 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(고치지 않음). 완성본 번호 29(`docs/TOPIC_BACKLOG.md`).

**영상미 기준(2026-11-07 사용자 피드백 "다이내믹함과 비주얼함을 높여야 해")을 처음 적용한 편입니다.** 화면 전체를 쓰는 배경(태양 플라스마, 원자로 물의 푸른 빛, 빛줄기가 내리는 어두운 실험실), 3D 명암을 넣은 핵자 구(미리 그린 구 스프라이트 + 테두리 빛 + 반사광), 화면 공간 블룸(¼ 해상도, 대비 문턱 + 두 단계 흐림, 가산 합성), 계속 움직이는 카메라, 적은 이름표와 큰 숫자.

## 소리 (`--emit-sound`)

분열 → 낮은 쿵(55~62 Hz), 융합 → 따뜻한 화음 부풂, 중성자 → 지나가는 바람 소리, 원자로 → 세대마다 분열 틱(k = 1이면 일정한 박자) + 낮은 웅웅, 골짜기 → 내려간 높이만큼 내려가는 음(융합 330 → 110 Hz, 분열 196 → 147 Hz), 온도 → 로그 음높이, 토카막 → 낮은 맥동, 식음 → 음이 내려가며 꺼짐. 모든 기본음 700 Hz 미만, 패닝 없음. 설명용 합성음(녹음 아님).

## 단순화

핵자는 구슬이 아니며 크기·색·배치는 설명용입니다. 액체방울 분열, 원자로 개체 수, 토카막 자기장·입자는 설명 모형입니다. 골짜기는 실측 B/A를 부드럽게 이은 곡선을 입체 띠로 그린 것입니다. 체렌코프 빛은 물에 잠긴 연구용 원자로와 사용후연료 저장조에서 실제로 보이는 현상입니다. 화면에 각주는 없습니다.
