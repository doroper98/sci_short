## 기원·배경

- 1938년 12월 오토 한·프리츠 슈트라스만: 중성자를 쏜 우라늄에서 바륨 검출. 1939년 1~2월 리제 마이트너·오토 프리시가 해석하고 생물학의 세포 분열(binary fission)에서 'fission'을 빌려 옴(프리시가 생물학자 윌리엄 아널드에게 물음).
- 1920년 아서 에딩턴: 애스턴의 질량 측정(헬륨 핵이 수소 핵 4개보다 약 0.7% 가벼움)을 근거로 별이 수소를 헬륨으로 바꿔 빛난다고 제안. 1938~39년 베테가 별의 핵융합 과정을 설명.
- 한국 전기: 2024년 원자력 발전량 188.8 TWh, 총발전량의 31.7%(산업통상자원부 '2024년 에너지 수급 동향', 2025-05-11) → 대본 "약 30퍼센트".
- 태양: 초당 약 426만 톤의 질량이 에너지로(광도 3.828×10²⁶ W ÷ c²) → "400만 톤이 넘는".
- KSTAR(한국핵융합에너지연구원): 2023-12~2024-02 실험에서 이온 온도 1억 도 48초(2024-03 발표), H-모드 102초. 화면에 "2024 발표" 키커.
- ITER(프랑스 카다라슈): 2024-07 새 일정 — 연구 운전 시작 2034, 중수소·삼중수소 운전 2039 → 대본 "2030년대에 본격적인 실험".
- 출처: Wikipedia "Nuclear fission"(발견·명명), "Arthur Eddington", "Nuclear binding energy", "Cherenkov radiation", "KSTAR", "ITER"; 산업통상자원부 보도(2025-05-11); Live Science 2024-03 KSTAR; World Nuclear News 2024-07 ITER baseline; NASA Sun fact sheet.

## 본질(제1원리)

- 결합 에너지: 핵자를 묶는 강한 힘. 더 단단히 묶인 핵은 구성 핵자 질량의 합보다 가볍다(질량 결손) → ΔE = Δm·c².
- 핵자당 결합 에너지 곡선: 철·니켈 근처(약 8.8 MeV)가 꼭대기. 시각화는 **거꾸로 뒤집은 '골짜기'**(핵자당 질량, 철이 골짜기 바닥) — 가벼운 핵은 왼쪽 비탈에서 합쳐지며 굴러 내려가고, 무거운 핵은 오른쪽 비탈에서 쪼개지며 굴러 내려간다. 내려간 높이 = 나온 에너지. 이 골짜기가 이 편의 '지도'.
- 분열: U-235 + n → U-236(들뜬 상태, 물방울처럼 출렁) → 두 조각(예: Ba-141 + Kr-92) + 중성자 2~3개 + 약 200 MeV(질량의 약 0.09%).
- 연쇄와 제어: 분열당 평균 2.4개 중성자 중 정확히 1개가 다음 분열을 일으키게(k = 1). 제어봉(붕소·카드뮴 등)이 중성자를 흡수.
- 체렌코프 빛: 물속에서 빛의 속도(물속 약 0.75c)보다 빠른 전자가 내는 푸른 빛 — 물에 잠긴 연구용 원자로·사용후연료 저장조에서 보임(관측 사실).
- 융합: D + T → He-4(3.5 MeV) + n(14.1 MeV) = 17.6 MeV(질량의 약 0.38%). 쿨롱 장벽 때문에 약 1억 도 필요. 질량당 약 4배(D-T 대 U-235).
- 토카막: 도넛 모양 진공 용기, 감은 자기장(나선)으로 플라스마를 벽에서 띄워 가둠.
- 오해: "핵융합 발전소도 폭발할 수 있다" → 플라스마 속 연료는 1그램 미만(ITER 기준), 가둠이 흐트러지면 몇 초 안에 식어 반응이 멈춤. 연쇄 반응이 아님.

## 모형(제안 — 구현자가 판단해 조정)

- 원자핵 그리기: 핵자 구(sphere)를 피보나치 나선 배치 + 약간 무작위, 깊이 정렬, 한쪽 빛 + 테두리 빛, 전체에 블룸. 액체방울 변형: 구 → 타원체 → 땅콩(두 구의 합) → 두 조각, 표면 출렁임은 몇 개의 구면 조화 진동으로.
- 결합 에너지 곡선: 실측 B/A 값(H-2 1.11, He-4 7.07, C-12 7.68, O-16 7.98, Fe-56 8.79, Ni-62 8.79, Kr-92 8.51, Ba-141 8.33, U-235 7.59 MeV 등)을 이은 부드러운 곡선을 골짜기로 뒤집어 2D 선 그래프(축·눈금·실측점)로 그림. 굴러 내려간 높이(MeV/핵자)를 큰 숫자로.
- 연쇄·제어: 노심 격자 위 중성자 개체 수 모형(k를 제어봉 위치로 조절), 화면의 빛줄기 수와 큰 숫자가 같은 값.
- 토카막: 토러스 매개변수 곡면 + 나선 자기장 선(안전 계수 q≈3 정도의 감김) + 플라스마 입자 수천 개(자기장 선을 따라 돎, 가산 합성), 카메라 궤도 회전.
- 체렌코프: 푸른 가산 빛 + 물결 굴절 무늬(사인파 잡음) + 기포 입자.

## 소리 이벤트

- 배경음악 없음. 모든 기본음 700 Hz 미만.
- 분열: 중성자 도착 틱 → 출렁임(낮은 떨림) → 끊어짐의 둔한 쿵 + 짧은 저역 잡음. 연쇄: 분열 수에 맞춘 틱 밀도(k=1이면 일정한 박자).
- 체렌코프·원자로: 낮고 고요한 웅웅거림(물속 느낌).
- 융합: 반발에 튕길 때 둔한 툭, 붙을 때 밝지 않은 저역 '팡'(700 Hz 미만).
- 토카막: 회전에 맞춘 느린 맥동 저음, 꺼질 때 음이 내려가며 사라짐.
- 골짜기: 굴러 내려가는 높이에 맞춰 내려가는 음.

## 단순화 메모

- 원자핵 크기·핵자 배치·색은 설명용(핵자는 실제로 구슬이 아님). 액체방울 모형은 설명 모형.
- 골짜기 곡선은 실측 B/A를 부드럽게 이은 것(점이 실측값). 쿨롱 언덕 그래프는 모양만 보인 설명 모형.
- 토카막 자기장 감김·플라스마 입자는 설명 모형(KSTAR·ITER 실제 형상 아님).
- 체렌코프 빛은 연구용 원자로·저장조에서 실제로 보이는 현상.
- 시간 배율(분열은 실제 10⁻²¹~10⁻¹⁴초 수준)을 키커에 선언.
- 소리는 설명용 합성음.
- 화면에 각주 없음.
