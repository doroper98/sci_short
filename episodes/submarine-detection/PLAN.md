## 0. 합격 기준 (모든 장면)

기준 문서: `docs/ANIMATION_QUALITY.md` 맨 위 결정 절(문법 여덟 가지). 본보기 코드: `episodes/sar/scenes.mjs`(구조·도우미·소리 내보내기), 화면: `samples/look-proposal-radar/stills.jpg`.

1. **움직이는 것은 전부 사슬의 고리다.** 장식 입자, 출렁이는 물결, 뜻 없는 카메라 이동, 깜박임을 넣지 않는다. 수면선은 정지.
2. **같은 시계.** 신호가 닿는 프레임에 계기가 반응하고 숫자가 뜬다. 모든 시각은 `plan(tl)` 한 곳에서 계산하고 그림·계기·소리가 그것을 읽는다. 숫자를 코드에 박지 않는다(낱말 기준점에서 계산).
3. **조건 하나를 바꿔 잔상으로 비교.** 앞 결과(옛 음선, 옛 기록선, 옛 점)는 흐린 점선·흐린 선으로 남긴다. 비교 중에는 카메라 고정.
4. **빛나는 것은 신호뿐.** 소리 파면·음선, 레이더 전파, 부표의 무선, 계기의 선만 Glow 버퍼로 빛난다. 잠수함·초계기·군함·헬리콥터·부표는 **면과 명암이 있는 무광 덩어리**(위가 밝고 아래가 어두운 그라데이션 + 가는 윗선 하이라이트). 윤곽선만으로 그리지 않는다. 신호에 맞는 순간만 0.25초쯤 그 색으로 물든다.
5. **색의 역할(전편 고정).** 난색 `#FFB454` = **잠수함에게서 온 것**(잠수함이 내는 소리, 잠수함에 맞고 돌아온 메아리, 자기장의 흐트러짐, 계기에 찍힌 탐지). 한색 `#8CD9FF` = **찾는 쪽이 내보낸 것**(쏜 소리, 레이더 전파, 부표의 무선). 지구 자기장 선·눈금·지시선은 무채색에 가까운 `#9FC3CF` 저알파.
6. **무대 하나.** 바다를 옆에서 자른 단면. 세계의 자와 계기의 자는 같은 자(계기의 가로축 = 세계의 가로 위치, 같은 원점·축척, 필요하면 점선으로 이음).
7. **시간 배율은 키커에 선언**(아래 장면표의 키커 그대로).
8. **글자는 셋**(머리글, 큰 숫자 하나, 계기 눈금) + 사슬의 고리에 붙는 짧은 이름표(장면표에 적힌 것만). 문장을 화면에 쓰지 않는다. 24 px 미만 글자 금지.
9. 2초 넘게 아무 고리도 움직이지 않는 구간 금지. 내레이션이 길면 사슬을 한 번 더 돌린다(펄스 반복).
10. 쇼츠 안전 영역: 핵심 물체·글자는 x ≤ 940, y ≤ 1340(자막은 그 아래). 배경(물)은 화면 끝까지 채운다.
11. 금지: 3D 질감·광택·노을 하늘·화면 전체 빛 번짐·흰 번쩍·화면 흔들림·캐릭터·의성어·이모지. 실제 기종·국적 표식.

## 2. 시간표와 낱말 기준점

- `tl.wordStart(sid, '낱말')`은 **`tts`(발음용) 글자열**에서 찾는다. 숫자가 있는 문장은 `script.json`의 `tts` 표기('천오백미터를', '이초', '팔분의')로 찾는다.
- `plan(tl)`(scenes.mjs → kit 또는 각 장면 모듈)이 `P.sc[장면id] = {start, end}` 와 낱말 기준점을 계산해 `WeakMap`으로 캐시한다(`episodes/sar/scenes.mjs` 100행의 방식). 장면 모듈마다 `planCore(tl, P)`, `planIntro(tl, P)`, `planAir(tl, P)` 를 내보내고 `scenes.mjs`의 `plan(tl)`이 차례로 불러 한 객체 `P`에 채운다.
- 낱말이 `tts`에 없으면 `wordStart`가 오류를 낸다. 그때는 그 문장의 `tts`를 `outputs/submarine-detection/narration/timeline.json`에서 읽어 실제 낱말로 맞춘다(대본은 고치지 않는다).

### 3.2 카메라와 세계 좌표

세계 좌표: `X`(m, 오른쪽 +), `Z`(m, 수면에서 아래 +, 하늘은 음수). 화면: `sx = cam.x0 + (X − cam.X0)·cam.kx`, `sy = cam.surfY + Z·cam.kz`.
장면마다 카메라 상수가 다르다(아래 장면표). **물체(잠수함·비행기·배·헬리콥터·부표)는 세계 축척과 무관한 화면 크기로 그린다**(크기 과장). 신호는 물체의 기준점(소나, 마이크, 선체 중심, 꼬리 막대 끝)에서 나오고 닿는다.

장면 전환: 하늘·바다 배경은 끊기지 않는다. `surfY(t)`만 장면 경계 앞뒤 0.5초씩(총 1.0초) `easeInOut`으로 이어 움직이고, 장면의 배우·신호·계기는 경계 앞 0.35초 동안 사라지고 뒤 0.35초 동안 나타난다(알파). 하드컷 금지.

### 3.5 신호 그리기 (Glow 버퍼 2개: `GW` 난색, `GC` 한색)

매 프레임 `begin()` → splat → 장면 끝에서 `flush(stage, {gain: 1.25, bloom: 0.38})`. splat 은 신호가 있는 자리에만.
- **원형 파면** `ringWave(G, cx, cy, r, {col, amp, crests = 3, gap = 16, a0, a1, clip})`: 반지름 `r − gap·j`(j = 0..crests−1, 세기 1, 0.6, 0.32)를 호 길이 약 7 px 간격으로 splat(반지름 6). `a0, a1`(각도 범위)로 부채꼴만, `clip(x, y)`가 false 면 버린다(수면 위로 나간 소리는 그리지 않는다: `y < surfY` 는 버림).
- **빔 펄스**(레이더) `beamPulse(G, from, to, q, {col, amp})`: from→to 직선 위 진행률 `q`의 자리에, 진행 방향에 수직인 짧은 호 3줄(폭 ±0.16 rad).
- **음선**: 4절의 `traceRay` 결과(세계 좌표 점열)를 화면으로 옮겨, 머리(현재 시각까지 간 자리)는 Glow splat, 지나온 길은 캔버스 선 1.6 px(색 알파 0.5).
- 맞는 순간: 대상 물체의 `lit`을 0.25초 동안 1 → 0.

## 4. 모형 (model.mjs — 그림·계기·소리가 함께 읽는 값)

### 4.1 소리 빠르기와 음선

```js
export const SSP = {Z1: 60, Z2: 140, C0: 1520, G: 0.017, C2: 1497};      // m, m/s, 1/s
// c(z): z < Z1 → C0 + G·z (혼합층, 1521.02 at 60 m) ; Z1 ≤ z < Z2 → 선형으로 1521.02 → 1497 (수온약층) ; z ≥ Z2 → C2 + G·(z − Z2)
export function c(z) …;  export function dcdz(z) …;
// 음선: θ 는 수평에서 아래쪽 +. dθ/ds = −(c′(z)/c(z))·cos θ (느린 쪽으로 휜다). 중점법, ds = 4 m. z < 0 이면 수면 반사(z → −z, θ → −θ).
```

### 4.4 자기 이상

- 단면은 동서 방향으로 자른 것으로 본다(단면 안의 지구 자기장 방향 = 세로). 선체는 그 방향으로 자화된 쌍극자 하나.
- 기록선: `S(x, d) = ((3d²/r²) − 1)/2 · (d0/r)³`, `r² = x² + d²`, `x` = 잠수함 바로 위에서 잰 가로 거리, `d` = 지나가는 높이에서 잠수함까지의 세로 거리, `d0` = 낮게 지날 때의 `d`. `S(0, d0) = 1`, `S(0, 2·d0) = 1/8`, 0 이 되는 자리 `x = ±√2·d`.
- 휜 자기장 선(그림용): `B = B0·ẑ + (M/r³)(3(ẑ·r̂)r̂ − ẑ)`(화면 px 단위, `M = 0.6·110³`, 즉 r = 110 px 에서 쌍극자 세기가 B0 의 0.6배), `r < 70 px` 에서는 `r = 70` 으로 고정. x = 60, 140, …, 1020 에서 위에서 아래로 흐름선을 적분(스텝 4 px). 선 위의 점에서 `|B_dip|/B0 > 0.06` 인 구간은 난색(알파는 그 비에 비례, 최대 0.9), 나머지는 `PAL.field` 알파 0.16.

- `wd(s21,'디젤') − 0.2`부터 1.6초: 잠수함이 `(700, 716)`으로 올라온다(함교탑 꼭대기가 수면 아래 20 px). `wd(s21,'관만') − 0.5`부터 0.6초: 관이 올라와 수면 위 46 px 까지(`mast` 0 → 1, 수면을 뚫는 프레임에 무채색 작은 고리). 관이 다 올라온 프레임부터: 관을 따라 아래로 내려가는 무채색 짧은 점 3개(공기, 0.5초 주기) + 계기 띠 왼쪽 칸 `배터리` 막대 20% → 80%(장면 끝까지).
- `tM = wd(s21,'레이더에') − 1.5`: 초계기 기수에서 한색 빔 펄스가 관 끝으로 0.7초 → 닿는 프레임에 관이 한색으로 물듦 → 난색 메아리 0.7초 → 도착 프레임(≈ '레이더에')에 계기 띠 오른쪽 칸 `레이더 화면`의 관 x 에 난색 봉우리(높이 80). `tM + 2.2`에 한 번 더(봉우리가 다시 솟음). 수면에 닿은 전파의 번짐(6.1)은 관 옆 수면에 작게. 물속 선체는 물들지 않는다.

### 6.9 close (s23) — surfY 640

- 키커/제목: `정리` / `숨길 수 없는 흔적`. `P.poster − 0.3`부터 머리글이 사라진다.
- 배우: 잠수함은 mast 장면의 자리 `(700, 716)`에서 이어진다(관이 나온 채). 군함(길이 220, 뱃머리 오른쪽) x 170 이 장면 시작에 0.4초에 나타난다.
- 계기 띠: 네 칸(각 폭 200, x 100/310/520/730 시작), 칸 이름 `듣기 · 메아리 · 자기장 · 레이더`(24 px). **장면 시작(직전 문장 뒤 쉼)부터 0.55초 간격**으로 네 칸에 난색 작은 기록(파형 / 봉우리 / 혹 / 봉우리)이 차례로 생기고 남는다. 각 칸이 켜지는 프레임에 세계에서도 그 사건이 한 번 일어난다: ① 잠수함 꼬리의 난색 파면이 군함 소나에 닿음 ② 군함의 한색 파면(760 px/s)이 잠수함에 맞고 난색 메아리가 돌아옴(이 칸은 메아리가 닿는 프레임에) ③ 휜 자기장 선의 난색 구간이 0.6초 나타남 ④ 관에 맞은 레이더 메아리(6.8의 마지막 펄스가 이어져도 됨). 시간이 모자라면 ①③④를 먼저 맞추고 ②는 메아리 도착 시각에 맞춘다.
- s23: `wd(s23,'가려도') − 0.4`부터 관이 내려가고 잠수함이 `(690, 1000)`으로 가라앉으며 `dim` 0.92 까지(1.6초). 난색 파면은 계속 나오고, `wd(s23,'소리와')`부터 휜 자기장 선의 난색 구간이 다시 나타난다(알파 0.7). `P.poster`부터 포스터 구도: 초계기 `(300, 430)`, 부표 `(880, 640)`와 마이크, 제목 판(6.1의 0초와 같은 그림, 잠수함 `dim 0.45`).

## 8. 작업 순서

1단계(작업자 A): `glow.mjs` 복사 → `model.mjs`(4절 검증값 확인) → `kit.mjs` → `scenes_core.mjs`(layer 먼저, 그다음 sonar) → `scenes.mjs`(나머지 장면은 배경과 머리글만 그리는 임시 함수) → `--emit-sound` → 정지화면.
2단계(작업자 B·C, 동시에): B 는 `scenes_intro.mjs`, C 는 `scenes_air.mjs`. `kit.mjs`·`model.mjs`에 더할 것이 있으면 **함수를 새로 더하기만** 하고 있는 함수의 동작은 바꾸지 않는다(서로의 장면이 깨지지 않게). `scenes.mjs`에는 자기 모듈을 잇는 줄만 고친다.
3단계(제작 세션): 정지화면 검수·수정 지시 → 전체 렌더 → 마감·검증.

## 9. 작업자 자체 점검과 보고

- `--stills` 뒤 contact sheet 와 사건 시각의 정지화면을 **직접 열어 본다**. 한글 깨짐, 겹침, 안전 영역, 빈 화면(세계의 절반 이상이 비었는가), 사슬의 순서, 계기와 세계가 같은 프레임에 반응하는가.
- 보고서(짧게): 만든 파일, 계획과 다르게 한 곳과 이유, 4절 검증값, 직접 본 정지화면에서 고친 것, 남은 문제, 확인하지 못한 것.
