# 에피소드 `twinkle` — 별은 왜 반짝일까 (반짝임은 공기가 만든다)

"반짝임은 별이 아니라 우리 머리 위의 공기가 만든다. 별은 점이라 흔들리고, 달과 태양은 넓어서 흔들림이 평균된다." 175.7초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
**모형 하나가 화면·그래프·소리를 함께 움직입니다.** 얼어붙은 흐름(frozen flow)으로 바람에 실려 가는 난류 위상 화면 하나에서 땅 위의 밝고 어두운 무늬, 7 mm 눈동자에 들어오는 별빛 밝기, 행성·달 원반의 평균, 지평선 근처의 세기, 시리우스의 색 깜빡임, 그림자 띠, 적응광학의 별 상까지 모두 계산합니다.

## 모형 (화면·계기·소리가 같은 값을 씀)

| 양 | 식 / 값 |
|---|---|
| 위상 화면 φ | 시드 고정 복소 백색잡음 W(k)를 1024×1024 주기 격자(256 cm × 256 cm, 칸 0.25 cm)에서 FFT로 성형. 폰 카르만 스펙트럼 \|φ̂\| ∝ (k² + k₀²)^(−11/12), 외부 규모 1 m, 내부 규모 1 cm. 층 높이 H = 5 km |
| 땅 위 무늬 χ | 얇은 위상 화면의 Rytov 필터 χ̂ = sin(k² r_F²/2)·φ̂, r_F = √(λH/2π) = 2.09 cm (λ = 550 nm) → 수 cm 크기의 밝고 어두운 무늬. 분산 1로 정규화 |
| 밝기 | I = exp(s·χ − s²/2) (로그정규, 평균 1). 세기 s = 1.15·tanh(0.30·X^1.5/1.15), X = 공기량(Kasten–Young). 천정 σ_I ≈ 0.30, 45° 0.53, 9° 1.6(포화) |
| 공기 덩어리 POCK | 같은 φ를 고역 통과(약 10–40 cm) → 단면 그림의 따뜻한(주황)·찬(파랑) 덩어리. 양(+) = 찬 공기 = 굴절률 큼. 단면의 빛줄기는 POCK의 기울기로 굽힘(굴절률 큰 쪽으로), 땅의 밝기는 그린 빛줄기와 같은 계산의 520개 광선 밀도 |
| 바람 | 3 m/s, 방위 4°(눈동자가 주기 격자를 같은 길로 다시 지나지 않게 조금 비스듬히). 무늬 전체가 그대로 흘러감(frozen flow) |
| 화면 속도 | 계기 장면(본질·덩어리·점과 원반·사례) **실제의 1/20**(무늬 15 cm/s), 하늘 장면 **0.15배 + 눈의 적분 시간 0.03 s 평균**(하늘에서 2~3 Hz로 반짝임). s08의 "실제 속도 · 1초" 막대는 같은 신호를 실제 빠르기로 그림 → 이 모형에서 1초에 **21번** 밝아짐("수십 번") |
| 눈동자 | 지름 7 mm. 별 밝기 = χ를 7 mm 원반으로 평균(FFT의 Airy 필터 2J₁(kR)/(kR))한 값으로 계산. 땅 무늬 그림에서 눈동자는 실제 축척(링으로 강조) |
| 원반 평균 | 원반의 각 점은 같은 무늬를 H·θ만큼 옮겨 만듦 → 밝기 = I를 지름 H·θ 원반으로 평균(FFT). 별 0.005″ → 0.012 cm(평균 없음), 목성 40″ → 지름 97 cm, 달·태양 1,900″ → 지름 46 m. 결과: σ_I 별(45°) 0.53, 목성 0.011, 달 0.00004 |
| 가장자리 일렁임 | 달 가장자리 각 점의 빛이 층을 지나는 곳(2.3 m 반지름 원 위)의 POCK 기울기 = 도달각 → 가장자리 반지름 방향 변위(×16 과장, 이웃 6° 평균) |
| 색 깜빡임 | 대기 분산으로 빨강·초록·파랑 경로가 층에서 0.6 cm·tan z/cos z(최대 40 cm)만큼 떨어짐 → 높은 별(57°)은 세 색이 함께, 9°의 시리우스는 24 cm 떨어져 따로 출렁(상관 −0.02) |
| 그림자 띠 | 실처럼 가는 초승달 = 길이 600 cm·폭 1 cm 선 발자국으로 I를 평균(FFT, sinc × 가우스) → 한 방향으로만 평균되어 줄무늬. 모형 명암 σ 4.7 %, 화면 4배 과장 |
| 적응광학 | 지름 50 cm 범위의 POCK을 4 rad/σ 위상으로 쓴 28칸 동공 → 64² FFT로 별 상(PSF) 계산. 변형 거울 = 10×10 구동기(칸 평균, 쌍선형). 가운데 밝기(Strehl 비슷한 값) 보정 전 0.02–0.04 → 보정 후 0.25–0.34 |
| 산꼭대기 | 위에 남은 난류가 적다는 모형값: s × 0.5 (σ_I 0.53 → 0.26). 허블 = 공기 없음(일정) |

머리글은 가운데 정렬, 장면 안 전환은 이전 줄이 사라진 뒤 새 줄이 나오는 순차 교체(origin·cells·point 한 번, horizon 두 번, use 한 번). 화면에 각주·출처 줄 없음.

## 단순화·설명 모형 (화면에는 각주 없음; 화면의 과장 표시는 "대기 두께는 크게 과장", "꺾이는 정도는 크게 과장", "그림의 꺾임은 크게 과장", "각도 크게 과장", "가장자리만 일렁임 (크게 과장)", "(크게 과장)", "명암 크게 과장", "화면은 느리게", "느린 화면 · 실제의 1/20 속도"뿐)

- **위상 화면은 하나의 얇은 층(5 km)**으로 둔 모형입니다. 실제 대기는 여러 높이의 층이 서로 다른 바람으로 흐르고, 무늬가 시간에 따라 변하기도 합니다(완전한 frozen flow가 아님). 스펙트럼 모양(폰 카르만, Rytov 필터)은 표준 약한 섬광 이론을 따르지만 세기 s(고도)는 화면용 모형값입니다(천정 σ_I 0.3, 포화 1.15). 강한 섬광의 포화·초점 무늬(caustic) 세부는 다루지 않습니다.
- **로그정규 밝기** exp(sχ − s²/2)는 점에서의 통계를 맞추는 근사이며 넓은 면적의 에너지 보존을 정확히 지키지는 않습니다(주기 격자 전체 평균은 1로 맞춤).
- **단면 그림(본질·덩어리·점과 원반·사례)**의 덩어리 크기·층 두께·굽는 각도는 모두 과장한 모식입니다. 실제 굽음은 각초 수준입니다. 단면의 땅 밝기 줄은 그린 광선과 같은 계산의 광선 밀도이고, "위에서 본 땅" 평면은 2차원 χ 무늬라 두 그림이 칸칸이 일치하지는 않습니다(같은 φ에서 나온 두 그림).
- **단면 덩어리의 높이 방향**: 2차원 위상 화면의 한 단면을 세로로 펼쳐 그린 것입니다(덩어리 모양을 보이기 위한 그림).
- **화면 속도**: 실제 반짝임은 수십 Hz(이 모형 1초 21번)라 30 fps 화면으로 그대로 보일 수 없습니다. 계기 장면은 1/20, 하늘은 0.15배로 늦추고 하늘은 눈의 반응 시간(0.03 s 실시간)만큼 평균했습니다. 소리는 각 화면과 같은 시간 척도를 따르고, s08의 1초만 실제 속도(빠른 떨림)입니다.
- **하늘의 별·은하수는 화면용 무작위 배경**(별 목록 아님)이며 은하수 띠의 위치도 구도용입니다. 주인공 별, 목성, 초승달의 위치·크기도 구도용입니다(달은 실제 시직경보다 약 3배 크게, 지구조 포함). 목성의 밝기는 목성 원반(40″)의 계산값이라 그래프상 1 % 안팎만 출렁입니다. 배경 별의 색 깜빡임은 채도를 45 %로 줄여 그렸고 시리우스·렌즈는 그대로 그렸습니다.
- **점과 원반 장면**: 원반 위 19개(목성)·37개(달) 점과 9·15개 빛줄기는 계산한 원반 안의 표본을 보여 주는 것이고, 그래프의 행성·달 값은 원반 전체(연속) 평균입니다. 그림 크기(별·목성·달 칸)는 각지름 비율과 다릅니다(글자로 각지름 표시). 각초 값: 별 0.005″ 안팎, 목성 30~50″, 달 약 1,900″(31′).
- **지평선 장면**: 공기 경로 그림은 반지름 9,000 px 지구와 110 px 대기 껍질의 실제 기하(대기는 과장), 라벨의 배수는 Kasten–Young 공기량(57° 1.2, 9° 6.2). 색 경로의 갈라짐 각(±3.2°)은 크게 과장했고, 실제 층에서의 간격은 모형값 24 cm입니다. 파랑 경로를 위(높은 겉보기 고도)로 그린 것은 굴절이 파랑에서 더 크기 때문입니다.
- **개기일식**: 화면 시간에 맞춘 연출(초승달이 약 3초 만에 실처럼 가늘어짐). 그림자 띠는 대기 섬광 모형으로 계산했지만 이 설명은 "유력"한 것으로만 표시했습니다(완전히 결론 나지 않음 — brief). 선 발자국 길이(600 cm)는 모형값입니다.
- **사례 장면**: 높이·크기 축척 다름. 허블 궤도 고도(약 540 km)는 화면에 숫자로 쓰지 않았습니다. 산꼭대기 세기 ×0.5는 모형값입니다.
- **적응광학**: 적응광학이 지우는 것은 **파면의 흔들림(별 상의 번짐·흔들림)**입니다. 큰 망원경은 거울이 넓어(원반 평균과 같은 이유) 밝기 반짝임 자체는 이미 작습니다. 그래서 전후 비교는 밝기 그래프가 아니라 계산한 별 상(PSF)으로 보였고, 소리는 별 상의 가운데 밝기에 대응했습니다. 동공 위상 크기(4 rad/σ)와 구동기 10×10은 화면용이며 보정 후 상은 실제처럼 "선명한 중심 + 희미한 테"입니다. 거울은 실제 1초에 수백~천 번 바뀌지만 화면은 매 프레임(느린 화면) 바뀝니다.
- **궤도에서 본 지구**: `globe.mjs`의 생성 질감(위성 사진 아님), 구름은 잡음 모식, 태양 방향은 구도용.
- **뉴턴 인용**은 brief의 번역 요지이며 판본 연도는 쓰지 않았습니다.
