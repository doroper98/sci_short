# 에피소드 `gamma-ray-burst` — 감마선 폭발 (우주에서 가장 밝은 섬광)

"무거운 별이 무너지거나 중성자별이 부딪치는 순간, 좁은 제트에 몰린 빛이 몇 초 동안 우주를 가장 밝게 비춘다." 175.55초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
**모형 하나가 화면·계기·소리를 함께 움직입니다.** 폭발의 모형 빛 곡선과 에너지(태양 100억 년 치), Vela 위성의 도착 시각(평면 파면 Δt = −r·s/c), 광자 에너지와 대기 흡수 높이, 하늘 지도(등방 무작위 점 대 은하 원반 모형), 잔광의 적색이동(× 1.835)과 되돌아본 거리, 원뿔 반각 θ와 f = 1 − cos θ, 제트 속 덩어리의 충돌(운동량 보존), 주변 기체에 의한 감속과 잔광 곡선, 지속 시간 분포, 별의 붕괴와 제트 돌파 시간, 중성자별 처프(f ∝ τ^−3/8)와 1.74초 지연, GRB 221009A의 계수율·이온층, 무작위 제트 방향의 "보이는 비율"이 모두 `scenes.mjs` 머리의 순수 함수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·시간 계획) + 가산 부동소수 빛 버퍼(별·제트·섬광) + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/gamma-ray-burst/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/gamma-ray-burst/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/gamma-ray-burst/run.sh stills            # outputs/gamma-ray-burst/stills/
SKIP_NARRATE=1 episodes/gamma-ray-burst/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 빛 버퍼(`Glow`), 별 표면(`starGlow`), 머리글·포스터 제목, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`)는 퀘이사·에딩턴 한계 편에서 복사해 이 편에 맞게 고쳤습니다(에피소드 사이 import 없음). 빛 버퍼는 오로라·에딩턴·퀘이사에 이어 네 번째 사용이라 `pipeline/`으로 올릴 후보입니다(이번 범위 밖). 지구는 `pipeline/render/globe.mjs`의 `earthTextures`·`drawEarthLit`으로 그리되, 이 폴더에는 `scenes.mjs`·`sound.json`·`README.md`만 둘 수 있어 다른 편의 `land.json`을 복사하지 않고 **손으로 줄인 거친 해안선(경위도 꼭짓점 몇십 개씩)**을 `scenes.mjs`에 넣었습니다(색은 생성한 것, 위성 사진 아님).

## 단순화·설명 모형 (화면에는 각주 없음; 표식은 "모형", "모형 곡선", "설명 모형 · 화면 속도", "비교 모형", "모형 · 무작위 점", "모형 · 시간 압축", "모양만 (모형)", "높이 과장"뿐)

- **포스터 별·제트**: 무너지는 무거운 별의 바깥 모습과 두 제트는 그림입니다. 별 크기에 비해 제트 길이(별 반지름의 70배로 그림)·폭·밝기 비(다가오는 제트 1 : 멀어지는 제트 0.42), 돌파 자리의 코쿤은 화면용이고, 실제로는 빛에 가까운 제트의 도플러 효과로 다가오는 쪽이 훨씬 더 밝습니다. 제트 안 결 무늬는 바깥으로 흐르는 설명용 무늬입니다. 훅 줌은 크기의 연속성만 보여 주며 실제 거리 배율(10^3.6배)은 표시하지 않습니다.
- **에너지 비교**: 폭발 에너지를 빔 보정한 값의 대표값 1.2×10⁴⁴ J로 두어 태양 100억 년 치(1.21×10⁴⁴ J)와 같게 그렸습니다(문헌 범위 10⁴³~10⁴⁴ J). 폭발 막대는 모형 빛 곡선을 2배 빠르게 다시 재생해 쌓았습니다.
- **Vela**: 위성 넷을 한 궤도면(화면)에 90° 간격으로 둔 그림이며 실제 Vela 3·4 쌍의 위치가 아닙니다. 지구 크기는 궤도에 비해 크게(반지름 비 1:3, 실제 약 1:18.5) 그렸고, 시각 차는 같은 평면 안의 방향만 정합니다(실제는 3차원, 위성 쌍이 여럿 필요). 두 섬광 곡선은 모양을 보여 주는 모형입니다.
- **광자·대기**: 띠의 대표 파장, 물결의 화면 파장(로그로 줄임), 광자 막대 위 물결 묶음은 그림입니다. 흡수는 500 keV 하나의 감쇠 계수로 계산했고(컴프턴 산란을 "흡수"로 묶음), 높이 축은 로그로 압축했습니다. 우주 망원경의 실제 고도는 다양합니다("약 500 km"는 축 눈금). 초고에너지 감마선의 지상 간접 관측(공기 샤워)은 다루지 않습니다(대본 "주로").
