# 44번 구현 계획서 — GPT는 어떻게 배웠을까 (P)

공통 규칙·부품·파일 구조는 `episodes/gpt-generative/PLAN.md` 1~3절입니다(먼저 읽기). 부품은 `../gpt-generative/kit.mjs` 를 import 합니다. 이 문서는 44번의 모형·무대·장면입니다.

## 1. 모형 — `episodes/gpt-pretrained/model.mjs`

**실제로 배우는 아주 작은 모형**입니다(GPT 가 아님 — README 에 밝힘). 화면의 확률·다이얼·곡선은 모두 이 모형을 실제로 학습시킨 기록에서 나옵니다. 순수 계산만 하고, `node model.mjs` 로 확인 값을 찍습니다.

- 조각(읽기 쉽게 어절 단위, 약 25가지): `해는 달은 별은 비는 눈은 물은 동쪽에서 서쪽으로 밤에 낮에 구름에서 아래로 뜬다 진다 빛난다 내린다 흐른다 .`(이 18개가 앞) + 대화용 `질문: 대답: 어디에서 어디로 뜨나 지나 ?`.
- 공부할 글 `CORPUS`(아홉 문장, 각각 `.` 로 끝남): 해는 동쪽에서 뜬다 / 해는 서쪽으로 진다 / 달은 동쪽에서 뜬다 / 달은 서쪽으로 진다 / 별은 밤에 빛난다 / 해는 낮에 빛난다 / 비는 구름에서 내린다 / 눈은 구름에서 내린다 / 물은 아래로 흐른다.
- 대화 본보기 `DIALOG`(세 줄): `질문: 해는 어디에서 뜨나 ? 대답: 동쪽에서 뜬다 .` / `질문: 해는 어디로 지나 ? 대답: 서쪽으로 진다 .` / `질문: 달은 어디에서 뜨나 ? 대답: 동쪽에서 뜬다 .` 본보기에 없는 시험 질문: `질문: 달은 어디로 지나 ? 대답:` → 정답 `서쪽으로`.
- 식: `logit(next | 문맥) = c[next] + A[바로 앞][next] + B[그 앞][next] + 평균_{문맥의 모든 조각 w} C[w][next]`, 확률 = softmax. 숫자(매개변수)는 `3·V·V + V` 개(약 1,900).
- 처음 값: 씨앗 고정 정규 난수. 씨앗은 "해는 동쪽에서 [뜬다]"에서 `p(뜬다)` 가 2~6% 이고 엉뚱한 조각 하나가 20% 이상으로 맨 위가 되는 것을 찾아 고정합니다.
- 공부: 한 번에 자리 하나(그 자리의 정답 조각에 대한 −ln p 를 줄이는 경사 하강, 걸음 크기 η 고정). 첫걸음은 "해는 동쪽에서 [뜬다]", 그 뒤는 씨앗 고정 순서로 말뭉치의 모든 자리를 돕니다. η 는 첫걸음에서 `p(뜬다)` 가 1.3~2배(예: 4% → 6~7%)가 되게 고릅니다. 걸음 수 `N_PRE` 는 "해는 동쪽에서 → 뜬다"와 "해는 서쪽으로 → 진다"가 모두 0.9 이상이 될 때까지(수백~천여 걸음).
- 이어서 `DIALOG` 로 `N_TUNE` 걸음 더(같은 식, 같은 η). 시험 질문의 `p(서쪽으로)` 를 본보기 공부 전·후로 잽니다(뒤가 0.6 이상이어야 함 — 안 되면 본보기나 걸음 수를 조정하고 보고).
- 내보낼 것: `VOCAB`, `CORPUS`, `DIALOG`, `init`, `probs(params, ctx)`, `step(params, ctx, target, lr) → {params, pBefore, pAfter, grad}`(grad = 화면에 쓸 A 줄의 기울기), `TRACE[k] = {sent, pos, ctx, target, pBefore, pAfter}`, `CURVE`(걸음별 "말뭉치 전체 자리의 평균 정답 확률"), `SNAP`(장면이 쓰는 걸음의 params: 0, 1, `K_SMALL`, `N_PRE`, `N_PRE + N_TUNE`), `K_SMALL`(같은 예시에서 `pBefore ≥ 0.6` 인 가장 이른 걸음), `BIG`(아래), `rowA(params, piece)`(다이얼 18개 값 = `A[piece][앞 18조각]`).
- `BIG` — "크게 고치면": 공부 중간의 한 스냅숏에서 "해는 동쪽에서 [뜬다]"를 η 의 30배로 한 걸음 고쳤을 때, 이 글의 `p(뜬다)` 와 **다른 글 한 줄**의 정답 확률이 어떻게 바뀌는지(`{snapStep, other: {ctx, target}, pSelf: [before, after], pOther: [before, after], pOtherSmall: [before, after]}`). 다른 글은 "해는 서쪽으로 [진다]"부터 시험해 정답 확률이 가장 뚜렷이 **떨어지는** 스냅숏과 글을 고릅니다. 떨어지는 경우를 못 찾으면 그대로 보고합니다(지어내지 않음).
- 확인 출력: 숫자 개수, 씨앗·η, 초기 분포(위 4개 + 뜬다), 첫걸음의 4% → ?%, `K_SMALL` 과 그 걸음의 값, `BIG` 의 네 숫자, `N_PRE`·`N_TUNE`, 끝난 뒤 `p(뜬다 | 해는 동쪽에서)`·`p(진다 | 해는 서쪽으로)`, 시험 질문의 전·후 확률, `CURVE` 의 처음·끝 값.

## 2. 무대

- 글줄(세계): 첫 줄 y 300, 크기 48(대화 본보기는 40). 공부에 쓰는 글 조각은 `given`(한색), 가린 자리는 `cover`, 열린 정답은 `given` + `hi`.
- GPT 의 속(몸통): `{x: 110, y: 470, w: 860, h: 470}` 무광 몸통(kit `machine` 과 같은 면 처리로 이 편에서 직접 그림, 왼쪽 위에 작은 `GPT` 이름표). 그 안에 `dialGrid` 6×3: 첫 다이얼 중심 (215, 600), dx 130, dy 120, r 46. 다이얼 j = 조각 j 로 가는 숫자(`rowA(params, 가린 자리 바로 앞 조각)`).
- 계기: `probBars` y0 = 985, 5줄(엉뚱한 위 3개 + 정답 + 그 밖). 그 아래 y 1290 에 가로 `틀린 정도` 막대(−ln p, 눈금 0~4.6, `progressBar`). 빨리 감기·규모 장면에서는 막대 대신 `panel` 안의 `curve`(평균 정답 확률, 세로 0~100%)와 `axisTicks`(걸음 수).
- 0초 포스터 프레임: 글줄 "해는 동쪽에서 [가림막]"(위), 제목(가운데 — 그동안 몸통은 알파 0), 아래 `panel` 에 오르는 곡선. 제목이 줄어들며 몸통과 다이얼이 나타납니다. `POSTER = {q: ['GPT는 어떻게', '배웠을까?'], a: '다음 말 맞히기로', …}`.
- 색: 주어진 글 = 한색. GPT 가 매긴 확률·고쳐지는 바늘·거꾸로 가는 펄스 = 난색. 빛(Glow)은 **거꾸로 가는 펄스**와 **가림막이 열리는 순간의 정답**에만.
- 큰 숫자(한 번에 하나): 정답에 준 확률, 걸음 수, `1,750억 개`, `3,000억 조각`, `약 4,000년`.
- 시간 배율: 한 걸음을 보이는 장면은 느리게, 되풀이는 키커 "빨리 감기".

- 다이얼이 도는 프레임과 막대가 바뀌는 프레임이 같은가(같은 params 에서 계산).
