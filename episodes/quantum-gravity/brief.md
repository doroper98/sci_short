## 기원·배경

- **양자(量子, quantum)**: 라틴어 *quantus*("얼마나 많은") → *quantum*("얼마만큼"). 플랑크가 1900년 흑체 복사를 설명하며 에너지가 덩어리(최소 단위)로 오간다고 본 데서 물리 용어가 됐다. (대본에는 음절 예산 때문에 넣지 않음 — 설명란·README 에만.)
- **양자중력**: 중력의 이론(일반상대성이론, 1915)과 양자역학을 하나로 잇는 이론. 아직 확립된 것이 없다(s03).
- **왜 어려운가 ①**(s04): 양자역학의 계산은 고정된 시간·공간을 무대로 삼는데, 중력에서는 그 무대(시공간)가 스스로 휘고 요동한다 — 논문 서론의 "background independence".
- **왜 어려운가 ②**(s05·s06): 그래서 평평한 시공간 위의 작은 요동(중력자)으로 어림하면(섭동), 짧은 파장의 기여를 더할수록 발산한다 — 논문 서론 "loop corrections … lead to UV divergences that make the theory perturbatively nonrenormalizable [41]".
- **널(null) 원뿔**: 빛이 가는 길은 시공간 간격이 0(null)이라서 빛원뿔을 null cone 이라 부른다. 논문 제목의 'from the null cone'. 화면의 이름표로만("빛원뿔 null cone").
- **인과 다이아몬드(causal diamond)**: 앞 사건의 미래 빛원뿔과 뒤 사건의 과거 빛원뿔이 감싼 영역. 앞 사건의 영향을 받고 뒤 사건에 영향을 줄 수 있는 모든 점. 둘이 만나는 닫힌 면이 corner(모서리) — 대본에서는 "테두리".

"시공간을 빛의 길로 조각내어, 중력을 어림하지 않고 계산하면, 무한대가 사라진다는 것이 이 논문의 주장입니다." (s07 · s20 같은 문장)

- 상위 원리: 인과율(빛보다 빠른 신호는 없다 → 빛원뿔이 영향의 경계) + 빛의 모임(중력은 빛줄기를 모은다 — 레이차우두리 방정식).

## 메커니즘 단계

1. **인과 다이아몬드**(s08·s09): 앞 사건 p 에서 빛이 퍼짐(미래 빛원뿔), 뒤 사건 q 로 빛이 모임(과거 빛원뿔). 둘이 만나는 둥근 테두리 S. 감싼 영역 = 다이아몬드.
2. **빛원뿔 위의 자료와 모임**(s10): 빛원뿔 위에서 자유롭게 줄 수 있는 것은 단면의 모양 변화(conformal metric of its cuts, 편광 둘 = 중력파)이고, 넓이는 모임 방정식을 적분해 정해진다(논문 3.2절). 식 (3.25e) `£Θ + Θ²/2 + σ·σ = 0` — 층밀림(shear) σ 의 제곱이 늘 양수라 **언제나 모이는 쪽**.
3. **중력 시계**(s11·s12): 빛줄기(null generator)의 아핀 매개변수를 아래 덮개에서 0 으로 두고 테두리 S 에서 읽은 값 = 중력 시계의 눈금(서론). "shear reduces the expansion … Reaching the same area element at S then takes a larger clock reading, so a bound on the average reading restricts the radiation on the null cone"(3장). 주의: 빛줄기 위의 '길이'(고유 길이)는 0 이므로 대본은 '길이'가 아니라 **'눈금'**이라고 말한다.
4. **유한한 상태 수**(s13): 시계 눈금의 상한(다이아몬드의 최대 크기 ℓ(𝒟))을 걸면 준비할 수 있는 중력자 상태가 제한되고, 힐베르트 공간이 유한 차원(5장: "a macroscopic causal diamond with a given maximum size has a finite dimensional Hilbert space").
5. **이어 붙이기**(s14): 이웃 조각의 경계에서 장을 맞추고(entangling product), 경계의 중간 상태를 모두 더한다. 식 (4.29)·(4.30): 코시–슈바르츠로 합이 절대수렴("converges absolutely in the amplitude, even when Σ admits infinitely many independent states").
6. **확인 계산**(s15·s16): 빛원뿔 위 중력자 쌍 생성·소멸 진폭. 통째로: `(1/2s²) Σ_k e^{-2ik/s}/k²` — 모든 s>0 에서 절대수렴. G_N 으로 먼저 전개한 3차 항: 식 (4.34) `−(i/s³) Σ_{k≤N} 1/k = −(i/s³)[log N + O(1)]` — 로그 발산.

### 모형 (`model.mjs` — 그림·계기·소리가 모두 여기서)

- **빛의 모임(설명 모형, 식 3.25f 의 꼴)**: 단면 반지름 ϱ(u), `ϱ'' = −σ² ϱ`, ϱ(0)=0, ϱ'(0)=1 → `ϱ(u) = sin(σu)/σ`(σ=0 이면 ϱ=u, 곧은 원뿔). 중력자 n 개: `σ_n² = n·ε`. 테두리 반지름 b 에 닿는 시계 눈금 `u*(n) = asin(σ_n b)/σ_n`(σ_n b ≤ 1). 값: `ε b² = 0.11`, 다이아몬드 크기 한계 `ℓ = 1.30 b` → n = 0…8 은 들어가고(u*/b = 1.00 … 1.30) n = 9 는 넘친다(1.48). **8 이라는 수는 '유한하다'를 보이기 위한 모형 값**이다(실제 상태 수는 e^{넓이/4} 꼴로 엄청나게 크다) — 화면에 "모형"이라고 한 번 적는다(머리글 키커).
- **두 합(논문 식 그대로의 부분합)**: 어림 `H_N = Σ_{k≤N} 1/k`(식 4.34, 끝없이 커짐: H_10=2.93, H_1000=7.49, H_10⁶=14.39), 통째 `Z_N = Σ_{k≤N} 1/k²`(통째 계산의 항 크기 상한, π²/6 ≈ 1.645 로 모임). 계기의 가로축은 더한 잔물결의 수 N(로그 눈금 1 … 10⁶), 세로축은 합. 앞의 계수(1/s³, 1/2s²)는 뺐다 — 크기 비교용.
- **블랙홀**: `S = A/4`(플랑크 넓이 단위). 계기는 직선.
