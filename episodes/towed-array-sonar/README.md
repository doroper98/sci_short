"예인 소나의 핵심은, 긴 줄에 늘어선 귀들이 소리의 도착 시각 차이로 방향을 찾는 것입니다." 149.2초, 1080×1920, 30 fps, 테마 `{base: 'navy', accent: '#FFB85C'}`, 배경음악·배경음 없음. 음성 M3 ×0.85 + 6반음(`degraded: false`, 고치지 않음). 완성본 번호 27(`docs/TOPIC_BACKLOG.md`).

**화풍**: [ANIMATION_QUALITY](../../docs/ANIMATION_QUALITY.md) '2026-11-07 후속 결정: 시리즈 화풍은 지킨다'. 어두운 남색 바다 단면(단색 바탕, 가는 수면선, 옅은 깊이 눈금, 떠도는 작은 점), 가는 선(1.5~3 px), 가산 합성의 작은 빛 점(물속 마이크), 가는 호로 그린 파면, 그래프·축·이름표, 강조색 하나(주황 #FFB85C: 답·빔·우리 배가 쏜 소리·큰 숫자)와 보조색 하나(하늘색 #7FD8FF: 멀리서 오는 소리). 배·잠수함·초계기·소노부이는 실제 함급·나라·표식이 없는 일반 선 아이콘(`glyphs.mjs`). 광택 3D, 부피감 있는 물, 화면 전체 빛 번짐 없음. 전체 렌더 전에 시안(0초 포스터와 핵심 장면 5장, 20장 개요)을 보였고, 지적된 두 곳(소노부이 근접 장면이 비어 보임, 좌우 모호성 평면도가 작음)을 고친 뒤 렌더했습니다.

## 모형 (화면·그래프·이름표·소리가 같은 값을 씀, `scenes.mjs` 머리)

| 양 | 식 / 값 |
|---|---|
| 소리 빠르기 | 물 c = 1,500 m/s(교과서 값, 실제 1,450~1,550), 공기 340 m/s → 4.41배 |
| 파장 | λ = c / f, 100 Hz → 15 m |
| 선 배열 (설명 모형) | N = 12, 간격 d = λ/2 = 7.5 m(실제 장비 수치 아님), 방향 θ = 125°(줄 축 기준). 이웃 사이 Δt = d·cosθ / c ≈ 2.87 ms → 화면에서 약 110배 느리게 |
| 빔 | 지연 후 합 B(φ) = ｜Σ e^{ik x_n (cos φ − cos θ)}｜ ÷ N. −3 dB 폭: N = 12 약 10.4°, N = 24 약 5.2° |
| 좌우 모호성 | 같은 식이 줄 축에 대해 대칭(원뿔). 배가 40° 틀면 진짜 음원 방향선은 같은 점에서 만나고 거울상은 새 축에 대한 반사점으로 옮겨 감 |
| 자기 소음 | 프로펠러에서 거리 r의 크기 ∝ 1/r² → 그래프는 −20·log₁₀ r(20~2,600 화면 단위를 0~1로) |
| 메아리 | 왕복 2R/c, 상대가 듣는 시각 R/c(화면 속도로 압축: 바닥 2.52초, 두 화면 1.27초, 오해 장면 1.50초) |
| 소노부이 (설명 모형) | 부표 i의 도착 시각 = 거리 / c(화면 속도), 두 부표의 시각 차이 → 쌍곡선(|p−A| − |p−B| = 상수), 세 개가 음원에서 만남. 전파 중계는 보이게 하려고 화면에서 느리게(900 단위/초) |
| 숫자 (화면) | 1942, ×4.4, 340 m/s, 1,500 m/s, 100 Hz → 파장 15 m. 실제 장비 이름·성능·탐지 거리·전술 없음 |

## 소리 (`--emit-sound`, 사건 74개)

파면이 마이크에 닿음 → 닿는 순서대로 작은 틱(거리 ÷ 화면 속도), 방향 훑기 → 빔 크기 B(φ)를 따라 음높이(98~196 Hz)·크기가 커짐(24개 줄은 더 짧게 솟음), 내 배 소음 → 줄 위치의 1/r² 크기를 따르는 낮은 잡음(줄이 풀리며 작아짐), 능동 핑 → 짧은 262 Hz 음과 2R/c 뒤 더 작은 메아리, 프로펠러·엔진 → 낮은 웅웅·55 Hz 떨림, 부표 → 떨어짐·수면·도착 틱, 전파 중계 → 보내는 순간의 작은 표시음(전파는 들리지 않음), 100 Hz 음 하나. 모든 기본음 700 Hz 미만, 패닝 없음. 설명용 합성음(녹음 아님).

## 단순화

물속 소리 빠르기는 일정(실제는 온도·염분·압력에 따라 바뀌고 소리가 휨). 줄은 곧은 직선(실제는 늘어지고 흔들림). 마이크 수·간격·줄 길이·거리는 설명용. 파면 진행·배의 선회·전파 중계는 화면에서 느리게 또는 빠르게(시간 압축). 전파와 햇빛의 감쇠 길이 비는 설명용. 소노부이 위치 좁히기는 설명 모형. 화면에 각주는 없습니다.
