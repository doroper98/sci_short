# 에피소드 `cold-vaccine` — 감기 주사는 왜 없을까 (범인이 200가지)

"감기 주사가 없는 까닭은, 감기가 겉모양이 저마다 다른 수많은 바이러스가 일으키는 병이기 때문이다." 172.06초, 1080×1920, 30 fps, 테마 `noturno`, 배경음악·배경음 없음.
**모형 하나가 화면·계기·소리를 함께 움직입니다.** 리노바이러스 169형의 겉모양 벡터와 항체 맞물림(fit), 감기 바이러스 202개의 등장 순서, 1960년대 한 형 백신, 온도별 배가 시간, 주사 항체의 핏속 : 점막 겉면 비, 독감 형의 해마다 바뀌는 색과 2월 갱신, 비용·이득 저울의 감쇠 진동, 2016년 원숭이 두 마리의 항체 수, 항생제 충돌과 세균 파열, 손 씻기의 지수 제거 시각이 모두 `scenes.mjs` 머리의 순수 함수와 시간 계획(`plan()`)에서 나옵니다.

| 파일 | 내용 |
|---|---|
| `brief.md` | 기획·출처·단순화 메모 (고치지 않음) |
| `script.json` | 문장 20개, 장면 9개 (고치지 않음) |
| `scenes.mjs` | 모형(순수 함수·시간 계획) + 정이십면체·외피 바이러스 그림 + 장면 + `--emit-sound` |
| `sound.json` | **생성 파일**: `node episodes/cold-vaccine/scenes.mjs --emit-sound`가 씀 |
| `render.mjs`, `run.sh` | 스캐폴드 그대로 (고치지 않음) |

```bash
node episodes/cold-vaccine/scenes.mjs --emit-sound            # 타임라인·모형이 바뀌면 먼저 (sound.json 다시 씀; 낡으면 렌더가 경고)
SKIP_NARRATE=1 episodes/cold-vaccine/run.sh stills            # outputs/cold-vaccine/stills/
SKIP_NARRATE=1 episodes/cold-vaccine/run.sh stills render sfx mix finish validate
```

파이프라인 파일은 고치지 않았습니다. 머리글·포스터 제목, 순차 머리글 교체, `lowBandOnly`, 낡은 소리 표 검사(`modelSignature`/`checkSoundTable`), `--emit-sound`는 감마선 폭발 편에서 복사해 이 편에 맞게 고쳤습니다(에피소드 사이 import 없음). 썸네일 글자 방식(흰 질문 + 큰 강조색 답)은 로그 눈금 편 `thumbnail.mjs`를 따랐습니다. 바이러스·항체·주사기·세포막·소·원숭이·손 그림은 모두 이 파일 안의 캔버스 경로이며 외부 이미지·생성 이미지는 쓰지 않았습니다. 감마선 폭발 편의 가산 빛 버퍼(`Glow`)는 이 편의 번쩍임이 `glow()` 방사 그라디언트로 충분해 가져오지 않았습니다(처음 복사했다가 쓰는 곳이 없어 지움).

## 단순화·설명 모형 (화면에는 각주 없음; 표식은 "모식", "모형", "설명 모형", "비유", "실험실 결과", "세포 실험", "색 변화 = 모식"뿐)

- **바이러스 그림**: 실제 크기 약 30 nm이고 색이 없습니다. 형마다 다른 색과 별 모양 고리는 "겉모양이 다르다"의 비유입니다. 리노바이러스의 실제 항원 부위(VP1~VP3 바깥 고리)는 이렇게 별 모양으로 보이지 않으며, 별 모양은 다섯겹 대칭축 둘레의 돌출부를 단순화한 것입니다. 다른 바이러스(코로나 · 아데노 · RSV · 파라인플루엔자 · 엔테로 · 메타뉴모)는 겉모양의 특징만 따른 그림이고 크기 비는 맞추지 않았습니다.
- **수**: "200가지 넘음"의 무리는 리노바이러스 169 + 다른 바이러스 33개(그림의 수)입니다. 리노바이러스가 감기의 30~50%라는 비율은 출처마다 다릅니다(30~80%).
- **맞물림**: 4차원 겉모양 벡터와 가우스 맞물림 함수는 "형마다 항체가 대체로 따로"라는 사실을 보이기 위한 설명 모형입니다. 실제로는 부분적인 교차 반응도 있어 이웃 형 C4를 희미하게(0.395) 남겼습니다. 항체 끝 단면, 열쇠·자물쇠 모양은 비유입니다.
- **1960~70년대 시험**: RV13 하나를 대표로 그렸습니다(실제로는 여러 시험이 있었음). 두 바이러스와 항체 넷의 움직임은 그림입니다.
- **항체와 세포 문**: 수용체는 한 종류의 그림으로 그렸고(리노바이러스 대부분은 ICAM-1, 일부는 다른 수용체), 항체가 중화하는 방식은 "붙어서 막는다"만 보였습니다. 항체 수와 결합 위치는 그림입니다.
- **콧속**: 머리 단면은 모식입니다. 숨길 온도 곡선과 배가 시간(0.7 s · 1.15 s, 화면 시간)은 "33 °C에서 더 잘 불어난다"는 세포 실험 결과(쥐 기도 세포 등)를 보이기 위한 모형이며 실제 배수·시간이 아닙니다.
- **주사 항체**: 핏속 100 : 점막 겉면 3은 "점막 겉면에는 적게 닿는다"는 일반 원리를 보이는 설명 모형입니다(실제 비는 항체 종류·사람마다 다름, 항체 이름 생략).
- **독감**: 유행 형의 색 변화와 해마다의 갱신은 모식이며 실제 백신 형의 이름·연도를 나타내지 않습니다. "세 가지 안팎"은 대본 그대로(2024년부터 3가 권고).
- **저울**: 비용과 이득의 판단을 보이는 비유이며 숫자가 없습니다. 저울의 흔들림(감쇠 진동)은 화면용입니다.
- **2016년 연구**: 원숭이 두 마리의 41 · 45 → 49 / 50은 논문 값입니다. 50칸 중 어느 칸이 켜졌는지, 빠진 한 칸, 169칸에서 고른 50칸은 그림입니다. 원숭이는 실루엣 그림입니다.
- **오해**: 세균과 바이러스의 크기 비를 맞추지 않았습니다("크기는 세균보다 훨씬 작음" 표기). 항생제가 세포벽을 공격하는 그림은 여러 작용 방식 중 하나만 보인 것입니다.
