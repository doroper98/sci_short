# 에피소드 구성 — 기원과 본질에서 원리와 현상까지

2026-10-30 사용자 확정 방향입니다. 이 문서는 어떤 과학·공학 주제든 같은 흐름으로 설계하기 위한 **사고 순서와 시간 예산**입니다.
장면 수·그림체·팔레트를 고정하지 않는다는 [화면 설계 원칙](CREATIVE_DIRECTION.md)은 그대로입니다.

## 목표 한 줄

> 참고 영상 7편의 **메커니즘적 자세함**을 유지하면서, 수정 성장 영상처럼 **이해를 돕는 배경지식**을 넣고,
> 지식을 소화할 **흐름과 호흡**으로, **최대 2분·세로 쇼츠**, **유치하지 않게** 만든다.

| 항목 | 확정값 |
|---|---|
| 대상 | 초등학교 고학년 ~ 고등학교 저학년(약 11~16세). 어린아이용이 아니라 **지적 호기심이 있는 청소년**용 |
| 길이 | 최대 120초. 권장 95~115초. 음성 가속으로 맞추지 않고 대본을 줄인다 |
| 규격 | 1080×1920, 30fps, 세로 9:16. 쇼츠·릴스 UI 안전 영역을 비운다 |
| 설명 범위 | 기원·배경 → 본질(제1원리) → 메커니즘 → 현상·사례 → 한 줄 결론 |
| 문체 | 내레이션은 **합니다체**. 표준 목소리의 문장 끝 억양 보정은 `니다`로 끝나는 문장에만 적용되므로 문체와 음성 기준이 일치한다 |
| 목표 제작 시간 | 주제 지시 후 **약 1시간** 안에 완성본. 절차는 [SKILL](../skills/science-short/SKILL.md) |

## 두 참고 계열에서 가져올 것

| 참고 영상 7편(망막·도플러·하늘·입자 소나기·블랙홀·전자레인지·우주 평탄성) | 수정 성장 영상 |
|---|---|
| 작동하는 부품·입자·파면이 **실제로 움직인다** | 용어의 뜻, 재료가 어디서 오는지, 왜 그 조건이 필요한지 **배경을 먼저 깐다** |
| 전체 → 확대 → 원인 작동 → 전체 결과 | 한 단계가 끝나면 **잠시 관찰할 여유**를 둔다 |
| 조건을 하나 바꿔 결과를 비교한다 | 결합이 있다고 결정은 아니다처럼 **개념의 경계**를 짚는다 |
| 약점: 배경이 없어 "왜 지금 이걸 보는지" 놓치기 쉽다 | 약점: 어미가 "~요/~죠"라 어리게 들리고, 길이가 2분을 넘겼다 |

두 계열의 장점을 합치고 약점을 버립니다.

## 권장 비트 구조와 시간 예산

전체 100~115초 기준입니다. 비트 순서는 권장이며, 주제에 따라 2와 3을 합치거나 5를 뺄 수 있습니다.

| # | 비트 | 시간 | 하는 일 | 화면 | 소리 |
|---|---|---|---|---|---|
| 0 | 훅 | 0~8초 | 관찰 가능한 현상 또는 구체적 질문 하나. 결론을 미리 말하지 않는다 | 현상 자체를 크게. 제목은 작게 | 현상의 실제음 또는 침묵 |
| 1 | 기원·배경 | 8~22초 | 이 현상이 언제 어떻게 알려졌는지, 용어의 어원 한 문장, 당시 무엇이 문제였는지 | 연표 한 줄, 옛 관측 장치, 이름의 뜻을 보여주는 글자 분해 | 낮은 밀도. 음악 거의 없음 |
| 2 | 본질·제1원리 | 22~40초 | 한 문장으로 쓸 수 있는 핵심 명제. 보존·대칭·확률·파동·평형 같은 더 큰 원리와 연결 | 가장 단순한 모형 하나. 변수 두 개 | 변수에 대응하는 설명용 음 |
| 3 | 메커니즘 | 40~80초 | 2~4단계로 쪼갠 작동 과정. 각 단계가 화면에서 실제로 움직인다. 가장 긴 비트 | 전체 → 확대 → 단계별 작동 → 전체 | 사건마다 소리. 전파 지연 반영 |
| 4 | 현상·사례 | 80~100초 | 원리가 일상·자연·공학에서 나타나는 예 1~2개. 조건을 바꾸면 결과가 어떻게 바뀌는지 비교 | 나란히 비교 또는 조건 슬라이더 | 조건 차이가 귀로 구별되게 |
| 5 | 오해 바로잡기 | 선택, 8~10초 | 흔한 오해 하나 → 판정. 메커니즘에서 이미 보여준 근거로 | 오해 화면에 X가 아니라 올바른 모형을 다시 | 짧게 |
| 6 | 마지막 한 줄 | 100~115초 | 전체를 관통하는 문장. 새 정보 없음 | 엔드카드. 핵심 명제를 따옴표로 | 음악 페이드 |

비트 3이 전체의 35~40%를 차지해야 "자세함"이 유지됩니다. 비트 1·2가 합쳐 25% 미만이면 배경 없이 기술 설명만 남고, 35%를 넘으면 메커니즘이 얕아집니다.

## 호흡 — 숫자로 정한 기준

기존 석영 영상의 실제 음성에서 측정한 값을 출발점으로 삼습니다.
표준 목소리(M3 ×0.95)는 약 **6.5음절/초**, 문장 평균 **4.0초**, 문장 사이 평균 **1.4초**였습니다.

- **대본 총량**: 120초 상한에서 관찰 여유를 빼면 발화는 85~95초. 띄어쓰기·문장부호를 뺀 **600~650음절**이 상한입니다. 700음절을 넘기면 반드시 줄입니다.
- **문장 길이**: 25~40음절. 한 문장에 새 개념은 하나. 50음절이 넘으면 둘로 나눕니다.
- **문장 사이 간격**: 기본 0.6초. 새 비트가 시작되기 전 1.2~2.0초. 메커니즘의 핵심 단계가 끝난 뒤 1.5~2.5초의 **무언 관찰 구간**을 둡니다.
- **장면 길이**: 10~20초. 5초 미만의 장면 전환이 연속되면 호흡이 없는 것입니다.
- **정보 밀도**: 한 장면에 새 용어 최대 2개. 용어는 현상을 먼저 보여준 뒤 이름을 붙입니다.
- **반복**: 핵심 명제는 비트 2에서 말하고, 비트 6에서 같은 말로 돌아옵니다. 다른 표현으로 바꾸지 않습니다.

## 배경지식을 끼워 넣는 다섯 가지 방법

배경은 장식이 아니라 "왜 이 메커니즘을 봐야 하는지"를 만드는 장치입니다. 한 편에 2~3개를 고릅니다.

1. **어원 한 문장**: 용어가 어떤 말에서 왔고 원래 무엇을 가리켰는지. 예: "스펙트럼은 라틴어로 '유령', 뉴턴이 프리즘 뒤에 나타난 색의 띠를 그렇게 불렀습니다."
2. **발견의 맥락**: 누가, 어떤 도구로, 무엇을 이상하게 여겼는지. 연도는 한 번만.
3. **이전 믿음과 전환**: 사람들이 전에는 어떻게 설명했고, 무엇이 그 설명을 깨뜨렸는지.
4. **척도 감각**: 크기·시간·에너지를 익숙한 것과 비교. 비율을 과장하지 않고 실제 수치를 표시한다.
5. **상위 원리와의 연결**: 이 현상이 에너지 보존·파동·확률·평형 같은 더 큰 틀의 한 사례임을 한 문장으로.

배경 문장에도 출처를 둡니다. 확인되지 않은 일화("뉴턴의 사과" 류)는 쓰지 않습니다.

## 유치하지 않게 — 금지와 권장

| 금지 | 대신 |
|---|---|
| 마스코트, 눈 달린 입자, 말풍선, 이모지, 의성어 자막("펑!") | 실제 형태와 재질의 모형. 사건은 빛·움직임·소리로 |
| "신기하죠?", "놀랍게도", "우와", "~해 볼까요?"의 반복 | 관찰 결과를 서술하고 다음 질문으로 넘긴다. 질문형은 훅과 전환에 각 1회 |
| "~요/~죠" 어미의 내레이션 | 합니다체. 단정은 짧게, 조건은 분명히 |
| 수치 없는 "아주 작다/엄청 빠르다" | 실제 수치와 단위. 비교 대상을 함께 표시 |
| 둥근 파스텔 팔레트, 손글씨체, 장식 폰트 | [르포 보고서 글꼴 체계](#글꼴과-화면-톤) |
| 비유를 사실처럼 말하기 | "모형에서는", "설명을 위해 크기를 과장했습니다"를 자막 하단 작은 글씨로 |
| 배경음악이 계속 울리는 구성 | 핵심 비교 구간에서 음악을 비운다 |

유치함의 반대는 어려움이 아니라 **정확함과 밀도**입니다. 용어를 피하지 말고, 보여준 뒤 이름 붙입니다.

## 글꼴과 화면 톤

사용자가 지정한 기준은 `doroper98/agents_reviewer`의 르포(reportage) 보고서 템플릿입니다.

| 역할 | 글꼴 | 비고 |
|---|---|---|
| 제목·장 제목·큰 숫자 | GmarketSans Bold | 자간 약간 좁게 |
| 부제·키커 | GmarketSans Medium | 소문자 키커는 자간 넓게 |
| 자막·라벨·출처 줄 | Noto Sans KR 400/500/700 | 본문용. 자막은 500 |
| 기본 테마 `noturno` | 배경 `#001621`, 판 `#06222E`, 글자 `#EFE3D4`, 보조 `#8AA0A6`, 강조 `#FF4103` | 주제에 따라 다른 테마 선택 가능 |

글꼴 파일은 Git에 넣지 않고 `pipeline/render`의 받기 스크립트로 가져옵니다. 색은 주제의 물리적 의미(온도·파장·전하)와 충돌하지 않게 고릅니다.

## 자막과 화면 정보의 역할 분담

- **자막** = 내레이션 문장. 실제 음성 글자 시각에 맞춰 나타나고, 2줄·줄당 약 18음절 이내.
- **라벨** = 화면 속 대상의 이름·수치. 자막과 글꼴 크기·위치를 다르게.
- **각주 줄** = 단순화·출처. 가장 작은 글씨, 화면 하단 안전 영역 바로 위.
- 자막 위치는 기본 하단이지만 현상이 아래에 있으면 장면 단위로 위로 올립니다.

## 과학적 정확성 점검

대본을 쓸 때 문장마다 셋 중 하나로 표시합니다. **관측 사실 / 설명 모형 / 비유**.
모형과 비유는 화면 하단 각주로 경계를 알립니다. 인과를 단순화할 때는 "모든 경우"가 아니라 "이 조건에서"로 씁니다.
수치·연도·인명은 출처를 `brief.md`에 남깁니다. 확인하지 못한 것은 빼고, 빼서 설명이 무너지면 주제를 바꿉니다.

## 완성 전 확인 질문

1. 소리를 끄고 봐도 메커니즘의 각 단계가 무엇이 움직여 무엇이 바뀌는지 보이는가?
2. 비트 1·2 없이 비트 3만 보면 이해가 어려운가? 어렵다면 배경이 제 역할을 한 것이다.
3. 15세가 "유치하다"고 느낄 요소가 있는가? 어미, 효과음, 그림체, 감탄사를 점검한다.
4. 핵심 명제가 비트 2와 6에서 같은 문장으로 나오는가?
5. 120초 이하이고, 음성을 가속하지 않았는가?
6. 단순화한 부분이 각주로 표시되었는가?
