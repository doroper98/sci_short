# 에피소드 구성 — 기원과 본질에서 원리와 현상까지

2026-10-30 사용자 확정 방향입니다. 이 문서는 어떤 과학·공학 주제든 같은 흐름으로 설계하기 위한 **사고 순서와 시간 예산**입니다.
장면 수·그림체·팔레트를 고정하지 않는다는 [화면 설계 원칙](CREATIVE_DIRECTION.md)은 그대로입니다.

## 목표 한 줄

> 장치 해부도 참고 영상(9~13번)의 **기구적·메커니즘적 자세함**을 유지하면서, 수정 성장 영상처럼 **이해를 돕는 배경지식**을 넣고,
> 지식을 소화할 **흐름과 호흡**으로, **최대 3분·세로 쇼츠**, **유치하지 않게** 만든다.

| 길이 | **최대 180초**(2026-10-30 변경, 이전 120초). 권장 150~170초. 음성 가속으로 맞추지 않고 대본을 줄인다 |

## 세 참고 계열에서 가져올 것

| 계열 | 가져올 것 | 버릴 것 |
|---|---|---|
| **장치 해부도** (9~13번, Chiong Lab: 엔진·레이저 프린터·마그네트론·DLP·LIGO) | 실제 장치의 전체 단면에 모든 부품 이름. 전체 → 번호 붙인 확대 → 측정값 그래프의 **3단 계기판**. 하나의 부품에 원을 쳐서 세 단을 잇는 **추적 표식**. 예/아니오로 답하는 **예측 질문** 제목. "50× slower"처럼 **시간 배율을 선언**. 각주에 모든 단순화 | 내레이션 없음, 12~14초 루프라 호흡·배경이 없음. 한 화면에 글자가 너무 많아 음성 없이는 멈춰 읽어야 함 |
| **현상 설명** (1~8번: 망막·도플러·하늘·입자 소나기·블랙홀·전자레인지·우주 평탄성·천둥) | 보이지 않는 파동·입자를 선과 점으로. 전체 → 확대 → 원인 작동 → 전체 결과. 조건 하나를 바꾼 비교. 일상으로 닫기 | 배경이 없어 "왜 지금 이걸 보는지" 놓치기 쉬움. 17~36초에 사실만 압축 |
| **수정 성장** (previews/quartz) | 용어의 뜻, 재료의 출처, 조건의 이유를 **먼저 깐다**. 단계 뒤 **관찰 여유**. "결합이 있다고 결정은 아니다"처럼 개념의 경계 | 어미 "~요/~죠"가 어리게 들림. 장치 해부도만큼 부품 수준의 자세함은 없음 |

세 계열의 장점을 합치고 약점을 버립니다. 요약하면 **장치 해부도의 밀도 + 현상 설명의 비교 + 수정 영상의 배경과 호흡**입니다.

## 권장 비트 구조와 시간 예산

전체 150~170초 기준입니다. 비트 순서는 권장이며, 주제에 따라 2와 3을 합치거나 5를 뺄 수 있습니다.

| # | 비트 | 시간 | 하는 일 | 화면 | 소리 |
|---|---|---|---|---|---|
| 0 | 훅 | 0~10초 | 예/아니오 또는 둘 중 하나로 답하는 **예측 질문**. "불꽃이 튀는 순간 압력이 뛸까?" 결론을 미리 말하지 않는다 | 현상 또는 장치 자체를 크게. 제목은 작게 | 현상의 실제음 또는 침묵 |
| 1 | 기원·배경 | 10~35초 | 이 현상·장치가 언제 어떻게 알려졌는지, 용어의 어원 한 문장, 당시 무엇이 문제였는지 | 연표 한 줄, 옛 장치, 이름의 뜻을 보여주는 글자 분해 | 낮은 밀도. 음악 거의 없음 |
| 2 | 본질·제1원리 | 35~55초 | 한 문장으로 쓸 수 있는 핵심 명제. 보존·대칭·확률·파동·평형 같은 더 큰 원리와 연결 | 가장 단순한 모형 하나. 변수 두 개 | 변수에 대응하는 설명용 음 |
| 3 | 메커니즘 | 55~120초 | 2~4단계로 쪼갠 작동 과정. **3단 계기판**: 전체 단면(부품 이름) → 번호 붙인 확대 → 측정값 그래프. 추적 표식이 세 단을 잇는다. 가장 긴 비트 | 전체 → 확대 → 단계별 작동 → 전체. 시간 배율을 화면에 선언 | 사건마다 소리. 전파 지연 반영 |
| 4 | 현상·사례 | 120~145초 | 원리가 일상·자연·공학에서 나타나는 예 1~2개. 조건을 바꾸면 결과가 어떻게 바뀌는지 비교 | 나란히 비교 또는 조건 슬라이더 | 조건 차이가 귀로 구별되게 |
| 5 | 오해 바로잡기 | 선택, 145~155초 | 흔한 오해 하나 → 판정. 메커니즘에서 이미 보여준 근거로 | 오해 화면에 X가 아니라 올바른 모형을 다시 | 짧게 |
| 6 | 마지막 한 줄 | 155~170초 | 훅의 질문에 답하고, 전체를 관통하는 문장. 새 정보 없음 | 엔드카드. 핵심 명제를 따옴표로 | 음악 페이드 |

비트 3이 전체의 35~40%를 차지해야 "자세함"이 유지됩니다. 비트 1·2가 합쳐 25% 미만이면 배경 없이 기술 설명만 남고, 35%를 넘으면 메커니즘이 얕아집니다.

## 호흡 — 숫자로 정한 기준

기존 석영 영상의 실제 음성에서 측정한 값을 출발점으로 삼습니다.
표준 목소리(M3 ×0.95)는 약 **6.5음절/초**, 문장 평균 **4.0초**, 문장 사이 평균 **1.4초**였습니다.

- **대본 총량**: 180초 상한에서 관찰 여유를 빼면 발화는 115~130초. 띄어쓰기·문장부호를 뺀 **750~850음절**이 권장, **900음절**이 상한입니다. 넘기면 사례·오해 비트부터 줄입니다.
- **문장 길이**: 30~45음절, 쉼표 하나. 한 문장에 새 개념은 하나. 55음절이 넘으면 둘로 나눕니다. 같은 목소리·같은 속도 설정이라도 짧은 문장은 빠르게 들립니다(2026-10-30 실측: 15~25음절 문장 7.8음절/초, osint 최종 영상의 35~50음절 문장 6.3음절/초). 느리게 들리게 하려면 속도가 아니라 문장 길이와 간격을 조정합니다.
- **문장 사이 간격**: 기본 0.9초(osint 호흡 설정 `sentence_gap_sec 0.9`). 새 비트가 시작되기 전 1.2~2.0초. 메커니즘의 핵심 단계가 끝난 뒤 1.5~2.5초의 **무언 관찰 구간**을 둡니다.
- **장면 길이**: 10~25초. 5초 미만의 장면 전환이 연속되면 호흡이 없는 것입니다.
- **정보 밀도**: 한 장면에 새 용어 최대 2개. 용어는 현상을 먼저 보여준 뒤 이름을 붙입니다. 부품 이름 라벨은 용어로 세지 않되, 내레이션이 가리키는 부품만 밝게 켭니다.
- **반복**: 핵심 명제는 비트 2에서 말하고, 비트 6에서 같은 말로 돌아옵니다. 다른 표현으로 바꾸지 않습니다.

## 메커니즘 비트의 3단 계기판

장치 해부도 계열에서 일반화한 구조입니다. 장치가 아닌 자연 현상에도 "무대 → 확대 → 측정값"으로 그대로 적용됩니다.

| 단 | 내용 | 규칙 |
|---|---|---|
| 상단: 전체 | 실제 장치·계의 단면. 부품마다 이름과 지시선. 작은 삽화로 소비자가 아는 겉모습 | 처음부터 전부 보여주되 흐리게. 내레이션이 가리키는 부품만 켠다 |
| 중단: 확대 | ①②③ 번호를 붙인 하위 메커니즘. 입자·전하·빛·압력이 실제로 움직인다 | "50× 느리게" 같은 시간 배율과 "크기 과장"을 화면에 선언 |
| 하단: 측정값 | 지금 이 순간의 그래프·눈금·수치(압력, 전압, 각도, 세기) | 확대 화면의 상태와 같은 모형 값에서 그린다. 현재 시각 표식 |
| 추적 표식 | 상단의 부품 하나에 원을 치고, 중단과 하단이 그 부품을 따른다 | 한 편에 추적 표식은 하나 |

세 단을 동시에 다 채우지 않아도 됩니다. 세로 화면에서는 상단·중단을 번갈아 크게 하고 하단 그래프를 작게 유지하는 편이 읽힙니다.

## 배경지식을 끼워 넣는 다섯 가지 방법

배경은 장식이 아니라 "왜 이 메커니즘을 봐야 하는지"를 만드는 장치입니다. 한 편에 2~3개를 고릅니다.

1. **어원 한 문장**: 용어가 어떤 말에서 왔고 원래 무엇을 가리켰는지. 예: "스펙트럼은 라틴어로 '유령', 뉴턴이 프리즘 뒤에 나타난 색의 띠를 그렇게 불렀습니다."
2. **발견의 맥락**: 누가, 어떤 도구로, 무엇을 이상하게 여겼는지. 연도는 한 번만.
3. **이전 믿음과 전환**: 사람들이 전에는 어떻게 설명했고, 무엇이 그 설명을 깨뜨렸는지.
4. **척도 감각**: 크기·시간·에너지를 익숙한 것과 비교. 비율을 과장하지 않고 실제 수치를 표시한다.
5. **상위 원리와의 연결**: 이 현상이 에너지 보존·파동·확률·평형 같은 더 큰 틀의 한 사례임을 한 문장으로.

배경 문장에도 출처를 둡니다. 확인되지 않은 일화("뉴턴의 사과" 류)는 쓰지 않습니다.

## 유치하지 않게 — 금지와 권장

| 금지 | 대신 |
|---|---|
| 마스코트, 눈 달린 입자, 말풍선, 이모지, 의성어 자막("펑!") | 실제 형태와 재질의 모형. 사건은 빛·움직임·소리로 |
| "신기하죠?", "놀랍게도", "우와", "~해 볼까요?"의 반복 | 관찰 결과를 서술하고 다음 질문으로 넘긴다. 질문형은 훅과 전환에 각 1회 |
| "~요/~죠" 어미의 내레이션 | 합니다체. 단정은 짧게, 조건은 분명히 |
| 수치 없는 "아주 작다/엄청 빠르다" | 실제 수치와 단위. 비교 대상을 함께 표시 |
| 둥근 파스텔 팔레트, 손글씨체, 장식 폰트 | [르포 보고서 글꼴 체계](#글꼴과-화면-톤) |
| 비유를 사실처럼 말하기 | "모형에서는", "설명을 위해 크기를 과장했습니다"를 자막 하단 각주로 |
| 배경음악이 계속 울리는 구성 | 핵심 비교 구간에서 음악을 비운다. 기본 음악은 osint와 같은 Chris Zabriskie(CC BY 4.0) 트랙, 말하는 동안 내레이션보다 12 dB 아래 |

유치함의 반대는 어려움이 아니라 **정확함과 밀도**입니다. 용어를 피하지 말고, 보여준 뒤 이름 붙입니다.
진지함은 그림체가 아니라 네 가지 정보 규율에서 나옵니다. **실제 수치, 고정된 역할 색, 하나의 무대, 선언된 단순화.**

## 글꼴과 화면 톤

사용자가 지정한 기준은 `doroper98/agents_reviewer`의 르포(reportage) 보고서 템플릿입니다.

| 역할 | 글꼴 | 비고 |
|---|---|---|
| 제목·장 제목·큰 숫자 | GmarketSans Bold | 자간 약간 좁게 |
| 부제·키커 | GmarketSans Medium | 소문자 키커는 자간 넓게 |
| 자막·라벨·출처 줄 | Noto Sans KR 400/500/700 | 본문용. 자막은 500 |
| 기본 테마 `noturno` | 배경 `#001621`, 판 `#06222E`, 글자 `#EFE3D4`, 보조 `#8AA0A6`, 강조 `#FF4103` | 주제에 따라 다른 테마 선택 가능 |

글꼴 파일은 Git에 넣지 않고 `pipeline/render`의 받기 스크립트로 가져옵니다. 색은 주제의 물리적 의미(온도·파장·전하)와 충돌하지 않게 고릅니다.
장치 해부도 계열은 흰 종이 배경에 세리프 글꼴을 씁니다. 밝은 배경이 부품 선을 더 잘 보여주는 주제에서는 밝은 테마를 선택할 수 있습니다. 글꼴 체계는 유지합니다.

## 자막과 화면 정보의 역할 분담

- **자막** = 내레이션 문장. 실제 음성 글자 시각에 맞춰 나타나고, 2줄·줄당 약 18음절 이내.
- **라벨** = 화면 속 대상의 이름·수치. 자막과 글꼴 크기·위치를 다르게.
- **각주 줄** = 단순화·출처·시간 배율. 가장 작은 글씨, 화면 하단 안전 영역 바로 위.
- 자막 위치는 기본 하단이지만 현상이 아래에 있으면 장면 단위로 위로 올립니다.
- 내레이션이 있으므로 긴 문장을 화면 중앙에 쓰지 않습니다. 참고 영상의 문장형 라벨은 음성으로 옮기고 화면에는 이름·수치만 남깁니다.

## 과학적 정확성 점검

대본을 쓸 때 문장마다 셋 중 하나로 표시합니다. **관측 사실 / 설명 모형 / 비유**.
모형과 비유는 화면 하단 각주로 경계를 알립니다. 인과를 단순화할 때는 "모든 경우"가 아니라 "이 조건에서"로 씁니다.
수치·연도·인명은 출처를 `brief.md`에 남깁니다. 확인하지 못한 것은 빼고, 빼서 설명이 무너지면 주제를 바꿉니다.
