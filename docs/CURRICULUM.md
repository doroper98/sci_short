# 커리큘럼 초안 — 본다 · 잰다 · 안다

상태: **제안 초안(2026-11-02)**. 사용자와 다듬은 뒤 확정합니다. 확정 전에는 제작 규칙으로 쓰지 않습니다.
근거: 지금까지 만든 5편(중력파, LIGO, 엘니뇨·라니냐, 파장, 바람의 띠)과 사용자 제안("현상 이해 → 분석 방법 이해 → 원리 이해", "초~고 모든 교과목의 과학적 사안").

## 1. 뼈대: 세 층 사다리

사용자의 세 층을 시리즈 이름으로 줄였습니다.

| 층 | 이름 | 질문 | 이 층이 주인공인 편의 모습 | 이미 만든 예 |
|---|---|---|---|---|
| 현상 | **본다** | 무엇이 일어나나? | 눈에 보이는 현상 하나를 끝까지 따라감. 오해로 시작하기 좋음 | 바람의 띠, 엘니뇨·라니냐 |
| 방법 | **잰다** | 어떻게 알아냈나? | 측정 도구·그래프·모형·비교 실험이 주인공. 장치 해부도(참고 9~13번) 문법 | LIGO |
| 원리 | **안다** | 왜 그렇게 되나? | 여러 현상을 한 원리로 꿰는 허브 편 | 파장 |

운영 원칙 세 가지.

1. **모든 편은 세 층을 조금씩 다 담는다.** 쇼츠는 알고리즘이 무작위로 한 편씩 보여주므로 한 편만 봐도 완결돼야 합니다. "현상편만 보고 원리는 다음 편"으로 쪼개지 않습니다. 대신 편마다 무게중심 층을 하나 정합니다(현재 `EPISODE_FLOW`의 훅 → 기원 → 본질 → 메커니즘 → 사례 → 오해 → 결론 구조 그대로).
2. **사다리는 주제 안이 아니라 주제 사이에 놓는다.** 같은 원리를 공유하는 다른 현상들이 계단이 됩니다. 예) 바람의 띠(본다) → 에라토스테네스(잰다) → 각도와 에너지(안다).
3. **나선형으로 돌아온다.** 같은 큰 생각을 학년이 오를수록 더 깊게 다시 봅니다(브루너, 『교육의 과정』 1960: "어떤 교과든 어떤 발달 단계의 아이에게도 지적으로 정직한 형태로 가르칠 수 있다"). 예) 파동: 소리(초) → 파장(중) → 간섭·LIGO(고) → 중력파(심화).

### 왜 "잰다"가 이 채널의 무기인가

현상 설명 영상은 많지만 "그걸 어떻게 알았는지"를 보여주는 짧은 영상은 드뭅니다. 2022 개정 통합과학에 '기본량과 단위', '측정과 어림', '정보와 신호'가 새로 들어간 것과도 맞습니다. 이 프로젝트의 3단 계기판(전체 단면 → 확대 → 측정값 그래프)은 원래 "잰다"를 위한 형식입니다.

## 2. 수준 표시

| 표시 | 대상 | 원칙 |
|---|---|---|
| L1 | 초3~4 | 숫자 적게, 보이는 현상 위주. 길이 90~120초 검토 |
| L2 | 초5~6 | 기본 대상. 수치는 비교 대상과 함께 |
| L3 | 중1~3 | 기본 대상. 식 하나까지 허용(c = λf 수준) |
| L4 | 고1 통합과학·심화 | 중력파·LIGO 같은 "도전 편" |

어조는 수준과 관계없이 하나입니다(합니다체, 유치하지 않게). 초1~2는 대상으로 잡지 않습니다. 180초 내레이션 밀도가 맞지 않습니다.

## 3. 여덟 줄기와 교과 넘나들기

2022 개정 과학과 영역(운동과 에너지, 물질, 생명, 지구와 우주, 과학과 사회)을 쇼츠에 맞게 여덟 줄기로 나눴습니다.
교육과정 단원명과의 정밀 대조는 원문 접근 후 합니다(§7).

표 읽는 법: 층(본/잰/안), 수준(L1~L4), ✔ = 이미 제작.

## 4. 원리 허브

한 원리에 여러 현상 편을 매답니다. 허브 편이 생기면 그 원리를 쓰는 편의 고정 댓글·재생목록에서 서로 잇습니다.

| 허브 | 이어지는 현상 편 |
|---|---|
| 에너지 보존과 전환 | 지레, 발전기, 냉장고, 로켓 |
| 파동 | 소리, 파장, 간섭, 중력파, 분광기 |
| 되먹임과 평형 | 엘니뇨, 온실 효과, 체온 조절 |

| 규모(크기·시간) | 파장, 세포, 로그 척도 |

## 5. 시즌 1 제안 (12편)

선정 기준: 오해로 여는 훅, 교육과정 중심성, 기존 엔진 재사용(지구본·프리즘·스펙트럼), 세 층과 줄기의 균형.

| 순서 | 편 | 줄기 | 층 | 수준 | 재사용 |
|---|---|---|---|---|---|
| 1 | 계절은 왜 생길까 | 지구·우주 | 본·안 | L2 | 지구본 |
| 2 | 에라토스테네스, 막대 그림자로 지구 둘레 재기 | 지구·우주 | 잰 | L2·L3 | 지구본 |
| 3 | 달의 모양은 왜 바뀔까 | 지구·우주 | 본 | L2 | 지구본(달 추가) |
| 4 | 식물은 무엇을 먹고 자랄까 | 생명 | 본·안 | L2 | |
| 5 | 무거운 것이 먼저 떨어질까 | 힘과 운동 | 본 | L2·L3 | |
| 6 | 배는 쇠인데 왜 뜰까 | 힘과 운동 | 본·안 | L2 | |
| 7 | 무지개는 왜 생길까 | 파동 | 본 | L2 | 프리즘 광선 추적 |
| 8 | 지진계, 진앙까지 거리를 재는 법 | 지구 | 잰 | L3 | |
| 9 | 전기는 전지에서 닳는 걸까 | 전기 | 안 | L2·L3 | |
| 10 | 지진 규모·데시벨·pH는 왜 한 칸에 10배일까 | 넘나들기(수학) | 잰 | L3 | |
| 11 | 같은 '도'인데 소리가 다른 이유 | 넘나들기(음악) | 본·안 | L2·L3 | 파동 패널 |
| 12 | 에너지는 사라지지 않는다 | 원리 허브 | 안 | L3 | |

층 분포는 본 7, 잰 3, 안 6(두 층에 걸친 편은 양쪽에 셈)이고, 수준은 L2 중심에 L3를 섞었습니다.
지구본 엔진이 1~3편에서 반복되므로 3편째에 `pipeline/`으로 올립니다(AGENTS.md "세 편 이상 반복" 규칙).

## 6. 시리즈 형식에 더할 것 (확정 전 제안)

- **brief에 커리큘럼 위치 항목 추가**: 줄기, 층, 수준, 선수 편, 다음 편, 교육과정 영역.
- **훅 위 작은 표지**: "본다 · 지구와 우주" 같은 줄기·층 표시. 화면 상단 키커 자리를 씁니다.
- **다음 편 연결**: 쇼츠의 '관련 동영상' 링크와 고정 댓글로 사다리의 다음 계단을 잇습니다. 화면에 "다음 편" 자막은 넣지 않습니다(편마다 완결).
- **재생목록**: 줄기별 8개와 층별 3개(본다·잰다·안다)를 함께 둡니다.

- 검색으로 확인된 것: 과학과 영역은 운동과 에너지·물질·생명·지구와 우주·과학과 사회의 다섯. 초3-1 '힘과 우리 생활'·'동물의 생활', 3-2 '지구와 바다'·소리 단원, 4-1 '물의 상태 변화', 6학년 첫 단원 '지구와 달'. 중학교 과학은 23개 단원이며 첫 단원은 통합 단원. 고1 공통 과목은 통합과학1·2와 과학탐구실험1·2이고 '기본량과 단위', '측정과 어림', '정보와 신호', '감염병과 병원체' 등이 신설.
- 표의 수준(L1~L4)은 위 확인 범위와 일반적인 교과 배치를 근거로 한 **추정**입니다.
- 측우기의 "세계 최초" 같은 표현은 제작 시 사실 확인 후에만 씁니다.
