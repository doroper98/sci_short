# 틱톡 — 직접 게시 (반자동)

2026-11-08 사용자 결정: "그럼 틱톡으로 확장하자" → 방식 **반자동: 직접 게시**, 계정 **새 개인 계정 만들기**.

## 왜 자동 게시가 아닌가

틱톡 공식 게시 API(Content Posting API)는 이 용도로 쓸 수 없습니다(2026-11-08 공식 문서 확인, 지침 갱신일 2026-08-04).

- 개발자 지침 'Intended Use'가 허용하지 않는 예로 **"A utility tool to help upload contents to the account(s) you or your team manages"**를 듭니다. 심사를 통과할 길이 사실상 없습니다.
- 심사 전 앱으로 올린 게시물은 **비공개(SELF_ONLY)**로만 올라가고, 계정도 비공개여야 합니다.
- 외부 예약 서비스로 자동 게시하는 방법도 있지만, 월 이용료가 들고 틱톡 계정 권한을 그 회사에 맡겨야 합니다. 사용자는 고르지 않았습니다.

## 매일 하는 일

| 시각(KST) | 무엇이 | 하는 일 |
|---|---|---|
| 06:37 | `youtube-daily` | 오늘 유튜브에 올린 편을 골라(없으면 아직 안내하지 않은 옛 편) 틱톡 안내를 만든다 |
| 06:40~07:00 | 이슈 | '공개 전환 대기' 이슈 끝에 **틱톡 — 직접 게시** 절이 붙는다. 유튜브가 쉰 날은 '틱톡 게시: …' 이슈가 따로 열린다 |
| 출근길 | 사용자 | 아래 순서로 1~2분 |

**휴대전화에서 올리는 순서** (이슈에 그대로 적혀 있습니다)
1. 이슈의 영상 링크를 길게 눌러 다운로드 → 사진에 저장
2. 틱톡 앱 → + → 업로드 → 그 영상 → 다음
3. 이슈의 '설명:' 아래 글을 길게 눌러 복사해 붙여 넣기
4. 커버: 첫 장면(0초)
5. 더보기 → 'AI 생성 콘텐츠' 켜기(2026-11-08 사용자 결정 '켜 둠', 유튜브·인스타와 같음)
6. 게시 → 이슈의 '틱톡에 게시' 칸 체크, 이슈 닫기

## 어떤 편을, 무슨 설명으로

- 하루 한 편. 오늘 유튜브에 올린 편(새 편 또는 다시 올린 편)이 먼저입니다. 유튜브가 쉰 날은 아직 틱톡 안내를 하지 않은 옛 편(번호 순).
- 설명은 `upload.md` 의 '틱톡 설명' 블록이 있으면 그것, 없으면 '인스타그램(릴스) 설명'(친절한 해요체, 해시태그 5개 이내). 인스타에 붙는 유튜브 링크는 틱톡 설명에는 넣지 않습니다(틱톡 설명의 링크는 눌리지 않습니다).
- 기록: `finals/<ep>/tiktok_offer.json`(안내한 날, 영상 주소, 설명). **안내한 편은 다시 고르지 않습니다.** 게시를 건너뛴 편을 다시 안내받으려면 그 파일을 지웁니다. 틱톡에서 빼려면 그 편 `meta.json` 에 `"tiktok": false`.
- 영상 주소는 그 실행 커밋의 GitHub raw 주소입니다(저장소 공개). 1080×1920, 2~3분 MP4 그대로입니다.
- 설정: `config/tiktok.json`(`enabled` 로 끄기, `account` 에 사용자 이름을 넣으면 안내에 표시).

## 새 계정 만들기 (사용자, 한 번)

1. 틱톡 앱 → 가입. **개인 계정**으로 둡니다. 크리에이터 보상 프로그램은 비즈니스 계정이 대상이 아닙니다(여러 자료가 일치, 틱톡 공식 페이지로는 미확인).
2. 이름·프로필 사진은 유튜브·인스타와 같게(과학쑛츠).
3. 사용자 이름이 정해지면 알려 주십시오. `config/tiktok.json` 의 `account` 에 넣습니다.

## 수익화 조건 (참고, 2026-11-08 검색 — 대부분 제3자 자료)

- 크리에이터 보상 프로그램: 팔로워 1만, 최근 30일 조회 10만, 만 18세 이상(한국은 19세라는 자료도 있음), **1분 넘는 원본 영상**만 보상. 한국은 대상 국가로 적힌 자료가 많습니다.
- 조회 1천 회당 약 0.4~1달러(조건에 맞는 조회만). 유튜브 쇼츠의 수 배입니다.
- AI 생성 표시를 켠 원본 영상이 보상 대상인지는 자료가 엇갈립니다. 첫 수익화 신청 때 틱톡 스튜디오의 안내로 확인합니다.
