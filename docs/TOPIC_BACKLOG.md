# 나중에 만들 영상 주제 (사용자 기록)

사용자가 "나중에 만들 영상 주제"로 기록해 두라고 한 목록입니다. 어느 세션에서든 사용자가 "내가 기록했던 것 보여줘"라고 하면 이 파일을 그대로 보여 줍니다.
기록만 해 둔 것이며, 사용자가 만들라고 하기 전에는 제작하지 않습니다. 주제 문구는 사용자의 말을 바꾸지 않고 옮겼습니다.

## 번호 = 완성본 번호 (2026-11-07 사용자 결정)

사용자 지시: "그럼 번호를 일치시켜". 이 목록의 번호는 그 주제가 완성됐을 때의 `finals/<번호>-<slug>/` 번호입니다. 완성본은 21번까지 있어 22번부터 붙였습니다.
- 만드는 순서와 상관없이 예약된 번호를 씁니다. 28번을 먼저 만들면 `finals/28-…`이 먼저 생기고, 22~27번 자리는 비어 있어도 됩니다.
- 이 목록에 없는 새 주제를 만들 때는 먼저 이 목록 끝에 다음 번호(지금은 35번)로 적은 뒤 그 번호로 만듭니다.
- 한번 정한 번호는 바꾸지 않습니다. 만들지 않기로 한 주제도 번호를 비워 둡니다.

## 참고 (기록할 때 덧붙인 연결 정보, 사용자 지시 아님)

- 25번에서 말한 "예전에 만든 무역풍(?)편"은 `finals/05-global-winds/`(바람의 띠 — 무역풍·편서풍·적도 무풍대) 편입니다.

- 31번의 LEO는 23번(고도 비교)에도 나옵니다.
- 33번 SAR는 32번 레이더의 원리 위에 쌓이는 주제입니다.
- 34번 망원경은 23번의 허블·제임스웹과 이어집니다.

## 번호를 바꾼 기록

2026-11-07 처음 기록할 때는 1~14번이었습니다. 같은 날 사용자 지시로 완성본 번호와 맞췄습니다(옛 1~7번 → 22~28번, 옛 8·9번 → 29번, 옛 10~14번 → 30~34번).
