# 인스타 릴스 자동 게시

완성 쇼츠가 main 에 병합되면 유튜브(비공개)와 함께 **인스타 릴스로 바로 게시**합니다.
2026-11-07 사용자 결정: "영상 제작이 끝나면 유튜브와 인스타에 각각 자동으로 업로드" → 게시 시점은 "병합 즉시 양쪽".

**인스타는 게시하는 순간 공개입니다.** 메타의 게시 API 에는 비공개·초안 상태가 없습니다(공식 문서 Content Publishing, 2026-11-07 확인).
그래서 사람의 확인은 병합 전에 와야 합니다. 병합이 곧 공개 승인입니다.

## 흐름

```
[제작]  skills/science-short → finals/<NN>-<slug>/ (mp4 · upload.md 의 '인스타그램(릴스) 설명')
   ▼
[PR]    ci: 인스타 설명 규칙(해시태그 5개 이내, AI 안내 금지)·릴스 규격 dry-run
   ▼
[병합]  youtube-upload 워크플로 (같은 job)
        ① 유튜브 비공개 업로드  ② 인스타 릴스 게시(즉시 공개)  ③ 기록 커밋  ④ 요약·이슈
```

인스타 단계는 유튜브 단계가 실패해도 따로 돕니다("각각"). 인스타 결과는 '공개 전환 대기' 이슈 본문과 작업 요약에 함께 적힙니다.

## 무엇을 자동으로 하나

| 항목 | 값 |
|---|---|
| 캡션 | 각 편 `upload.md` 의 '인스타그램(릴스) 설명' 블록 그대로(21편 모두 있음) |
| 커버 | 0초 프레임(`thumb_offset=0`). 썸네일은 첫 프레임이라는 원칙 |
| 피드 공유 | 켬(`share_to_feed`) |
| AI 표시 | `is_ai_generated` 켬 — 유튜브 합성 표시와 같은 사용자 결정 대기(아래) |
| 영상 전송 | 시스템 사용자 토큰이면 파일 직접 전송(rupload), 인스타그램 로그인 토큰이면 공개 주소(GitHub raw) |
| 기록 | `finals/<ep>/instagram_post.json`(미디어 ID·게시물 주소·영상 md5) |

## 안전장치

| 위험 | 장치 |
|---|---|
| 다른 계정에 게시 | `config/instagram.json` 의 `ig_user_id`·`username` 잠금. 비어 있으면 게시 거부. 토큰 계정이 다르면 중단 |
| 옛 편이 다시 공개 게시 | push 자동 실행은 **22번 이상 새 편만**(`auto_from_number`). 01~21 은 손으로 올린 편이 섞여 있다. 유튜브에도 같은 규칙 |
| 같은 영상 두 번 | md5 기록으로 건너뜀. 영상이 바뀌면 멈춤(`--allow-repost` 로만 새 게시물) |
| 게시 응답이 끊김 | 게시 요청은 재시도하지 않는다. 컨테이너가 게시 전(FINISHED)이면 기록 없이 실패, 불명이면 `uncertain` 기록을 남겨 다시 게시하지 않는다 |
| 설명 규칙 위반 | 해시태그 5개 초과, "AI·인공지능·합성 음성·내레이션·실제와 다르다" 문구는 게시 전에 멈춤(2026-11-07 사용자 규칙) |
| 릴스 규격 | 3초~15분, 300MB, H.264/HEVC, AAC 48kHz 이하, 23~60fps, 가로 1920 이하, moov 앞쪽. 어긋나면 멈춤 |
| 전체 게시 사고 | 인스타에는 `--all` 이 없다. 수동 실행은 `instagram` 을 켜고 episode 하나일 때만 |
| 긴급 정지 | `config/instagram.json` 의 `enabled: false` 또는 `IG_ACCESS_TOKEN` 비밀값 삭제 |

편별 예외는 `meta.json` 으로: `"instagram": false`(인스타에 안 올림), `"auto_publish": true`(옛 번호도 자동 대상).

## 연결 준비 (사용자, 한 번)

### 1. 계정 상태 확인
인스타 계정이 **프로페셔널(크리에이터 또는 비즈니스)** 이어야 API 로 게시할 수 있습니다. 개인 계정이면 앱에서 전환합니다(무료, 되돌릴 수 있음).

### 2. 토큰 경로 고르기

| | 경로 A: 시스템 사용자 토큰 (권장) | 경로 B: 인스타그램 로그인 |
|---|---|---|
| 토큰 수명 | 만료 없음으로 발급 가능(메타 문서 기준, 발급 화면에서 확인) | **60일**. 24시간 뒤부터 갱신 가능, 60일 안에 갱신 못 하면 다시 로그인 |
| 필요한 것 | 메타 비즈니스 포트폴리오, 인스타 계정을 포트폴리오에 추가, 시스템 사용자 | 메타 개발자 앱 하나 |
| 페이스북 페이지 | 필요할 수 있음 | 필요 없음 |
| 설정 값 | `api_host: graph.facebook.com`, `transfer: upload` | `api_host: graph.instagram.com`, `transfer: url` |
| 권한 | `instagram_basic`, `instagram_content_publish` | `instagram_business_basic`, `instagram_business_content_publish` |

경로 B 는 60일마다 토큰을 바꿔야 합니다. 자동 갱신을 하려면 갱신한 토큰을 GitHub Secrets 에 다시 쓰는 별도 권한이 필요해 이번 범위에 넣지 않았습니다.
만료 없는 토큰은 새어 나가면 위험도 오래갑니다. 값은 Secrets 에만 두고 채팅·저장소에 붙이지 않습니다.

### 3. 비밀값과 계정 잠금
- 저장소 Settings → Secrets and variables → Actions → `IG_ACCESS_TOKEN`
- 계정 확인: 수동 실행 `youtube-token-check`(인스타 단계 포함) 또는 로컬 `python -m publish.instagram --whoami --env-file .env`
- 확인한 ID·사용자 이름을 `config/instagram.json` 의 `ig_user_id`·`username` 에 넣고 병합(비밀이 아닌 식별자)

### 4. 첫 시험
22번 이상의 새 편이 병합될 때 첫 게시가 일어납니다. 그 전에 옛 편 하나로 시험하려면 수동 실행에서 episode 와 instagram 을 켭니다(즉시 공개).

## 열린 결정

- **AI 표시**(`ai_label`, 유튜브 `contains_synthetic_media`): 둘 다 켜져 있음. 메타는 "디지털로 만든 사실적 음성·영상"에 표시를 요구하고, 유튜브는 애니메이션은 불요·합성 음성 내레이션은 표시 예로 든다. 사용자 규칙("AI 안내 빼")은 설명란 문구에 대한 것이고 이 설정은 플랫폼 표시라 별개로 묻는 중.
- **토큰 경로**(A/B): 계정 상태 확인 뒤 결정.

## 문제 해결

| 증상 | 조치 |
|---|---|
| `IG_ACCESS_TOKEN 비밀값이 없어 건너뜀` | 연결 전 정상 동작. 3단계 |
| `ig_user_id 가 비어 있습니다` | `--whoami` 로 확인해 config 에 넣고 병합 |
| `오류 190` | 토큰 만료·무효. 새 토큰을 받아 비밀값 교체 |
| `권한 부족` | 토큰 권한에 content_publish 가 있는지 확인 |
| `처리하지 못했습니다(ERROR)` | 영상 규격. 우리 mp4 는 ffmpeg 편집 목록(elst)을 가진다 — 거부되면 편집 목록 없는 재포장을 검토(현재 21편 모두 elst 있음, 실제 거부 여부 미확인) |
| `게시됐을 수 있어 다시 게시하지 않습니다` | 인스타 앱에서 확인. 올라갔으면 `--mark-posted <주소>`, 아니면 기록 파일을 지우고 수동 실행 |
| 한도 초과 | 계정당 24시간 100건(API 게시). 나중에 다시 |

## 미시험

- 실제 게시 0건. 가짜 API 로 흐름(계정 확인→컨테이너→전송→대기→게시→주소)과 실패 경로를 시험했다. 실제 21편의 캡션·릴스 규격 dry-run 은 통과했다.
- 우리 mp4 의 편집 목록(elst)을 인스타가 받는지, `thumb_offset=0` 커버가 포스터 인트로로 보이는지는 첫 게시에서 확인한다.
