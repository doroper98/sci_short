홈개인정보처리방침

1. 수집하는 정보

이 도구는 이용자의 개인정보를 수집·보관·전송하지 않습니다.

Google 계정 인증으로 받은 OAuth 토큰은 도구를 실행하는 운영자 본인의 환경(개인 PC 의 환경 변수 또는 GitHub Actions 비밀값)에만 저장됩니다. 도구 제작자나 제3자 서버로 보내지 않습니다.

2. Google 사용자 데이터의 이용

요청하는 권한은 youtube.upload, youtube.readonly 두 가지입니다. 이 권한은 다음 목적에만 씁니다.

  • 운영자 본인 채널에 영상·제목·설명·썸네일을 비공개로 올리기
  • 업로드 대상 채널의 이름과 ID 를 읽어, 다른 채널로 올라가는 실수를 막기

올라간 영상, 댓글, 자막을 수정하거나 삭제하는 권한은 요청하지 않습니다. 필요한 최소한의 권한만 받습니다.

시청자 정보, 댓글, 구독자 목록, 분석 데이터는 읽지 않습니다. 영상 메타데이터 외의 계정 정보를 저장하지 않습니다.

3. 저장 기록

업로드가 끝나면 영상 ID, 업로드 시각, 제목, 채널 ID 를 저장소 안의 기록 파일(youtube_upload.json)에 남깁니다. 이 기록에는 토큰이나 계정 식별 정보가 들어가지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 제공, 판매, 양도하지 않습니다. 광고·분석 도구를 쓰지 않습니다.

5. 권한 철회

운영자는 언제든 Google 계정 > 보안 > 서드파티 앱 및 서비스에서 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 쓸 수 없습니다.

6. Google API 서비스 사용자 데이터 정책 준수

이 도구의 Google API 사용은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

7. 변경과 연락

이 방침이 바뀌면 이 페이지의 시행일을 갱신합니다. 문의는 GitHub 저장소 이슈로 남겨 주십시오.
