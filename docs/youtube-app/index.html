sci_short Shorts Uploader

아이도 이해하는 60~90초 한국어 과학 쇼츠를 제작자의 유튜브 채널에 올리는 개인용 도구입니다.

홈개인정보처리방침소스 코드

무엇을 하는가

제작이 끝난 영상 파일, 제목·설명, 한국어 자막을 YouTube Data API 로 채널에 비공개(private) 상태로 올립니다.

공개 여부는 채널 운영자가 YouTube Studio 에서 직접 결정합니다. 도구는 영상을 공개로 바꾸지 않습니다.

누가 쓰는가

이 도구는 저장소 소유자가 자기 채널에만 쓰는 1인용 도구입니다. 제3자에게 서비스로 제공하지 않습니다.

요청하는 권한

  • youtube.upload — 영상 업로드
  • youtube.force-ssl — 자막 추가, 업로드 대상 채널 확인

연락

문의는 GitHub 저장소 이슈로 남겨 주십시오.

이 페이지는 Google OAuth 앱 게시에 필요한 앱 홈페이지입니다. 코드는 저장소 publish/ 폴더에 있습니다.
