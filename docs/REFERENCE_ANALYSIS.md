## 분석 방법과 한계

- ffprobe로 길이·해상도·프레임률·오디오 스트림을 확인했습니다. 모든 영상은 720×1280, 30fps, H.264/AAC입니다.
- 1번은 약 4초, 2~3번은 약 2초, 4·6번은 약 2초, 5번은 약 1초, 7번은 약 6초 간격으로 전체 흐름을 확인했습니다. 주요 전환·문구는 추가 프레임으로 확인했습니다.
- 7번은 한국어 자막과 Whisper base + VAD 자동 전사를 함께 확인했습니다. 정확한 녹취록으로 교정한 것은 아닙니다.
- 1~5번은 VAD 발화 검출 0초, 6번은 약 0.56초 검출이나 유의미한 전사 없음. 음향 신호는 있지만 이것만으로 음악·효과음만 있다고 단정하지 않았습니다. 직접 청취에 따른 음향 품질 평가는 하지 않았습니다.
- 3번 원본 말미에 partial-file/invalid-NAL 경고가 있었습니다. 약 18.9초까지 프레임을 확인했고 추출 오디오는 약 17.90초였습니다. 원본 파일을 그대로 보존했습니다.
- 과학적 주의점은 제작 전에 검증할 항목입니다. 원본의 모든 수치·출처를 외부 문헌으로 검증한 보고서는 아닙니다.
- 원본 제작 도구·소스코드·시뮬레이션 정확도는 MP4만으로 확인할 수 없습니다.

## 1. 망막 — 빛이 어떻게 신경 신호가 되는가

[원본](../references/videos/01-retina.mp4) · [장면 모음](../references/contact-sheets/01-retina.jpg)

### 관찰한 흐름

| 대략 시간 | 화면 내용 |
|---|---|
| 1~6초 | 망막 전체와 층 구조 |
| 6~15초 | 어두울 때의 막대세포, 지속적 글루탐산 방출, 세포 확대 |
| 16~23초 | 광자 흡수, 세포 내부·막 구조 확대 |
| 24~34초 | rhodopsin→transducin→PDE6, cGMP 감소, 이온 통로 닫힘, 막전위 −40→−65mV |
| 38~45초 | ON/OFF 양극세포 신호 처리 |
| 46~53초 | 신경절세포 활동전위와 망막 전체로 복귀 |
| 55초 이후 | 제작자 엔드카드 |

짙은 남색 바탕, 푸른 세포, 보라색 광수용체, 주황색 활성화 표시를 사용합니다.
전체→세포→분자→전체로 이동해 서로 다른 규모를 연결합니다. `TIME SLOWED FOR CLARITY`, `GRADED · NO SPIKES` 같은 표기는 시각화의 의미를 구분하는 장점입니다.

아이에게는 단백질·이온·막전위·세포 이름과 그래프가 한꺼번에 등장합니다. 빛이 들어오면 오히려 광수용체 전위와 글루탐산 방출이 감소한다는 과정은 설명 없이 이해하기 어렵습니다.
막대세포 설명에서 원뿔세포 ON/OFF 회로로 이어지는 전환도 처음 보는 사람에게는 혼란스러울 수 있습니다.

**가져올 것:** 어디를 보는지 유지하는 확대, 원인 작동을 강조하는 색, 전체로 복귀해 결과 보여주기.
**재구성 제안:** 눈에 들어온 빛→빛 감지 세포의 변화→다음 세포로 정보 전달→뇌에서 시각 정보 처리. 단백질 연쇄와 ON/OFF 회로는 심화 주제로 분리할 수 있습니다.
**정확성 메모:** 빛 입자가 그대로 뇌까지 가는 것처럼 표현하지 않습니다. 광수용체의 연속적 전위 변화와 신경절세포의 활동전위를 구분합니다.

## 2. 도플러 효과 — 지나가는 사이렌의 음높이

[원본](../references/videos/02-doppler.mp4) · [장면 모음](../references/contact-sheets/02-doppler.jpg)

0~4초 이동하는 음원의 앞쪽 파면이 조밀하고 뒤쪽은 넓어집니다. 4~7초 속도가 올라가고, 약 7~9초에는 음속 부근의 파면이 겹칩니다.
9~19초에는 초음속 마하 원뿔과 충격파를 보여줍니다. 표시 마하수는 약 0.50에서 2.00으로 증가합니다.

주황색 음원과 청록색 관측자를 구분하고, 아래에 관측 음높이 그래프와 속도 슬라이더를 둡니다.
스페인어 제목, 접근·후퇴 도플러 식, Hz·마하수·속도·각도까지 동시에 표시합니다.

**가져올 것:** 보이지 않는 파동을 선으로 표현하고, 간격과 관측자의 경험을 연결하는 방식.
**어려운 점:** 19초 안에 도플러 효과와 충격파라는 서로 다른 설명이 들어갑니다. 점만 있는 화면은 구급차·귀 같은 일상 경험과 바로 연결되지 않습니다.
**재구성 제안:** 구급차와 듣는 사람→같은 간격으로 소리를 내는 모습→접근 시 자주 도착, 멀어질 때 드물게 도착→음높이 비교. 충격파는 별도 편으로 다룰 수 있습니다.
**정확성 메모:** 소리가 앞쪽에서 더 빠르게 이동해서 높아진다고 말하지 않습니다. 도착 빈도가 달라집니다. 원형 선은 파면이며 공기 입자가 그 원을 따라 이동한다는 뜻이 아닙니다. 단순 접근·후퇴 식에는 적용 가정이 있습니다.

## 3. 하늘과 노을 — 빛의 경로와 관측 결과

[원본](../references/videos/03-sky-and-sunset.mp4) · [장면 모음](../references/contact-sheets/03-sky-and-sunset.jpg)

0~3초 흰빛에 여러 색이 있다는 설명과 높은 태양, 4~9초 짧은 파장 빛의 강한 산란,
10~13초 태양이 낮아지며 길어지는 대기 경로, 14초 이후 노랑·주황으로 바뀌는 관측창이 이어집니다.

중앙의 지구 단면·대기·빛 경로와 우측 위의 '관측자가 보는 하늘'을 함께 보여줍니다.
아래에는 스펙트럼 그래프가 있고 상단에는 `I∝1/λ⁴`, `(700/400)⁴≈9.4`, 고도·대기량·색 비율 등이 나옵니다.

**가져올 것:** 원인 모형과 실제 결과 화면을 연결하는 구성. 이 자료들 중 어린이용 설명에 특히 직접적으로 응용하기 좋습니다.
**어려운 점:** 20초 안에 태양 고도, 경로 길이, 색, 그래프가 함께 바뀝니다. 지수식과 로그 눈금은 핵심을 따라가는 데 부담이 됩니다.
**재구성 제안:** 낮/노을 비교→햇빛은 여러 색→공기가 파란 계열 빛을 더 잘 흩뜨림→흩어진 빛을 보므로 낮 하늘이 파랑→긴 경로를 지난 직접광은 붉은 계열의 비중이 커짐.
**정확성 메모:** 산란은 빛의 소멸이나 파랑이 빨강으로 바뀌는 과정이 아닙니다. '빨강만 도착한다'를 보편 법칙처럼 말하지 않습니다. 400nm는 보라색에 가까우므로 '파랑은 정확히 9배'라는 고정값으로 옮기지 않습니다. 산란광과 태양에서 직접 오는 빛을 구분합니다.

## 4. 우주선 입자 소나기 — 하나가 많은 입자로

[원본](../references/videos/04-cosmic-ray-shower.mp4) · [장면 모음](../references/contact-sheets/04-cosmic-ray-shower.jpg)

| 대략 시간 | 화면 내용 |
|---|---|
| 0~3초 | 우주 입자 하나가 오면 지면에는 몇 개가 도달할지 질문 |
| 3~5초 | 양성자와 질소 원자핵 충돌 확대, 파이온 생성 |
| 6~8초 | 파이온, 광자·뮤온 등의 입자와 경로 |
| 9~15초 | `TOY MODEL`, 1→2→4→8의 분기와 수치 |
| 16~23초 | 세대와 입자 수 급증, 지면 도착 |
| 24초 | 33세대, 2³³=8,589,934,592 표시 |
| 25~30초 | 최고 에너지 실제 샤워의 규모 및 우리 주변 뮤온과 연결 |
| 32~34초 | 단일 입자로 돌아가는 루프 |

보라색 배경과 분기하는 궤적, 큰 카운터가 규모 증가를 눈으로 보이게 합니다.
원자핵 확대 후 대기 전체로 나오는 움직임이 좋습니다. 다만 약 10초 안에 여러 입자 이름이 나오고 세대·고도·지수까지 함께 변합니다.

**가져올 것:** 첫 몇 단계를 천천히 이해시킨 뒤 규모를 확장하는 표현, 일상과의 마지막 연결.
**재구성 제안:** 첫 충돌과 1→2→4를 충분히 보여주고 핵심 입자 이름만 사용합니다. 숫자가 커지는 사실과 실제 물리적 한계를 구분합니다.
**정확성 메모:** 모든 입자가 지면까지 계속 두 배가 되는 모형은 실제 샤워 전체를 재현하지 않습니다. 실제로 에너지를 잃고 최대 발달 이후 입자 수가 줄어듭니다. 파이온은 원자핵에 들어 있던 부품이 단순히 떨어져 나오는 것으로 설명하지 않습니다. 최고 에너지 샤워 규모와 일상적인 지면 뮤온 유입량은 서로 다른 정보입니다.

## 5. 블랙홀 병합 — 운동과 파형의 연결

[원본](../references/videos/05-black-hole-merger.mp4) · [장면 모음](../references/contact-sheets/05-black-hole-merger.jpg)

0~11초 두 물체가 돌며 가까워지고 아래 파형이 촘촘해집니다. 12~13초 접근·회전이 빨라지고,
약 14초 `¡FUSIÓN!`과 함께 하나로 합쳐지며 격자에 큰 변화가 퍼집니다. 15~17초에는 흔들림이 잦아듭니다.

흰 배경의 상단에는 수식·수치, 중앙에는 청록·주황 물체와 격자, 하단에는 중력파 파형을 둡니다.
`GW150914 · Mc≈30 M☉ · tiempo ×20 · tono ×4`라는 시간·음높이 가공 표기가 있습니다.

**가져올 것:** 운동과 신호가 같은 시간축에서 변함, 대상의 색을 끝까지 유지함, 접근→병합→진정이라는 명확한 사건.
**어려운 점:** 블랙홀·격자·파형·주파수·수식의 의미를 한꺼번에 알아야 합니다. 왜 가까워지는지, 아래 선이 무엇인지 설명 시간이 부족합니다.
**재구성 제안:** 둘이 도는 모습→에너지를 내보내며 가까워지고 빨라짐→파형과 연결→병합 후 진동 감소→검출 신호를 소리로 바꿔 들을 수 있음을 설명.
**정확성 메모:** 중력파를 우주 공간에서 마이크로 녹음한 소리로 설명하지 않습니다. 격자는 실제 그물이 아닙니다. `GW150914` 표기만으로 실제 관측 데이터의 직접 재생이라고 단정할 수 없습니다. 원본 오디오의 제작 방식을 확인한 것은 아닙니다.

## 6. 전자레인지 — 생활 질문에서 원인으로

[원본](../references/videos/06-microwave-heating.mp4) · [장면 모음](../references/contact-sheets/06-microwave-heating.jpg)

| 대략 시간 | 화면 내용 |
|---|---|
| 0~2초 | '왜 가운데는 여전히 차가울까?'와 음식 |
| 3~6초 | 물 분자 확대, +/− 방향, 전기장 화살표 |
| 7~12초 | 전기장 방향 변화와 분자 움직임, 가열 연결 |
| 13~17초 | 음식 단면으로 복귀, 안쪽에서 약해지는 파동 표현 |
| 18~24초 | 2.45GHz와 방향 전환 카운터, 뜨거운 가장자리·찬 중심의 열 지도 |
| 25~26초 | 음식 속 약 2.5cm 표시 |
| 27~30초 | 가운데로 열이 전해지는 과정, 중간에 저으라는 행동 |
| 31~36초 | 1분간 방향 전환 수치 후 초기 화면으로 회귀 |

**가져올 것:** 생활 질문→분자 확대→전체 결과→행동으로 이어지는 구조. 어린이 대상 구성의 유력한 참고입니다.
**어려운 점:** 극성·전기장·열운동·침투 깊이·전도·큰 숫자가 36초에 모여 있습니다. 거대한 카운터가 핵심 질문보다 시선을 끌 수 있습니다.
**재구성 제안:** 분자 몇 개로 원인을 먼저 보여주고 전체 음식으로 연결합니다. 얕은/두꺼운 음식, 섞기 전/후처럼 비교에 시간을 사용할 수 있습니다.
**정확성 메모:** 약 2.5cm는 모든 음식의 고정 도달 한계가 아닙니다. 실제 불균일 가열에는 전자기장 분포와 음식 형태·성분도 관여합니다. 차가운 음식의 분자도 움직입니다. 2.45GHz의 주기 수와 초당 49억 방향 전환을 혼용하지 않습니다. 젓기는 뜨거운 부분과 찬 부분을 섞는 것이며 전도 자체와는 구분합니다.

## 공통적으로 얻은 제작 방향

1. 질문과 결과를 연결하고, 보이지 않는 원인을 화면에서 추적할 수 있게 합니다.
2. 규모가 바뀌면 지금 어디를 보는지 알려줍니다.
3. 수식·그래프·용어는 이해에 도움이 될 때 선택합니다. 귀여운 그림체만으로 개념 난도가 낮아지지는 않습니다.
4. 한 순간에 중요한 변화를 알아볼 수 있게 시선을 정리합니다. 장면 수와 레이아웃을 고정할 필요는 없습니다.
5. 과학적 정확성은 시각적 완성도와 별도로 확인합니다. 비유나 단순화 모형을 실제 법칙으로 오인하게 만들지 않습니다.
6. 설명할 시간이 짧으면 핵심 질문을 좁힙니다. 긴 대본의 빠른 낭독으로 해결하지 않습니다.
