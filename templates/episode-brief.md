# 에피소드 메모 — 필요에 맞게 항목을 바꾸세요

이 양식은 필수 스키마가 아닙니다. 불필요한 항목은 지우고 새로운 표현에 필요한 항목을 추가할 수 있습니다.

## 의도

- 주제 / 시청자가 궁금해할 질문:
- 대상 연령·미리 알아야 할 것:
- 보고 나서 이해하면 되는 핵심:
- 이번 편에서 설명하지 않을 범위:

## 과학 근거

- 핵심 주장과 출처:
- 관측 사실 / 설명 모형 / 비유의 구분:
- 단순화할 부분과 오해하지 않게 보여줄 장치:

## 시각 설명

- 눈에 보이지 않거나 이해하기 어려운 이유:
- 원인과 결과를 보여줄 움직임 또는 비교:
- 선택한 표현과 이유:
- 다른 표현이 더 나을 수 있는 부분:
- 발생원·경로·관측자 또는 장치의 공간 배치:
- 깊이·가림·명암·단면이 설명에 기여하는 부분:
- 실제로 작동시킬 부품·파면·물질과 상태값:
- 전체 → 확대 → 전체로 이어갈 대상과 위치:
- 처음에는 숨기고 이해가 쌓인 뒤 추가할 정보:

## 청각 설명

- 소리를 통해 이해하게 할 원인과 결과:
- 실제 현상음 / 모형 합성음 / 설명용 데이터 음향의 구분:
- 화면의 어떤 변화가 소리의 어떤 변화와 연결되는지:
- 발생·전파·도착 시각과 영상 시간의 대응:
- 중요한 소리를 위해 말·음악을 비울 구간:
- 최종 영상과 함께 청취하며 확인할 차이:

## 대본·장면 초안

장면 수와 순서는 자유롭게 정합니다. 시간은 실제 음성을 얻은 뒤 조정합니다.

| 이해가 한 단계 늘어나는 이유 | 공간·작동·시선의 변화 | 같은 사건에 연결할 소리 | 표시용 문장 / 발음용 문장 | 관찰·청취 여유 |
|---|---|---|---|---|
| | | | | |

## 핵심 구간의 실제 제작

- 먼저 렌더할 핵심 인과와 짧은 구간:
- 영상·그래프·음향이 공유할 모형 값과 사건:
- 과학 시간·영상 시간·전파 지연의 관계:
- 결과 파일과 확인 방법:
- 확인 후 전체 제작에 반영할 수정:

## 결과 확인 메모

- 음성·자막·핵심 화면 변화가 맞는지:
- 어린이가 혼동할 부분:
- 공간의 앞뒤·경로·관측 위치가 읽히는지:
- 정지 그림·숫자 교체·장식이 작동 과정의 설명을 대신하는 부분:
- 휴대전화 크기 가독성·모노 청취 확인 여부:
- 실제 렌더/청취에서 바꿀 점:
